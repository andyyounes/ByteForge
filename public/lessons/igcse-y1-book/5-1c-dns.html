5.1c Domain Name Servers (DNS)
Why you never have to memorise an IP address — the lookup chain behind every URL you type.
Key Terms
HTML
HyperText Markup Language — used to structure/display website content in a browser.
DNS
Domain Name Server/System — finds the IP address matching a URL's domain name.
Theory

Why DNS is needed

  • Websites are written in HTML and hosted on a web server with its OWN IP address.
  • To retrieve pages, the browser needs that IP address — but users type a readable URL, not a raw IP.
  • DNS converts a URL (e.g. www.hoddereducation.co.uk) into the matching IP address (e.g. 107.162.140.19) the computer understands.
  • DNS/URLs eliminate the need to MEMORISE IP addresses.
  • DNS servers hold a DATABASE of URLs matched to IP addresses. The lookup process can involve MORE THAN ONE server.
The DNS lookup process — step by step
  1. User types the URL into their browser; the browser asks DNS server (1) for the matching IP address
  2. If DNS server (1) can't find it in its own database/cache, it forwards the request to DNS server (2)
  3. DNS server (2) finds the URL and its matching IP address
  4. This IP address is sent BACK to DNS server (1), which now stores it in its own cache/database (for next time)
  5. The IP address is sent back to the user's computer
  6. The computer sets up communication with the website server directly; HTML pages are downloaded and the browser interprets/displays them
The computer first asks DNS server 1; if it doesn't know the answer, it checks DNS server 2, then relays the IP address back down the chain.
Practice — Test Yourself

These questions only cover what THIS subsection taught — retrieval/location of web pages via DNS.

Short answer 1
What is the core job of a DNS server?
Reveal answer

To find/convert the IP address matching a domain name given in a URL — turning a human-readable web address into the numeric IP address the computer needs.

Short answer 2
Why does DNS server 1 store the IP address in its own cache/database after getting it from DNS server 2?
Reveal answer

So the NEXT time it's asked for that same URL, it already has the answer directly, without needing to forward the request to another DNS server again — speeding up future lookups.

Fill in the blank pseudocode 3
The DNS process converts a ______ (e.g. www.hoddereducation.co.uk) into an ______ (e.g. 107.162.140.19).
Reveal answer

Blank 1: URL (domain name). Blank 2: IP address.

Spot the error 4
A student claims: "A user's computer contacts the website server directly using the URL, and the website server itself looks up its own IP address." What real step does this get backwards?
Reveal answer

The USER'S computer must first get the IP address from a DNS server BEFORE it can contact the website server at all — the website server isn't involved in the lookup process; the DNS servers do the URL-to-IP conversion, and only afterwards does the computer set up direct communication with the website server using that IP.

Applied / scenario 5
A user types a URL for a website they've never visited before. DNS server 1 doesn't have it cached. Using this lesson's content, describe the full sequence of events until the web page finally appears on their screen.
Reveal answer

1. Browser asks DNS server 1 for the IP address. 2. Not found/cached there, so it's forwarded to DNS server 2. 3. DNS server 2 finds the matching IP address. 4. This is sent back to DNS server 1, which caches it. 5. The IP address is sent back to the user's computer. 6. The computer contacts the website server directly using that IP, downloads the HTML, and the browser interprets/displays it as the visible web page.

Short answer 6
What language are websites written in, and what does the browser do with it?
Reveal answer

Websites are written in HTML. The browser INTERPRETS this HTML to structure and display the content on the user's screen.
