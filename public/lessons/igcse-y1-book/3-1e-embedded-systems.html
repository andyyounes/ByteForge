3.1e Embedded Systems
Hardware and software dedicated to ONE specific job — from a washing machine to a car's airbag controller.
Key Terms
Embedded system
A combination of hardware and software designed to carry out a specific, dedicated set of functions.
Microcontroller
A single chip with a CPU plus RAM, ROM, and other peripherals all together, carrying out one task.
Microprocessor
An integrated circuit with ONLY a CPU on the chip — RAM, ROM, and peripherals must be added separately.
System on chip (SoC)
A single chip containing CPU, memory, I/O ports, AND secondary storage all together — may include a microcontroller as one component.
Theory

What an embedded system is

  • An embedded system combines electronic/electrical/electro-mechanical hardware with software, designed for a SPECIFIC set of functions.
  • Three main types: microcontrollers (CPU + RAM + ROM + peripherals on one chip); microprocessors (just a CPU on the chip — everything else added separately); and system on chips / SoC (CPU, memory, I/O ports AND secondary storage together on one microchip).
  • Embedded systems are feedback-oriented: they take analogue or digital INPUT (from a user, e.g. a dial, or a SENSOR, e.g. oxygen/fuel-pressure sensors), then produce some OUTPUT that carries out the system's function (e.g. increasing heating power, adjusting fuel levels).
  • Important distinction: a general-purpose computer is NOT an embedded system, because computers are multi-functional (their task can change entirely just by running different software) — embedded systems are always dedicated to one job.
Feedback-oriented flow: input (analogue/digital or sensor) → embedded system processes it → output controls the component.

Programmable vs. non-programmable, and updating

  • Non-programmable devices generally need to be REPLACED for a software upgrade.
  • Programmable devices can be updated two ways: connecting to a computer to download updates (e.g. GPS map updates), or automatic updates via Wi-Fi/satellite/cellular link (e.g. a modern car's engine management system).
Benefits of embedded systems
  • Small size — easy to fit into devices
  • Relatively low cost to make
  • Dedicated to one task — simple interfaces, often no OS needed
  • Consume very little power
  • Can be controlled remotely (e.g. via smartphone)
  • Very fast reaction to changing input (real-time, feedback-oriented)
  • Mass production brings reliability
Drawbacks of embedded systems
  • Can be difficult to upgrade for new technology
  • Troubleshooting faults becomes a specialist task
  • A "simple" interface (e.g. one knob) can be more confusing in practice
  • Internet-connected devices are open to hackers/viruses
  • Often just thrown away rather than repaired (wasteful)
  • Contributes to a "throw away" society when devices are discarded once outdated

Real-world applications

  • Embedded systems can be as simple as a single microcontroller (e.g. an MP3 player) or as complex as multiple coordinated units (e.g. a medical imaging system).
  • Modern cars rely heavily on embedded systems: engine management, airbags, in-car entertainment, GPS, and more.
  • Because many embedded systems connect to the internet, they can be controlled remotely — e.g. switching on a home's central heating remotely, or instructing a set-top box to record a TV programme from a smartphone.
Practice — Test Yourself

These questions only cover what THIS subsection taught — embedded systems.

Short answer 1
What is the key difference between a microcontroller and a microprocessor?
Reveal answer

A microcontroller has a CPU PLUS RAM, ROM, and other peripherals all on one chip. A microprocessor has ONLY a CPU on the chip — RAM, ROM, and peripherals must be added separately.

Short answer 2
Why is a general-purpose computer NOT classed as an embedded system?
Reveal answer

Computers are multi-functional — their task can be changed entirely just by running different software. Embedded systems, by contrast, are always dedicated to one specific set of functions.

Fill in the blank 3
Programmable embedded devices can be updated by connecting to a ______, or via automatic updates over ______, satellite, or cellular link.
Reveal answer

Blank 1: computer. Blank 2: Wi-Fi.

Spot the error 4
A student claims: "A device with a genuinely simple interface, like a single knob, is always easier for users to operate than a device with a full menu system." What real drawback from this lesson contradicts this?
Reveal answer

The lesson explicitly gives the example of a cooker clock with a single knob — the interface LOOKS simple, but in practice changing the time can require several confusing steps. A simple-looking interface is not necessarily easier to actually use.

Applied / scenario 5
A smart thermostat connects to the internet so its owner can control it remotely from a smartphone. Using this lesson's content, identify one genuine benefit AND one genuine risk of this design.
Reveal answer

Benefit: it can be controlled remotely, e.g. switching heating on/off while away from home — a real convenience the lesson explicitly gives as an example.

Risk: any device accessible over the internet is also open to hackers and viruses — the same internet connectivity that enables remote control is exactly what creates this security exposure.

Short answer 6
What does "feedback-oriented" mean in the context of an embedded system?
Reveal answer

It means the system takes in some input (analogue/digital signal or sensor reading) and reacts to it very quickly by producing an output that controls the relevant component — operating in real time, continuously responding to changing conditions.
