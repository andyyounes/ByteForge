1.2c Representation of (Bitmap) Images
How a picture becomes a grid of numbers — pixels, colour depth, and image resolution.
Key Terms
Pixel
Short for "picture element" — the smallest single point of colour in a bitmap image.
Bitmap image
An image made up of a two-dimensional matrix (grid) of pixels, each stored as a binary number.
Colour depth
The number of bits used to represent each pixel's colour. More bits = more possible colours per pixel.
Image resolution
The number of pixels that make up an image, e.g. 4096 × 3072 pixels. Higher resolution = more detail.
Theory

Pixels and colour depth

  • A bitmap image is made of pixels arranged as a two-dimensional matrix. Each pixel is stored as a binary number, so the whole image is stored as a series of binary numbers.
  • A black-and-white image needs only 1 bit per pixel — each pixel is one of exactly two colours (0 or 1).
  • With 2 bits per pixel, each pixel can be one of four colours (2² = 4): 00, 01, 10, or 11.
  • With 3 bits per pixel, each pixel can be one of eight colours (2³ = 8): 000 through 111.
  • The number of bits used to represent each pixel's colour is called the colour depth.
  • An 8-bit colour depth gives 256 colours (2⁸ = 256). Modern computers typically use a 24-bit colour depth, giving over 16 million colours.
  • The general rule: with x bits, 2^x colours can be represented.
  • Increasing colour depth also increases the resulting file size.

Image resolution

  • Image resolution is the number of pixels that make up the whole image — e.g. an image could be 4096 × 3072 pixels, which is 12,582,912 pixels in total.
  • Many cameras let you vary the resolution before taking a photo. Photos with a LOWER resolution have less detail than those with a HIGHER resolution.
  • An image with too low a resolution becomes pixelated ("fuzzy") — there simply aren't enough pixels to represent fine detail.
  • The main drawback of high-resolution images: a bigger file size. This affects how many images fit on a storage device, and how long an image takes to download or transfer.
  • A certain amount of resolution reduction is possible before the loss in quality is actually noticeable to a viewer.
Worked example — RGB colour combinations

A colour image is made of red, green, and blue components, each using 8 bits.

Total possible colours = 256 × 256 × 256 = 16,777,216 — this is exactly the "24-bit colour depth, over 16 million colours" figure from the theory above (8+8+8 = 24 bits total).

Practice — Test Yourself

These questions only cover what THIS subsection taught — pixels, colour depth, and image resolution.

Short answer 1
What is "colour depth", and how many colours can a pixel represent with a colour depth of 4 bits?
Reveal answer

Colour depth is the number of bits used to represent each pixel's colour. With 4 bits: 2⁴ = 16 colours.

Short answer 2
What is "image resolution", and what visible effect does a LOW resolution have on a photo?
Reveal answer

Image resolution is the number of pixels making up the image. A low resolution means fewer pixels represent the same picture, so the image becomes pixelated ("fuzzy") and has visibly less detail.

Fill in the blank 3
A modern computer typically uses a ______-bit colour depth, giving over ______ million possible colours.
Reveal answer

Blank 1: 24. Blank 2: 16 (16,777,216 exactly).

Spot the error 4
A student claims: "With 3 bits per pixel, a pixel can be one of six possible colours." What is wrong with this, and what's the correct number?
Reveal answer

Wrong — the rule is 2^x colours for x bits, so 3 bits gives 2³ = 8 possible colours (000 through 111), not 6.

Applied / scenario 5
A budget smartphone camera app has to keep every photo small enough to send quickly over a slow connection. A professional photographer needs the maximum realistic detail for large prints. Recommend a general resolution AND colour-depth approach for each, and justify using this lesson's content.
Reveal answer

Budget app: LOWER resolution and/or lower colour depth, since the lesson shows both genuinely reduce file size, at the cost of some detail loss — an acceptable trade-off for fast transfer over a slow connection.

Professional photographer: HIGHER resolution (more pixels, more detail) and higher colour depth (e.g. 24-bit), since the lesson shows this gives the most realistic, detailed image — the larger resulting file size is an acceptable trade-off for print quality.

Short answer 6
How many bits per pixel are needed for a plain black-and-white image, and why?
Reveal answer

1 bit per pixel — since each pixel only ever needs to be one of exactly two colours (black or white), a single 0 or 1 is genuinely enough to represent it.
