6.3c Machine Learning
How a spam filter, a shopping recommendation, and fraud detection all learn from data instead of being explicitly programmed.
Key Terms
Machine learning
A subset of AI where algorithms are "trained" on data and learn from past experience, without explicit reprogramming for new data.
Training data set
Sample data used to teach a machine learning model before it's used live.
Collaborative filtering
Comparing customers with similar behaviour to recommend items one hasn't bought yet.
Theory

What machine learning is

  • A SUBSET of AI: algorithms are "trained" and learn from past experiences/examples, then make predictions or decisions on NEW data.
  • Offers fast, accurate outcomes due to powerful processing — able to manage/analyse huge, complex data volumes that would take humans years to process manually.
AI vs. machine learning — the real distinction

Example 1 — spam email detection

  • Algorithm collects email data (content, headers, sender), then "cleans" it (removing stop-words like "the/and/a", punctuation).
  • Certain words/phrases ("lottery", "earn", "full-refund") strongly indicate spam.
  • A model is built, trained on a set of KNOWN spam emails, then evaluated, fine-tuned, and tested live.

Example 2 — recommending purchases (collaborative filtering)

  • Compares a new customer's shopping behaviour against EXISTING customers with similar patterns.
  • Example: Customer A (likes football) buys a jazz CD, a Roman history book, and health food. Customer B (likes cycling) buys the same jazz CD and Roman history book. Machine learning then recommends health food to Customer B, based on the shared pattern with A.
  • Also used to generate music playlists based on selected criteria.

Example 3 — fraud detection

  • The full machine learning model-building process: DATA COLLECTION (survey/web scraping) → DATA CLEANING (removing redundant data carefully, to avoid wrong predictions) → BUILDING A MODEL (trained on real customer purchasing examples) → the model can now flag unusual transactions (e.g. sudden large jewellery purchase) as likely fraud → MODEL EVALUATION (tested with known outcomes, modified if it doesn't meet criteria).

Search engines and self-improvement

  • A search engine counts it as SUCCESS if a user finds what they want on page 1 of results, and FAILURE if they need to dig to page 2/3/4.
  • The search engine LEARNS from this past performance, becoming more sophisticated and accurate over time.
Practice — Test Yourself

These questions only cover what THIS subsection taught — machine learning.

Short answer 1
What is the key difference between AI generally and machine learning specifically?
Reveal answer

AI aims to build machines that think LIKE humans (simulated intelligence). Machine learning specifically aims to get machines making decisions WITHOUT being explicitly programmed to, by learning through data acquisition.

Short answer 2
What is "collaborative filtering", and give the example used in this lesson.
Reveal answer

Comparing a customer's shopping behaviour to OTHER customers with similar patterns to make recommendations. Example: Customer A (football, jazz CD, Roman history book, health food) and Customer B (cycling, same jazz CD, same history book) — health food is recommended to B based on the shared pattern with A.

Fill in the blank 3
In fraud detection, an unusual transaction — like an unexpectedly large jewellery purchase — is flagged as a high chance of ______ activity.
Reveal answer

Fraudulent.

Spot the error 4
A student claims: "A spam filter must be manually reprogrammed by a human every time a new type of spam email appears." What's wrong with this?
Reveal answer

This is exactly what machine learning avoids — the definition explicitly states machine learning lets machines make decisions/predictions on NEW, UNSEEN data WITHOUT needing to be specifically reprogrammed for it, since it learned general patterns (like common spam words/phrases) from its training data.

Applied / scenario 5
A bank wants to build a machine learning system to detect fraudulent credit card transactions. Using this lesson's content, describe the correct order of steps in building this system.
Reveal answer

1. Data collection (survey/web scraping of transaction types, shopping habits, personal data). 2. Data cleaning (carefully removing redundant data to avoid wrong predictions). 3. Building a model (trained on real examples of customer purchasing behaviour). 4. Using the model to detect fraud (e.g. flagging unusual purchases). 5. Model evaluation (testing with known data/outcomes, modifying if criteria aren't met).

Short answer 6
How does a search engine determine whether a search was a "success" or "failure", and what does it do with this information?
Reveal answer

Success = the user finds relevant results on PAGE 1. Failure = the user needs to check pages 2, 3, or 4. The search engine learns from this past performance, becoming increasingly sophisticated and accurate over time.
