3.3e Virtual Memory
The illusion of unlimited RAM — how the hard disk quietly extends memory, and the real cost when it's overused.
Key Terms
Virtual memory
RAM (physical memory) PLUS swap space on the HDD/SSD, giving the illusion of more memory than actually exists.
Paging
Moving fixed-length blocks of data (pages) between HDD/SSD and RAM.
Disk thrashing
Excessive swapping between RAM and disk, causing the CPU to spend more time moving data than processing.
Thrash point
The point where execution effectively halts because the system is entirely consumed by data-swapping.
Theory

The problem virtual memory solves

  • If multiple running programs exceed available RAM, this can cause a system crash.
  • Virtual memory solves this by using the HDD/SSD as extra memory: RAM (physical memory) + swap space on disk = virtual memory.
  • A 32-bit "map" tracks which programs are actually in RAM vs. swapped out to disk. When a program tries to access RAM, it's directed through this map.

How the swap actually works

  • Example: 5 programs (0-4) need RAM, but RAM only has 4 available address spaces. Without virtual memory, program 4 trying to access RAM with no space left would CRASH the system.
  • WITH virtual memory: the OLDEST data (e.g. program 0's) is moved OUT of RAM into HDD/SSD, freeing up that RAM space for program 4.
  • The 32-bit map is updated to reflect the new mapping — program 4 now has RAM access, and program 0's data lives on disk instead.
  • This continues as needed, giving the ILLUSION of unlimited memory even though RAM itself is genuinely full.
Data swaps back and forth between RAM and disk, tracked by the 32-bit map — programs "believe" they have direct RAM access.

Paging

  • A page is a fixed-length, consecutive block of data used in virtual memory systems.
  • Paging is how the operating system moves these blocks between HDD/SSD and RAM.
  • Accessing data via virtual memory is SLOWER than direct RAM access — which is exactly why larger RAM improves overall speed (less swapping needed).
Benefits of virtual memory

Programs can be LARGER than physical memory and still run; no memory wasted on unused data (e.g. during error handling); reduces the need to buy/install more expensive RAM (though there are limits to how far this helps).

Disk thrashing — the real drawback

  • As main memory fills up, MORE and more data must be swapped between RAM and disk, causing very high rates of HDD read/write head movement — this is disk thrashing.
  • If more time is spent MOVING data than actually processing, overall speed drops considerably. At the extreme, execution can effectively HALT — the thrash point — since the system is entirely busy swapping data.
  • Excessive head movements can also cause premature HDD failure.
  • Fixes: install more RAM, reduce the number of running programs, reduce the swap file size, or use an SSD instead of an HDD (faster, no moving parts).
Practice — Test Yourself

These questions only cover what THIS subsection taught — virtual memory.

Short answer 1
Define "virtual memory" in terms of what it's actually made of.
Reveal answer

Virtual memory = physical RAM + swap space on the HDD/SSD — the disk acts as an extension of RAM.

Short answer 2
What is "disk thrashing", and what real symptom does it cause?
Reveal answer

Disk thrashing is excessive swapping between RAM and disk, causing very high rates of HDD read/write head movement. This causes overall processing speed to drop considerably, since more time is spent moving data than actually processing it — at worst, execution can effectively halt (the thrash point).

Fill in the blank 3
A ______ is a fixed-length, consecutive block of data moved between HDD/SSD and RAM — this process is called ______.
Reveal answer

Blank 1: page. Blank 2: paging.

Spot the error 4
A student claims: "Virtual memory means a computer can genuinely have unlimited real RAM." What real distinction does this ignore?
Reveal answer

Virtual memory only gives the ILLUSION of unlimited memory — the actual RAM is still physically limited and genuinely full. Data is being swapped in and out of disk to create that illusion; it's not a real increase in RAM capacity, and accessing swapped-out data is genuinely slower.

Applied / scenario 5
A user notices their computer has become extremely slow, with the hard disk light constantly flashing, while running several large programs at once. Using this lesson's content, diagnose the likely problem and suggest two possible fixes.
Reveal answer

This is likely disk thrashing — RAM is overloaded by too many running programs, forcing constant swapping to/from disk (explaining the flashing disk light and slowdown). Fixes: install more RAM, close some running programs, reduce the swap file size, or switch to an SSD.

Short answer 6
Name one genuine benefit of virtual memory, according to this lesson.
Reveal answer

Any of: programs can be larger than physical memory and still run; no memory is wasted on unused data; reduces the need to buy more expensive RAM.
