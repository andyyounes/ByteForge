3.1a The CPU & Von Neumann Architecture
The stored-program concept that underlies every modern computer, and the CPU components that carry it out.
Key Terms
CPU
Central Processing Unit — executes all instructions and processes all data in a computer application.
Von Neumann architecture
The "stored program" concept (1940s) — programs AND data are both stored together in memory and executed in sequence.
ALU
Arithmetic and Logic Unit — carries out arithmetic (+, −, shifts) and logic (AND, OR) operations.
CU
Control Unit — reads instructions from memory, decodes them, and generates signals to synchronise the rest of the computer.
Register
A tiny, extremely fast storage location inside the CPU used to hold data mid-instruction.
System bus
A pathway connecting CPU, memory, and I/O — split into address bus, data bus, and control bus.
Theory

The CPU

  • The CPU (also called a microprocessor/processor) is central to EVERY modern computer system — including tablets and smartphones — usually built as a single integrated-circuit microchip.
  • The CPU is responsible for executing/processing all instructions and data in an application.
  • It consists of: the control unit (CU), the arithmetic and logic unit (ALU), and registers and buses.

The stored-program concept (Von Neumann architecture)

  • Early computers had to be FED data while running — they could not store programs or data, so they needed constant human intervention.
  • In the mid-1940s, John von Neumann introduced the "stored program computer" — the basis of computer architecture ever since.
  • Its main novel features (none of which existed before): the concept of a CPU; the CPU could access memory DIRECTLY; memory could store PROGRAMS as well as data; and stored programs are made of instructions executed in SEQUENTIAL order.

ALU and CU in detail

  • ALU: performs arithmetic (+, −, shifting) and logic (AND, OR) operations while a program runs. A computer can have more than one ALU for specific tasks. Multiplication and division are actually carried out as a SEQUENCE of addition/subtraction and logical shift operations.
  • CU: reads an instruction from memory (its address is held in the Program Counter), interprets it via the Fetch-Decode-Execute cycle, and generates signals on the control bus telling other components what to do. It keeps everything SYNCHRONISED.
  • A system clock produces timing signals on the control bus to keep this synchronisation working — without it, the computer would simply crash.
  • RAM (sometimes called the Immediate Access Store, IAS) holds data/programs the CPU needs. The CPU copies data from slower backing store (e.g. hard disk) into RAM temporarily, since RAM read/write is much faster — speeding up operations considerably.

The system bus connects CPU, memory, and I/O ports — split into address bus, data bus, and control bus (not shown, runs alongside).
Worked example — reading from memory using MAR/MDR

Reading memory location 1111 0001:

1. Address 1111 0001 is written into the MAR.

2. A "read signal" is sent to memory.

3. The contents at that address are placed into the MDR: 0101 1011.

Writing value 1001 0101 to location 1111 1101:

1. The data 1001 0101 is written into the MDR.

2. The target address 1111 1101 is written into the MAR.

3. A "write signal" is sent — the value is written into that memory location.

Practice — Test Yourself

These questions only cover what THIS subsection taught — the CPU and Von Neumann architecture.

Short answer 1
Name the four main novel features of Von Neumann's stored-program computer.
Reveal answer

The concept of a CPU; the CPU could access memory directly; memory could store programs AS WELL AS data; stored programs are made of instructions executed in sequential order.

Short answer 2
Why is RAM used, if backing store (e.g. hard disk) can already hold all the same data?
Reveal answer

Read/write operations to RAM are considerably FASTER than to backing store. Copying key data into RAM temporarily speeds up processing significantly compared to constantly accessing the slower backing store.

Fill in the blank pseudocode 3
To read memory location X: write X into the ______, send a read signal, then the contents appear in the ______.
Reveal answer

Blank 1: MAR (Memory Address Register). Blank 2: MDR (Memory Data Register).

Spot the error 4
A student claims: "Multiplication and division are carried out directly by the ALU as single, one-step operations, just like addition." What does this get wrong?
Reveal answer

Multiplication and division are NOT single-step operations — they're carried out as a SEQUENCE of addition, subtraction, and left/right logical shift operations. Only addition/subtraction/shifts are the ALU's true single-step primitives.

Applied / scenario 5
A computer needs to write the value 1010 1100 into memory address 0000 1111. Describe, step by step, which registers are used and in what order, based on this lesson's content.
Reveal answer

1. The data 1010 1100 is first written into the MDR (Memory Data Register).

2. The target address 0000 1111 is written into the MAR (Memory Address Register).

3. A "write signal" is sent to memory, and the value is stored at that address.

Short answer 6
What would happen to a computer without a working system clock, according to this lesson?
Reveal answer

The computer would simply crash — the clock's timing signals on the control bus are what keep every component synchronised; without them, synchronisation breaks down entirely.
