4.1j File Management & Multitasking (Operating Systems)
How the OS organises your files, and how it juggles multiple running programs without them clashing.
Key Terms
File extension
The suffix after a filename's dot (e.g. .docx, .txt) indicating file type.
Multitasking
The OS running more than one process at a time, sharing hardware resources.
Pre-emptive multitasking
Allocating resources for a fixed time, allowing interruption, and using priority — how the OS keeps processes from clashing.
Theory

File management

  • Uses FILE NAMING conventions, e.g. filename.docx (extension indicates type: .bat, .htm, .dbf, .txt, .xls, etc.)
  • Performs specific tasks: create, open, close, delete, rename, copy, move.
  • Maintains DIRECTORY structures (folders).
  • Ensures ACCESS CONTROL is maintained — file access rights, password protection, making files editable or locked.
  • Ensures MEMORY ALLOCATION for a file — reading it from HDD/SSD and loading it into memory when needed.

Multitasking

  • Lets a computer carry out MORE THAN ONE task (process) at a time — all sharing hardware resources, controlled by the OS.
  • To prevent processes clashing, the OS must constantly MONITOR each process's status. Three key mechanisms (together called pre-emptive multitasking):
  • Resources are allocated to a process for a SPECIFIC TIME LIMIT.
  • The process CAN be interrupted while running.
  • The process is given a PRIORITY, receiving resources accordingly — the risk: a low-priority process could be "starved" of resources.
  • Effective multitasking management improves use of main memory, HDD/SSD, virtual memory, and CPU time overall.
The OS sits above all running processes, sharing the CPU's time between them.
Practice — Test Yourself

These questions only cover what THIS subsection taught — file management and multitasking.

Short answer 1
Name three specific tasks that file management performs on files.
Reveal answer

Any three of: create, open, close, delete, rename, copy, move.

Short answer 2
What real risk exists for a low-priority process under multitasking?
Reveal answer

It could be "starved" of resources — since resources are allocated based on priority, a consistently low-priority process might not get enough CPU time to make meaningful progress.

Fill in the blank 3
Under pre-emptive multitasking, resources are allocated to a process for a specific ______, and the process can be ______ while running.
Reveal answer

Blank 1: time limit. Blank 2: interrupted.

Spot the error 4
A student claims: "Multitasking means a computer genuinely runs multiple programs at the exact same physical instant, using the CPU simultaneously." What real detail from this lesson does this oversimplify?
Reveal answer

The lesson describes multitasking as the OS allocating resources to EACH process for a specific TIME LIMIT and using priority to decide who gets resources — this implies processes take turns rapidly (with interruption), rather than genuinely running at the exact same instant on the same CPU resource.

Applied / scenario 5
A user is running a spreadsheet, a web browser, and background anti-virus scanning at the same time. Using this lesson's content, explain how the operating system prevents these three processes from interfering with each other.
Reveal answer

The OS constantly monitors each process's status, allocating each one resources for a specific time limit, allowing them to be interrupted, and giving each a priority level — this coordinated, monitored sharing of hardware resources under OS control is exactly what prevents the processes clashing with each other.

Short answer 6
What does file management do when a file needs to actually be used by a running program?
Reveal answer

It ensures memory allocation for the file — reading it from the HDD/SSD and loading it into memory (RAM) so it can be used.
