6.1b Automated Systems: Transport
Self-parking cars and adaptive cruise control — the same sensor-microprocessor-actuator pattern, driving your car.
Theory

Example 3 — self-parking cars

  • Sensors/cameras gauge parking space size as the driver passes; the on-board computer warns when a suitable space is found.
  • Bumper sensors act as BOTH transmitters and receivers — they send signals that bounce off objects, and the time taken to return lets the computer calculate object positions, building a 3D image of surroundings.
  • Once "auto-parking" is selected, actuators control steering, brakes, and throttle — the car parks with NO driver intervention.
  • Note: cheaper/older systems are NOT fully automatic — they only control steering, leaving brakes/throttle to the driver.
Self-parking — advantages
  • Same number of cars fit into fewer spaces
  • Avoids traffic disruption (faster than manual parking)
  • Fits into smaller spaces
  • Fewer dents/scratches (lower insurance claims)
  • Safer — stops if a new object (e.g. a child) appears
  • Very consistent results
Self-parking — disadvantages
  • Driver over-reliance — loss of manual skill
  • Faulty/dirty sensors can cause malfunctions
  • Kerbing wheels — low kerbs may go undetected
  • Expensive, doesn't really save the driver money
  • Needs additional maintenance

Example 4 — adaptive cruise control

  • Driver sets a cruising speed (e.g. 100 kph). Bumper LASERS constantly send signals that bounce off the vehicle in front, reflecting back to sensors.
  • The on-board computer uses the signal's round-trip TIME to calculate the DISTANCE between vehicles.
Adaptive cruise control logic
  1. Receive sensor signals; calculate distance to vehicle in front
  2. IF distance < safe distance THEN send signals to actuators to apply brakes / reduce throttle
  3. ELSE (distance is safe): check if current speed = driver's set value
  4. IF speed ≠ set value THEN send signals to actuators to increase/decrease throttle accordingly
Practice — Test Yourself

These questions only cover what THIS subsection taught — self-parking cars and adaptive cruise control.

Short answer 1
How does a self-parking car's on-board computer calculate the position of nearby objects?
Reveal answer

Bumper sensors transmit signals that bounce off objects and reflect back; the computer uses the TIME taken for the signal to return to calculate the object's position, building a 3D image of the surroundings.

Short answer 2
In adaptive cruise control, what does the car's computer do if the vehicle in front is closer than the safe distance?
Reveal answer

It sends signals to actuators to apply the brakes and/or reduce the throttle, slowing the car down.

Fill in the blank pseudocode 3
IF distance < safe distance THEN send signals to actuators to ______; ELSE check IF speed ______ set value.
Reveal answer

Blank 1: apply brakes/reduce throttle. Blank 2: ≠ (not equal to).

Spot the error 4
A student claims: "All self-parking systems, cheap or expensive, fully control steering, brakes, and throttle with no driver input at all." What's wrong with this?
Reveal answer

The lesson explicitly notes that CHEAPER/OLDER self-parking systems are NOT fully automatic — they only control the STEERING, requiring the driver to still operate the brakes and throttle manually. Only the fully automatic (typically more expensive) systems control all three.

Applied / scenario 5
A car using adaptive cruise control is travelling at a speed BELOW the driver's set value, with the vehicle in front at a perfectly safe distance. Using this lesson's logic, describe what the on-board computer will do.
Reveal answer

Since the distance is safe, the computer checks if the current speed matches the set value — since it's below the set value, the speeds don't match, so the computer sends signals to actuators to INCREASE the throttle, bringing the car's speed up towards the driver's set cruising speed.

Short answer 6
Name one real safety benefit of self-parking cars mentioned in this lesson, beyond just convenience.
Reveal answer

Sensors monitor ALL objects, including young children — the car's manoeuvre is stopped if any new object is detected, making it genuinely safer than manual parking in this respect.
