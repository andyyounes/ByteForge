3.4a Network Interface Card & MAC Address
The unique hardware identity every network device carries — set at the factory, rarely changed.
Key Terms
NIC
Network Interface Card — hardware allowing a device to connect to a network.
WNIC
Wireless NIC — connects via an antenna using microwaves, instead of a physical cable.
MAC address
A 48-bit hardware address, in six hex groups, uniquely identifying a device on a network.
UAA / LAA
Universally Administered (factory-set, most common) vs. Locally Administered (user-changed) MAC address.
Theory

Network Interface Cards

  • A NIC is needed for any device to connect to a network (e.g. the internet). It's usually built into the device hardware, and contains the MAC address generated at manufacturing.
  • A WNIC (Wireless NIC) does the same job but connects wirelessly, using an antenna and microwaves — typically via USB or built into the device's circuitry.

MAC address structure

  • A MAC address is 48 bits, shown as SIX groups of hex digits: NN-NN-NN-DD-DD-DD.
  • The FIRST three groups identify the MANUFACTURER (e.g. Apple). The LAST three groups are the device's own SERIAL NUMBER (unique to that device).
  • If a device's NIC is replaced, its MAC address CHANGES (since the MAC is tied to the physical card, not the device as a whole).
Worked example — reading a MAC address
00
1C
B3
4F
25
FF

First 3 groups (blue) = manufacturer code. Last 3 groups (green) = unique device serial number.

UAA vs. LAA

  • UAA (Universally Administered Address): the FACTORY-SET MAC address — by far the most common type, rarely changed by users.
  • LAA (Locally Administered Address): a user/organisation-CHANGED MAC address. Easy to do, but causes big problems if the new address isn't unique.
  • Real reasons to use LAA: some mainframe software requires MAC addresses to follow a strict format; bypassing a MAC address filter on a router/firewall (only certain formats allowed through); or emulating unrestricted MAC addresses to get past network restrictions.
Practice — Test Yourself

These questions only cover what THIS subsection taught — NICs and MAC addresses.

Short answer 1
How many bits make up a MAC address, and how many hex groups is it shown as?
Reveal answer

48 bits, shown as six groups of hexadecimal digits.

Short answer 2
What do the FIRST three hex groups of a MAC address represent, and what do the LAST three represent?
Reveal answer

The first three groups identify the MANUFACTURER's device code. The last three groups are the device's unique SERIAL NUMBER.

Fill in the blank 3
The factory-set MAC address is called a ______; a user-changed MAC address is called a ______.
Reveal answer

Blank 1: UAA (Universally Administered Address). Blank 2: LAA (Locally Administered Address).

Spot the error 4
A student claims: "A device's MAC address is permanently fixed for life and can never change under any circumstances." What's wrong with this?
Reveal answer

A MAC address CAN change — either by replacing the device's NIC card (the MAC is tied to that physical card, not the device as a whole), or by deliberately changing it to an LAA address (though this must be done carefully to avoid creating a non-unique address).

Applied / scenario 5
An organisation's router only allows devices with MAC addresses in a specific format to connect (a MAC filter). One of their devices has a MAC address in the wrong format. Using this lesson's content, explain a real solution to this problem.
Reveal answer

They could change the device's MAC address to an LAA (Locally Administered Address) that matches the required format — the lesson explicitly lists bypassing a MAC filter on a router/firewall as a real reason organisations use LAA addresses.

Short answer 6
What is a WNIC, and how does it differ from a standard NIC?
Reveal answer

A WNIC (Wireless NIC) connects a device to a network wirelessly, using an antenna and microwaves, rather than via a physical cable — otherwise it serves the same purpose as a standard NIC.
