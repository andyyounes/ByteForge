4.2b Assembly Language
A step above raw machine code — using LDA, ADD, STO instead of streams of hex.
Key Terms
Assembly language
A low-level language using mnemonics (LDA, ADD, STO) instead of raw binary/hex.
LDA
Load — copies a variable's value into the accumulator.
ADD
Adds a variable's value to whatever is currently in the accumulator.
STO
Store — copies the accumulator's value into a named variable.
Theory

Why some programmers still write assembly

  • To make use of SPECIAL hardware.
  • To use special MACHINE-DEPENDENT instructions.
  • To write code that doesn't take up much PRIMARY MEMORY.
  • To write code that performs a task very QUICKLY.
Worked example — adding two numbers in assembly
LDA First
ADD Second
STO Sum

LDA First: load the value of "First" into the ACCUMULATOR.

ADD Second: add the value of "Second" to what's currently in the accumulator.

STO Sum: replace the value of "Sum" with what's now in the accumulator.

From assembly to machine code

  • Assembly language needs to be TRANSLATED into machine code before a computer can run it.
  • The program that does this translation is called an assembler (covered in the next lesson).
Practice — Test Yourself

These questions only cover what THIS subsection taught — assembly language.

Short answer 1
What does the assembly instruction "LDA First" actually do?
Reveal answer

It loads the value of the variable "First" into the accumulator.

Short answer 2
Name two genuine reasons a programmer might choose to write in assembly language rather than a high-level language.
Reveal answer

Any two of: to make use of special hardware; to use machine-dependent instructions; to write compact code (little primary memory used); to write code that runs very quickly.

Fill in the blank pseudocode 3
Complete this assembly sequence to compute Total := X + Y:
LDA X
______ Y
______ Total
Reveal answer

ADD Y then STO Total.

Spot the error 4
A student claims: "Assembly language programs can be run directly by the computer without any translation, since assembly is already close to machine code." What's wrong with this?
Reveal answer

Assembly language still genuinely needs to be TRANSLATED into machine code (by an assembler) before a computer can run it — being "close to" machine code doesn't mean the computer can execute it directly. Only actual machine code (binary) can be run by the CPU.

Applied / scenario 5
A programmer needs to write extremely time-critical code for a specific embedded chip, where every microsecond and every byte of memory matters. Which type of language is most appropriate, and why, based on this lesson's content?
Reveal answer

Assembly language. The lesson explicitly lists writing code that doesn't take up much primary memory, and writing code that performs a task very quickly, as real reasons programmers choose assembly — a direct match for this time- and memory-critical embedded scenario.

Short answer 6
What does the "STO" instruction do?
Reveal answer

It replaces the value of a named variable with whatever value is currently held in the accumulator.
