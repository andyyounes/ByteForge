1.1e Two's Complement
Representing NEGATIVE binary numbers, using one small change to the place-value headings.
Key Terms
Two's complement
A way of representing both positive and negative integers in binary, by making the left-most place value negative.
Sign bit
The left-most bit — 0 means the number is positive, 1 means it's negative.
Theory

The one change that makes negative numbers possible

  • Up to now, every binary number has been assumed to be a positive integer. Two's complement is how negative integers get represented too.
  • The ONLY change needed: the left-most heading becomes NEGATIVE. For an 8-bit number, the headings become −128, 64, 32, 16, 8, 4, 2, 1 — every other heading stays exactly the same.
  • This gives an 8-bit two's complement range of −128 to +127.
  • The left-most bit always determines the sign: a 1 there means the number is negative; a 0 there means it's positive.

Positive numbers work exactly as before

  • Writing a POSITIVE number in two's complement is no different from ordinary binary — just place a 0 in the −128 column, then fill in the rest exactly as before.
  • Reading a two's complement number back to denary also works the same way — add up the headings wherever there's a 1, except the −128 column subtracts if it's a 1.
Worked example — reading a two's complement number

Convert 11110101 (two's complement) to denary:

−1286432168421
11110101

−128 + 64 + 32 + 16 + 4 + 1 = −11. So 11110101 is −11.

Writing a NEGATIVE denary number in two's complement — two valid methods

  • Method 1 — direct place-value fitting. Since the number is negative, the −128 column must hold a 1. Work out what remains (e.g. for −67: −67 = −128 + 61), then fit the remainder (61) into the ordinary positive headings.
  • Method 2 — invert and add 1 (the standard shortcut). Write the POSITIVE version of the number in ordinary binary. INVERT every bit (swap every 0 for a 1 and every 1 for a 0). Then ADD 1 to the inverted result. This gives the two's complement negative version.
  • Both methods always agree — Method 2 is the one usually used in practice because it's a fixed, mechanical process that doesn't need you to re-derive place values by hand each time.
Worked example — negative denary to two's complement (Method 2)

Convert −79 to an 8-bit two's complement binary number.

1. Write 79 in ordinary binary: 01001111

2. Invert every bit: 10110000

3. Add 1: 10110000 + 1 = 10110001

Answer: 10110001 represents −79.

Pseudocode — Method 2 as an algorithm
INPUT positiveNumber
binary ← ConvertToBinary(positiveNumber)
inverted ← InvertEveryBit(binary)
twosComplement ← inverted + 1
OUTPUT twosComplement

Two's complement isn't limited to 8 bits

  • The same idea works for a register of ANY size — a 4-bit two's complement number uses headings −8, 4, 2, 1; a 12-bit one uses −2048, 1024, 512, 256, 128, 64, 32, 16, 8, 4, 2, 1.
  • Whatever the register size, the process is identical: only the left-most heading becomes negative, and Method 2 (invert then add 1) still works exactly the same way.
Worked example — two's complement in a 4-bit register

The 4-bit binary number 0110 represents +6 (using headings −8, 4, 2, 1). Apply two's complement: invert (1001), then add 1 → 1010.

1010 under headings −8, 4, 2, 1: −8 + 2 = −6. So 1010 represents −6 — exactly the negative of the original +6, as expected.

Practice — Test Yourself

These questions only cover what THIS subsection taught — two's complement. Answer each one, then reveal the answer key to check.

Short answer 1
Convert the two's complement binary number 11101100 into denary.
Reveal answer

−128 + 64 + 32 + 8 + 4 = −20

Answer: −20

Short answer 2
Convert −52 into an 8-bit two's complement binary number, using the invert-and-add-1 method. Show all three steps.
Reveal answer

52 in binary: 00110100. Inverted: 11001011. Add 1: 11001100.

Answer: 11001100

Fill in the blank 3
In an 8-bit two's complement number, the ______ bit determines the sign — a value of ______ there means the number is negative.
Reveal answer

Blank 1: left-most (most significant). Blank 2: 1.

Spot the error 4
A student converts −40 to two's complement by writing 40 in binary (00101000), inverting it (11010111), and stopping there — giving the final answer 11010111. What real step have they missed?
Reveal answer

They forgot to add 1 after inverting — the invert-and-add-1 method genuinely has three steps, not two. The correct answer is 11010111 + 1 = 11011000. Stopping after inverting alone gives what's called "one's complement", not two's complement, and it doesn't represent the correct negative value.

Applied / scenario 5
A temperature sensor stores readings as 8-bit two's complement numbers, since temperatures can genuinely be negative. It records the binary value 11111110. (a) What real temperature (in the sensor's unit) does this represent? (b) Explain, using what this lesson taught about the range of two's complement, why an 8-bit register would NOT be suitable if this sensor needed to record temperatures as extreme as −200.
Reveal answer

(a) −128 + 64 + 32 + 16 + 8 + 4 + 2 = −2.

(b) An 8-bit two's complement register can only represent values from −128 to +127 — −200 falls outside that range entirely, so an 8-bit register genuinely could not store it correctly; a register with more bits (e.g. 16-bit) would be needed instead.

Short answer 6
What is the two's complement range of a 4-bit register (headings −8, 4, 2, 1)? Give both the smallest and largest values it can represent.
Reveal answer

Smallest: 1000 = −8. Largest: 0111 = +7. So the full range is −8 to +7.
