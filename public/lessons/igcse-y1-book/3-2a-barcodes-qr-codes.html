3.2a Input Devices: Barcodes & QR Codes
How a pattern of lines or squares becomes readable data — from the supermarket checkout to a boarding pass.
Key Terms
Barcode
A series of dark/light parallel lines of varying thickness, each digit (0-9) represented by a unique line pattern.
Guard bars
Bars marking the start, middle, and end of a barcode, separating its left and right halves.
Key field
The barcode number, used to uniquely identify one specific stock item record in a database.
QR code
Quick Response code — a matrix of dark/light squares (pixels) that can store far more data than a traditional barcode.
Attagging
Embedding malicious code inside a QR code, since anyone can generate one using free apps.
Theory

How a barcode is structured and scanned

  • Each digit is made of 2 dark lines and 2 light lines, all the same total width. Left-side digits have an ODD number of dark elements and start with a LIGHT bar; right-side digits have an EVEN number of dark elements and start with a DARK bar — this deliberate asymmetry allows a barcode to be scanned in EITHER direction.
  • Scanning process: a red laser or LED reads the barcode; dark areas reflect little/no light; photoelectric sensors read the reflected light; as the light scans across, a pattern is generated and converted into digital (binary) data.
A barcode section: bar thickness (1-4 units) encodes each digit; alternating thick/thin patterns are read by a laser/LED scanner.

What happens after a barcode is scanned

  • The barcode number (the KEY FIELD) is looked up in the stock database to find the matching stock item record.
  • The price and stock details are sent back to the checkout / point-of-sale (POS) terminal.
  • The stock count is reduced by 1 and written back to the record.
  • Stock count is compared to the re-order level — if at or below it, more stock is automatically ordered, and a flag prevents repeated re-ordering until new stock arrives and the database is updated.
Other devices at a checkout

Keypad: key in item quantity/weight, or the barcode number manually if unreadable. Screen: shows cost/info. Speaker: beeps on a successful scan, different sound on error. Printer: prints the receipt. Card reader: reads credit/debit cards (PIN or contactless). Touchscreen: for selecting loose items like fresh fruit.

Barcode benefits — management
  • Easier/faster to change prices
  • Better, more up-to-date sales data
  • No need to price every item on shelves
  • Automatic stock control
  • Easier to track buying habits (e.g. via loyalty cards)
Barcode benefits — customers
  • Faster checkout queues
  • Fewer charging errors
  • Itemised bill provided
  • Cost savings passed on
  • Better sell-by-date tracking = fresher food

QR codes

  • A QR code is a matrix of small dark/light squares (pixels), holding up to 4,296 characters (or 7,089 digits) — far more than a barcode's ~30-digit maximum, and can encode web addresses directly.
  • Three large corner squares provide alignment; a fourth, smaller corner square helps the scanning camera get the correct size/angle.
  • Reading process: point a smartphone/tablet camera (with a QR app) at the code → the app converts the squares to data → the browser reads/decodes it (including any embedded web address) → the user is automatically taken to the website, phone dialer, or boarding pass.
A simplified QR code pattern — the three large dark corner blocks are alignment markers.
QR code advantages vs. barcode
  • Holds far more information
  • Built-in error-checking reduces read errors (barcodes have almost no data redundancy)
  • Readable by ordinary smartphone/tablet cameras — no expensive laser/LED scanner needed
  • Easy to transmit as text/images
  • Can be encrypted for extra protection
QR code disadvantages vs. barcode
  • More than one QR format exists
  • Can carry malicious code ("attagging") — anyone can generate a QR code with free apps, potentially exposing photos, contacts, or passwords when scanned, or redirecting to fake websites/malware
Practice — Test Yourself

These questions only cover what THIS subsection taught — barcodes and QR codes.

Short answer 1
What design feature allows a barcode to be scanned in either direction?
Reveal answer

Left-side digits always have an ODD number of dark elements and start with a light bar, while right-side digits always have an EVEN number of dark elements and start with a dark bar — this asymmetry lets the scanner tell direction and orientation regardless of which way the barcode is scanned.

Short answer 2
What is the "key field" in a barcode-linked stock database record?
Reveal answer

The barcode number itself — it uniquely identifies one specific stock item record.

Fill in the blank 3
A QR code can hold up to ______ characters, compared to a traditional barcode's maximum of around ______ digits.
Reveal answer

Blank 1: 4,296. Blank 2: 30.

Spot the error 4
A student claims: "QR codes are strictly worse than barcodes for security, since anyone can create one." Using the lesson's content, explain what this misses.
Reveal answer

This ignores that QR codes can ALSO be encrypted, giving them GREATER protection than traditional barcodes in that respect. The lesson lists both a real security risk (attagging, since anyone can generate one) AND a real security advantage (encryption support) — it's not simply worse across the board.

Applied / scenario 5
A supermarket scans a barcode at checkout, and the stock count for that item drops to exactly the re-order level. Describe, step by step, what happens next in the system based on this lesson's content.
Reveal answer

Since the stock count is now at or below the re-order level, the system automatically triggers an order for more of that stock item. A flag is then added to the record to prevent the system from re-ordering again every time the barcode continues to be scanned. When the new stock physically arrives, the stock level in the database is updated accordingly.

Short answer 6
Name two real, non-shopping uses of barcode/QR technology mentioned in this lesson.
Reveal answer

Any two of: library book/borrower tracking (barcodes); electronic boarding passes at airports/train stations (QR codes); product advertising with embedded web addresses (QR codes).
