IGCSE Year 1 · Unit 5 · The Internet & Its Uses
5.1d Cookies
Small (key, data) lookup tables that remember you between visits — and quietly track you too.
Key Terms
Cookie
A small file/code stored on a user's computer by a web server, holding (key, data) pairs.
Session cookie
Temporary, no expiry date, exists only until the browser/session closes.
Persistent cookie
Stored on the hard drive until its expiry date or manual deletion — survives closing the browser.
Theory

What cookies are and do

  • Small files/code, sent by a web server, stored on the USER'S computer — effectively a small look-up table of (key, data) pairs, e.g. (surname, Jones), (music, rock).
  • On each visit, the site checks if it set a cookie before; if so, the browser reads it — holding preferences (language, currency, past browsing).
  • Allows user TRACKING, maintaining preferences, and CUSTOMISING the page per user (e.g. "customers who bought X also bought Y").
  • Any cookie with NO expiry date is automatically a SESSION cookie.
Session cookies
  • Used e.g. for a virtual shopping basket
  • Stored in TEMPORARY memory
  • Doesn't collect info or personally identify the user
  • Ceases to exist once browser/session closes
Persistent (permanent) cookies
  • Remembers LOGIN details (authenticates the browser)
  • Stored on the HARD DRIVE until expiry/manual deletion
  • Remains active even after browser/session closes
  • Removes the need to re-type login details every visit
  • Legitimate sites ENCRYPT personal info stored this way
  • Many countries legally require deactivation after 6 months (even before expiry)

Why persistent cookies are efficient

  • Carries data between sessions/related websites WITHOUT storing massive amounts of data on the web server itself.
  • Without cookies, retrieving a user's data would require the user to LOG IN every single visit.

Summary of (persistent) cookie uses

  • Remember passwords/emails/invoice details (no re-entry needed).
  • Recognise returning users.
  • Save shopping basket/cart items.
  • Track internet habits/website history/favourites.
  • Target ADVERTISING matching past buying/browsing habits.
  • Store user preferences (customised pages).
  • Used in online financial transactions.
  • Save progress in online games/quizzes.
  • Let social networks recognise preferences/browsing history.
  • Automatically apply the right LANGUAGE on login.
Practice — Test Yourself

These questions only cover what THIS subsection taught — cookies.

Short answer 1
What determines whether a cookie is automatically classed as a session cookie?
Reveal answer

If it has NO expiry date associated with it, the cookie is always considered a session cookie.

Short answer 2
Give two real differences between session cookies and persistent cookies.
Reveal answer

Any two of: session cookies are stored in TEMPORARY memory (persistent are stored on the HARD DRIVE); session cookies disappear when the browser/session closes (persistent remain until expiry/deletion); session cookies don't personally identify the user (persistent typically DO, storing login details).

Fill in the blank 3
Legitimate websites always ______ personal information stored in a persistent cookie, to prevent unauthorised use by a ______ party.
Reveal answer

Blank 1: encrypt. Blank 2: third.

Spot the error 4
A student claims: "Persistent cookies can legally be kept active forever, as long as the website sets a very far-future expiry date." What real legal safeguard from this lesson contradicts this?
Reveal answer

Many countries have laws requiring persistent cookies to be DEACTIVATED after six months, even if their set expiry date hasn't been reached yet — a far-future expiry date does NOT override this legal requirement.

Applied / scenario 5
An online shopping site wants shoppers to be able to add items to a basket during their visit, WITHOUT storing any personally identifiable information about them. Which type of cookie should they use for this feature, and why, based on this lesson's content?
Reveal answer

A session cookie. The lesson explicitly gives virtual shopping baskets as a session cookie use case — it doesn't collect information from the user's computer or personally identify them, and disappears once the browser/session closes, exactly matching the requirement.

Short answer 6
Why are persistent cookies described as an efficient way to carry data between sessions?
Reveal answer

Because they remove the need to store massive amounts of user data directly on the web server — the data instead lives on the user's own computer, and without this, retrieving user data would require logging in every single visit.
