3.1b System Buses & the Fetch-Decode-Execute Cycle
The three buses that connect the CPU to everything else, and the repeating cycle that runs every single instruction.
Key Terms
Address bus
Carries memory addresses. UNIDIRECTIONAL between CPU and memory.
Data bus
Carries actual data (addresses, instructions, or values). BIDIRECTIONAL.
Control bus
Carries signals from the CU to other components. Bidirectional, usually 8 bits wide.
Word
A group of bits treated as a single unit, e.g. 16-bit, 32-bit, or 64-bit word lengths.
Fetch-Decode-Execute cycle
The repeating three-stage process the CPU uses to run every single instruction.
Theory

The three system buses

  • Buses are PARALLEL transmission components — each wire carries one bit.
  • Address bus: carries addresses. UNIDIRECTIONAL between CPU and memory (prevents addresses being sent back to the CPU, which would be undesirable). Wider = more memory locations addressable at once: a 16-bit bus addresses 2¹⁶ = 65,536 locations; a 32-bit bus addresses 4,294,967,296 locations.
  • Data bus: BIDIRECTIONAL — carries data both ways (CPU ↔ memory, CPU ↔ I/O). "Data" here can be an address, an instruction, OR a numerical value. Wider = larger word length transportable at once, which can improve performance.
  • Control bus: also bidirectional, carries CU signals to all other components. Usually 8 bits wide — no real need for more, since it only carries control signals (not large data).

The Fetch-Decode-Execute cycle

  • To run instructions, the CPU first FETCHES data/instructions from memory into registers, using the address and data buses.
  • Fetch: the next instruction's address (from the PC) is copied to the MAR via the address bus. The instruction at that address is copied into the MDR, then into the CIR. The PC is then INCREMENTED by 1, so it points to the next instruction.
  • Decode: the instruction in the CIR is decoded so it can be interpreted.
  • Execute: the CPU sends the decoded instruction out as control signals to the relevant components, carrying it out in the correct sequence.
  • This whole process repeats — fetch, decode, execute, fetch, decode, execute — for every single instruction in a program.
The Fetch-Decode-Execute cycle repeats continuously for as long as the program runs.

Practice — Test Yourself

These questions only cover what THIS subsection taught — system buses and the Fetch-Decode-Execute cycle.

Short answer 1
Which of the three buses is unidirectional, and why is that a deliberate design choice?
Reveal answer

The address bus is unidirectional (between CPU and memory). This is deliberate because there's no reason for an address to ever need to travel back TO the CPU — allowing that would be undesirable/unnecessary.

Short answer 2
A 16-bit address bus can address 65,536 memory locations. How many locations can a 32-bit address bus address?
Reveal answer

2³² = 4,294,967,296 memory locations.

Fill in the blank pseudocode 3
Complete the fetch step: MAR ← PC, MDR ← MEMORY[MAR], CIR ← MDR, PC ← PC ______
Reveal answer

PC ← PC + 1 — the Program Counter is incremented so it points to the NEXT instruction to be fetched.

Spot the error 4
A student claims: "The data bus only ever carries numerical data values, never addresses or instructions." What's wrong with this?
Reveal answer

The lesson explicitly states "data" on the data bus can be an ADDRESS, an INSTRUCTION, or a NUMERICAL VALUE — not just numbers. The data bus is genuinely used to transport all three kinds of information.

Applied / scenario 5
A manufacturer wants to increase how much memory their new computer can directly address, without changing anything else about the CPU's design. Which bus should they widen, and why, based on this lesson's content?
Reveal answer

The address bus. The lesson shows that a wider address bus directly increases the number of memory locations that can be addressed at once (e.g. 16-bit → 65,536 locations vs. 32-bit → over 4 billion) — this is specifically the address bus's job, not the data or control bus's.

Short answer 6
Name the three stages of the Fetch-Decode-Execute cycle, in order.
Reveal answer

Fetch, then Decode, then Execute.
