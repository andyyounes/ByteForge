1.1b Hexadecimal
The base-16 system, converting to/from binary and denary, and four genuine real-world uses.
Key Terms
Hexadecimal
A base 16 number system using digits 0-9 and letters A-F (A=10 ... F=15). Often just called "hex".
Nibble
4 bits — exactly enough to represent one hexadecimal digit, since 16 = 2⁴.
MAC address
A 48-bit number, shown as 6 hex byte-pairs, that uniquely identifies a device's network interface card.
IPv6 address
A 128-bit address written as hexadecimal chunks separated by colons — the successor to IPv4.
Theory

The hexadecimal system — base 16

  • Hexadecimal is closely related to binary, but is a base 16 system — it needs 16 different "digits" to represent each value.
  • Because there are only ten normal digits (0-9), hex also uses the letters A to F to stand in for 10 through 15: A=10, B=11, C=12, D=13, E=14, F=15.
  • Using the same idea as denary and binary, hex positions are worth powers of 16: reading right to left, the headings are 1, 16, 256, 4096, 65 536 (16⁰, 16¹, 16², 16³, 16⁴...).
  • Since 16 = 2⁴, exactly four binary digits (a nibble) are equivalent to one hexadecimal digit — this is the whole reason hex/binary conversion is so quick.

Converting binary to hexadecimal

  • Starting from the RIGHT and moving left, split the binary number into groups of 4 bits (a nibble each).
  • If the leftmost group has fewer than 4 bits, pad it with 0s on the left.
  • Convert each group of 4 bits into its equivalent hex digit using the reference table above.
Worked example — binary to hex

Convert 100001111111101 to hex. First pad and split into nibbles: 0010 0001 1111 1101.

Look up each nibble: 0010→2, 0001→1, 1111→F, 1101→D.

Answer: 21FD

Converting hexadecimal to binary, and hexadecimal to/from denary

  • Hex to binary: the reverse process — take each hex digit and write down its exact 4-bit code, then join the groups together.
  • Hex to denary: multiply each hex digit by its heading value (4096, 256, 16, 1...), remembering to convert A-F to 10-15 first, then add the results together.
  • Denary to hex: use successive division by 16 (instead of by 2, as in binary), writing down the remainder each time, then reading the remainders in reverse order — exactly the same idea as denary-to-binary, just dividing by 16.
Worked example — hex to denary

Convert 4 5 A to denary. Multiply each digit by its heading: (4×256=1024) + (5×16=80) + (10×1=10) — remember A=10.

Answer: 1024 + 80 + 10 = 1114

Worked example — denary to hex

Convert 2004 to hex using successive division by 16: 2004 ÷ 16 = 125 r4 → 125 ÷ 16 = 7 r13 → 7 ÷ 16 = 0 r7.

Reading the remainders in reverse (7, 13, 4) and converting 13 to D gives: 7D4

Why hexadecimal is genuinely useful — four real uses

  • Computer scientists still work with binary underneath, but hex is far easier for a human to remember, copy, and work with — a long binary number like 1101001010101111 is just D2AF in hex.
  • Error codes — memory-location error codes generated automatically by a computer are usually shown in hex, and a programmer needs to be able to interpret them.
  • MAC addresses — a Media Access Control address uniquely identifies a device's network card. It's usually 48 bits, shown as 6 pairs of hex digits (e.g. 00-1C-B3-4F-25-FE) — the first half identifies the manufacturer, the second half is the device's serial number.
  • IP addresses — an IPv4 address is a 32-bit number, written in denary or hex (e.g. 77.76.9e.01). Its successor, IPv6, is a 128-bit address broken into hex chunks separated by colons, e.g. a8fb:7a88:fff0:0fff:3d21:2085:66fb:f0fa.
  • HTML colour codes — a web colour is set using a # followed by SIX hex digits: two each for red, two for green, two for blue intensity. Since each pair can be 00-FF (0-255), there are 256×256×256 = 16 777 216 possible colours.
Worked example — HTML colour codes

The colour #FF9966 breaks down into three real hex pairs: FF (red intensity), 99 (green intensity), 66 (blue intensity).

#FF0000
#00FF00
#0000FF
#FF9966

Each of the three pairs is a genuine, independent hex-to-denary value from 0 (00) to 255 (FF) — exactly the hex-to-denary conversion covered above, just applied three times per colour.

Practice — Test Yourself

These questions only cover what THIS subsection taught — hexadecimal conversion and its uses. Answer each one, then reveal the answer key to check.

Short answer 1
Convert the binary number 101111100001 into hexadecimal.
Reveal answer

Split into nibbles: 1011 1110 0001 → B, E, 1

Answer: BE1

Short answer 2
Convert the hexadecimal number C8F into denary.
Reveal answer

(12×256=3072) + (8×16=128) + (15×1=15) = 3215

Answer: 3215

Fill in the blank 3
To convert denary to hexadecimal, you divide repeatedly by ______ instead of by 2 (as you would for binary), and then read the remainders in ______ order.
Reveal answer

Blank 1: 16 — hex is base 16, so successive division uses 16, not 2.

Blank 2: reverse (the last remainder calculated becomes the FIRST digit of the answer).

Spot the error 4
A student converts the binary number 11111101 to hex by splitting it into 1111 and 1101, correctly getting F and D, but writes the FINAL hex answer as DF instead of FD. What went wrong?
Reveal answer

The two nibbles were converted correctly, but they were written down in the WRONG order at the end — the nibbles must stay in the same left-to-right order they appeared in the original binary number. The first (leftmost) group, 1111 = F, must come first, then 1101 = D — giving FD, not DF.

Applied / scenario 5
A device's MAC address is 00-14-22-3A-9B-C1. (a) Which manufacturer made the network card, based on the identification numbers given in this lesson? (b) Explain, using what this lesson taught about MAC addresses, why the SECOND half of a MAC address (3A-9B-C1) is different for every single device, even from the same manufacturer.
Reveal answer

(a) Dell — the manufacturer code 00-14-22 matches Dell's identification number given in this lesson.

(b) The first half of a MAC address identifies the MANUFACTURER (the same for every device that company makes), but the second half is that specific device's own serial number — since no two devices should share a serial number, the second half genuinely differs even between two devices made by the exact same company.

Short answer 6
An HTML colour is written as #00FF00. What real colour does this represent, and how many total distinct colours can the six-hex-digit HTML system represent altogether?
Reveal answer

#00FF00 has zero red, maximum (FF=255) green, and zero blue — this is pure green.

Total possible colours: 256 × 256 × 256 = 16 777 216 (256 values each for red, green, and blue).
