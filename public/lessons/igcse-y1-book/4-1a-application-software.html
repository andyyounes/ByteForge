4.1a System Software & Application Software
Hardware, system software, application software — the three-layer stack every computer is built on.
Key Terms
System software
Controls/manages hardware and provides the platform other software runs on (OS, device drivers, utilities).
Application software
Software that performs specific tasks for the user (word processor, spreadsheet, database, apps, etc.).
HCI
Human Computer Interface — provided by system software so users can interact with the computer.
Record / Field
In a database: a row (record) and a column (field) within a table.
Theory

The three-layer hierarchy

  • Without software, hardware alone is useless. The stack is: HARDWARE (CPU, printer, HDD) → SYSTEM SOFTWARE (OS, utilities, device drivers) → APPLICATION SOFTWARE (word processor, spreadsheet, database, games, browser, etc.).
Software and hardware hierarchy — each layer depends on the one below it.

System software — general features

  • Controls/manages computer hardware operation.
  • Provides a PLATFORM for other software to run on.
  • Ensures hardware and software run without problems.
  • Provides the human computer interface (HCI).
  • Controls allocation/usage of hardware resources.

Application software — general features

  • Performs specific tasks/applications ("apps") for the user.
  • Lets the user use the computer's resources to accomplish specific goals.
  • May be a single program (e.g. NotePad) or a suite (e.g. Microsoft Office).
  • Run by the user AS AND WHEN they choose.
Spreadsheet
Organises/manipulates numerical data on a grid of cells (e.g. B6). Functions: formulas, graphs, "what if" modelling.
Database
Organises data in tables — rows are records, columns are fields. Functions: queries/reports, add/delete/modify data.
Apps (mobile)
Downloaded from an App Store, run on phones/tablets. Examples: video/music streaming, GPS, camera apps.
Control/measuring software
Interfaces with sensors to measure real-world quantities and control processes (e.g. adjusting a valve based on pH).
Video editing software
Adds titles, colour correction, sound; rearranges/removes clips; creates transitions.
Graphics manipulation software
Bitmap editors change pixels directly; vector editors manipulate lines/curves/text instead.
Photo editing software
Changes brightness/contrast/saturation, removes red-eye, complex manipulation (face features, combining photos).
Word processor
Creates/edits/formats text: copy-paste, spell-check/thesaurus, image import, translation.
Practice — Test Yourself

These questions only cover what THIS subsection taught — system vs. application software, and application software types.

Short answer 1
Name three general features of system software.
Reveal answer

Any three of: controls/manages hardware; provides a platform for other software; keeps hardware/software running without problems; provides the HCI; controls hardware resource allocation.

Short answer 2
In a database, what is the difference between a "record" and a "field"?
Reveal answer

A RECORD is a ROW in a table (one complete entry). A FIELD is a COLUMN in a table (one category of data across all records).

Fill in the blank 3
Bitmap graphics editors change the ______ of an image directly; vector graphics editors instead manipulate ______, curves, and text.
Reveal answer

Blank 1: pixels. Blank 2: lines.

Spot the error 4
A student claims: "Microsoft Office is a single application, since it's just one program you install." What's wrong with this?
Reveal answer

The lesson explicitly gives Microsoft Office as an example of a SUITE of programs (multiple applications bundled together), not a single program — NotePad is given as the example of a single-program application, in contrast.

Applied / scenario 5
A chemical plant needs software that reads real-time pH sensor data and automatically adjusts a valve to add acid when needed. Which type of application software from this lesson fits this need, and why?
Reveal answer

Control and measuring software. The lesson gives this exact example — interfacing with sensors to measure real-world quantities and control a process by comparing sensor data to stored values, then sending signals to adjust parameters (e.g. opening a valve to add acid and change pH).

Short answer 6
Where does system software sit in the software/hardware hierarchy, relative to application software and hardware?
Reveal answer

System software sits in the MIDDLE — between hardware (at the bottom) and application software (at the top). It manages the hardware directly, and provides the platform that application software runs on.
