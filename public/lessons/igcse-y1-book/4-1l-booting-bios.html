4.1l Booting Up & BIOS
What happens in the split second between pressing the power button and seeing your desktop.
Key Terms
Booting up
Loading part of the OS into RAM when a computer starts (also: bootstrap loader).
BIOS
Basic Input/Output System — handles motherboard start-up, locates and loads the OS.
Firmware
A program providing low-level control for devices (the BIOS is a form of firmware).
EEPROM
Electrically Erasable Programmable ROM — flash memory storing the BIOS itself; retains data with no power, but can be rewritten.
CMOS
The chip storing BIOS settings, kept powered by a small rechargeable battery on the motherboard.
Theory

Booting up

  • When a computer starts, part of the OS must be loaded into RAM — this is booting up (or the "bootstrap loader").
  • The motherboard's start-up is handled by the BIOS, which tells the computer WHERE the OS storage device is, then loads and executes the needed OS part.
  • The BIOS is a form of firmware — a program providing low-level device control.
Firmware sits as an interface between hardware and the operating system.

Where the BIOS lives — EEPROM vs. CMOS

  • The BIOS PROGRAM is stored on a special ROM called EEPROM (Electrically Erasable Programmable ROM) — flash memory that retains its contents even powered off, but CAN be rewritten/updated/deleted by a user.
  • The BIOS SETTINGS (different from the program itself) are stored on a separate CMOS chip, kept powered at all times by a small rechargeable battery on the motherboard.
  • If this battery is removed/disconnected, the BIOS settings RESET to factory defaults — the CMOS restarts and re-reads the same EEPROM program, but with the ORIGINAL factory settings (e.g. any custom clock speed change reverts).
Practice — Test Yourself

These questions only cover what THIS subsection taught — booting up and the BIOS.

Short answer 1
What is "booting up", and what other name is it given?
Reveal answer

Booting up is loading part of the operating system into RAM when a computer starts up — also called the "bootstrap loader".

Short answer 2
Where is the BIOS PROGRAM stored, and where are the BIOS SETTINGS stored?
Reveal answer

The BIOS program is stored on EEPROM. The BIOS settings are stored on a separate CMOS chip.

Fill in the blank 3
If the CMOS battery is removed, the BIOS settings ______ to their ______ defaults.
Reveal answer

Blank 1: reset. Blank 2: factory.

Spot the error 4
A student claims: "The BIOS program itself is stored on the CMOS chip, alongside its settings." What's wrong with this?
Reveal answer

The BIOS PROGRAM is stored on EEPROM, not CMOS. The CMOS chip holds only the BIOS SETTINGS — these are two genuinely separate memory locations with different behaviours (EEPROM retains data without power; CMOS needs its battery to hold settings).

Applied / scenario 5
A user manually overclocked their CPU by changing the BIOS clock speed setting. Later, the motherboard's CMOS battery dies and is removed for replacement. Using this lesson's content, explain what will happen to their custom clock speed setting.
Reveal answer

The custom clock speed setting will be LOST — since the CMOS battery kept those settings alive, removing it resets the CMOS to factory defaults. When power is restored, the same BIOS program (from EEPROM) will load, but with the original FACTORY clock speed setting, not the user's overclocked value.

Short answer 6
What does the BIOS do when a computer is first powered on?
Reveal answer

It handles the motherboard's start-up, tells the computer where the storage device holding the operating system is, then loads and executes the needed part of the OS.
