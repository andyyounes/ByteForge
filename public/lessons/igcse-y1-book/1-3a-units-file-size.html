1.3a Units of Data Storage & File Size Calculations
How memory is measured, and how to actually calculate the size of an image or sound file.
Key Terms
Bit / Byte / Nibble
A bit is 1 or 0 (binary digit). A byte is 8 bits. A nibble is 4 bits (half a byte).
SI system (KB/MB/GB)
Base-10 units where 1 kilo = 1000. Technically inaccurate for memory, but still commonly used for storage devices.
IEC system (KiB/MiB/GiB)
Base-2 units where 1 kibi = 1024 (2¹⁰). The accurate system for memory — used for RAM/ROM. This is the ONLY system covered in the syllabus.
Bandwidth
The maximum rate of data transfer across a network, measured in bits per second.
Theory

Measuring data storage

  • A bit is the basic unit of memory — either 1 or 0. The word comes from "binary digit".
  • A byte is the smallest unit of memory in a computer — 1 byte = 8 bits.
  • A nibble is 4 bits — half a byte.
  • Since 1 byte alone can't store much, memory is measured in larger multiples.
SI system vs. IEC system
SI unit (base 10)ValueIEC unit (base 2)Value
1 KB1,000 bytes1 KiB2¹⁰ = 1,024 bytes
1 MB1,000,000 bytes1 MiB2²⁰ = 1,048,576 bytes
1 GB1,000,000,000 bytes1 GiB2³⁰ = 1,073,741,824 bytes
1 TB10¹² bytes1 TiB2⁴⁰ bytes

The IEC system is the accurate one, since memory is really organised in powers of 2. Internal memories like RAM and ROM should be measured using IEC units — a 64 GiB RAM stores 64 × 2³⁰ = 68,719,476,736 bytes exactly.

Calculating file size

  • Image file size = image resolution (in pixels) × colour depth (in bits) — giving the size in bits, which you then divide by 8 for bytes.
  • Mono sound file size = sample rate (in Hz) × sample resolution (in bits) × length of sample (in seconds).
  • For a stereo sound file, multiply the mono result by two (there are two audio channels).
Worked example 1 — how many photos fit on a memory stick?

A photograph is 1024 × 1080 pixels, colour depth 32 bits. How many fit on a 64 GiB memory stick?

  1. Total pixels = 1024 × 1080 = 1,105,920 pixels
  2. Bits = 1,105,920 × 32 = 35,389,440 bits → bytes = 35,389,440 / 8 = 4,423,680 bytes
  3. 64 GiB = 64 × 1024 × 1024 × 1024 = 68,719,476,736 bytes
  4. Photos that fit = 68,719,476,736 / 4,423,680 = 15,534 photos
Worked example 2 — audio CD file size

An audio CD: sample rate 44,100 Hz, sample resolution 16 bits, stereo (2 channels), 60-minute recording.

  1. Bits = 44,100 × 16 × (60 × 60) = 2,540,160,000 bits
  2. Stereo → × 2 = 5,080,320,000 bits
  3. Bytes = 5,080,320,000 / 8 = 635,040,000 bytes
  4. MiB = 635,040,000 / 1,048,576 = 605 MiB
Pseudocode — image file size calculatorDECLARE width, height, colourDepth, totalBits, totalBytes : INTEGER INPUT width INPUT height INPUT colourDepth totalBits ← (width * height) * colourDepth totalBytes ← totalBits / 8 OUTPUT "File size in bytes: ", totalBytes
Practice — Test Yourself

These questions only cover what THIS subsection taught — memory units and file size calculations.

Short answer 1
Which system — SI (KB/MB/GB) or IEC (KiB/MiB/GiB) — is the one covered in the syllabus, and why is it considered more accurate?
Reveal answer

The IEC system is the one covered. It's more accurate because memory is genuinely organised in powers of 2, and the IEC system's units (e.g. 1 KiB = 1024 bytes) reflect that exactly, unlike the SI system's base-10 approximation (1 KB = 1000 bytes).

Fill in the blank 2
The formula for an image's file size in bits is: image ______ (in pixels) × colour ______ (in bits).
Reveal answer

Blank 1: resolution. Blank 2: depth.

Fill in the blank pseudocode 3
Complete this pseudocode line that converts a mono sound file size in bits into bytes:
totalBytes ← totalBits ______ 8
Reveal answer

totalBytes ← totalBits / 8 — dividing by 8 converts bits to bytes.

Spot the error 4
A student calculates a stereo sound file's size as: sample rate × resolution × length in seconds — with no further step. What real step have they missed?
Reveal answer

They've forgotten that for a STEREO file, the mono result must be multiplied by 2 (for the two audio channels) — the formula given only calculates the MONO file size on its own.

Applied / scenario 5
A camera detector has an array of 2048 × 2048 pixels and a colour depth of 16 bits. Calculate the size of one image from this camera, in MiB, showing each step.
Reveal answer

1. Total pixels = 2048 × 2048 = 4,194,304 pixels.

2. Bits = 4,194,304 × 16 = 67,108,864 bits.

3. Bytes = 67,108,864 / 8 = 8,388,608 bytes.

4. MiB = 8,388,608 / 1,048,576 = 8 MiB.

Short answer 6
What is "bandwidth", and in what unit is it measured?
Reveal answer

Bandwidth is the maximum rate at which data can be transferred across a network, measured in bits per second.
