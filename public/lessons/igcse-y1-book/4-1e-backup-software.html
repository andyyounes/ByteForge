4.1e Back-up Software
Three copies, three locations — how Windows File History and Mac Time Machine actually protect your data.
Key Terms
Restore point
A saved snapshot of a computer's state at an earlier time, allowing rollback if something goes wrong.
File History
Windows' backup utility — takes snapshots of files at regular intervals onto an external drive.
Time Machine
Mac OS's backup utility — replaces a drive's contents with backed-up data using hourly/daily/weekly backups.
Theory

Why use the OS backup utility (not just manual backups)

  • Manual backups (e.g. to a memory stick) are sensible, but the OS backup utility adds real value: it allows a SCHEDULE for backing up files, and only backs up when there have been actual CHANGES to a file.
  • For total security, three versions of a file should exist: (1) the current working version on the internal HDD/SSD; (2) a LOCAL backup copy (e.g. portable SSD); (3) a REMOTE backup, stored well away from the computer (e.g. cloud storage).

Windows backup facilities

  • RESTORE data/files/the whole computer from a backup — useful if files are lost and need recovery.
  • Create a restore point — a "time machine" letting the computer be restored to an earlier state — very useful if an important file is deleted and can't be recovered any other way.
  • Options to choose WHERE backup files are saved — can be automated to a chosen device.
  • File History: takes snapshots of files at regular intervals onto an external HDD, building up a library of past file versions over time. Defaults to backing up EVERY HOUR, and retains past versions FOREVER unless the user changes this setting.

Mac OS's Time Machine

  • Erases the selected drive's contents and replaces them with the backup's contents.
  • Requires an external HDD/SSD connected via USB, with Time Machine installed and activated.
  • Automatically backs up: EVERY HOUR; DAILY backups for the past month; WEEKLY backups for all months before that.
  • Once the backup drive is almost full, the OLDEST backups are deleted and replaced with the newest data.
Time Machine's backup schedule at a glance

Hourly → most recent backups, high granularity. Daily → for the past month. Weekly → for everything before that. When storage runs low, the OLDEST data is dropped first, keeping the most recent backups intact.

Practice — Test Yourself

These questions only cover what THIS subsection taught — backup software.

Short answer 1
For "total security", what three versions of a file should exist?
Reveal answer

1. The current working version (internal HDD/SSD). 2. A local backup copy (e.g. portable SSD). 3. A remote backup, stored well away from the computer (e.g. cloud storage).

Short answer 2
What is a "restore point", and when would it be especially useful?
Reveal answer

A restore point saves the computer's state at an earlier time, letting it be rolled back to that point. It's especially useful if an important file has been deleted and can't be recovered by any other utility.

Fill in the blank 3
Windows File History backs up by default every ______, and retains past file versions ______ unless the user changes this setting.
Reveal answer

Blank 1: hour. Blank 2: forever.

Spot the error 4
A student claims: "The OS backup utility performs a full backup of every single file, every single time it runs, regardless of whether anything changed." What's wrong with this?
Reveal answer

The lesson explicitly states the OS backup utility only carries out a backup procedure if there have been CHANGES made to a file — it doesn't blindly re-backup unchanged files every time.

Applied / scenario 5
A Mac user's Time Machine backup drive is nearly full, but they keep using it without buying a new one. Using this lesson's content, explain what will happen to their oldest backups.
Reveal answer

Once the backup drive is almost full, the OLDEST backups are automatically deleted and replaced with the newest backup data — so their earliest historical backups will gradually be lost to make room for more recent ones.

Short answer 6
What must be true of a drive before Time Machine can be used with it?
Reveal answer

It must be an external HDD or SSD, connected via USB, with the Time Machine utility installed and activated on the computer.
