5.1a The Internet vs. the World Wide Web, URLs & HTTP(S)
Two genuinely different things people use interchangeably — plus how a web address is actually structured.
Key Terms
Internet
A worldwide collection of INTERconnected NETworks — the physical/logical infrastructure itself.
World Wide Web (WWW)
The collection of web pages/multimedia accessible via a browser — just ONE way of using the internet.
URL
Uniform Resource Locator — the text address typed to access a website.
HTTPS
HTTP with security (SSL/TLS) added — the 's' means secure, often shown with a padlock icon.
Theory

Internet vs. World Wide Web — genuinely different things

  • The internet is a CONCEPT, not something tangible — it's the worldwide collection of interconnected networks/devices, relying on physical infrastructure.
  • The WWW is only PART of the internet, accessed via a browser — a massive collection of web pages, based on the hypertext transfer protocol (HTTP).
  • So the WWW is a WAY of accessing information using the internet — they are NOT the same thing.
Internet
  • Send/receive emails
  • Online chatting (text/audio/video)
  • Uses TCP and IP
  • Worldwide collection of interconnected networks/devices
World Wide Web
  • Collection of multimedia web pages/websites
  • http(s) protocols written using HTML
  • URLs specify web page locations
  • Accessed via web browsers, using the internet to reach web servers

URL structure

  • Format: protocol://website address/path/file name
  • Protocol: usually http or https.
  • Website address: domain host (www), domain name (site name), domain type (.com, .org, .net, .gov), and sometimes a country code (.uk, .de, .cy).
  • Path: the specific web page — often omitted, defaulting to the site's root directory.
  • File name: the specific item on the page.
Worked example — breaking down a URL
https://www.hoddereducation.co.uk/ict

Protocol: https. Website address: www.hoddereducation.co.uk (domain host "www", domain name "hoddereducation", domain type ".co", country code ".uk"). Path: /ict.

HTTP and HTTPS

  • HTTP (HyperText Transfer Protocol): rules that must be obeyed when transferring files across the internet.
  • HTTPS: HTTP WITH security added (SSL or TLS) — the 's' means "secure", offering a more secure way of sending/receiving data. Often shown with a green padlock icon in the browser.
Practice — Test Yourself

These questions only cover what THIS subsection taught — internet vs. WWW, URLs, and HTTP/HTTPS.

Short answer 1
Explain the real difference between "the internet" and "the World Wide Web".
Reveal answer

The internet is the worldwide collection of interconnected networks and devices — the underlying infrastructure. The WWW is only PART of the internet — the collection of web pages accessible via a browser. The WWW is a WAY of using the internet, not the same thing as it.

Short answer 2
What does the "s" in HTTPS stand for, and what does it indicate?
Reveal answer

"Secure" — it indicates the connection uses added security (SSL/TLS), making data transfer more secure than plain HTTP.

Fill in the blank 3
A URL follows the format: ______://website address/______/file name.
Reveal answer

Blank 1: protocol. Blank 2: path.

Spot the error 4
A student claims: "The internet and the World Wide Web are just two different names for exactly the same thing." What's wrong with this?
Reveal answer

They're genuinely different: the internet is the underlying worldwide network infrastructure, while the WWW is only ONE service that runs on top of it — the collection of web pages accessed via browsers using HTTP. The internet ALSO supports other things (email, online chat) that aren't part of the WWW at all.

Applied / scenario 5
A user is sending an email and, separately, browsing a website — both using their internet connection. Using this lesson's content, explain which of these two activities is a WWW activity, and which is not.
Reveal answer

Browsing the website IS a WWW activity — it uses a web browser to access a web page via HTTP(S), exactly what the WWW is. Sending an email is an INTERNET activity but NOT part of the WWW — the lesson lists sending/receiving emails as an internet function, separate from the web-page-based World Wide Web.

Short answer 6
In the URL "https://www.hoddereducation.co.uk/ict", identify the protocol and the path.
Reveal answer

Protocol: https. Path: /ict.
