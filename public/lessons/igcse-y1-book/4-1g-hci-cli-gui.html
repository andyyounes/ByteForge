4.1g Human Computer Interfaces: CLI & GUI
Typing commands vs. clicking icons — the two fundamentally different ways of talking to a computer.
Key Terms
CLI
Command Line Interface — user types instructions to operate the computer.
GUI
Graphical User Interface — user interacts via icons/pictures rather than typed commands.
WIMP
Windows, Icons, Menus, Pointing device — the classic PC GUI model.
Post-WIMP
Touch-based interaction (pinch, rotate) used on phones/tablets, going beyond a single pointer.
Theory

What an operating system provides

  • An OS provides the ENVIRONMENT for applications to run in, and a usable INTERFACE between humans and the computer — disguising the underlying complexity of hardware/software.
  • Common OS examples: Microsoft Windows, Apple Mac OS, Google Android, Apple iOS.
  • Most computers store the OS on HDD/SSD (large programs); phones/tablets use solid-state storage (too small for an HDD).

Command Line Interface (CLI)

  • User TYPES instructions to choose menu options, open software, etc.
  • Requires learning a number of commands for even basic operations — slow, since commands must be typed EVERY time.
  • Advantage: direct communication with the computer — NOT restricted to pre-determined options.

Graphical User Interface (GUI)

  • User interacts via PICTURES/ICONS instead of typed commands — simply selecting an icon loads the application.
  • WIMP (Windows, Icons, Menus, Pointing device): the classic PC GUI model — a mouse controls a cursor to select icons and open/run windows. A "windows manager" oversees interaction between windows, applications, pointing devices, and cursor position.
  • Post-WIMP: increasingly used on phones/tablets — fingers touch the screen directly, enabling pinching/rotating gestures a single mouse pointer couldn't easily do.
CLI vs. GUI — full comparison
CLIGUI
Direct communication with the computerNo commands to learn
Not restricted to pre-determined optionsMore user-friendly (icons represent applications)
Can alter configuration settingsSimpler: click an icon (or touch it) to launch an app
Uses a SMALL amount of memoryUses considerably MORE memory than CLI
Must learn commands for basic operationsLimited to the icons provided on screen
Typing takes time and can be error-proneNeeds an OS (e.g. Windows) — uses considerable memory
Commands must be typed with correct format/spelling

Who uses which interface?

  • CLI: programmers, analysts, technicians — anyone needing direct computer communication to develop software, locate/remove errors, initiate memory dumps, etc.
  • GUI: everyday end-users who don't need (or want) deep computer knowledge — running software, playing games, managing photos, etc.
Practice — Test Yourself

These questions only cover what THIS subsection taught — CLI, GUI, WIMP, and post-WIMP interfaces.

Short answer 1
Name one advantage and one disadvantage of a CLI.
Reveal answer

Advantage (any one): direct communication with the computer; not restricted to pre-determined options; can alter configuration settings; uses less memory. Disadvantage (any one): must learn commands; typing takes time and is error-prone; must match exact format/spelling.

Short answer 2
What does the acronym WIMP stand for?
Reveal answer

Windows, Icons, Menus, Pointing device.

Fill in the blank 3
A GUI uses considerably ______ memory than a CLI, since it needs a full ______ (e.g. Windows) to operate.
Reveal answer

Blank 1: more. Blank 2: operating system.

Spot the error 4
A student claims: "GUIs are always the better choice for every user, since CLIs have no real advantages left." What's wrong with this?
Reveal answer

CLIs have genuine advantages: direct computer communication (useful for programmers/technicians developing software or diagnosing errors), freedom from pre-determined menu options, the ability to alter configuration settings, and lower memory use. The right choice depends on the USER — a technician needing deep control benefits from CLI, while an everyday end-user benefits from GUI.

Applied / scenario 5
A systems technician needs to diagnose a server error by directly examining memory contents and running precise diagnostic commands. A separate office worker just wants to open a spreadsheet and browse photos. Which interface — CLI or GUI — suits each person, and why, using this lesson's content?
Reveal answer

Technician: CLI — the lesson explicitly identifies technicians as CLI users, needing direct computer communication to locate/remove errors and initiate memory dumps. Office worker: GUI — the lesson identifies GUI as suited to end-users who don't need deep computer knowledge, running everyday software like spreadsheets or photo viewers.

Short answer 6
What real interaction does "post-WIMP" allow on touchscreens that classic WIMP (with a mouse) struggles with?
Reveal answer

Multi-finger gestures like pinching and rotating — actions that are difficult to perform with a single mouse pointer, but natural when fingers directly touch the screen.
