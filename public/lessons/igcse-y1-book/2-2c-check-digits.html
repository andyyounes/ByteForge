2.2c Check Digits
The final digit that catches mis-typed barcodes and product codes — using two real algorithms: ISBN-13 and Modulo-11.
Key Terms
Check digit
The final digit in a code, calculated from all the other digits, used to catch data-entry errors.
Transposition error
Two digits swapping order by mistake, e.g. 5037 typed instead of 5307.
ISBN-13
A 13-digit book identification code whose 13th digit is a check digit, calculated from the other 12.
Modulo-11
A check-digit method usable on numbers of varying length, using positional weightings (8,7,6,...) and division by 11.
Theory

What check digits catch

  • Check digits are used on barcodes such as ISBNs (books) and VINs (vehicles) to catch data-entry errors from mis-typing or mis-scanning.
  • They typically catch: an incorrect digit (5327 instead of 5307); a transposition error (5037 instead of 5307); omitted or extra digits (537 or 53107 instead of 5307); and phonetic errors (13 instead of 30).
ISBN-13 — generating the check digit

Algorithm: (1) add all odd-positioned digits; (2) add all even-positioned digits, ×3; (3) add both totals, ÷10; (4) if remainder is 0, that's the check digit — otherwise, check digit = 10 − remainder.

Worked example, using ISBN 978034098382 (12 digits, no check digit yet):

  1. Odd digits: 9+8+3+0+8+8 = 36
  2. Even digits ×3: 3 × (7+0+4+9+3+2) = 3 × 25 = 75
  3. (36 + 75) / 10 = 111/10 = 11 remainder 1
  4. 10 − 1 = 9 (the check digit)

Final 13-digit ISBN: 9780340983829

ISBN-13 — verifying a 13-digit code

Algorithm: (1) add all odd-positioned digits INCLUDING the check digit; (2) add even-positioned digits ×3; (3) add both totals, ÷10; (4) code is correct if remainder = 0.

Using the full 13-digit ISBN 9780340983829:

  1. Odd digits (incl. check digit): 9+8+3+0+8+8+9 = 45
  2. Even digits ×3: 3 × (7+0+4+9+3+2) = 75
  3. (45 + 75) / 10 = 120/10 = 12 remainder 0
  4. Remainder is 0 → the number is correct.
Modulo-11 — generating the check digit

Algorithm (for a 7-digit number): (1) weight each digit 8,7,6,5,4,3,2 from the left; (2) multiply each digit by its weighting and sum; (3) divide the total by 11; (4) check digit = 11 − remainder (if remainder is 10, use 'X').

Worked example, using 7-digit number 4156710:

  1. (8×4)+(7×1)+(6×5)+(5×6)+(4×7)+(3×1)+(2×0) = 32+7+30+30+28+3+0 = 130
  2. 130 / 11 = 11 remainder 9
  3. 11 − 9 = 2 (the check digit)

Final 8-digit number: 41567102

Modulo-11 — verifying an 8-digit code

Algorithm: (1) weight each digit 8,7,6,5,4,3,2,1 from the left (now including the check digit); (2) multiply and sum; (3) divide by 11; (4) correct if remainder = 0.

Using 8-digit number 41567102:

  1. (8×4)+(7×1)+(6×5)+(5×6)+(4×7)+(3×1)+(2×0)+(1×2) = 32+7+30+30+28+3+0+2 = 132
  2. 132 / 11 = 12 remainder 0
  3. Remainder is 0 → the number is correct.
Practice — Test Yourself

These questions only cover what THIS subsection taught — check digits (ISBN-13 and Modulo-11).

Short answer 1
What is a "transposition error", and give the example from this lesson.
Reveal answer

A transposition error is when two adjacent digits swap places by mistake — e.g. 5037 entered instead of the correct 5307.

Short answer 2
In the Modulo-11 method, what special check digit is used if the calculation produces a remainder of 10?
Reveal answer

The letter 'X' is used as the check digit.

Fill in the blank 3
In ISBN-13's generation algorithm, if the remainder after step 3 is NOT zero, the check digit = ______ − remainder.
Reveal answer

10 − remainder.

Spot the error 4
A student verifying an ISBN-13 code gets a remainder of 3 in the final step, and concludes: "The remainder isn't 0, so I need to recalculate the check digit and use 10 minus 3." What's wrong with this reasoning?
Reveal answer

The "10 − remainder" step only applies when GENERATING a new check digit from the 12 other digits. During VERIFICATION of a full 13-digit code (already including its check digit), a non-zero remainder simply means the code is INCORRECT — there is no recalculation step; it just fails the check.

Applied / scenario 5
A 7-digit product code is 3216450. Using the Modulo-11 method (weightings 8,7,6,5,4,3,2), calculate its check digit, showing each step.
Reveal answer

1. (8×3)+(7×2)+(6×1)+(5×6)+(4×4)+(3×5)+(2×0) = 24+14+6+30+16+15+0 = 105.

2. 105 / 11 = 9 remainder 6.

3. 11 − 6 = 5 (the check digit). Final 8-digit code: 32164505.

Short answer 6
Name one real product/document type (besides books) that uses check digits, according to this lesson.
Reveal answer

Vehicle Identification Numbers (VINs) — also, product barcodes generally.
