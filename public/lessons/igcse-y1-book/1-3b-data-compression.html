1.3b Why Compress, and Lossy Compression
Why files get compressed, and how lossy algorithms (MP3, MP4, JPEG) shrink files by discarding data the human eye or ear won't miss.
Key Terms
Data compression
Reducing the size of a file so it takes up less storage space and/or transfers faster.
Lossy compression
Compression that permanently discards some data — the original file can never be reconstructed exactly.
Perceptual music shaping
MP3's technique of removing sounds the human ear can't perceive, e.g. a softer sound masked by a louder one played at the same time.
JPEG
A lossy compression algorithm for bitmap images, exploiting the eye's lower sensitivity to colour vs. brightness changes.
Theory

Why compress files at all?

  • Sound and image files can be very large (as the previous lesson's calculations showed), so compression is needed to:
  • Save storage space on devices like hard disk drives/solid state drives.
  • Reduce the time taken to stream a music or video file.
  • Reduce the time to upload, download, or transfer a file across a network.
  • Reduce bandwidth use — bandwidth is the maximum data transfer rate across a network (bits per second); compressed files contain fewer bits, so they use less bandwidth and transfer faster.
  • Reduce costs — cloud storage is often priced by file size, and an ISP may charge based on data downloaded.

Lossy file compression

  • Lossy compression eliminates data the algorithm judges "unnecessary" from the file — meaning the ORIGINAL file can never be reconstructed once compressed.
  • This results in some real loss of detail compared to the original — the algorithm decides which parts to keep and which to discard.
  • For an image, lossy compression may reduce the resolution and/or the colour depth.
  • For a sound file, it may reduce the sampling rate and/or the sampling resolution.
  • Lossy files end up smaller than lossless files — a real benefit for storage and transfer speed, at the cost of some quality.
MP3 / MP4 — lossy sound compression

MP3 reduces a normal music file's size by about 90%. MP3 audio can never fully match CD/DVD quality, but it's satisfactory for most general purposes.

How it works: the algorithm removes sounds the human ear genuinely can't perceive properly —

• Sounds outside the human ear's audible range are removed.

• If two sounds play at the same time, only the louder one is actually perceived, so the softer one is discarded (this is called perceptual music shaping).

MP4 is a related format that stores multimedia — music, video, photos, animation — not just sound. It's also lossy, but retains acceptable quality; movies can be streamed via MP4 without noticeable quality loss.

JPEG — lossy image compression

A camera's raw bitmap file can be very large and is only temporary. JPEG compresses it — once compressed, the original raw file can no longer be reconstructed.

JPEG's compression is based on two key facts:

• Human eyes are LESS sensitive to differences in colour shade than to differences in brightness.

• By separating colour from brightness, the image is split into blocks (e.g. 8×8 pixels), letting certain colour "information" be discarded within each block without any real noticeable quality loss.

Lossy compression is a one-way street — data is genuinely discarded, so there's no path back to the exact original file.
Practice — Test Yourself

These questions only cover what THIS subsection taught — why files are compressed, and lossy compression (MP3/MP4/JPEG).

Short answer 1
Give TWO real reasons why files are compressed.
Reveal answer

Any two of: save storage space; reduce streaming time; reduce upload/download/transfer time; reduce bandwidth use; reduce storage/download costs.

Short answer 2
What is "perceptual music shaping" in MP3 compression?
Reveal answer

When two sounds play at the same time, only the louder one is actually perceived by the human ear — so MP3's algorithm discards the softer, masked sound, since removing it causes no perceptible quality loss.

Fill in the blank 3
MP3 compression typically reduces a normal music file's size by about ______%.
Reveal answer

90%.

Spot the error 4
A student writes: "JPEG compression works by reducing the number of pixels in an image." What real mechanism does this miss?
Reveal answer

JPEG's real mechanism is based on the eye being less sensitive to colour than brightness — it separates colour from brightness and discards colour "information" within pixel blocks (e.g. 8×8), NOT by simply reducing the pixel count. Reducing resolution is a different, separate technique (mentioned for lossy compression generally, not JPEG's specific mechanism).

Applied / scenario 5
A video-streaming service wants to deliver movies quickly over average home internet connections, accepting some quality trade-off. Would MP4 be an appropriate lossy format here? Justify your answer using this lesson's content.
Reveal answer

Yes — the lesson states that MP4 is a lossy format that stores multimedia (video, music, photos), and that movies can genuinely be streamed via MP4 without any noticeable quality loss, while still benefiting from the smaller file size lossy compression provides. This directly matches the service's needs (fast delivery, acceptable quality trade-off).

Short answer 6
Why can the original file never be reconstructed after lossy compression?
Reveal answer

Because the lossy algorithm permanently eliminates data it judges unnecessary — that data is genuinely gone, not just hidden, so there's no way to recover the exact original file afterward.
