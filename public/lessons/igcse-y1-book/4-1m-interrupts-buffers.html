4.1m Interrupts & Buffers
The signal that pauses the CPU, and the memory area that keeps slow devices from freezing everything up.
Key Terms
Interrupt
A signal from a device or software telling the CPU to temporarily stop its current task and service the interrupt.
Buffer
A memory area temporarily storing data, compensating for speed mismatches between devices.
ISR
Interrupt Service Routine — the code executed to handle a specific interrupt.
Theory

What causes an interrupt

  • A timing signal.
  • An I/O process needing attention (e.g. a disk drive/printer needing more data).
  • A hardware fault (e.g. printer paper jam).
  • User interaction (e.g. pressing CTRL+ALT+BREAK).
  • Software errors (e.g. a missing .exe file, two processes fighting for the same memory location, dividing by zero).

How an interrupt is serviced

  • The computer identifies the interrupt TYPE and establishes its PRIORITY.
  • The current task's status is SAVED — the Program Counter (PC) and other register contents are stored.
  • The Interrupt Service Routine (ISR) is executed — its start address is loaded into the PC.
  • Once fully serviced, the interrupted task's status is RESTORED (saved registers retrieved), and the process continues.

Why buffers exist

  • Interrupts let a computer appear to run multiple tasks "simultaneously" — e.g. downloading a file while listening to music. In reality, data is rapidly passed in/out of memory, servicing both.
  • A buffer is a memory area storing data temporarily — needed whenever two devices/processes work at genuinely different SPEEDS.
  • Example: streaming a movie — the transmission rate from web server to buffer must be FASTER than the rate the buffer feeds the media player, otherwise the movie would constantly freeze.
Interrupts + buffers together — printing a document
  1. Data from the document is sent to the (printer) buffer from computer memory
  2. The processor is FREE to carry out other tasks while the buffer empties to the printer
  3. The buffer's contents are emptied to the printer and printed
  4. Once all data is printed, the buffer is empty — an INTERRUPT signal is sent to request more data
  5. The current task is suspended while the interrupt is serviced (more data sent to buffer)
  6. This repeats until all document data has been sent — then the processor continues fully with other tasks
The buffer absorbs the speed mismatch — the CPU writes fast, the printer drains slowly, and neither has to wait for the other directly.

Why this matters — maximising CPU efficiency

  • Printing takes MUCH longer than sending data to the printer. Without buffers/interrupts, the microprocessor would sit IDLE waiting for printing to finish — a huge waste of processing power.
  • Buffers + interrupts let the microprocessor carry on with OTHER tasks while the buffer empties, maximising both processing power and speed.
Practice — Test Yourself

These questions only cover what THIS subsection taught — interrupts and buffers.

Short answer 1
Give two real causes of an interrupt.
Reveal answer

Any two of: a timing signal; an I/O process needing attention; a hardware fault; user interaction (e.g. a key combination); a software error.

Short answer 2
Why is a buffer needed when streaming a movie from the internet?
Reveal answer

Because the download speed and the media player's playback speed are genuinely different rates — the buffer compensates for this mismatch, storing incoming data temporarily so playback doesn't freeze, as long as the incoming rate stays faster than the playback rate.

Fill in the blank 3
When an interrupt occurs, the contents of the ______ and other registers are saved first, then the ______ is executed to handle it.
Reveal answer

Blank 1: Program Counter (PC). Blank 2: Interrupt Service Routine (ISR).

Spot the error 4
A student claims: "Without buffers, printing a document would just take slightly longer, but nothing else would really change." What real cost does this ignore?
Reveal answer

Without buffers (and interrupts), the microprocessor would sit COMPLETELY IDLE the entire time printing was happening — since printing takes far longer than sending data to the printer, this would be an enormous waste of processing power, not just a minor slowdown to the printing itself.

Applied / scenario 5
A user is printing a large document while simultaneously browsing the web. Using this lesson's content, explain how buffers and interrupts together let both tasks happen without the computer freezing.
Reveal answer

Document data is sent to the printer BUFFER from memory, and the buffer feeds the (slow) printer while the processor is freed up to work on other tasks — like the web browser. Once the buffer empties, an INTERRUPT is sent requesting more data; the browsing task is briefly suspended while this interrupt is serviced (buffer refilled), then both tasks continue — giving the impression they're running simultaneously.

Short answer 6
Name two things the computer must establish once an interrupt signal is received.
Reveal answer

The interrupt TYPE, and its PRIORITY level.
