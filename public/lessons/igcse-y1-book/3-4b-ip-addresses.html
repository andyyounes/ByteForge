3.4b Internet Protocol (IP) Addresses
Public vs. private, IPv4 vs. IPv6, static vs. dynamic — and how an IP address differs from a MAC address.
Key Terms
Private IP address
Assigned by a router, unique WITHIN that network only.
Public IP address
Assigned by the ISP, unique across the ENTIRE internet.
IPv4 / IPv6
32-bit denary (four groups) vs. 128-bit hex (eight groups) IP address formats.
DHCP
Dynamic Host Configuration Protocol — automatically assigns a dynamic IP address each time a device connects.
Theory

Private vs. public IP addresses

  • When a device connects to a PRIVATE network, a router assigns it a private IP — unique on THAT network only (it could match an IP on a different network).
  • When the router itself connects to the internet, it gets a unique PUBLIC IP address (usually from the ISP) — no other device on the internet shares it.
  • All devices behind one router share the SAME public IP, but each has its OWN different private IP within that network.
IPv4 vs. IPv6
IPv4IPv6
32 bits128 bits
Four groups of 8 bits (denary), e.g. 254.25.28.77Eight groups of hex digits, e.g. A8FB:7A88:FFF0:0FFF:3D21:2085:66FB:F0FA
Limited address space — running out of unique addressesVastly larger address space, built for internet growth

IPv6 advantages: removes IP address COLLISION risk; built-in AUTHENTICATION checks; more EFFICIENT packet routing.

MAC address vs. IP address

  • MAC identifies the PHYSICAL device on a network; IP identifies the GLOBAL address on the internet.
  • MAC is unique for the device on its network; an IP address may NOT necessarily be unique (private IPs can repeat across different networks).
  • MAC is assigned by the MANUFACTURER (part of the NIC); dynamic IP is assigned by the ISP via DHCP each time a device connects.
  • MAC uses 48 bits; IP uses either 32 bits (IPv4) or 128 bits (IPv6).
  • MAC identifies sender/recipient DEVICES when a packet is sent; IP is used in ROUTING (identifying where a device connects to the internet).

Static vs. dynamic IP addressing

  • Static IP: permanently assigned by the ISP — doesn't change. Commonly used for: web-hosting servers, online databases, FTP servers.
  • Dynamic IP: assigned by the ISP via DHCP EACH time a device connects — can be different every time.
Dynamic IP
  • Greater privacy (changes each login)
  • Can be an issue for VoIP (less reliable, can disconnect/change mid-call)
  • Allows faster upload/download speeds
Static IP
  • Fully traceable (never changes)
  • More expensive to maintain (device must run constantly)

How dynamic IP addressing works in practice

  • Device requests an IP address → a DHCP server assigns a temporary IP and sends it back.
  • Device wants a webpage (e.g. hoddereducation.com) → a DNS server translates the URL into an IP address and sends it back.
  • Device sends a request to that IP → the website server sends the requested webpage back.
Practice — Test Yourself

These questions only cover what THIS subsection taught — IP addresses (IPv4/IPv6, static/dynamic, vs. MAC).

Short answer 1
What is the key difference between a private and a public IP address?
Reveal answer

A private IP is unique only WITHIN its own network (could match an address on another network). A public IP is unique across the ENTIRE internet — no other device anywhere shares it.

Short answer 2
Name two advantages of IPv6 over IPv4.
Reveal answer

Any two of: removes IP address collision risk; built-in authentication checks; more efficient packet routing (plus its much larger overall address space).

Fill in the blank 3
A ______ IP address is assigned via DHCP every time a device connects; a ______ IP address stays the same permanently.
Reveal answer

Blank 1: dynamic. Blank 2: static.

Spot the error 4
A student claims: "A MAC address and an IP address are basically the same thing, just written in different formats." What real distinctions does this ignore?
Reveal answer

They serve genuinely different purposes: MAC identifies the PHYSICAL device on a network (assigned by the manufacturer, 48 bits, always unique to that device); IP identifies the device's GLOBAL address on the internet (assigned by the ISP, can be 32 or 128 bits, and may NOT be unique across different networks if private). MAC is used to identify sender/recipient devices for a packet; IP is used for routing.

Applied / scenario 5
A company is setting up a public-facing website that must always be reachable at the exact same address, and also wants to use VoIP calling for staff, prioritising call reliability. Recommend static or dynamic IP addressing for EACH use case, and justify your answers.
Reveal answer

Website server: static IP — the lesson lists web-hosting servers as a typical static IP use case, since it must remain consistently reachable at the same address.

VoIP: static IP is also better here — the lesson explicitly states dynamic IP addressing can cause VoIP connections to fail, since the connection can disconnect and the IP change mid-call; static IP avoids this reliability issue.

Short answer 6
What role does a DNS server play when a device wants to visit a website by typing its URL?
Reveal answer

The DNS server translates the human-readable website URL into the actual IP address of the website's server, and sends that IP address back to the device so it can request the webpage.
