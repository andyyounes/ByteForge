6.3b Expert Systems
Knowledge base + rules base + inference engine = a computer that reasons like a human specialist.
Key Terms
Expert system
A computer system mimicking the decision-making ability and expert knowledge of a human specialist.
Knowledge base
A repository of facts — a collection of objects and their attributes.
Rules base
A set of inference rules (often IF-THEN statements) the inference engine uses to draw conclusions.
Inference engine
The main processing element — searches the knowledge base using the rules base to find matches.
Theory

What an expert system does

  • Uses knowledge and inference to solve problems that would normally need a human expert — e.g. asking a series of symptom questions to diagnose a patient, then explaining its reasoning.
  • Supplies a CONCLUSION, suggested ACTIONS, and a PROBABILITY of the conclusion's accuracy (e.g. "the probability of finding oil-bearing rocks here is about 21%").
  • Real applications: oil/mineral prospecting, patient illness diagnosis, mechanical/electronic fault diagnostics, tax/financial calculations, strategy games (chess), delivery logistics, identifying plants/animals/chemical compounds.
Expert system advantages
  • High level of expertise and accuracy
  • Consistent results
  • Can store vast amounts of ideas/facts
  • Traceable, logical solutions/diagnostics
  • Can hold MULTIPLE areas of expertise
  • Very fast response — much quicker than a human expert
  • Unbiased reporting/analysis
  • Indicates the probability of a solution being correct
Expert system disadvantages
  • Needs considerable user training to use correctly
  • Very high set-up/maintenance costs
  • Can give "cold" responses — inappropriate in some medical situations
  • Only as good as the facts entered into it
  • Users can dangerously assume it's infallible

Expert system structure

  • User interface: how the user interacts (dialogue boxes, prompts) — usually simple Yes/No or multiple-choice questions, each based on previous answers.
  • Inference engine: the main processing element — acts like a search engine over the knowledge base, gathering information via a series of questions, using the rules base to find matching objects.
  • Knowledge base: a repository of facts — a collection of OBJECTS and their ATTRIBUTES.
  • Rules base: inference rules mimicking human reasoning, typically as IF-THEN statements, e.g. IF continent="South America" AND language="Portuguese" THEN country="Brazil".

Setting up an expert system

  • Gather information from human experts/written sources.
  • Populate the KNOWLEDGE BASE with this data.
  • Build the RULES BASE (inference rules).
  • Set up the INFERENCE ENGINE (the main, complex processing element).
  • Develop the USER INTERFACE.
  • TEST thoroughly using known outcomes, adjusting as needed.
Practice — Test Yourself

These questions only cover what THIS subsection taught — expert systems.

Short answer 1
What is the difference between the knowledge base and the rules base in an expert system?
Reveal answer

The knowledge base is a repository of FACTS (objects and their attributes). The rules base is a set of INFERENCE RULES (often IF-THEN statements) used by the inference engine to draw conclusions from that knowledge.

Short answer 2
What role does the inference engine play in an expert system?
Reveal answer

It's the main PROCESSING element — it acts like a search engine, examining the knowledge base for matches, gathering information via a series of questions, and applying the rules base's inference rules to reach a conclusion.

Fill in the blank 3
An expert system's conclusions include a suggested action and a ______ indicating how accurate the conclusion is likely to be.
Reveal answer

Probability (percentage).

Spot the error 4
A student claims: "An expert system's diagnosis is always correct, since it's based on expert knowledge." What real disadvantage from this lesson contradicts this?
Reveal answer

The lesson explicitly states an expert system is only as GOOD as the information/facts entered into it, and warns that users can dangerously assume it's INFALLIBLE — its expertise is genuinely limited by the quality of its knowledge base, not guaranteed to be correct.

Applied / scenario 5
Using the animal knowledge base table in this lesson, a user answers: Is it a mammal? NO. Does it live in water? YES. What conclusion should the expert system reach, and why?
Reveal answer

Duck — of the three objects in the knowledge base, only the duck is NOT a mammal AND lives in water; dog is a mammal (fails the first condition) and whale is a mammal too (also fails), so duck is the only matching object.

Short answer 6
Name two real applications of expert systems mentioned in this lesson.
Reveal answer

Any two of: oil/mineral prospecting, patient illness diagnosis, equipment fault diagnostics, tax/financial calculations, chess strategy, delivery logistics, identifying plants/animals/compounds.
