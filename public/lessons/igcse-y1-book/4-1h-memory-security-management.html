4.1h Memory & Security Management (Operating Systems)
Two more essential OS jobs — stopping applications from colliding in memory, and keeping data confidential and intact.
Key Terms
Memory protection
Ensuring two competing applications cannot use the same memory location at the same time.
Integrity
Data being accurate and unaltered.
Confidentiality
Data being accessible only to those authorised to see it.
Privilege
Access-level restrictions preventing users from entering "private areas" they aren't authorised for.
Theory

Memory management

  • Manages primary storage (RAM), moving data between RAM and HDD/SSD as programs run.
  • Keeps track of ALL memory locations currently in use.
  • Carries out memory protection — ensuring two competing applications can never use the SAME memory location at the same time.
  • Without memory protection, real problems could occur: data loss; applications producing WRONG results (using incorrect data in memory); SECURITY issues (data in the wrong location becoming accessible to other software); and in extreme cases, a system CRASH.

Security management

  • Ensures the INTEGRITY, CONFIDENTIALITY, and AVAILABILITY of data. Achieved by:
  • Carrying out OS updates as they become available.
  • Keeping anti-virus/security software up to date, preserving data integrity/security/privacy.
  • Communicating with a FIREWALL to check all traffic to/from the computer.
  • Using PRIVILEGES to prevent users entering "private areas" on multi-user computers (via user accounts, passwords, user IDs) — protecting data privacy.
  • Maintaining ACCESS RIGHTS for all users.
  • Offering data RECOVERY (and system restore) if data is lost/corrupted.
  • Helping prevent ILLEGAL INTRUSION into the system — also protecting data privacy.
Practice — Test Yourself

These questions only cover what THIS subsection taught — memory management and security management.

Short answer 1
What is "memory protection", and why does it matter?
Reveal answer

Memory protection ensures two competing applications cannot use the SAME memory location at the same time. Without it, data could be lost, applications could give wrong results, security issues could arise (data accessible to unauthorised software), or the computer could crash.

Short answer 2
Name three things security management aims to ensure about data.
Reveal answer

Its integrity, confidentiality, and availability.

Fill in the blank 3
Security management uses ______ — via user accounts, passwords, and user IDs — to prevent users entering "private areas" on a multi-user computer.
Reveal answer

Privileges.

Spot the error 4
A student claims: "If memory protection fails and two applications overlap in memory, the worst that could happen is one program runs a bit slower." What does this ignore?
Reveal answer

This significantly understates the real risks: the lesson lists data LOSS, applications producing genuinely INCORRECT results, real SECURITY issues (unauthorised access to misplaced data), and in extreme cases a full system CRASH — not just a minor slowdown.

Applied / scenario 5
A shared family computer has separate accounts for each family member. One child tries to access a parent's private financial documents stored on the same machine. Using this lesson's content, explain what OS feature would normally prevent this.
Reveal answer

Privileges, set up via user accounts, passwords, and user IDs, as part of security management. These are specifically designed to prevent users from entering "private areas" on a multi-user computer, protecting the parent's private files from the child's account.

Short answer 6
Name one way security management helps if data is lost or corrupted.
Reveal answer

It offers data RECOVERY (and system restore) capabilities.
