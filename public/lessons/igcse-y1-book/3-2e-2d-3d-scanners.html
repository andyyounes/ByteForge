3.2e Input Devices: 2D & 3D Scanners
From flatbed document scanning and OCR to full 3D object scanning and CT/MRI imaging.
Key Terms
2D scanner
Scans flat, hard-copy documents into an electronic image, using a scan head, mirrors, lens, and CCD.
OCR
Optical Character Recognition — converts a scanned image of text into an editable text file.
3D scanner
Scans a solid object across x, y, z coordinates to build a 3D digital image.
Tomography
Building a 3D image from a series of thin 2D "slices" — used in CT, MRI, and SPECT scanners.
Theory

How a 2D scanner works

  • Cover raised → document placed on glass panel → cover closed.
  • A bright light (xenon lamp or LED) illuminates the document.
  • A scan head moves across the document; the image is sent via a series of mirrors to a lens, which focuses it.
  • The focused image falls onto a CCD — made of thousands of light-sensitive pixels, each generating an electric charge when light hits it, turning the image into electronic form.
  • Software then produces a digital image from this electronic data.
  • With OCR software, scanned TEXT can be converted into an editable text file (importable into a word processor). A scanned photo/image instead simply becomes an image file (e.g. JPEG).
Real application — airport passport scanning

2D scanners with OCR read passport pages, automatically placing extracted text into the correct database fields (often stored as ASCII).

The passport photo is scanned/stored as a JPEG. A live 2D photo of the passenger is also taken. FACE RECOGNITION software compares key facial positions between the two images — e.g. distance between the eyes, nose width, cheekbone shape, jaw line length, eyebrow shape — to check if they represent the SAME face.

3D scanners

  • 3D scanners capture a solid object across its x, y, and z coordinates, forming a full digital 3D image.
  • Used in computer-aided design (CAD), or sent to a 3D printer to produce a physical model.
  • Many underlying technologies exist: lasers, magnetic resonance, white light, etc.

Tomography — building 3D images from 2D "slices"

  • Tomography builds a 3D image of a solid object from a series of very thin 2D "slices". Each slice is stored as a digital image, and together they represent the whole object.
  • Each slice can be produced using different imaging methods — this is what distinguishes CT, MRI, and SPECT.

Practice — Test Yourself

These questions only cover what THIS subsection taught — 2D and 3D scanners.

Short answer 1
What does OCR software allow you to do with a scanned document that a plain image file wouldn't?
Reveal answer

OCR converts scanned text into an EDITABLE text file format — the text can then be imported into a word processor and edited/manipulated, unlike a plain image which is just a picture of the text.

Short answer 2
Why does a 3D scanner need to capture data across x, y, AND z coordinates, unlike a 2D scanner?
Reveal answer

A solid object has depth as well as width and height — genuinely three dimensions — so capturing it fully requires images at multiple points along all three (x, y, z) coordinates, not just a flat 2D surface.

Fill in the blank 3
A CT scanner uses ______, while an MRI uses ______, and a SPECT scanner uses gamma rays.
Reveal answer

Blank 1: X-rays. Blank 2: radio frequencies.

Spot the error 4
A student claims: "A CT scanner takes one single image of the whole object at once, just like a photo." What real process does this misunderstand?
Reveal answer

A CT scanner (like other tomographic scanners) builds up the 3D image from a SERIES of very thin 2D "slices" — it does NOT capture the whole object in one single image. Each slice is stored separately as a digital image, and together they represent the full solid object.

Applied / scenario 5
At airport passport control, the system needs to confirm the person standing at the gate matches their passport photo. Using this lesson's content, describe the process the system uses to do this.
Reveal answer

The passport's photo page is scanned (often stored as a JPEG), and a live 2D photo of the passenger is also taken with a digital camera. Face recognition/detection software then compares KEY facial positions between the two images — e.g. distance between the eyes, nose width, cheekbone shape, jaw line length, eyebrow shape — to determine whether both images represent the same face.

Short answer 6
Name two real applications of a 3D digital scan, according to this lesson.
Reveal answer

Computer-aided design (CAD), and producing a physical model via a 3D printer.
