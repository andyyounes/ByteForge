3.4c Routers
The device that translates between networks — using IP addresses to find the right switch, and MAC addresses to find the right device.
Key Terms
Router
Connects and routes data packets between different networks (e.g. a LAN to a WAN), converting protocols/formats as needed.
Switch
Delivers data to the correct device on a LAN, using its MAC address.
Firewall
Protects the computers on a network; broadband routers typically sit behind one.
Theory

What routers do

  • Routers enable data packets to move BETWEEN different networks — e.g. connecting a LAN to a WAN.
  • A router takes data in one network's format/protocol and CONVERTS it to a format the other network understands, allowing them to communicate.
  • A typical router has an internet cable plugged in, plus several cables to computers/devices on the LAN.
  • Broadband routers sit BEHIND a firewall, which protects the network's computers. The router's main job: transmit internet/transmission protocols between two networks, and connect private networks together.
Router flow: internet → router (protocol conversion) → switch (uses IP to find the right switch, MAC to find the right device) → LAN devices.

How a router delivers a packet to the right device

  • Routers INSPECT the data packet sent from any connected computer/network.
  • Since every device on the same network shares part of the same IP address structure, the router sends the packet to the correct SWITCH.
  • The switch then delivers the packet to the correct DEVICE using its MAC destination address.
  • If a MAC address doesn't match any device on that switch, the packet is passed to ANOTHER switch on the same network, until the right device is found.
  • Routers can be WIRED or WIRELESS devices.
Practice — Test Yourself

These questions only cover what THIS subsection taught — routers.

Short answer 1
What is the core function of a router?
Reveal answer

To enable data packets to be routed BETWEEN different networks (e.g. connecting a LAN to a WAN), converting the data's format/protocol so the two networks can communicate.

Short answer 2
Once a router has directed a packet to the correct switch, what address does the switch use to find the exact right device?
Reveal answer

The device's MAC destination address.

Fill in the blank 3
Broadband routers typically sit ______ a firewall, which protects the ______ on the network.
Reveal answer

Blank 1: behind. Blank 2: computers.

Spot the error 4
A student claims: "A router alone delivers a packet all the way to the exact correct device, using only the IP address." What real step does this miss?
Reveal answer

The router uses the IP address to find the correct SWITCH, but it's the SWITCH — not the router — that then delivers the packet to the exact correct device, using its MAC destination address. There are genuinely two separate steps here, using two different address types.

Applied / scenario 5
A switch receives a packet from a router, but the destination MAC address doesn't match any device currently connected to that switch. Using this lesson's content, explain what happens next.
Reveal answer

The packet is passed on to ANOTHER switch on the same network, and this continues until a switch is found where a device's MAC address actually matches the destination — at which point the packet is delivered to that device.

Short answer 6
Can a router be wireless? What form can routers take, according to this lesson?
Reveal answer

Yes — routers can be either WIRED or WIRELESS devices.
