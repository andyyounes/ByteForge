4.1d Defragmentation Software
Watching a hard disk gradually scatter itself, sector by sector — and how a defragmenter tidies it back up.
Key Terms
Contiguous
Meaning "next to each other" — sectors storing a file with no gaps or scattering.
Defragmenter
Software that rearranges disk blocks to store files in contiguous sectors wherever possible.
Theory

Why fragmentation happens

  • As an HDD fills up, blocks used for files become scattered across the disk (different sectors, tracks, even surfaces) — this happens naturally as files are deleted, partially deleted, and extended over time.
  • Result: SLOWER data access, since the read-write head needs several movements to find and retrieve all of a file's scattered pieces.
  • Storing files in contiguous sectors (next to each other) would considerably reduce head movements — this is exactly what defragmentation aims to achieve.
  • Note: this is NOT a problem for SSDs, due to their fundamentally different (no moving parts) way of accessing data.

Practice — Test Yourself

These questions only cover what THIS subsection taught — defragmentation software.

Short answer 1
What does "contiguous" mean in the context of disk sectors?
Reveal answer

"Contiguous" means "next to each other" — a file's sectors are stored adjacently, with no gaps or scattering.

Short answer 2
Why does an HDD's data access get slower as fragmentation increases?
Reveal answer

When a file's data is scattered across many non-adjacent sectors (and even different tracks/surfaces), the read-write head needs SEVERAL movements to find and retrieve all the pieces of the file, instead of one smooth continuous read.

Fill in the blank 3
Defragmentation is NOT a problem for ______ (unlike HDDs), because of their fundamentally different way of accessing data.
Reveal answer

SSDs (Solid State Drives).

Spot the error 4
A student claims: "When a file is deleted, its freed-up sectors are always immediately reused by other growing files right away." What does the worked example in this lesson contradict?
Reveal answer

The worked example explicitly shows that freed-up sectors (from a deleted file) are NOT immediately reused, since doing so would require "too much effort" for the HDD resources at that moment — a growing file's new data can instead be written to entirely different sectors, contributing to fragmentation.

Applied / scenario 5
A user has been using their HDD-based laptop heavily for a year — installing, deleting, and updating many programs — and it's become noticeably slower opening files. Using this lesson's content, explain the likely cause and the appropriate fix.
Reveal answer

The likely cause is FRAGMENTATION — a year of installs/deletes/updates has scattered file data across many non-contiguous sectors, forcing the read-write head to make many movements to retrieve each file. The fix: run defragmentation software, which rearranges the disk's blocks to restore contiguous storage wherever possible, speeding access back up.

Short answer 6
What does a defragmenter actually do to fix a fragmented disk?
Reveal answer

It rearranges the blocks of data on the disk to store files in contiguous sectors wherever possible, undoing the scattering that built up over time.
