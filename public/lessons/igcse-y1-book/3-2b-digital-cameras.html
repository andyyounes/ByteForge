3.2b Input Devices: Digital Cameras
From light hitting a lens to a stored binary image — sensors, ADCs, brightness, and RGB colour.
Key Terms
CCD
Charge coupled device — a light-sensitive cell made of millions of tiny sensors (photodiodes) that convert light into electricity.
Pixel
One tiny sensor/component making up the captured image (picture element).
ADC
Analogue-to-Digital Converter — turns each pixel's electric charge into a digital brightness/colour value.
24-bit RGB
A colour system giving each pixel 8 bits for red, 8 for green, 8 for blue — each 0-255 in denary.
Theory

From film to digital

  • Digital cameras have largely replaced film cameras, which required developing/printing before results could even be seen, and made it impossible to delete unwanted photos cheaply.
  • Modern digital cameras connect to a computer via USB or Bluetooth (wireless file transfer).
  • An embedded system in the camera automatically handles: shutter speed, autofocus, flash, aperture size, image size, red-eye removal, and more.

How a photograph is captured, step by step

  • Light passes through the lens onto a light-sensitive cell made of millions of tiny sensors (photodiodes) — this is the CCD (Charge Coupled Device), converting light into electricity.
  • Each sensor is called a pixel — the tiny unit that makes up the image.
  • The image becomes tiny electric charges, passed through an ADC (Analogue-to-Digital Converter) to form a digital image array.
  • The ADC converts each pixel's charge into a BRIGHTNESS level. An 8-bit ADC gives 2⁸ = 256 possible brightness levels per pixel.
  • Sensors also measure COLOUR: most cameras use 24-bit RGB — 8 bits each for red, green, blue, each ranging 0-255 in denary.
Worked example — one orange pixel

Brightness value: 115 denary (73 hex, 0111 0011 binary).

R=215 G=165 B=40

Red = 215 (D7 hex), Green = 165 (A5 hex), Blue = 40 (28 hex).

Full binary pattern for this pixel's RGB values: 1101 0111 1010 0101 0010 1000 — or D7A528 in hex.

What determines image size and quality

  • The NUMBER OF PIXELS determines the file size needed to store the photograph.
  • Image QUALITY depends on: the recording device (lens quality, sensor array quality), the number of pixels used (more = better), lighting levels, and how the image is stored (e.g. JPEG vs. raw file).
  • Mobile phones now often match dedicated cameras in pixel count, though can still lag in lens quality and storage — though this gap has narrowed rapidly with modern smartphone optics.
Light → lens → CCD (photodiodes convert light to electric charge) → ADC (converts charge to digital brightness/colour values) → stored digital image.
Practice — Test Yourself

These questions only cover what THIS subsection taught — digital cameras.

Short answer 1
What does a CCD actually do inside a digital camera?
Reveal answer

The CCD (Charge Coupled Device) is made of millions of tiny photodiode sensors that convert incoming LIGHT into ELECTRIC CHARGES — this is the first step turning light into data.

Short answer 2
In a 24-bit RGB system, how many bits represent each of the red, green, and blue components, and how many total distinct values can each component take?
Reveal answer

Each component (R, G, B) uses 8 bits, giving 2⁸ = 256 possible values (0 to 255) for each.

Fill in the blank 3
An 8-bit ADC gives 2⁸ = ______ possible ______ levels per pixel.
Reveal answer

Blank 1: 256. Blank 2: brightness.

Spot the error 4
A student claims: "Image quality depends only on how many pixels the camera has — nothing else matters." What real factors from this lesson does this ignore?
Reveal answer

The lesson lists SEVERAL factors affecting image quality besides pixel count: the recording device itself (lens quality, sensor array quality), lighting levels, and how the image is stored (e.g. JPEG vs. raw file) all genuinely matter too.

Applied / scenario 5
A pixel has a red value of 255, a green value of 0, and a blue value of 0. (a) What colour does this represent? (b) Write the full binary pattern for this pixel's RGB values.
Reveal answer

(a) Pure red (maximum red, no green, no blue).

(b) 255 = 1111 1111, 0 = 0000 0000, 0 = 0000 0000. Full pattern: 1111 1111 0000 0000 0000 0000.

Short answer 6
Name two tasks a digital camera's embedded system automatically handles.
Reveal answer

Any two of: adjusting shutter speed, autofocus, operating the flash, adjusting aperture size, adjusting image size, removing red-eye.
