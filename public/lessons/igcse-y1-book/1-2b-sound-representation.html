1.2b Representation of Sound
How a continuous, analogue sound wave gets turned into the discrete binary numbers a computer can store.
Key Terms
Sampling
Measuring the amplitude of a sound wave at set, regular time intervals to turn it into digital data.
Amplitude
The height of the sound wave at a given moment — how loud the sound is at that instant.
Sampling resolution
Also called bit depth — the number of bits used per sample. More bits = more possible amplitude values = more accuracy.
Sampling rate
The number of samples taken per second, measured in hertz (Hz). 1 Hz = one sample per second.
Theory

Turning a wave into numbers

  • A sound wave is naturally analogue — it varies smoothly and continuously — but a computer can only store discrete binary numbers, so the wave must be sampled.
  • Sampling means measuring the amplitude of the sound wave at set time intervals, giving only an APPROXIMATE representation of the original continuous wave (not a perfect copy).
  • Each sample is then encoded as a series of binary digits and stored.
The pink curve is the true analogue sound wave. Each green dot is a discrete sample — a single amplitude value read at one time interval. The gaps between samples are where information is lost.

Sampling resolution and sampling rate

  • If the amplitude range is 0 to 10, then 4 binary bits are enough to represent every possible value (e.g. 9 = 1001).
  • Increasing the number of possible values used to represent amplitude — e.g. using a range of 0 to 127 instead of 0 to 10 — increases the ACCURACY of the sampled sound.
  • The number of bits used per sample is the sampling resolution (also called bit depth).
  • The sampling rate is how many samples are taken per second, measured in Hz.
  • Using a higher sampling rate OR a larger sampling resolution both give a more faithful (accurate) representation of the original sound — but BOTH also increase the resulting file size.
Benefits & drawbacks of a larger sampling resolution
BenefitsDrawbacks
Larger dynamic rangeLarger file size
Better sound qualityTakes longer to transmit/download
Less sound distortionRequires greater processing power

Real-world reference point: an audio CD uses a 16-bit sampling resolution and a 44.1 kHz sampling rate — that's 44,100 samples taken every single second — which is why CD audio sounds high quality.

Practice — Test Yourself

These questions only cover what THIS subsection taught — sound sampling, resolution, and rate.

Short answer 1
Define "sampling rate" and state its unit of measurement.
Reveal answer

Sampling rate is the number of sound samples taken per second, measured in hertz (Hz).

Short answer 2
If an amplitude range of 0 to 127 is used instead of 0 to 10, what real effect does this have on the sound sample's accuracy?
Reveal answer

Using the larger range genuinely INCREASES the accuracy of the sampled sound, since far more distinct amplitude values can be recorded.

Fill in the blank 3
An audio CD uses a sampling resolution of ______ bits and a sampling rate of ______ kHz.
Reveal answer

Blank 1: 16. Blank 2: 44.1.

Spot the error 4
A student writes: "Increasing sampling resolution only improves sound quality — it has no other real effect on the file at all." What real drawback from this lesson does this claim miss?
Reveal answer

The claim misses that a larger sampling resolution ALSO produces a genuinely larger file size, takes longer to transmit/download, and requires more processing power — real drawbacks, not just a quality-only benefit.

Applied / scenario 5
A voice-memo app for quick, casual notes wants the smallest possible file size. A professional music-mastering studio wants the highest possible fidelity. Recommend a general sampling-resolution/rate approach for EACH, and justify your answer using this lesson's content.
Reveal answer

Voice-memo app: a LOWER sampling resolution and/or rate, since the lesson shows this genuinely produces smaller files that are faster to transmit — an acceptable trade-off when voice clarity matters more than pristine audio quality.

Music studio: a HIGHER sampling resolution and rate (e.g. matching or exceeding CD-quality 16-bit/44.1kHz), since the lesson shows this genuinely gives a more faithful, less distorted representation of the original sound — the larger file size and slower transfer are an acceptable trade-off here.

Short answer 6
Why can a computer only ever store an APPROXIMATE version of a real sound wave, never a perfect one?
Reveal answer

A real sound wave is continuous (analogue), but sampling only measures its amplitude at set, discrete time intervals — the gaps between samples are genuinely not captured at all, so what's stored is only ever an approximation of the true wave.
