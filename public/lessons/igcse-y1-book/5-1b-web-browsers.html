5.1b Web Browsers
The software that turns raw HTML into the pages you actually see — bookmarks, tabs, history, and hyperlinks.
Key Terms
Browser
Software that interprets HTML from websites and displays the result (text/images/video/audio).
Bookmark
A saved favourite website/page for quick future access.
Hyperlink
A clickable link navigating between websites/pages.
Cache
Locally stored data from previously visited pages, speeding up future visits.
Theory

What a browser does

  • Interprets (translates) HTML from websites and displays the result — text, images, video, audio.

Common browser features

  • A HOME PAGE.
  • Bookmarks — storing favourite websites/pages.
  • User HISTORY — a record of visited websites.
  • NAVIGATION forwards/backwards through already-opened pages.
  • Multiple TABS — many pages open simultaneously.
  • Cookies (covered in the next lesson).
  • Hyperlinks for navigation — opened either in a NEW tab (Ctrl+click) or the SAME tab (simple click).
  • Data stored as a cache (covered in the next lesson).
  • Support for JavaScript.
  • An ADDRESS BAR for typing/showing the current URL.
Practice — Test Yourself

These questions only cover what THIS subsection taught — web browsers and their features.

Short answer 1
What is the core job of a web browser?
Reveal answer

To interpret (translate) HTML sent from websites and display the result on the user's screen — as text, images, video, or audio.

Short answer 2
How does a user open a hyperlink in a NEW tab, rather than the same one?
Reveal answer

By holding Ctrl and clicking the link (Ctrl+click). A plain click opens it in the SAME tab.

Fill in the blank 3
A browser's ______ stores a record of previously visited websites, while a ______ stores favourite sites for quick future access.
Reveal answer

Blank 1: history. Blank 2: bookmark.

Spot the error 4
A student claims: "A browser can only ever display one web page at a time." What real feature from this lesson contradicts this?
Reveal answer

Browsers support multiple TABS, allowing many web pages to be open at the same time — the claim that only one page can be displayed at once is directly contradicted by this feature.

Applied / scenario 5
A user wants to keep reading their current article while also opening a linked reference from it, without losing their place on the original page. Using this lesson's content, describe how they should click the link.
Reveal answer

They should Ctrl+click the link, opening it in a NEW tab — this keeps the original article open in its current tab while the referenced link loads separately, letting them return to the original page exactly where they left it.

Short answer 6
Where is a URL typed to visit a website?
Reveal answer

The browser's address bar.
