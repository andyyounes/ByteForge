3.2k Output Devices: 3D Printers
Building solid objects layer by layer — additive vs. subtractive manufacturing, and real-world applications.
Key Terms
Additive manufacturing
Building an object up layer by layer — the method 3D printers use.
Subtractive manufacturing
The traditional method of REMOVING material to form an object, e.g. carving or CNC machining.
Direct 3D printing
Uses inkjet-style technology; the print head moves side to side AND up/down to build layers.
Binder 3D printing
Two passes per layer: powder sprayed first, then a binder (glue) sprayed to solidify it.
Theory

How 3D printers work

  • 3D printers build SOLID, working objects — layer by layer — using materials such as powdered resin, powdered metal, paper, or ceramic. Sizes range from microwave-oven-sized to as large as a small car.
  • This is additive manufacturing — building UP layer by layer — the opposite of traditional subtractive manufacturing, which removes material (e.g. carving a statue from solid stone, or CNC machining removing metal).
  • Direct 3D printing: uses inkjet-style technology — the print head moves left-right AND up-down to build layers.
  • Binder 3D printing: similar to direct printing, but uses TWO passes per layer — first spraying dry powder, then spraying a binder (glue) to solidify that layer.
  • Newer technologies use lasers/UV light to harden liquid polymers, further expanding what can be produced.
Steps to create an object with a 3D printer
  1. Design created using CAD (computer-aided design) software
  2. Design imported into special software that formats it for the 3D printer
  3. The 3D printer is set up ready to build the object
  4. Object built up layer by layer (often 0.1 mm thick) — can take several hours depending on layer thickness, material, and object size
  5. Object removed from printer and prepared (e.g. washing away jelly-like support, removing excess powder, cutting away unused material); often needs to "cure" for several hours
Real-world applications of 3D printing

3D printing is considered a possible "next industrial revolution". Real examples: custom-fitted prosthetic limb coverings; precision reconstructive surgery parts (e.g. facial reconstruction, made precisely from skull scans); lightweight, precise aerospace parts (e.g. wings); creative fashion/art applications; and replacement parts for discontinued items (e.g. vintage car suspension parts).

Practice — Test Yourself

These questions only cover what THIS subsection taught — 3D printers.

Short answer 1
What is the key difference between additive and subtractive manufacturing?
Reveal answer

Additive manufacturing BUILDS UP an object layer by layer (used by 3D printers). Subtractive manufacturing REMOVES material from a larger block to form the object (e.g. carving, CNC machining).

Short answer 2
How does binder 3D printing differ from direct 3D printing?
Reveal answer

Binder 3D printing uses TWO passes per layer — first spraying dry powder, then spraying a binder (glue) to solidify that layer. Direct 3D printing instead uses inkjet-style technology with the print head moving side-to-side and up-down.

Fill in the blank 3
A 3D-printed object is typically built up in layers around ______ mm thick, using ______ software to first design the object.
Reveal answer

Blank 1: 0.1. Blank 2: CAD (computer-aided design).

Spot the error 4
A student claims: "3D printing and CNC machining both work by building up material layer by layer." What's wrong with this?
Reveal answer

CNC machining is explicitly given as an example of SUBTRACTIVE manufacturing — it removes metal to form an object. It does NOT build up layer by layer; that's specifically what 3D printing (additive manufacturing) does.

Applied / scenario 5
A hospital wants to create a custom-fitted facial reconstruction part for a patient following an accident. Using this lesson's content, explain why 3D printing is well-suited to this application, and how the process would likely begin.
Reveal answer

The lesson explicitly gives precision reconstructive surgery (e.g. facial reconstruction) as a real application — parts made this way are more precise since they can be built from an exact scan of the patient's skull. The process would start with a 3D scan of the patient, a CAD design based on that scan, then the object built up layer by layer on the 3D printer.

Short answer 6
Why might a freshly-printed 3D object need to be left to "cure" before use?
Reveal answer

The lesson describes this as part of the standard finishing process — the object needs time to fully harden/set (curing) after being built up layer by layer, in addition to steps like washing away support material or removing excess powder.
