3.3b Secondary Storage: Hard Disk Drives
Spinning platters, read-write heads, latency, and fragmentation — the mechanics behind the classic HDD.
Key Terms
Platter
A spinning magnetic disk inside an HDD where data is physically stored.
Read-write head
An electromagnet that reads/writes data on the platter surface.
Latency
The time taken for a specific block of data to rotate around to the read-write head.
Fragmentation
Sectors of a file scattered non-adjacently across the disk, gradually slowing access over time.
Theory

What's inside an HDD

  • Data is stored digitally on magnetic platters, which can spin at up to about 7,000 times a MINUTE (the book's figure of "7000 times a second" describes rotational speed context — platters can be aluminium, glass, or ceramic).
  • Read-write heads (electromagnets) read/write data — they can move from the disk's centre to its edge and back up to 50 times a second.
  • Each platter usually has TWO usable surfaces. Data is organised into sectors and tracks — a sector on a given track holds a fixed number of bytes.
Concentric TRACKS on the platter, each divided into SECTORS — the read-write head moves radially to reach the right track, then waits for the right sector to rotate underneath.

Latency and slow access

  • HDDs have much slower data access than RAM. Latency is the time taken for a specific data block to rotate around to the read-write head.
  • Users notice latency's effects as "Please wait" messages, or worst-case, "not responding".

Fragmentation

  • When a file is stored, its needed sectors are allocated — but they may NOT be adjacent to each other.
  • Over time, repeated deletions/edits cause sectors to become increasingly FRAGMENTED, gradually slowing down HDD performance.
  • Defragmentation software "tidies up" the sectors to improve performance again.
  • Data within a given sector is read SEQUENTIALLY (in order); but reaching that sector in the first place requires a direct read/write head movement.

Removable hard disk drives

  • These are HDDs external to the computer, connected via USB — used as backup devices, or for transferring files between computers.
Practice — Test Yourself

These questions only cover what THIS subsection taught — hard disk drives.

Short answer 1
Define "latency" in the context of a hard disk drive.
Reveal answer

Latency is the time it takes for a specific block of data on a data track to rotate around to the read-write head.

Short answer 2
Why does an HDD's performance gradually deteriorate over time as more files are deleted and edited?
Reveal answer

Files' sectors become increasingly FRAGMENTED (scattered non-adjacently across the disk), meaning the read-write head has to move more to gather all the data for one file — gradually slowing down access speed.

Fill in the blank 3
Data on an HDD is organised into ______ (rings on a platter), each divided into ______ (containing a fixed number of bytes).
Reveal answer

Blank 1: tracks. Blank 2: sectors.

Spot the error 4
A student claims: "A file's sectors are always stored right next to each other on the disk, so fragmentation never actually happens in practice." What's wrong with this?
Reveal answer

Sectors allocated to a file are NOT guaranteed to be adjacent — the lesson explicitly states fragmentation genuinely happens over time as the disk undergoes deletions and edits, which is exactly why defragmentation software exists to fix it.

Applied / scenario 5
A user notices their computer's HDD has become noticeably slower over the past year of heavy use — lots of files added, deleted, and edited. Using this lesson's content, explain the likely cause and one possible fix.
Reveal answer

The likely cause is FRAGMENTATION — a year of deletions and edits has scattered file sectors across the disk non-adjacently, forcing the read-write head to move more to retrieve each file, worsening latency's effects. The fix: run defragmentation software, which reorganises the sectors to improve performance.

Short answer 6
What is a removable hard disk drive, and name one real use for it.
Reveal answer

An HDD external to the computer, connected via USB. Real uses: as a backup device, or for transferring files between computers.
