4.1k Management of User Accounts (Operating Systems)
Why the office clerk can't see the CEO's files — multi-access levels on a shared computer system.
Key Terms
User account
A protected identity (username + password) for one person on a multi-user system.
Administrator
The person overseeing account creation, deletion, and activity restrictions.
Multi-access levels
Different permission tiers letting different users access only what they're authorised for.
Theory

Why user accounts are needed

  • Multiple people logging onto the same computer means each user's data must be stored in SEPARATE parts of memory, for security.
  • Each user gets a protected account (username + password). The OS manages these different accounts, letting each user:
  • Customise their own screen layout/settings.
  • Use separate folders/files, managed independently.

The role of an administrator

  • An administrator usually oversees user account management: creating accounts, deleting accounts, restricting account activity.
  • On large systems (universities, industrial computers), the OS manages potentially many user accounts, ranging across very different data types — personal data, technical research, even stationery ordering.
Multi-access levels in practice

Different users get different permission LEVELS. Example: an office clerk may have access to order stationery, but genuinely CANNOT access any personal data on the system — their permission level restricts what they can reach, protecting more sensitive information from unauthorised users elsewhere on the same shared system.

Practice — Test Yourself

These questions only cover what THIS subsection taught — management of user accounts.

Short answer 1
Why must each user's data be stored in a separate part of memory on a multi-user system?
Reveal answer

For SECURITY — keeping user data separated prevents one user from accidentally or deliberately accessing another user's private data.

Short answer 2
What real tasks can an administrator carry out regarding user accounts?
Reveal answer

Creating accounts, deleting accounts, and restricting user account activity.

Fill in the blank 3
Each user logging onto a computer is given a user account protected by a ______ and ______.
Reveal answer

Blank 1: user name. Blank 2: password (either order).

Spot the error 4
A student claims: "Every user account on a multi-user system has exactly the same level of access to all data." What real feature from this lesson contradicts this?
Reveal answer

Multi-access levels explicitly give different users DIFFERENT permission levels — the lesson's clerk example shows a clerk having access to order stationery, but no access to any personal data, proving accounts are genuinely NOT all equal.

Applied / scenario 5
A university's shared computer system stores student personal records, staff research data, and general stationery ordering information all on the same servers. Using this lesson's content, explain how the operating system can allow a stationery clerk to do their job without also giving them access to student personal records.
Reveal answer

Through multi-access levels — the OS assigns the clerk's account a permission level that grants access only to stationery-ordering functions, while genuinely restricting access to personal student records, which require a different, higher access level the clerk's account simply doesn't have.

Short answer 6
Name two things a user can personalise once they have their own account.
Reveal answer

Their own screen layout/settings, and use of separate folders/files they manage themselves.
