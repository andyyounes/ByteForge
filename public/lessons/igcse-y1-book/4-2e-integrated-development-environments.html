4.2e Integrated Development Environments (IDEs)
One tool, seven jobs — how modern IDEs like PyCharm and Visual Studio speed up writing code.
Key Terms
IDE
Integrated Development Environment — a tool suite helping programmers write and develop programs.
Breakpoint
A marker telling the debugger to pause execution at a specific line, so variables can be inspected.
Prettyprinting
Colour-coding and meaningful layout of code, making it easier to read.
The Seven Core IDE Features
Code editor
Write/edit programs without switching to a separate text editor — speeds up development.
Translator
Usually a compiler AND/OR interpreter, built in. Interpreter for development, compiler for the final version.
Runtime environment + debugger
Runs the program under development, allowing single-stepping (line by line) or breakpoints, with a report window showing variable/expression values.
Error diagnostics
Dynamic error checking flags likely errors WHILE typing, with suggested corrections — catching many errors before the program even runs.
Auto-completion
Context-sensitive prompts completing variable names and reserved words as you type.
Auto-documenter
Automatically explains the function/purpose of code (e.g. what a built-in function does).
Prettyprinting
Colour-codes words and lays out code meaningfully, making it easier to read.
Practice — Test Yourself

These questions only cover what THIS subsection taught — Integrated Development Environments (IDEs).

Short answer 1
What does a debugger allow a programmer to do that just running the program normally doesn't?
Reveal answer

Step through the program a line at a time (single-stepping), or set a breakpoint to pause execution at a specific point — then inspect the contents of variables/expressions at that moment, to check for logic errors.

Short answer 2
What is "prettyprinting"?
Reveal answer

Colour-coding words in the program and laying it out in a meaningful way, making the code easier to read.

Fill in the blank 3
Dynamic ______ checking finds possible errors while the code is being ______, alerting the programmer immediately with a suggested correction.
Reveal answer

Blank 1: error. Blank 2: typed.

Spot the error 4
A student claims: "An IDE only ever includes an interpreter, never a compiler." What real detail from this lesson does this ignore?
Reveal answer

Most IDEs provide a translator that can be a compiler AND/OR an interpreter — the interpreter is often used during development, while a compiler is used to produce the final version of the program to be distributed.

Applied / scenario 5
A student is writing a program and can't figure out why a calculation is giving the wrong result partway through the program's logic. Using this lesson's content, describe which IDE feature would help them, and how they'd use it.
Reveal answer

The debugger. They could set a BREAKPOINT at the line where the calculation happens, run the program, and when execution pauses there, use the report window to inspect the actual contents of the relevant variables at that exact point — revealing whether the values match what was expected, and helping pinpoint the logic error.

Short answer 6
Name two IDE examples given in this lesson, and the programming languages they're associated with.
Reveal answer

Any two of: PyCharm (Python), Visual Studio (Visual Basic), BlueJ (Java).
