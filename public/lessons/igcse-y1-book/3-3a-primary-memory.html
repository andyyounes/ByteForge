3.3a Primary Memory: RAM & ROM
The memory the CPU can access directly — volatile RAM (DRAM/SRAM) and permanent ROM.
Key Terms
Primary memory
Memory directly addressable by the CPU — RAM, ROM, and cache.
Volatile
Memory contents are LOST when the power is turned off (true of RAM).
DRAM
Dynamic RAM — uses transistors/capacitors, needs constant refreshing, cheaper, higher capacity.
SRAM
Static RAM — uses flip-flops, no refreshing needed, much faster, used for CPU cache.
ROM
Read-Only Memory — non-volatile, permanent, cannot be written to; stores BIOS/bootstrap.
Theory

Primary memory vs. secondary storage — the basic split

  • Primary memory: directly addressable by the CPU, contains RAM/ROM/cache.
  • Secondary storage: NOT directly addressable by the CPU, all non-volatile, includes HDD/SSD/DVD/memory stick/Blu-ray — can be internal or external.

Random Access Memory (RAM)

  • "Random" means any memory location can be accessed independently of which was last used — not truly "random" data.
  • When an application runs, data moves temporarily from secondary storage into RAM (much faster to access than secondary storage).
  • RAM: can be written to/read from (data changeable), stores currently-used data/files/apps/OS parts, and is VOLATILE — contents lost on power-off.
  • More RAM generally = faster computer. RAM never technically "runs out" — it just gets slower as the CPU must repeatedly overwrite old RAM data with new data from secondary storage. More RAM reduces how often this has to happen.
DRAM vs. SRAM

DRAM's capacitor HOLDS the bit value (0/1); its transistor acts as a switch letting the circuitry read/change that value. Without refreshing, the capacitor's charge leaks away, losing its value (defaulting to 0) — this is why DRAM needs constant refreshing and SRAM does not.

Read-Only Memory (ROM)

  • ROM is NON-VOLATILE (contents survive power-off) and PERMANENT (cannot be written to/changed by the user, computer, or any program).
  • Commonly stores the BIOS/start-up instructions ("bootstrap") the computer needs when first powering on.
Real example — RAM and ROM in a remote-controlled toy car

ROM: stores factory settings (e.g. remote control frequency), start-up routines, and fixed button routines (turn left, accelerate, stop, etc.).

RAM: stores any custom routines the user programs in, plus the live data/instructions received from the remote control unit as it operates.

Practice — Test Yourself

These questions only cover what THIS subsection taught — primary memory (RAM and ROM).

Short answer 1
What does "volatile" mean, and which of RAM/ROM is volatile?
Reveal answer

"Volatile" means the memory's contents are LOST when the power is switched off. RAM is volatile; ROM is non-volatile.

Short answer 2
Why does DRAM need to be constantly refreshed, but SRAM does not?
Reveal answer

DRAM stores each bit as a charge in a capacitor, and that charge leaks away naturally over time unless recharged (refreshed) every ~15 microseconds. SRAM uses flip-flops instead, which hold their value stably without needing this constant recharging.

Fill in the blank 3
A CPU's memory cache uses ______ (for its speed), while main memory is built from ______ (for its cost and capacity).
Reveal answer

Blank 1: SRAM. Blank 2: DRAM.

Spot the error 4
A student claims: "When RAM becomes completely full, the computer simply stops working and crashes." What real behaviour does this get wrong?
Reveal answer

RAM never technically "runs out" in this crashing sense — it continues to operate, but becomes progressively SLOWER, since the CPU must keep overwriting old RAM data with new data fetched from secondary storage. Increasing RAM size reduces how often this slow overwrite process is needed, improving speed — it doesn't prevent a crash that wasn't going to happen anyway.

Applied / scenario 5
A microwave oven has circuitry containing both RAM and ROM chips. Suggest one realistic use for each type of chip in this device, based on this lesson's content and the toy-car example.
Reveal answer

ROM: could store the factory-set cooking programs/start-up routines (e.g. preset defrost or popcorn settings) that never change.

RAM: could store the user's currently entered cooking time/power level while the microwave is running — data that's temporary and changes with every use, lost once the microwave is unplugged/reset.

Short answer 6
What does ROM typically store that a computer needs the very first moment it's switched on?
Reveal answer

The BIOS (start-up instructions, or "bootstrap").
