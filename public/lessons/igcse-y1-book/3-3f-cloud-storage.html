3.3f Cloud Storage
Data stored on someone else's servers — public, private, hybrid, and the very real security risks that come with giving up control.
Key Terms
Cloud storage
Data stored on remote servers, owned/managed by a hosting company.
Data redundancy
Storing the same data on more than one server, so maintenance/repair on one doesn't cause data loss.
Public cloud
Client and cloud provider are DIFFERENT companies.
Private cloud
Dedicated environment behind a company firewall; client and provider are the SAME entity.
Theory

What cloud storage is

  • Data is stored on REMOTE servers rather than a local hard disk. The same data is stored on MULTIPLE servers — data redundancy — protecting against loss during maintenance/repair.
  • The physical infrastructure (potentially hundreds of servers, multiple locations) is owned/managed by a hosting company.

Three cloud models

  • Public cloud: client and cloud provider are DIFFERENT companies.
  • Private cloud: dedicated environment behind a company's own firewall — client and provider are effectively the SAME entity/integrated as one.
  • Hybrid cloud: a combination — sensitive data stays in the private cloud, less sensitive data uses public cloud storage.
Benefits of cloud storage
  • Access files anytime, from any device, anywhere (with internet)
  • No need to carry an external storage device or use the same computer
  • Remote backup — helps with disaster recovery/data loss prevention
  • Recovers data even if a local hard disk/backup device fails
  • Almost unlimited storage capacity
Drawbacks of cloud storage
  • Slow/unstable internet connection makes accessing/downloading files difficult
  • Can be costly for large storage capacity, or high transfer limits with an ISP
  • The cloud PROVIDER itself could fail — risking loss of ALL backed-up data

Data security concerns

  • Companies transferring confidential data to a cloud provider are effectively giving up CONTROL of their own data security. Real questions this raises:
  • What physical security protects the building housing the data?
  • How resistant is the provider to natural disasters or power cuts?
  • What safeguards prevent the provider's own PERSONNEL from misusing their access to confidential data?
Real security breaches (why some people are wary of cloud storage)

XEN security threat: a problem in the XEN hypervisor forced several cloud operators to reboot ALL their servers.

Routine backup failure: a large cloud provider permanently LOST data during a routine backup procedure.

Celebrity photo hacking scandal: hackers accessed cloud accounts, leaking 100+ private celebrity photos, later sold/published online.

2016 Mexico electoral breach: 93 million voter registrations from a central database were compromised and made publicly available — worsened by the data linking to a cloud server OUTSIDE Mexico.

Practice — Test Yourself

These questions only cover what THIS subsection taught — cloud storage.

Short answer 1
What is "data redundancy" in cloud storage, and why does it matter?
Reveal answer

Data redundancy means the SAME data is stored on more than one server, so if one server needs maintenance or repair, the data is still accessible from another — this allows clients to access their data at any time without interruption.

Short answer 2
What is the key difference between public cloud and private cloud?
Reveal answer

In PUBLIC cloud, the client and cloud provider are different companies. In PRIVATE cloud, storage is provided by a dedicated environment behind the company's own firewall — client and provider are effectively the same entity.

Fill in the blank 3
A ______ cloud combines both approaches — sensitive data stays in the ______ cloud, while less sensitive data can use the public cloud.
Reveal answer

Blank 1: hybrid. Blank 2: private.

Spot the error 4
A student claims: "Cloud storage completely eliminates the risk of losing data, since it's backed up in multiple places." What real event from this lesson contradicts this?
Reveal answer

The lesson explicitly describes a real case where a large cloud provider PERMANENTLY lost data during a routine backup procedure — data redundancy reduces risk, but does not eliminate it entirely. The cloud PROVIDER itself could also fail, risking loss of all backed-up data.

Applied / scenario 5
A hospital wants to store both highly sensitive patient medical records AND general, non-sensitive administrative documents (like public event schedules) using cloud storage. Which cloud model best fits this need, and why, based on this lesson's content?
Reveal answer

Hybrid cloud. The lesson describes hybrid cloud as combining both models — sensitive data (the medical records) can reside in the private cloud behind the hospital's own firewall, while less sensitive/non-commercial data (the public schedules) can use public cloud storage — a direct match for the hospital's two different data types.

Short answer 6
Name one real question a company should ask before transferring confidential data to a cloud provider, according to this lesson.
Reveal answer

Any of: what physical security exists at the building housing the data; how resistant is the provider to natural disasters/power cuts; what safeguards exist against misuse by the provider's own personnel.
