3.1c Cores, Cache & Internal Clock
The four real factors that determine CPU performance — and why more of any one of them doesn't simply mean "faster".
Key Terms
Clock speed
How many clock cycles occur per second, e.g. 3.5 GHz = 3.5 billion cycles/second.
Overclocking
Running the CPU at a higher clock speed than it was designed for, via BIOS settings.
Cache memory
Very fast memory located INSIDE the CPU, storing frequently-used instructions/data.
Core
One complete processing unit (ALU + control unit + registers). A CPU can have multiple cores (dual, quad, etc.).
Theory

Factor 1: Clock speed

  • The system clock defines the clock cycle that synchronises all computer operations, via timing signals on the control bus.
  • A higher clock speed increases processing speed — a typical modern value is 3.5 GHz (3.5 billion clock cycles per second).
  • BUT: a higher clock speed alone does NOT necessarily mean better overall performance — other factors matter too.

Factor 2: Bus width

  • As covered previously, wider address and data buses can also improve performance (more addressable memory, larger word transport at once).

Factor 3: Overclocking (and its risks)

  • Overclocking means changing the clock speed via BIOS settings, running the CPU faster than it was designed for.
  • Real risks: instructions executed outside design limits can cause seriously UNSYNCHRONISED operations — an instruction may not complete before the next is due, causing frequent crashes and instability.
  • Overclocking can also cause serious CPU OVERHEATING, leading to further unreliable performance.

Factor 4: Cache memory

  • Cache memory sits INSIDE the CPU itself (unlike RAM), giving much faster access times than RAM.
  • It stores frequently-used instructions/data that need faster access, improving CPU performance.
  • When the CPU wants to read memory, it checks the CACHE first, and only falls back to main memory/RAM if the data isn't in the cache.
  • Larger cache size generally means better CPU performance.

Factor 5: Multiple cores

  • One core = one ALU + one control unit + registers. CPUs commonly have 2 cores (dual-core) or 4 cores (quad-core).
  • More cores reduces the need to keep increasing clock speed to improve performance.
  • HOWEVER: doubling the number of cores does NOT simply double performance — the CPU must communicate with each core, and this communication overhead grows fast: a dual-core CPU needs just 1 communication channel between its 2 cores, but a quad-core CPU needs 6 channels to connect all 4 cores to each other — considerably reducing the potential performance gain.
More cores need exponentially more communication channels — this overhead eats into the theoretical performance gain.
Practice — Test Yourself

These questions only cover what THIS subsection taught — clock speed, overclocking, cache, and cores.

Short answer 1
What does a clock speed of 3.5 GHz actually mean?
Reveal answer

3.5 GHz means 3.5 billion clock cycles per second.

Short answer 2
Name TWO real risks of overclocking a CPU.
Reveal answer

Unsynchronised operations causing frequent crashes/instability (instructions can't complete in time), and serious CPU overheating leading to unreliable performance.

Fill in the blank 3
When the CPU wants to read memory, it first checks the ______, and only falls back to ______ if the required data isn't found there.
Reveal answer

Blank 1: cache (cache memory). Blank 2: main memory / RAM.

Spot the error 4
A student claims: "Doubling the number of CPU cores always doubles the computer's performance." What real factor does this ignore?
Reveal answer

It ignores the communication overhead BETWEEN cores. A dual-core needs only 1 channel between its cores, but a quad-core needs 6 channels to connect all 4 cores — this overhead genuinely reduces the performance gain, meaning doubling cores does NOT simply double performance.

Applied / scenario 5
A user overclocks their CPU to make their computer run faster, and shortly afterwards notices frequent system crashes and a CPU that runs unusually hot. Using this lesson's content, explain the likely cause.
Reveal answer

The lesson identifies both symptoms as real risks of overclocking: running instructions beyond the CPU's design limits causes unsynchronised operations (instructions failing to complete in time), leading directly to crashes/instability, while operating outside design limits also causes serious overheating — both are direct, expected consequences of overclocking, not unrelated coincidences.

Short answer 6
What is cache memory, and what is its main advantage over RAM?
Reveal answer

Cache memory is very fast memory located INSIDE the CPU itself, storing frequently-used instructions/data. Its main advantage is much FASTER access time than RAM, since it doesn't need to travel outside the CPU.
