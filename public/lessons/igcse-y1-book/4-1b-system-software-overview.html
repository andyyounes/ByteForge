4.1b System Software: Drivers, OS, Compilers & Linkers
The five main categories of system software, and what each one is actually for.
Key Terms
Device driver
Software letting a hardware device communicate with the operating system.
Operating system
Background software managing basic computer functions (I/O, HCI, error handling, security).
Compiler
Translates high-level language source code into machine code (object code).
Linker
Combines multiple compiled object files (modules) into one runnable program.
Theory

Device drivers

  • Enables hardware devices to communicate with the OS. Without a driver, a device (e.g. a printer) can't work with the computer.
  • Every connected hardware device needs an associated driver. When plugged into USB, the OS searches for the matching driver — an error appears if it can't find one.
  • Examples: printer drivers, memory stick drivers, mouse drivers, CD drivers.

Operating systems (OS)

  • Runs in the BACKGROUND, managing basic functions. Without an OS, computers would be extremely user-unfriendly.
  • Operating systems allow: input/output operations; user communication with the computer (e.g. Windows interface); error handling; loading/running programs; managing security (user accounts, login passwords).

Compilers

  • Translates a program written in a HIGH-LEVEL LANGUAGE (HLL) into MACHINE CODE the computer can directly run.
  • The original program is source code; the compiled result is object code.
  • Once compiled, the machine code can run repeatedly WITHOUT recompiling.
  • Example HLLs: Java, Python, Visual Basic, Fortran, C++, Algol.

Linkers

  • Takes one or more object files (produced by a compiler) and COMBINES them into a single runnable program.
  • Programmers often split code into separate MODULES to simplify programming (breaking a big task into smaller manageable sub-tasks).
  • At some point, all modules must be joined together into the final program — this is the linker's job.

Utility programs — quick overview

  • Programs that help manage/maintain/control computer resources — examples include anti-virus, anti-spyware, backup software, disk repair/analysis, file management/compression, security tools, screensavers, and defragmentation software.
  • (Virus checkers and defragmentation are covered in detail in the following lessons.)
Practice — Test Yourself

These questions only cover what THIS subsection taught — device drivers, operating systems, compilers, and linkers.

Short answer 1
What happens if a device is plugged in but the operating system can't find a matching driver?
Reveal answer

An error message is produced.

Short answer 2
What is the difference between "source code" and "object code"?
Reveal answer

Source code is the ORIGINAL program written in a high-level language. Object code is the MACHINE CODE produced after compiling that source code.

Fill in the blank 3
A ______ combines multiple compiled ______ (produced separately as modules) into one single runnable program.
Reveal answer

Blank 1: linker. Blank 2: object files.

Spot the error 4
A student claims: "Once source code is compiled, you must recompile it every single time you want to run the program again." What's wrong with this?
Reveal answer

Once a program is compiled, the resulting machine code can be used AGAIN AND AGAIN to perform the task WITHOUT needing to recompile each time — recompilation is only needed if the source code itself changes.

Applied / scenario 5
A large software project is split by the development team into five separate modules, each written and compiled independently. Using this lesson's content, explain what tool is needed to combine these into one final runnable program, and why splitting the project into modules was useful in the first place.
Reveal answer

A linker is needed to combine the five separately compiled object files into a single program. Splitting the project into modules was useful because it simplifies programming by breaking a big task into smaller, more manageable sub-tasks — something the lesson explicitly identifies as the reason programmers use modules.

Short answer 6
Name three functions the operating system provides, according to this lesson.
Reveal answer

Any three of: input/output operations; user communication with the computer (HCI); error handling; loading and running programs; managing security (accounts/passwords).
