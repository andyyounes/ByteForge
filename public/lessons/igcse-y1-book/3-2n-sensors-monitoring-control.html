3.2n Sensors: Fundamentals, Monitoring & Control
Turning the real, analogue world into digital data — and the crucial difference between just watching and actually acting.
Key Terms
Sensor
An input device that reads/measures a physical property from its surroundings (e.g. temperature, pressure).
Feedback
When a system's output (e.g. adjusting a valve) changes the very conditions the sensor measures next.
Monitoring system
Watches a process and raises an alert if needed, but has NO effect on what it's watching.
Control system
Actively changes the process (valves, motors, etc.) based on sensor readings.
Theory

From analogue reality to digital data

  • Real-world physical data (temperature, pressure, etc.) is genuinely ANALOGUE — constantly changing, with no single discrete value. E.g. reading a mercury thermometer requires human judgement of where the mercury sits on the scale.
  • Computers cannot process analogue data directly — an ADC (Analogue-to-Digital Converter) converts the physical value into discrete digital data.
  • When a computer needs to CONTROL a device (motor, valve), it often needs a DAC (Digital-to-Analogue Converter) in reverse, since actuators frequently need analogue signals to operate.

Feedback

  • Sensors send CONSTANT readings — they don't wait for a change to occur before reporting.
  • It's the microprocessor that analyses the incoming data and decides what action (if any) to take.
  • Feedback: a microprocessor's action (e.g. adjusting a valve or motor) can change the very conditions the sensor measures NEXT — the output affects the next input, forming a loop that keeps adjusting the system towards a desired state.
Monitoring system
  • Sensor data → converted via ADC if needed → compared against stored values
  • If outside acceptable range: a WARNING message is shown, or an alarm sounds
  • The system has NO effect on what's being monitored — it simply "watches"
  • Examples: hospital patient vital-sign monitoring, burglar alarm systems, engine temperature checks, river pollution monitoring
Control system
  • Same sensor → ADC → comparison steps as monitoring
  • If outside acceptable range: signals are sent to VALVES, MOTORS, etc. to actually change the process
  • The output DOES affect the next input (feedback loop)
  • Examples: street lights turning on/off automatically, central heating/AC control, chemical process control, anti-lock brakes, greenhouse environment control
Real example — a security monitoring system
  1. System armed via password on a keypad
  2. Infrared sensor detects intruder movement; acoustic sensor detects footsteps/breaking glass; pressure sensor detects weight through a door/window
  3. Analogue sensor data passed through an ADC to produce digital data
  4. Microprocessor samples this digital data at a set frequency (e.g. every 5 seconds)
  5. Data compared against stored acceptable values
  6. If any value is outside the acceptable range: signal sent to a siren (sound alarm) and/or a light (start flashing) — a DAC is used if these devices need analogue signals
  7. Alarm/lights continue until the system is reset with a password
Practice — Test Yourself

These questions only cover what THIS subsection taught — sensor fundamentals, monitoring, and control.

Short answer 1
What is the essential difference between a monitoring system and a control system?
Reveal answer

A monitoring system only WATCHES a process and raises an alert (warning/alarm) if needed — it has no effect on the process itself. A control system actively CHANGES the process (via valves, motors, etc.) in response to sensor readings.

Short answer 2
Why is an ADC needed between a sensor and a computer?
Reveal answer

Real-world sensor readings are analogue in nature, but computers can only process digital data — an ADC converts the continuous analogue value into discrete digital data the computer can work with.

Fill in the blank 3
In a feedback loop, the ______ of a control system affects the next set of ______ received by its sensors.
Reveal answer

Blank 1: output. Blank 2: inputs.

Spot the error 4
A student claims: "A sensor only sends a reading the moment something changes — it stays silent otherwise." What's wrong with this?
Reveal answer

Sensors send CONSTANT readings, regardless of whether anything has changed — they don't wait for a change event. It's the microprocessor receiving that constant stream of data that analyses it and decides whether any action is needed.

Applied / scenario 5
A greenhouse system needs to keep the temperature within a specific range by automatically opening vents when it gets too hot. Is this a monitoring system or a control system? Justify your answer using this lesson's content.
Reveal answer

This is a control system, not just monitoring. The lesson defines a monitoring system as having no effect on what it watches, whereas a control system actively sends signals to actuators (here, opening vents) to change the process — automatically opening vents to correct the temperature is exactly this active control behaviour, which also creates a feedback loop (the vent opening changes the next temperature reading).

Short answer 6
In the security alarm example, what stops the alarm from sounding forever once triggered?
Reveal answer

The alarm/lights continue until the system is RESET with a password — the reset is what stops it, not any automatic timeout.
