3.2o Types of Sensor
Fourteen common sensor types — what each one measures, how, and where it's actually used.
Sensor Reference
Temperature
Signals change as temperature changes.
Central heating control; chemical process monitoring; greenhouse temperature.
Moisture
Measures water levels (e.g. in soil) via electrical resistance.
Greenhouse soil moisture; food factory moisture monitoring.
Humidity
Measures water vapour in air, via air's changing conductivity.
Building/factory humidity; microchip manufacturing; greenhouse air.
Light
Photoelectric cells produce current based on light brightness.
Street lights on/off; automatic car headlights.
Infrared (active)
An infrared beam is broken, changing radiation reaching the detector.
Automatic windscreen wipers (rain detection); security alarms (broken beam).
Infrared (passive)
Measures heat radiation given off by an object.
Security alarms (body heat); industrial freezer/chiller monitoring.
Pressure
A transducer generating current based on applied pressure.
Weighing lorries at a station; nuclear reactor gas pressure.
Acoustic/sound
Microphones converting sound into electric pulses.
Detecting footsteps in security; detecting dripping liquid at faulty pipes.
Gas
Detects oxygen/carbon dioxide (or other gas) levels.
Airport pollution monitoring; greenhouse O2/CO2; car exhaust oxygen.
pH
Measures acidity via voltage changes (e.g. in soil).
Greenhouse soil acidity; chemical process acidity control.
Magnetic field
Measures changes in magnetic fields.
Mobile phones/CD players; car anti-lock braking systems.
Accelerometer
Measures acceleration/change in velocity via a piezoelectric cell.
Car airbag deployment on rapid deceleration; phone portrait/landscape switching.
Proximity
Detects the presence of a nearby object.
Switching off a phone screen when held to the ear.
Flow (rate)
Measures the flow rate of a moving liquid/gas.
Hospital respiratory devices/inhalers; measuring natural gas flow in pipes.
Level
Uses ultrasonics or capacitance/conductivity to measure liquid levels.
Car petrol tank level; pharmaceutical powder levels; refrigerant leak detection.
Practice — Test Yourself

These questions only cover what THIS subsection taught — the specific types of sensor and their applications.

Short answer 1
What is the key difference between an active infrared sensor and a passive infrared sensor?
Reveal answer

An ACTIVE infrared sensor uses an emitted invisible beam and detects when it's BROKEN (e.g. by an intruder). A PASSIVE infrared sensor instead directly measures heat radiation given off by an object (e.g. body heat), without needing to emit its own beam.

Short answer 2
Which sensor type is used in a car's airbag system to detect a crash?
Reveal answer

An accelerometer — it measures rapid deceleration (change in velocity), triggering airbag deployment.

Fill in the blank 3
A ______ sensor detects the presence of a nearby object — this is why a phone screen switches off when held to the ear.
Reveal answer

Proximity sensor.

Spot the error 4
A student claims: "Moisture sensors and humidity sensors measure exactly the same thing, just with different names." What's wrong with this?
Reveal answer

They measure genuinely different things: a MOISTURE sensor measures water levels in something like soil (based on electrical resistance), while a HUMIDITY sensor measures water vapour content in AIR (based on air's changing conductivity) — different substances, different physical properties.

Applied / scenario 5
A greenhouse system needs to automatically monitor and control FOUR different environmental factors: soil moisture, air humidity, temperature, and soil acidity. Name the four sensor types needed, based on this lesson's content.
Reveal answer

Moisture sensor (soil moisture), Humidity sensor (air water vapour), Temperature sensor, and pH sensor (soil acidity) — all four are explicitly listed with greenhouse applications in this lesson.

Short answer 6
Which sensor type would be used to detect a gas leak by monitoring changing levels in a refrigerant system?
Reveal answer

A level sensor — the lesson lists refrigerant leak detection as an application of level sensors.
