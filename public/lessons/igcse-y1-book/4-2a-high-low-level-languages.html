4.2a High-Level & Low-Level Languages
Why "Sum := First + Second" and three lines of raw binary do exactly the same job.
Key Terms
High-level language
Problem-oriented, close to English, portable across computer types. E.g. Python, Java, C++.
Low-level language
Tied to a specific computer's architecture/hardware — machine code or assembly language.
Machine code
Binary instructions the computer directly understands — usually shown in hex for readability.
Theory

High-level languages

  • Let a programmer focus on the PROBLEM being solved, with NO need to know the target computer's hardware/instruction set.
  • Many are PORTABLE — usable on different computer types.
  • Designed with programmers in mind — closer to English, easier to read/understand/write/debug/maintain.
  • Skills learned in one high-level language TRANSFER to others.
  • Examples: C++, Delphi, Java, Pascal, Python, Visual Basic.
The same task, three levels of abstraction

High-level language (one readable statement):

Sum := FirstNumber + SecondNumber

Machine code (hex / binary):

1 12   0001 00010010
4 13   0100 00010011
0 1A   0000 00011010

The same task takes ONE understandable line in a high-level language, but three genuinely hard-to-read machine code instructions.

Low-level languages

  • Tied to the SPECIFIC architecture/hardware of one computer type.
  • Two forms: machine code (the raw binary instructions) and assembly language (needs translating INTO machine code — covered in the next lesson).
  • Programmers rarely write machine code directly — it's hard to understand, and complicated for managing data.

Practice — Test Yourself

These questions only cover what THIS subsection taught — high-level and low-level languages.

Short answer 1
Why don't programmers writing in a high-level language need to know the computer's hardware or instruction set?
Reveal answer

High-level languages let the programmer focus purely on the PROBLEM being solved — the language is designed to be readable and portable, independent of any specific computer's underlying hardware.

Short answer 2
Name two example high-level programming languages.
Reveal answer

Any two of: C++, Delphi, Java, Pascal, Python, Visual Basic.

Fill in the blank 3
Low-level languages relate to the specific ______ and ______ of a particular computer type.
Reveal answer

Blank 1: architecture. Blank 2: hardware.

Spot the error 4
A student claims: "High-level languages are always the better choice, since low-level languages have no real advantages." What genuine advantages does this ignore?
Reveal answer

Low-level languages have real advantages: they can use SPECIAL hardware and machine-dependent instructions, produce more COMPACT code (less primary memory used), and can perform tasks very QUICKLY — genuine reasons some programmers still choose them.

Applied / scenario 5
A team is writing software that needs to run on many different computer types with minimal changes, and needs many programmers to collaborate quickly. Which type of language — high-level or low-level — best fits this, and why, using this lesson's content?
Reveal answer

High-level. The lesson states high-level languages are independent of the computer type used (portable), and are easier/quicker to read, write, debug, and maintain — a direct match for a team needing cross-platform compatibility and fast collaborative development.

Short answer 6
Why is machine code usually SHOWN in hexadecimal rather than binary, even though the computer's actual instructions are binary?
Reveal answer

Because raw binary is genuinely very hard to read — hex is a more compact, human-manageable way of representing the same underlying binary instructions.
