2.1c Universal Serial Bus (USB)
The most common I/O port on modern computers — how it works, its cable, USB-C, and its real benefits and drawbacks.
Key Terms
USB
Universal Serial Bus — a standardised serial data transmission method, now the most common input/output port on computers.
Device driver
Software that lets the computer and a connected device communicate correctly; loaded automatically when a device is recognised.
USB-C
A newer, 24-pin, symmetrical (reversible) USB connector type — smaller, more powerful, and faster than older USB connectors.
USB hub
A device used to add more USB ports, or to extend cable length beyond the standard maximum.
Theory

What USB is and how it works

  • USB is a form of serial data transmission, and is now the most common type of input/output port on computers — it standardised how devices transfer data with a computer.
  • USB supports BOTH half-duplex AND full-duplex data transmission.
  • When a device is plugged in: the computer automatically DETECTS it (via a small voltage change on the data signal wires), the device is automatically RECOGNISED, and the matching device driver software is loaded so the computer and device can communicate.
  • If no matching driver is available, the user is prompted to download the correct driver software — some systems do this automatically, showing a permission prompt to connect to the device's website.
A standard USB cable: two power wires (red +5V, black ground) and two data wires (white/green) inside a shielded cable.

USB-C

  • USB-C is a newer connector becoming common on laptops, tablets, and phones — a 24-pin symmetrical connector that fits either way round.
  • It's smaller and thinner than older USB connectors, offers up to 100 watts (20V) of power (enough to charge full-sized laptops), and carries data at up to 10 Gbps — fast enough to support 4K video.
  • USB-C is backward compatible with USB 2.0/3.0 provided a suitable adaptor is used, and is expected to become the new universal industry standard.
Benefits of USB
  • Devices auto-detected, drivers auto-loaded
  • Connectors only fit one way (prevents wrong connections)
  • Industry standard — wide support
  • Supports many data rates (1.5 Mbps to 5 Gbps)
  • Cable itself supplies +5V power — no external power source needed
  • Re-transmits data automatically if errors are detected — leads to error-free transmission
  • Easy to add more ports via USB hubs
  • Backward compatible with older versions
Drawbacks of USB
  • Standard USB max cable length is only 5 m; hubs needed beyond that
  • Very early USB (V1) may not always be supported by the latest computers
  • Even USB V3/V4 (USB-C) is slower than, e.g., Ethernet connections (USB V2's max rate is only 480 Mbps)
Practice — Test Yourself

These questions only cover what THIS subsection taught — USB and USB-C.

Short answer 1
Is USB a form of serial or parallel data transmission? Which duplex modes does it support?
Reveal answer

USB is a form of serial transmission. It supports both half-duplex and full-duplex modes.

Short answer 2
How does a computer know a USB device has just been plugged in?
Reveal answer

A small change in the voltage on the data signal wires in the USB cable triggers automatic detection.

Fill in the blank 3
USB-C is a ______-pin, ______ connector — meaning it fits into a USB-C port either way round.
Reveal answer

Blank 1: 24. Blank 2: symmetrical.

Spot the error 4
A student claims: "USB is always faster than any other data transmission method, since it's the industry standard." What real drawback from this lesson contradicts this?
Reveal answer

The lesson states that even the latest USB versions (V3/V4, USB-C) have a data transfer rate that is genuinely SLOW compared to, for example, Ethernet connections — being an industry standard does not make USB the fastest transmission method available.

Applied / scenario 5
A user wants to connect an external hard drive that is 10 metres away from their computer using a standard USB cable. Using this lesson's content, explain the problem they'll face and how it can be solved.
Reveal answer

Standard USB only supports a maximum cable length of 5 m, so a single 10 m cable won't reliably work. The lesson's solution: use a USB hub to extend the cable length beyond the standard 5 m limit.

Short answer 6
Name two real advantages USB-C has over older USB connector types.
Reveal answer

Any two of: smaller/thinner; reversible (fits either way round); higher power delivery (100W/20V, enough for full-size laptops); faster data rate (10 Gbps, supporting 4K video).
