4.1.2-4.1.3 Components & Properties of a Communication System
The five parts every communication system needs, and the three qualities that make it a GOOD one.
Theory — Five Components
SenderGenerates and sends the message
→
MediumThe channel the message travels through
→
ReceiverReceives the message
  • Message — the information/data being communicated (text, numbers, pictures, audio, video).
  • Sender — the device that generates and sends a message (e.g. a computer, telephone handset).
  • Receiver — the device that receives the message, usually in a different location than the sender.
  • Medium — the channel or path the message travels through (e.g. twisted-pair cable, coaxial cable, radio waves).
  • Protocol — the rules and procedures computers follow to exchange data; both sender and receiver must follow the SAME protocol.
Theory — Three Properties of a GOOD Communication System
  • Delivery — the system must deliver data in the correct order to the correct destination.
  • Accuracy — data must arrive accurate; data altered during transmission and left uncorrected is useless.
  • Timeliness — data must be delivered in a timely manner; late data is useless.
Practice — Test Yourself

These questions only cover what this subsection taught — the five components and three properties.

Short answer 1
Why must a sender and receiver use the same protocol?
Reveal answer

Protocols are the rules and procedures for exchanging data — without both sides following the same rules, they couldn't correctly interpret each other's messages.

Short answer 2
Why is "accuracy" listed as a property of a good communication system, separate from "delivery"?
Reveal answer

Delivery just means the data arrives at the right place in the right order. Accuracy is about whether the CONTENT of that data is correct and unaltered — data could be "delivered" but still be wrong/corrupted.

Fill in the blank 3
The device that generates and sends a message in a communication system is called the ______.
Reveal answer

sender.

Spot the error 4
A student says the "medium" in a communication system refers to the content being sent. What's wrong?
Reveal answer

The medium is the CHANNEL or PATH the message travels through (e.g. a cable or radio waves) — the content being sent is the "message", a separate component.

Applied / scenario 5
A weather alert arrives at a town three days after the storm already happened. Which property of a good communication system has failed here?
Reveal answer

Timeliness — the data wasn't delivered in a timely manner, making it useless even though it may have been accurate and correctly delivered.

Short answer 6
List all five components of a communication system in order from sender to receiver.
Reveal answer

Sender → Message → Medium (with Protocol applying throughout) → Receiver. (All five — message, sender, receiver, medium, protocol — must be present.)
