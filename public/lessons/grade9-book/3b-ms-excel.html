3.2 MS Excel — Interface, Sorting, Formulas & Charts
Organizing, calculating, and visualizing data in a spreadsheet.

What MS Excel is

  • A spreadsheet program that organizes, displays, formats, and calculates data using formulas and advanced features.
  • Part of the Microsoft Office Suite; integrates with other Office applications.
  • Used to perform calculations, visualize data with graphs, and build pivot tables.

3.2.1 MS Excel User Interface

  • File Tab — opens file-related options (new, open, save, print).
  • Quick Access Toolbar — shortcuts to frequently used commands.
  • Ribbon — the main set of command tabs/groups.
  • Column Header / Row Indicators — label each column (A, B, C…) and row (1, 2, 3…).
  • Worksheet Area — the grid of cells where data is entered.
  • Status Bar — shows quick info at the bottom (e.g. sum/average of a selection).
  • View Buttons / Zoom Slider — change the worksheet's view and zoom level.

3.2.2 Sorting

  • Sorting rearranges data based on a criterion — size, quality, value, or quantity.
  • To sort: select all the rows/columns of the data, go to the Data tab, choose Sort, pick the column to sort by, and choose the order (e.g. A to Z).
  • When one column is sorted, the related data in other columns (e.g. prices, quantities) is automatically rearranged to match.

3.2.3 Formulas

  • A formula tells Excel what calculation to perform — always starts with an equal sign (=), defined in the Formula Bar.
  • Supports addition, subtraction, multiplication, division, comparisons, and averages.

Example — adding A2 (220) and B2 (87) into C2:

  1. Select cell C2.
  2. Type =.
  3. Select cell A2 (its reference is placed in the formula).
  4. Type +.
  5. Select cell B2.
  6. Press Enter — the answer (307) is displayed in C2.

3.2.4 Charts

  • Charts (graphs) present a set of data visually — a large data table can be hard to interpret, but a chart makes patterns clear at a glance.
  • Example: a table of average monthly temperatures is hard to compare month-to-month, but a bar chart immediately shows the hottest and coldest months.

Practice — Test Yourself

These questions only cover what this subsection taught — the Excel interface, sorting, formulas, and charts.

Short answer 1
Every Excel formula must start with which symbol?
Reveal answer

An equal sign (=).

Short answer 2
Where in MS Excel would you find the Sort option?
Reveal answer

Under the Data tab.

Fill in the blank 3
In the MS Excel interface, the grid of cells where data is entered is called the ______ area.
Reveal answer

Worksheet.

Spot the error 4
A student types A2+B2 into cell C2 (with no equal sign) and expects it to calculate the sum. What's wrong?
Reveal answer

Every formula must start with an equal sign — without it, Excel treats the entry as plain text, not a calculation. It should be =A2+B2.

Applied / scenario 5
A student has a huge table of sales data and wants to quickly spot which month had the highest sales. What Excel feature would help most, and why?
Reveal answer

A chart (graph) — it presents the data visually, making patterns like the highest value much easier to spot at a glance than scanning raw numbers in a table.

Short answer 6
When sorting a product list alphabetically by name, what happens to the related price and quantity columns?
Reveal answer

They are automatically rearranged to stay matched with their correct product, so the data stays correctly linked row by row.
