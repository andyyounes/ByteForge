7.3.4 Entity Relationship (ER) Model
The four shapes of an ER diagram, and the six steps to design one.

What an ER Model is

  • An Entity Relationship Diagram (ERD) describes entities, attributes, and relationships (with their types) in a simplified diagram.
  • Used TWO ways: (1) to design a database that doesn't exist yet, based on requirements, or (2) to DOCUMENT an existing database (many tools auto-generate an ERD from a live database).
Theory — Four ER Diagram Shapes

Rectangle — an entity (a real-world object like Student, Teacher, Class).

Ellipse — an attribute of an entity (one entity can have several).

Diamond — a relationship between two entities.

Line (annotated 1 or M) — connects entities, labeled to show One or Many on each end.

Six Steps to Design an ER Model

  1. Identify and design the entities, based on user requirements.
  2. Identify and design the attributes within those entities.
  3. Identify the relationships required between entities.
  4. Define Primary Keys in interrelated entities.
  5. Design Foreign Key relationships, binding them to the Primary Keys already created.
  6. Generate the final (often automated) Entity Relationship Diagram.

Worked example — "A writer creates a novel and a consumer buys a novel"

  • Entities (rectangles): Writer, Consumer, Novel.
  • Relationships (diamonds): Creates (Writer → Novel), Buys (Consumer → Novel).
Practice — Test Yourself

These questions only cover what this subsection taught — ER diagram shapes and design steps.

Short answer 1
Which ER diagram shape represents an entity, and which represents a relationship?
Reveal answer

A rectangle represents an entity. A diamond represents a relationship.

Short answer 2
In the ER design steps, why must Primary Keys be defined BEFORE Foreign Keys?
Reveal answer

A Foreign Key has to bind/connect to an existing Primary Key in another entity — so the Primary Keys must already exist before Foreign Key relationships can be designed around them.

Fill in the blank 3
In an ER diagram, an attribute of an entity is represented by an ______ shape.
Reveal answer

ellipse.

Spot the error 4
A student says an ER diagram can ONLY be made before a database is built, never afterward. What's wrong?
Reveal answer

An ERD can also be used to DOCUMENT an already-existing database — many database tools can auto-generate one from a live database for this purpose.

Applied / scenario 5
In the "A writer creates a novel" example, what shape would represent "Creates", and what shape would represent "Novel"?
Reveal answer

"Creates" is a relationship, so it's a diamond. "Novel" is an entity, so it's a rectangle.

Short answer 6
What do the labels "1" and "M" on a connecting line in an ER diagram represent?
Reveal answer

They describe the type of relationship at that end of the connection — "1" means One, "M" means Many (e.g. a 1-to-M line means one record connects to many).
