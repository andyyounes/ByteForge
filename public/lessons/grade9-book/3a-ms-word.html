3.1 MS Word — Page Layout & Table of Contents
The five groups of the Page Layout tab, automatic vs. manual tables of contents, and typing in other languages.

What MS Word is

  • One of the most famous word-processing programs, first released in the early 1980s by Microsoft.
  • Introduced WYSIWYG (What You See Is What You Get) — the document preview looks exactly like the printed page.
  • Part of the Microsoft Office Suite, alongside MS Excel and MS PowerPoint.
Theory — The Page Layout Tab (Five Groups)

Controls the look and feel of a document — margins, themes, page orientation/size, sections, line numbers, and paragraph indentation.

Themes Group

  • A theme is a predefined set of formatting, colors, and settings that changes the overall design of the whole document — gives it a professional look.

Page Setup Group

  • Margins — space between the main content and the page edges.
  • Orientation — portrait (vertical) or landscape (horizontal).
  • Size — the paper size for the document/section.
  • Columns — splits text into two or more vertical columns.
  • Breaks — inserts page, section, or column breaks.
  • Line Numbers — adds line numbers to the left of each line.

Page Background Group

  • Watermark — a faded background image/text behind the content.
  • Page Color — sets the page background color.
  • Page Border — puts a border around the page.

Paragraph Group

  • Indent Left/Right — blank space separating a paragraph from the left/right margin.
  • Space Before/After — space added before/after a selected paragraph.

Arrange Group

  • Arranges graphical/other elements relative to the main text: Position (place an object anywhere), Wrap Text (arrange text around an image), Bring Forward / Send Backward (stacking order), Selection Pane (select/show/hide/reorder objects), Align (align objects to margins or each other), Group (combine objects into one), Rotate (rotate or flip an object).
Theory — Table of Contents (ToC)
  • A ToC is an organized listing of a document's sections/headings with their page numbers — gives an overview and lets readers jump directly to a section.
  • Found under the References tab — Table of Contents is the first option.
  • Automatic Table — built automatically from the document's Heading presets; the only difference between "Automatic Table 1" and "2" is the title ("Contents" vs "Table of Contents").
  • Manual Table — creates a blank template that must be filled in by hand with headings, sub-headings, and page numbers.

Typing in Urdu and Sindhi

  • MS Word 2010 supports typing in languages beyond its default (usually English), including Urdu and Sindhi.
  • The keyboard layout for that language must first be installed in Windows.
  • MS Word's default language can be changed via File → Options → Language.
Practice — Test Yourself

These questions only cover what this subsection taught — the Page Layout tab's groups, the Table of Contents, and language typing.

Short answer 1
Which Page Layout group would you use to add a faded background image behind your document's text?
Reveal answer

The Page Background group, specifically the Watermark button.

Short answer 2
What is the only real difference between Automatic Table 1 and Automatic Table 2 in MS Word's Table of Contents feature?
Reveal answer

Just the title shown — "Contents" versus "Table of Contents". Both build the table automatically from Heading presets.

Fill in the blank 3
MS Word introduced the concept of ______ — meaning the on-screen preview looks exactly like the printed page.
Reveal answer

WYSIWYG (What You See Is What You Get).

Spot the error 4
A student says a Manual Table of Contents updates itself automatically as headings change. What's wrong?
Reveal answer

A Manual Table creates a blank template that must be edited by hand — headings, sub-headings, and page numbers are entered manually. Only the Automatic Table builds itself from Heading presets.

Applied / scenario 5
A student wants to type an assignment in Sindhi, but when they try, only English characters appear. What's the most likely cause?
Reveal answer

The Sindhi keyboard layout hasn't been installed in Windows yet — the language keyboard must be installed before it can be typed in MS Word.

Short answer 6
Which Page Layout group would you use to combine several shapes into one single object?
Reveal answer

The Arrange group, specifically the Group button.
