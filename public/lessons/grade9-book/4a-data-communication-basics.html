4.1 Data Communication — Basic Terms
Analog vs. digital signals, data rate vs. baud rate, and signal-to-noise ratio.
Key Terms
Data
A collection of raw, unprocessed facts and figures (text, numbers, images, voice, video).
Data Communication
The process of transferring data electrically between two parties.
Data Transmission
Emission of data in any direction via a wired or wireless medium.
Signal-to-Noise Ratio (SNR)
Compares the level of a desired signal to background noise, often in decibels.
Theory — Analog vs. Digital Signals

Analog Signal

  • A continuous wave that changes over time.
  • No fixed range.
  • Easily disturbed by other signals/waves.
  • Example: the human voice.
  • Represented by a sine wave.

Digital Signal

  • A discrete wave carrying information in binary form.
  • Finite number of values — 0 or 1.
  • Less prone to disturbance.
  • Example: signals used inside a computer.
  • Represented by square waves.
Theory — Data Rate vs. Baud Rate
  • Data Rate (Bit Rate) — the number of bits (0s and 1s) transmitted per second; measured in bps, kbps, or mbps. Faster when more bits are transferred per second.
  • Baud Rate — the number of signal units transmitted per second. One signal can represent more than one bit.
  • Formula: Bit rate = Baud rate × number of bits per signal unit. (So Baud rate = Bit rate ÷ number of bits per signal unit.)
  • Example: a signal that changes 1200 times per second has a baud rate of 1200.
Practice — Test Yourself

These questions only cover what this subsection taught — analog/digital signals, data rate, and baud rate.

Short answer 1
Which type of signal is less prone to disturbance from noise — analog or digital? Why?
Reveal answer

Digital — because it only has a finite number of values (0 or 1), making it much harder for noise to change its meaning compared to a continuously varying analog wave.

Short answer 2
What is the key difference between data rate (bit rate) and baud rate?
Reveal answer

Bit rate counts the number of bits transmitted per second. Baud rate counts the number of signal units transmitted per second — and one signal unit can represent more than one bit.

Fill in the blank 3
A digital signal is represented by ______ waves, while an analog signal is represented by a ______ wave.
Reveal answer

square; sine.

Spot the error 4
A student says the human voice is naturally a digital signal. What's wrong?
Reveal answer

The human voice is a classic example of an ANALOG signal — a continuously varying wave, not a discrete 0/1 pattern.

Applied / scenario 5
A signal changes 2400 times per second, and each signal unit carries 2 bits. What is the bit rate?
Reveal answer

Bit rate = Baud rate × bits per signal unit = 2400 × 2 = 4800 bits per second.

Short answer 6
What does Signal-to-Noise Ratio (SNR) actually compare?
Reveal answer

The level (power) of the desired signal compared to the level of background noise.
