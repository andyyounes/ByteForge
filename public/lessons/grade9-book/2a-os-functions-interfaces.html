2.1 Functions of an Operating System & User Interfaces
What an OS actually manages, and the two most common ways a user interacts with it.
Key Terms
Operating System (OS)
Software performing all basic tasks: booting, file/memory/process management, and controlling peripherals.
Process
Program code loaded into memory for execution by the CPU.
User Interface (UI)
The part of the OS that lets a user enter and receive information.
Command interpreter
Reads user commands and translates them into machine language instructions.
Theory — Eight Functions of an OS
  • Booting — starts the OS, checks resources, and makes the computer ready to perform tasks.
  • Resource Management — allocates/de-allocates the processor, memory, shared cache, and network resources.
  • User Interface / Command Interpreter — reads commands and translates them into machine language.
  • Memory Management — allocates/de-allocates memory space to programs and data as needed.
  • Input/Output (I/O) Management — provides device drivers so I/O devices (through their controllers) can be used.
  • File Management — organizes storage, retrieval, naming, sharing, and protection of files.
  • Process Management — creation, deletion, suspension, and resumption of processes; process scheduling decides the order and how much CPU time each process gets, so every process gets a fair share.
  • User Management — lets administrators control user access to resources (software, I/O devices, storage, networks).
Theory — Two Types of User Interface

Command Line Interface (CLI)

  • Screen/text-based — the user types commands at a prompt.
  • Harder to use (must remember commands/syntax).
  • Faster — text mode uses fewer resources.
  • Used by UNIX terminals, MS-DOS, Apple DOS.

Graphical User Interface (GUI)

  • User-friendly — menus, icons, buttons, graphical objects.
  • Easy to use — click a picture instead of memorizing commands.
  • Slower than CLI — graphics mode uses more memory/resources.
  • Used by Windows, iOS.
Practice — Test Yourself

These questions only cover what this subsection taught — OS functions and the two interface types.

Short answer 1
Which OS function decides the order in which processes get access to the CPU, and how much time each gets?
Reveal answer

Process management, specifically process scheduling.

Short answer 2
Why is a CLI generally faster than a GUI, even though it's harder to learn?
Reveal answer

Text mode takes fewer resources than graphics mode, so a CLI uses less memory/resources and runs faster — at the cost of needing to remember commands and their exact syntax.

Fill in the blank 3
The ______ reads commands from the user, interprets them, and translates them into machine language instructions.
Reveal answer

command interpreter.

Spot the error 4
A student says a GUI is faster than a CLI because it uses pictures. What's wrong?
Reveal answer

It's the opposite — a GUI is actually SLOWER than a CLI, because graphical mode uses more memory and resources than text mode.

Applied / scenario 5
A server administrator wants the fastest possible way to manage a machine and is comfortable memorizing commands. Which interface type should they use, and why?
Reveal answer

A Command Line Interface (CLI) — it's faster since text mode uses fewer resources, and the "harder to use" downside doesn't matter much for someone comfortable with commands.

Short answer 6
What does the "resource management" function of an OS actually allocate and de-allocate?
Reveal answer

The processor, memory, access to shared cache memory, and access to network resources.
