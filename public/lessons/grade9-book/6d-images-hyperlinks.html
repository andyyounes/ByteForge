6.5-6.6 Images, Backgrounds & Hyperlinks
The <img> tag's attributes, page backgrounds, and linking pages together with <a>.

Images — <img>

  • An empty tag (no closing tag needed) — it only REFERENCES an image file, it doesn't copy it.
  • src (required) — the image file's URL/path.
  • alt (required) — alternate text shown if the image can't load.
  • width / height (optional) — display size in pixels.
  • border (optional) — border width around the image.
<img src="bridge.jpg" alt="Bridge" width="600">

Backgrounds

  • By default, browsers show a white background. Change it with two <body> attributes:
  • bgcolor — sets a background color (RGB code, hex code, or color name): <body bgcolor="green">
  • background — sets a background IMAGE: <body background="image.jpg">

Hyperlinks — <a>

  • Defined by the <a> tag and its href attribute — turns text/media into something clickable that navigates somewhere.
  • Linking to another page: <a href="http://www.google.com">Goto Google</a>
  • Linking within the SAME page (two steps): give a section an id, then link to it with href="#thatId".
  • target attribute controls WHERE the link opens: _blank (new tab), _self, _parent, _top.
<p id="navigate">Send user here on click</p>
<a href="#navigate">Go to the linked paragraph</a>
Practice — Test Yourself

These questions only cover what this subsection taught — images, backgrounds, and hyperlinks.

Short answer 1
Which two <img> attributes are REQUIRED, not optional?
Reveal answer

src (the image source) and alt (alternate text).

Short answer 2
What are the two steps needed to link to a section WITHIN the same page?
Reveal answer

1. Give the target section an id attribute. 2. Create a link with href set to that id, prefixed with a hash (#) symbol.

Fill in the blank 3
Setting a link's target attribute to ______ opens the linked page in a new browser tab/window.
Reveal answer

_blank.

Spot the error 4
A student says <img> copies the image file into the HTML document itself. What's wrong?
Reveal answer

The <img> tag only creates a REFERENCE to the original image file stored elsewhere — it does not copy the image into the document.

Applied / scenario 5
A student wants their whole page background to be a specific shade of blue using a hex code. Which attribute, on which tag, should they use?
Reveal answer

The bgcolor attribute on the <body> tag — its value can be a hex code, RGB code, or color name.

Short answer 6
What does the alt attribute of an image do?
Reveal answer

It defines alternate text shown if the image itself fails to load (or is read aloud by accessibility tools).
