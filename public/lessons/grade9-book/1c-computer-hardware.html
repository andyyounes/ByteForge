1.3 Computer Hardware
The system unit, the five parts of a microprocessor, and input/output/storage devices.
Key Terms
Hardware
The physical parts of a computer — can be seen and touched, unlike software.
Motherboard
The main board connecting every part of the computer — CPU, RAM, ROM, slots, ports, buses.
CPU / Microprocessor
The "brain" of the computer — fetches, decodes, executes, and stores instructions.
Bus
An electric path that carries data/commands/addresses between components — like a road.
Theory — The System Unit

Motherboard

  • Connects every part of the computer — like a nervous system. Holds the CPU, memory slots, expansion slots, and chipsets.
  • Made of layered fiberglass with copper circuitry carrying electrical signals.
  • Ports on the motherboard connect input, output, and other peripheral devices.

Microprocessor (CPU) — five components

  • ALU (Arithmetic Logic Unit) — performs all actual calculations: arithmetic (add/subtract/multiply/divide) and logical comparisons.
  • CU (Control Unit) — controls the transfer of data/instructions between units, like a traffic policeman; does NOT do actual processing itself.
  • Clock — generates pulses that instructions are executed on; measured in MHz/GHz.
  • Registers — temporary storage holding data currently being processed (8/16/32/64 bit).
  • Cache — intermediate storage inside the microprocessor holding immediately-processed information (internal cache inside, external cache outside the chip).

Buses — three types

  • Control Bus — carries commands between components to control activities.
  • Data Bus — carries data between the processor, memory, and other components.
  • Address Bus — carries the ADDRESS of data (not the data itself), specifying the memory location to use.
Theory — Input, Output & Storage Devices

Input devices (three categories)

  • Text entering — e.g. keyboard (each key press sends a scan code to the CPU).
  • Pointing — mouse, joystick, trackball, trackpad — move the cursor, especially in graphic mode.
  • Image scanning — scanners convert images into electronic format using light sensing / Optical Recognition: OMR, OBR, OCR.
  • Others: microphones (sound input / voice recognition), touch screens, MICR, magnetic strip readers.

Output devices (two types)

  • Soft copy (screen display / voice — volatile, lost when replaced or powered off): monitors (CRT or Flat Panel), data projectors, speakers.
  • Hard copy (on paper — nonvolatile, permanent): printers (Impact or Non-Impact), plotters (for large images like maps or construction drawings).

Storage devices (two types)

  • Primary — small capacity, fastest access, used DURING processing. RAM (volatile — loses content when power is off) and ROM (permanent, stores major settings).
  • Secondary — larger capacity, permanent storage. Hard Disk, CD/DVD, SD Card, USB flash disk.
Practice — Test Yourself

These questions only cover what this subsection taught — the system unit, microprocessor parts, and input/output/storage devices.

Short answer 1
Which part of the microprocessor performs the actual arithmetic and logical comparisons?
Reveal answer

The Arithmetic Logic Unit (ALU).

Short answer 2
What is the difference between the Control Unit and the ALU?
Reveal answer

The ALU actually performs calculations/comparisons. The Control Unit only manages and coordinates the transfer of data/instructions between units — it does not process data itself.

Fill in the blank 3
RAM is volatile, meaning it loses its content when ______, while ROM is permanent memory.
Reveal answer

the power supply is disconnected (the computer is turned off).

Spot the error 4
A student says the Address Bus carries the actual data being transferred. What's wrong?
Reveal answer

The Address Bus carries the ADDRESS of the data (the memory location), not the data itself. The Data Bus is what carries the actual data.

Applied / scenario 5
A student needs to print a large construction drawing. Which output device is the best fit?
Reveal answer

A plotter — it's specifically used for large-format images like maps and construction drawings, unlike a regular printer.

Short answer 6
Give one example each of a primary storage device and a secondary storage device.
Reveal answer

Primary: RAM or ROM. Secondary: Hard Disk, CD/DVD, SD Card, or USB flash disk.
