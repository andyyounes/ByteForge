6.1 Web Development — Basic Terminology & Types of Websites
Nine key web terms, and nine kinds of website.
Key Terms
World Wide Web (WWW)
Computers connected through a network providing publicly accessible information.
Web Page
A document (usually HTML) accessible via a browser.
Website
A collection of web pages about a specific topic, accessed via a URL.
Web Browser
Software for accessing websites (Chrome, Firefox, Safari, etc.).
URL
The address of a resource — protocol (https://) + server location (www.google.com).
Search Engine
A tool to locate information on the web (Google, Bing, Yahoo).
Home Page
The starting point / landing page of a website.
Web Hosting
A service that makes a website publicly accessible on the internet.
Web Server
The computer responsible for serving a website's content to users.
Theory — Nine Types of Website

Portal

One access point for info from many sources (Yahoo, MSN).

News

Current affairs, sports, weather — the modern newspaper.

Informational

Detailed info on a specific field (science, sports, research).

Educational

Learning material for teachers/students (Khan Academy, sabaq.pk).

Personal

Someone's own biography/achievements.

Business

Markets an organization's products/services (psx.com.pk).

Blog

Articles/posts sorted by publish date (WordPress).

Forum

A place for users to discuss categorized topics.

Entertainment / Social

Videos/games for fun (YouTube) or socializing (Facebook, Twitter).

Practice — Test Yourself

These questions only cover what this subsection taught — web terminology and website types.

Short answer 1
What are the two components of a URL?
Reveal answer

The protocol used to access the resource (e.g. https://) and the location of the server (e.g. www.google.com).

Short answer 2
What's the difference between a website and a web page?
Reveal answer

A web page is a single document. A website is a COLLECTION of related web pages accessed through one URL.

Fill in the blank 3
A ______ is a service that allows a web developer to make a website publicly accessible on the internet.
Reveal answer

web hosting (service).

Spot the error 4
A student says the home page is any page on a website chosen at random. What's wrong?
Reveal answer

The home page is specifically the STARTING POINT of the website — it's not random, it's the designated landing page visitors see first.

Applied / scenario 5
A teacher wants students to find lesson videos and practice exercises organized by subject. Which type of website best matches this purpose?
Reveal answer

An Educational website — purely designed to deliver educational material to teachers and students.

Short answer 6
What is the role of a web server?
Reveal answer

It's the computer responsible for serving a website and all its content (text, media) to a user.
