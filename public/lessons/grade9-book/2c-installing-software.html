2.3 Installing Software
Minimum requirements, where Windows/Office/antivirus installers come from, and why the virus database matters.

Software installation — the basic idea

  • Software installation is the process of making programs ready for execution — the installer places files (applications, drivers, other software) onto a computer.
  • Software can be installed from the internet (downloaded), or from an installation CD/DVD or USB flash drive.
  • An OS vendor specifies minimum hardware requirements to maintain compatibility between hardware and software — e.g. Windows 10 needs at least a 1GHz processor, 1GB RAM (32-bit) / 2GB RAM (64-bit), and 32GB of storage.

Office Automation software (MS Office)

  • Office Automation software is a group of programs that help users in their daily work — the most common package is MS Office.
  • MS Office contains: MS Word (word processor), MS Excel (spreadsheet), MS PowerPoint (multimedia presentation), MS Access (database management system), and MS Outlook (email).
  • Before installing, hardware/software must meet minimum requirements for that version (these differ version to version).

Installing antivirus software

  • Antivirus software is needed to keep a computer secure and free from viruses — examples include AVG, Avast, Avira, and Kaspersky.
  • The installation file is usually downloaded (needs internet access) and then run to install automatically.
  • The most important component of antivirus software is its virus database — this must be updated regularly to protect against new virus threats.
Practice — Test Yourself

These questions only cover what this subsection taught — installing software, MS Office, and antivirus basics.

Short answer 1
Why does an OS vendor specify minimum hardware requirements?
Reveal answer

To maintain compatibility between the hardware and the software being installed.

Short answer 2
Which MS Office program is the database management system, and which is the spreadsheet?
Reveal answer

MS Access is the database management system; MS Excel is the spreadsheet.

Fill in the blank 3
The most important component of an antivirus software, which must be updated regularly, is its ______.
Reveal answer

virus database.

Spot the error 4
A student says antivirus software only needs to be installed once and never needs updating. What's wrong?
Reveal answer

The virus database must be updated regularly — without updates, the antivirus can't protect against new virus threats discovered after installation.

Applied / scenario 5
A computer has only 500MB of RAM. Can it meet Windows 10's minimum requirement? Why or why not?
Reveal answer

No — Windows 10 needs at least 1GB of RAM for 32-bit (or 2GB for 64-bit), and 500MB is below that minimum.

Short answer 6
Name two sources software can be installed from, besides downloading it over the internet.
Reveal answer

An installation CD/DVD, or a USB flash drive.
