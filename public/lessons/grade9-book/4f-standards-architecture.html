4.6-4.8 Standard Organizations, the OSI & TCP/IP Models, and IP Addressing
Five standards bodies, seven OSI layers mapped to four TCP/IP layers, and what an IPv4 address actually is.
Theory — Five Standard Organizations

ISO

International Organization for Standardization — covers a wide range of fields; endorses/coordinates other standards bodies.

IEEE

Institute of Electrical and Electronic Engineering — non-profit; develops communication/info-processing standards for electrical/computer engineering.

IETF

International Engineering Task Force — network designers/operators concerned with internet architecture and smooth operation.

ITU

International Telecommunication Union — resolves issues concerning information/communication technologies.

ANSI

American National Standards Institute — the official (private, non-profit) standards agency for the United States.

Theory — The OSI Model (7 Layers)

A conceptual model from ISO standardizing how communication happens, divided into 7 layers (from top to bottom):

#LayerWhat it does
7ApplicationLets users access the network via apps like email/file transfer; produces the data.
6PresentationConverts data to a uniform format (ASCII/Unicode); handles encryption/decryption and compression.
5SessionEstablishes, maintains, and ends a session between two applications; adds checkpoints.
4TransportEnsures reliable delivery — error control, flow control, requests resend if needed.
3NetworkSelects the shortest/suitable path; converts logical (IP) address to physical (MAC) address.
2Data LinkTransmits data using physical addresses; ensures error-free transmission (unit = "Frame").
1PhysicalConverts electrical signals to bits; defines cable types, cards, topology.

The TCP/IP Model (4 Layers)

  • TCP/IP is a suite of protocols that interconnects network devices on the internet — defines how data is broken into packets, addressed, transmitted, routed, and received.
  • Application Layer (= OSI's Application+Presentation+Session) — uses protocols like HTTP/FTP; encodes/decodes data.
  • Transport Layer (= OSI's Transport) — uses TCP/UDP; establishes a logical connection, ensures reliable delivery.
  • Internet Layer (= OSI's Network) — handles packet forwarding via the physical path.
  • Network Access Layer (= OSI's Data Link+Physical) — uses logical addressing to decide how data crosses different network paths.
Theory — Network Addressing & IPv4

Physical Address vs. Logical Address

  • Physical (MAC) Address — attached to the NIC's ROM by the manufacturer; 48 bits; CANNOT be changed; globally unique and permanent.
  • Logical (IP) Address — assigned by an ISP or network administrator; 32 bits; CAN be changed; unique only within one network, and temporary.

IPv4 Address

  • A unique number identifying a device (computer, printer, phone, etc.) on a network — every internet-connected device needs one to communicate.
  • Made of 32 binary bits, split into a network portion (identifies the network) and a host portion (identifies the specific device).
  • Written as four number segments separated by dots — e.g. 192.168.108.105.
Practice — Test Yourself

These questions only cover what this subsection taught — standards organizations, OSI/TCP-IP, and IP addressing.

Short answer 1
Which OSI layer is responsible for converting a logical IP address into a physical MAC address?
Reveal answer

The Network layer (layer 3).

Short answer 2
What is the key difference between a Physical (MAC) Address and a Logical (IP) Address?
Reveal answer

A MAC address is fixed to the NIC by the manufacturer, 48 bits, and can never change. An IP address is assigned by an ISP/administrator, 32 bits, and can be changed.

Fill in the blank 3
An IPv4 address is made up of ______ binary bits, split into a network portion and a host portion.
Reveal answer

32.

Spot the error 4
A student says the TCP/IP model has 7 layers, same as OSI. What's wrong?
Reveal answer

TCP/IP has only 4 layers (Application, Transport, Internet, Network Access) — several OSI layers are combined into one TCP/IP layer each.

Applied / scenario 5
A video call keeps freezing because data packets arrive scrambled and need re-requesting. Which OSI layer is most directly responsible for fixing this kind of reliability issue?
Reveal answer

The Transport layer — it handles error control, flow control, and requests a resend if data isn't properly transmitted.

Short answer 6
Which standards organization is specifically the official standards agency for the United States?
Reveal answer

ANSI (American National Standards Institute).
