2.2 Types of Operating System
Single-user vs multi-user, batch processing, time sharing, and real-time systems.

Single User vs. Multi-User OS

  • Single User OS — only one user can access the computer at a time (e.g. DOS, Windows 98).
  • Multi-User OS — multiple users can access the computer at the same time; the OS manages memory/resources between them (e.g. Linux, UNIX).

Batch Processing OS

  • Programs run with minimum human interaction — the OS does not interact directly during processing.
  • Each user submits a job to the operator; jobs with similar needs are batched together and run as a group.
  • Benefits: can be shared by multiple users, very little idle time, the next job starts right after the current one finishes.

Time Sharing OS

  • Multiple users share resources simultaneously, each task given a short time slot called a quantum.
  • The CPU switches rapidly between tasks, so every user feels like they have the system to themselves and get an immediate response.
  • Also called Multitasking Systems. When the quantum is over, the OS switches to the next task.

Real Time Processing OS (RTOS)

  • A time-bound OS with a fixed time limit — processing must finish within that limit or the system fails.
  • Hard Real Time System — guarantees critical tasks complete on time; even the shortest delay is unacceptable. Examples: missile systems, Air Traffic Control.
  • Soft Real Time System — the time constraint is less strict; meeting the deadline isn't compulsory every time, but a critical task still gets priority. Examples: online transaction systems, airline ticket reservation.
Practice — Test Yourself

These questions only cover what this subsection taught — the four types of operating system.

Short answer 1
What is a "quantum" in a Time Sharing Operating System?
Reveal answer

The short time slot given to each task/user for execution before the OS switches to the next task.

Short answer 2
What's the key difference between a Hard Real Time System and a Soft Real Time System?
Reveal answer

A Hard Real Time System guarantees critical tasks complete on time with zero tolerance for delay. A Soft Real Time System is less strict — meeting the deadline isn't compulsory every time, though critical tasks still get priority.

Fill in the blank 3
In a ______ Operating System, jobs with similar needs are grouped together and run with minimum human interaction.
Reveal answer

Batch Processing.

Spot the error 4
A student says Air Traffic Control is a good example of a Soft Real Time System. What's wrong?
Reveal answer

Air Traffic Control is a Hard Real Time System — even the shortest delay is unacceptable, which is the defining feature of "hard", not "soft", real time.

Applied / scenario 5
A university computer lab needs 30 students to each run small programs on one shared server at the same time, each getting a quick response. Which OS type fits best?
Reveal answer

A Time Sharing Operating System — it lets multiple users share resources simultaneously, with the CPU switching rapidly between them so each feels they have an immediate response.

Short answer 6
Give one example operating system each for single-user and multi-user systems.
Reveal answer

Single-user: DOS or Windows 98. Multi-user: Linux or UNIX.
