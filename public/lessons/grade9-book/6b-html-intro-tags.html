6.2-6.3 Introduction to HTML, Tags & Text Formatting
The 4 steps to make a web page, tag structure, and the tags that format text.

What HTML is & the 4 steps to create a page

  • HTML = HyperText Markup Language — the standard markup language for creating structured web content (headings, paragraphs, links, media).
  • 1. Text Editor — create a new blank file (e.g. Notepad).
  • 2. Write HTML code — add the tags and content.
  • 3. Save — with a .htm or .html extension (not plain text).
  • 4. View in Browser — the browser translates the HTML into a displayed page.
<html>
  <head><title>My Website</title></head>
  <body>Welcome to my first web page.</body>
</html>

Tag structure

  • Simple tag: <tag-name>content</tag-name>
  • Tag with attribute: <tag-name attribute-name="value">content</tag-name>
  • Most tags need a closing tag; a few, like <br>, are "empty tags" with no closing tag needed.
  • <!DOCTYPE html> declares the HTML version. <html> wraps the whole document. <head> holds extra info (title, meta, style, script). <body> holds the visible content.
Theory — Formatting Tags
<title> / <footer>

Page title (shown in the browser tab and search results) / page footer text.

<p> / <br> / <hr>

Paragraph (adds space before/after) / line break (no extra space) / horizontal rule.

<h1>-<h6>

Six heading levels — h1 is the heaviest/largest, h6 the lightest/smallest.

<b> / <i> / <u>

Bold / italic / underline text.

<pre>

Preformatted text — preserves spaces and line breaks exactly as written.

<sub> / <sup>

Subscript (below baseline, e.g. H2O) / superscript (above line, e.g. E=mc2).

Practice — Test Yourself

These questions only cover what this subsection taught — HTML basics, tag structure, and formatting tags.

Short answer 1
What's the difference between <p> and <br>?
Reveal answer

<p> defines a paragraph and adds space before and after. <br> just breaks to a new line without adding that extra spacing.

Short answer 2
Which heading tag produces the LARGEST, heaviest text — h1 or h6?
Reveal answer

h1 — it is the heaviest heading; h6 is the lightest.

Fill in the blank 3
An HTML file must be saved with a ______ or .htm extension to be recognized as a web page.
Reveal answer

.html.

Spot the error 4
A student says every HTML tag, including <br>, needs a matching closing tag. What's wrong?
Reveal answer

Some tags, like <br>, are "empty tags" that don't require a closing tag — most tags do, but not all.

Applied / scenario 5
A student wants to show a chunk of code exactly as typed, preserving every space and line break. Which tag should they use?
Reveal answer

<pre> — it preserves spaces and line breaks exactly as written in the HTML source.

Short answer 6
What goes inside the <head> tag versus the <body> tag?
Reveal answer

The <head> holds extra information about the page (title, meta, style, script) — nothing visible. The <body> holds the actual visible content of the page.
