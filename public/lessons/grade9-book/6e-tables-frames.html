6.7-6.9 Tables, Frames & Web Design Tools
Rows, columns, cell attributes, dividing a page into frames, and real tools used to build websites.

Tables — rows, columns & headers

  • <table> defines the table. <tr> defines a ROW. <td> defines a data cell (a column's content within a row).
  • <th> defines a HEADER cell — placed in the first <tr> to label each column, visually distinct from <td>.
  • A "cell" is where a row and column meet.
<table border="1">
  <tr><th>Component</th><th>Requirement</th></tr>
  <tr><td>Processor</td><td>1GHz</td></tr>
</table>

Table & cell attributes

  • Table attributes: align (table position vs. surrounding text), width, border (on/off), cellpadding (space inside a cell), cellspacing (space between cells).
  • Cell attributes: align (left/center/right), valign (top/middle/bottom/baseline), colspan (merge across columns), rowspan (merge across rows).

Frames & Framesets

  • <frame> displays the content of ANOTHER HTML document within one section of the page. Its src attribute gives the URL to show.
  • Other frame attributes: marginheight, marginwidth, noresize, scrolling.
  • <frameset> defines HOW the page is divided into rows/columns of frames, using rows and cols attributes (in pixels or %).
  • Frames/framesets are only supported up to HTML version 4.1 — considered an old technique today.

Practice — Test Yourself

These questions only cover what this subsection taught — tables, frames, and web design tools.

Short answer 1
What's the difference between <td> and <th>?
Reveal answer

<td> defines a regular data cell. <th> defines a header cell, visually distinct, usually used in the first row to label each column.

Short answer 2
Which cell attribute would you use to make one cell span across 2 columns?
Reveal answer

colspan (e.g. colspan="2").

Fill in the blank 3
A ______ defines HOW a web page is divided into rows and columns to display multiple frames.
Reveal answer

frameset.

Spot the error 4
A student says cellpadding controls the space BETWEEN two different cells. What's wrong?
Reveal answer

cellpadding controls the space INSIDE a cell, between its edge and its content. cellspacing is the one that controls space BETWEEN cells.

Applied / scenario 5
A student wants a table cell to merge vertically across 3 rows (like a category label spanning several rows of data). Which attribute should they use?
Reveal answer

rowspan (e.g. rowspan="3").

Short answer 6
Name two real tools used for website design/development mentioned in this lesson.
Reveal answer

Any two of: Microsoft FrontPage, CorelDraw, Adobe Dreamweaver, WordPress, Microsoft Visual Studio, Wix, Figma, CoffeeCup HTML Editor, Adobe XD.
