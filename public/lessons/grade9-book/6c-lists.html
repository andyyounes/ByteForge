6.4 Creating Lists
Unordered, ordered, description, and nested lists.

Unordered List — <ul>

  • For items where ORDER doesn't matter. Each item is an <li>, displayed as a bullet point.
<ul>
  <li>Word</li>
  <li>Excel</li>
</ul>

Ordered List — <ol>

  • For items where ORDER matters (e.g. exam rank). Items are numbered starting from 1 instead of bulleted.
  • start attribute sets the first number; reversed displays in descending order; a value attribute on an <li> places it at a specific position.

Description List — <dl>

  • For terms and their definitions, like a glossary. The term is <dt>, its description is <dd>.
  • One term can have multiple descriptions, and vice versa.
<dl>
  <dt>Operating System</dt>
  <dd>Software that manages a computer's resources.</dd>
</dl>

Nested Lists

  • Any list type can contain another list type as one of its items — just place the new list tag inside an <li> of the outer list.
  • Browsers automatically indent nested lists and assign their own markers.
<ul>
  <li>Twisted Pair Cable
    <ul>
      <li>Unshielded Twisted Pair</li>
      <li>Shielded Twisted Pair</li>
    </ul>
  </li>
  <li>Coaxial Cable</li>
</ul>
Practice — Test Yourself

These questions only cover what this subsection taught — the four list types.

Short answer 1
When would you choose an ordered list over an unordered list?
Reveal answer

When the order of the items actually matters — e.g. a ranked list of students by exam score. An unordered list is for items where order is irrelevant.

Short answer 2
Which tags make up a description list, and what does each one hold?
Reveal answer

<dl> wraps the whole list; <dt> holds the term; <dd> holds its description.

Fill in the blank 3
The reversed attribute on an <ol> displays the list items in ______ order.
Reveal answer

descending.

Spot the error 4
A student says nested lists require a completely different tag, not <ul> or <ol>. What's wrong?
Reveal answer

A nested list is just a normal <ul> or <ol> placed inside an <li> of the outer list — no special tag is needed.

Applied / scenario 5
A student is building a glossary page defining key computer science terms. Which list type fits best?
Reveal answer

A description list (<dl>) — it's specifically designed for terms and their definitions.

Short answer 6
What tag is used for each individual item inside both <ul> and <ol>?
Reveal answer

<li>.
