1.4-1.5 Basic Operations & Software
The four basic operations of a computer, and the two main types of software.
Theory — The Four Basic Operations
InputKeyboard, mouse, or data from a network
→
ProcessingCPU converts input into output (arithmetic/logic)
→
OutputMonitor, speakers, or printer
→
StorageRAM, ROM, or Hard Disk hold the data
  • Input — data entering the computer, from a keyboard/mouse command or sent from another computer on a network.
  • Processing — done by the CPU; converts input into meaningful output using arithmetic and logical operations.
  • Storage — holding/saving data; RAM, ROM, and Hard Disk are the storage devices used.
  • Output — the result of processing; viewed on a monitor, heard through speakers, or printed on paper (these are the output devices).
Theory — Computer Software

System Software

Coordinates all activities and controls the hardware. Includes:

  • Operating System — the master control program managing all system resources and creating the interface between the computer and the user (e.g. Windows, Linux).
  • Device Drivers — translators between the OS and a hardware device. "Plug and Play" devices are instantly recognized because drivers are pre-installed; non-plug-and-play devices need manual driver installation.
  • Utility Programs — help manage/maintain/control resources, e.g. antivirus software, disk cleaner (removes unnecessary files), and disk defragmenter (reorganizes files to improve performance).
  • Language Translators — convert human-readable instructions into machine language (0s and 1s). Three types:
    • Assembler — translates assembly language into machine language.
    • Compiler — translates the ENTIRE high-level program at once, before it runs.
    • Interpreter — translates a high-level program LINE BY LINE as it runs.

Application Software

Used to complete specific tasks — not pre-installed, must be installed separately. Types include:

  • Productivity Software — documents, spreadsheets, databases, presentations (e.g. MS Office).
  • Business Software — billing, database management, inventory management.
  • Entertainment Software — games, media players.
Practice — Test Yourself

These questions only cover what this subsection taught — the four basic operations and the two types of software.

Short answer 1
Put the four basic operations of a computer in the correct order.
Reveal answer

Input → Processing → Output → Storage (storage can also happen alongside/after processing, but input always comes first and processing always precedes output).

Short answer 2
What is the key difference between a compiler and an interpreter?
Reveal answer

A compiler translates the entire program at once, before execution. An interpreter translates and executes the program line by line.

Fill in the blank 3
A device driver acts as a ______ between the operating system and a hardware device.
Reveal answer

translator.

Spot the error 4
A student says MS Excel is an example of system software. What's wrong?
Reveal answer

MS Excel is application software (specifically productivity software) — it's used for a specific task (spreadsheets) and must be installed separately, unlike system software which coordinates the computer's own operations.

Applied / scenario 5
A computer's hard disk has become slow and fragmented over time. Which utility program should be used, and what does it do?
Reveal answer

Disk defragmenter — it reorganizes files on the hard disk drive to increase performance.

Short answer 6
Name the three types of language translators.
Reveal answer

Assembler, compiler, and interpreter.
