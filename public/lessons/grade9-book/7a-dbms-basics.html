7.1-7.2 DBMS Basics & Components
Flat files vs. a real DBMS, and the building blocks: tables, fields, records, data types, views.

What a DBMS is

  • A Database Management System (DBMS) is the interface between a database and its end users/programs — it keeps data consistently organized and accessible.
  • Popular DBMSs: MySQL, Oracle, Microsoft SQL Server, MongoDB, PostgreSQL, IBM Db2.
Theory — Flat File vs. DBMS

Flat File System

  • Single table structure, plain text, one record per line (fields separated by tabs/commas).
  • Only ONE user at a time.
  • Suitable only for small data sets.
  • Increases duplicate/redundant data.
  • No remote/online access.

DBMS

  • Multiple users can access data simultaneously.
  • Handles huge data sets.
  • Reduces duplication, keeps data integrity.
  • Supports online/remote access.
  • Good for small, medium, AND large businesses.
Theory — Four Components of DBMS
ComponentWhat it is
TableA collection of data organized in rows and columns (e.g. a contact list).
FieldThe SMALLEST component — a single named column where data is actually stored. Also called an attribute or column.
RecordA single ENTRY (row) in a table — also called a tuple. Made up of several fields' worth of data.
ViewA virtual way to SEE data from one or more tables — doesn't store data itself, and can't change the original data.

Hierarchy: several fields → one record; several records → one table; several tables → one database.

Data Types

  • Integer — whole numbers (145, -35).
  • Floating Point — numbers with decimals (5.6, 3.14).
  • Character/String — one character, or a combination of letters/numbers/symbols.
  • Boolean — only true/false (1/0).
  • Date & Time — a date/time in a specific format.
  • Choosing the right data type matters — it helps the database run faster.
Practice — Test Yourself

These questions only cover what this subsection taught — flat files vs. DBMS, and tables/fields/records/views.

Short answer 1
What is the SMALLEST component of a database, and what is it also called?
Reveal answer

A field — also called an attribute or column.

Short answer 2
Why can only one user access a flat file system at a time, unlike a DBMS?
Reveal answer

A flat file system is a simple plain-text single-table structure without the multi-user access features a real DBMS provides — DBMS is specifically built to let multiple users access data simultaneously.

Fill in the blank 3
A single entry (row) in a table is called a ______, also known as a tuple.
Reveal answer

record.

Spot the error 4
A student says a view stores its own copy of the data separately from the original table. What's wrong?
Reveal answer

A view does NOT store data — it only shows data virtually, fetched from the original tables, and doesn't allow changes to the underlying data.

Applied / scenario 5
A field needs to store whether a student has paid their fees (yes/no only). Which data type fits best?
Reveal answer

Boolean — it can only hold true/false (1/0), which is exactly a yes/no value.

Short answer 6
List the hierarchy from smallest to largest: field, database, record, table.
Reveal answer

Field → Record → Table → Database.
