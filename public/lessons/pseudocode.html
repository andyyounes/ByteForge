Cambridge Pseudocode

This sandbox runs Cambridge A-Level pseudocode — the standard used in CIE Computer Science exams.

Supported: DECLARE, OUTPUT, INPUT, IF/THEN/ELSE/ENDIF, FOR/TO/NEXT, WHILE/DO/ENDWHILE, PROCEDURE, FUNCTION, arrays, and more.

Show syntax reference ▼
DECLARE x : INTEGER
OUTPUT "Hello, " & name
INPUT x
IF x > 0 THEN
  OUTPUT "positive"
ELSE
  OUTPUT "negative"
ENDIF
FOR i ← 1 TO 10
  OUTPUT i
NEXT i
WHILE x < 10 DO
  x ← x + 1
ENDWHILE
