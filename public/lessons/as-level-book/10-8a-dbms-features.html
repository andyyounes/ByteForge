10.08 DBMS Features
The data dictionary, indexing for speed, and security — the DBMS's job beyond just storing rows. Completes Chapter 10.
Key Terms
Data dictionary
The hidden part of the database (visible only to the DBA) containing metadata — definitions of tables, attributes, and physical storage.
Index
A secondary table of attribute values + pointers to the corresponding original tuple, for faster searching.
Theory

The data dictionary — hidden from everyone except the DBA

  • Part of the database that is HIDDEN from view from everyone except the DBA.
  • Contains METADATA about the data: all table/attribute definitions, AND how physical storage is organised.

Indexes — why searching a big table can be made faster

  • Needed when a table contains a LOT of data.
  • An index is a SECONDARY table, associated with an attribute that has unique values — containing the attribute's values plus POINTERS to the matching tuple in the original table.
  • An index can be built on the primary key, OR on a secondary key (a candidate key that wasn't chosen as primary key).
  • Searching an index table is MUCH quicker than searching the full table — a smaller, focused structure to search through instead of every attribute of every row.

Security — the DBMS's third major responsibility

  • Setting ACCESS RIGHTS for users.
  • Implementing BACKUP procedures.
  • Ensuring an INTERRUPTED transaction cannot leave the database in an undefined (half-completed, inconsistent) state.
Practice — Test Yourself

These questions only cover what THIS subsection taught — the data dictionary, indexing, and DBMS security features (completes Section 10.08 and Chapter 10).

Short answer 1
Who is allowed to see the data dictionary, and what does it contain?
Reveal answer

Only the DBA. It contains metadata: definitions of all tables and attributes, plus how physical storage is organised.

Short answer 2
What two things does an index table store for each entry?
Reveal answer

The attribute's value, and a POINTER to the corresponding tuple in the original table.

Fill in the blank 3
An index can be built on the primary key, or on a ______ key — a candidate key that wasn't chosen as the primary key.
Reveal answer

Secondary.

Spot the error 4
A student says: "An index IS the actual data table, just sorted differently." What's the more accurate description?
Reveal answer

An index is a SEPARATE, secondary table — it holds attribute values and POINTERS to the real data, not the full rows themselves. This is exactly why searching it is faster than searching the full table.

Applied / scenario 5
A power outage interrupts a database transaction partway through. Which DBMS responsibility, from this lesson, is specifically meant to prevent lasting damage from this?
Reveal answer

Security/transaction control — specifically, ensuring an interrupted transaction cannot leave the database in an undefined (inconsistent, half-completed) state.

Short answer 6
List the three security-related responsibilities of a DBMS mentioned in this lesson.
Reveal answer

Setting access rights for users; implementing backup procedures; ensuring an interrupted transaction can't leave the database in an undefined state.
