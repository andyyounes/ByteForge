26.02 Records
Declaring and using record types across pseudocode, Python, VB.NET, and Pascal.
Theory

A quick recap

  • Records are USER-DEFINED types (Chapter 16) — already used for linked-list/tree NODES (Chapter 23).
  • A record groups related fields of potentially DIFFERENT types into one coherent structure.

Worked example — a car record

TYPE CarRecord DECLARE VehicleID : STRING // unique identifier / record key DECLARE Registration : STRING DECLARE DateOfRegistration : DATE DECLARE EngineSize : INTEGER DECLARE PurchasePrice : CURRENCY ENDTYPE DECLARE ThisCar : CarRecord DECLARE Car[1:100] OF CarRecord // an array of 100 car records

Language-specific implementations

  • Python has NO built-in record type — a CLASS is used instead (previewing Chapter 27): class CarRecord: with a constructor __init__ that sets default field values.
  • VB.NET uses a Structure: Structure CarRecord ... End Structure.
  • Pascal uses type CarRecord = record ... end;.
# Python — using a class as a substitute for a record type class CarRecord: def __init__(self): self.VehicleID = "" self.Registration = "" self.EngineSize = 0 self.PurchasePrice = 0.00 ThisCar = CarRecord() # instantiate ThisCar.EngineSize = 2500 # assign to a field Car = [ThisCar for i in range(100)] # a "list" of 100 car records Car[1].EngineSize = 2500 # field of the 2nd car in the list

Accessing fields consistently across languages

  • All four languages use DOT NOTATION to access a field: ThisCar.EngineSize (pseudocode/Python/Pascal-style), or in VB.NET, similarly ThisCar.EngineSize.
  • Accessing a field of an ARRAY element follows the same pattern: Car[2].EngineSize (index first, then dot, then field).
Practice — Test Yourself

These questions only cover what THIS subsection taught — records across pseudocode, Python, VB.NET, and Pascal (completes Section 26.02).

Short answer 1
Since Python has no built-in record type, what does it use instead?
Reveal answer

A class definition.

Short answer 2
What keyword does VB.NET use to define a record-like type?
Reveal answer

Structure (e.g. Structure CarRecord ... End Structure).

Fill in the blank 3
Fields within a record variable are accessed using ______ notation.
Reveal answer

Dot.

Spot the error 4
A student writes Python code creating 100 car records with Car = [ThisCar for i in range(100)], then modifies Car[1].EngineSize and is surprised to find EVERY car's EngineSize changed. What went wrong?
Reveal answer

This list comprehension puts the SAME object reference (ThisCar) into every list slot, rather than 100 independent copies — modifying one modifies all of them, since they all point to the identical underlying object in memory.

Applied / scenario 5
Write pseudocode to declare a record type Student with fields Name (STRING) and Age (INTEGER), then declare a single variable of that type.
Reveal answer

TYPE Student
  DECLARE Name : STRING
  DECLARE Age : INTEGER
ENDTYPE
DECLARE ThisStudent : Student

Short answer 6
What keyword does Pascal use to define a record type?
Reveal answer

record (e.g. CarRecord = record ... end;).
