18.04 Karnaugh Maps (K-maps)
A grid-based shortcut for simplifying Boolean expressions, without doing any algebra. Completes Chapter 18.
Theory

What a K-map is for

  • Reaches the SAME simplified expression that Boolean algebra would eventually reach, but through visual grouping instead of algebraic manipulation.
  • Each cell in the grid shows the truth table's output value for one specific combination of inputs.

The rules for reading a K-map

  • Only cells containing a 1 are considered.
  • Group 1s together where possible — a group can be a row, a column, or a rectangle.
  • Groups must contain a power-of-2 number of cells: 2, 4, 8, and so on.
  • Each group should be made as LARGE as possible.
  • Groups CAN overlap.
  • A cell that can't join any group is treated as its own group of one.
  • Within a group, only the input values that stay CONSTANT throughout the group are kept in the final expression.

Worked example — the OR gate

B=0B=1
A=001
A=111
  • Sum-of-products would give X = A.B̄ + Ā.B + A.B — correct, but not obviously equal to A+B.
  • Using the K-map: the COLUMN group (B=1) has B constant while A changes — keep B. The ROW group (A=1) has A constant while B changes — keep A.
  • Sum the retained values from each group: X = A + B — found with no algebra at all.

Worked example — a three-input problem, with wraparound

  • K-map columns for a 2-variable pair (B, C) are labelled using GRAY CODE order (00, 01, 11, 10) — NOT plain binary order — so that only ONE bit changes between adjacent columns.
  • K-maps WRAP AROUND: the leftmost and rightmost columns are also considered "adjacent" for grouping purposes (since Gray coding makes them differ by only one bit too).
  • For a truth table where output=1 whenever B=1 (regardless of A or C), plus one extra 1 at A=0,B=0,C=0: the four-cell "B=1" group gives the term B; a wraparound row group (using the extra cell plus its Gray-code neighbour) gives A.C̄.
  • Final simplified expression: X = A.C̄ + B — far simpler than the five-minterm sum-of-products expression derived directly from the truth table.

Chapter 18 summary

  • Boolean algebra laws let you simplify logic expressions — De Morgan's laws convert between AND/OR forms of an inverse.
  • A half adder (AND + XOR, or NAND-only) adds two bits; a full adder (two half adders + OR) adds two bits plus a carry-in.
  • SR and JK flip-flops are sequential circuits used to store a bit — JK avoids the SR flip-flop's invalid state via toggling.
  • Sum-of-products builds an expression directly from a truth table's 1-output rows.
  • A Karnaugh map visually groups 1s to reach a simplified expression without algebra.
Practice — Test Yourself

These questions cover Karnaugh maps and draw together the whole of Chapter 18 (completes Section 18.04 and Chapter 18).

Short answer 1
Why must K-map groups contain a power-of-2 number of cells (2, 4, 8...) rather than any number?
Reveal answer

Each cell added to a group must correspond to exactly one input variable changing while the others stay fixed — this only works out cleanly for group sizes that are powers of 2, matching how binary/Gray-code combinations pair up.

Short answer 2
Why are K-map columns labelled using Gray code rather than plain binary order?
Reveal answer

So that only ONE bit changes between any two ADJACENT columns — this is essential for correctly identifying which input values stay constant across a group of adjacent cells.

Fill in the blank 3
Within a K-map group, only the input values that remain ______ throughout the group are kept in the final expression.
Reveal answer

Constant.

Spot the error 4
A student groups together the top-left cell and the bottom-left cell of a 4-column K-map, believing they can't be adjacent because they're in different rows and not next to each other visually. What's the misconception?
Reveal answer

Actually, it's the leftmost and RIGHTMOST columns (within the same row) that wrap around and count as adjacent under Gray coding — not top and bottom of the SAME column, unless the map also wraps vertically for a 4-input problem. The student needs to check which wraparound rule actually applies to their specific map's dimensions.

Applied / scenario 5
A K-map group spans all four cells where B=1 (across both values of A and C). What term does this group contribute to the final expression?
Reveal answer

Just B — since A and C both change across the group but B stays constant (at 1), only B is retained.

Short answer 6
What should you do with a single 1-cell that cannot be paired with any adjacent 1-cell?
Reveal answer

Treat it as its own group of one — its full minterm (every input, inverted where needed) is kept as a separate term in the final expression.
