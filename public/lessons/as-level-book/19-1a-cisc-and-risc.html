19.01–19.02 The Control Unit, CISC and RISC
Hard-wired vs. microprogrammed control, and two competing philosophies of instruction set design.
Theory

The control unit — two design approaches

  • HARD-WIRED: the control unit is built as a logic circuit — machine-code instructions are handled DIRECTLY by hardware.
  • MICROPROGRAMMED: the control unit contains a ROM storing MICROINSTRUCTIONS (microcode) — often called FIRMWARE. Each machine instruction is carried out by running a small sequence of these microinstructions.
  • The choice largely depends on the TYPE of processor.

What "architecture" means for a processor

  • From a sophisticated programmer's viewpoint, architecture involves: the INSTRUCTION SET, the INSTRUCTION FORMAT, the ADDRESSING MODES, and the REGISTERS accessible by instructions.
  • The choice of instruction set is the main factor. Historically, the view that instruction sets should suit HIGH-LEVEL LANGUAGES became dominant — leading to increasingly complex (CISC) processors.

Why each approach makes the trade-offs it does

  • RISC's SIMPLICITY lets data stay in REGISTERS and be manipulated there, with memory only accessed for initial loading and final storing — this also makes HARD-WIRING feasible, since the control logic stays manageable.
  • CISC's SPECIALISED instructions often need REPEATED memory access, and are complex enough that hard-wiring becomes impractical — so MICROPROGRAMMING is the norm.
  • The upside of CISC's complexity: instructions closely matching high-level language constructs make COMPILER WRITING much easier for a CISC processor.
Practice — Test Yourself

These questions only cover what THIS subsection taught — control unit design, and CISC vs. RISC (completes Sections 19.01–19.02).

Short answer 1
What is the key difference between a hard-wired and a microprogrammed control unit?
Reveal answer

A hard-wired control unit is built directly as a logic circuit that handles machine instructions in hardware. A microprogrammed control unit stores microinstructions (firmware) in ROM, and each machine instruction is executed as a small sequence of those microinstructions.

Short answer 2
Why does RISC's instruction simplicity make hard-wiring more practical?
Reveal answer

Simpler instructions require less complex control logic — the reduced complexity keeps the hard-wired circuit manageable, unlike CISC's specialised instructions which are typically too complex to hard-wire.

Fill in the blank 3
A CISC processor's complexity is often justified by instructions closely matching ______ constructs, which makes ______ writing easier.
Reveal answer

High-level language; compiler.

Spot the error 4
A student says "RISC" means the processor can only run simple programs. What's the misconception?
Reveal answer

RISC refers to a REDUCED INSTRUCTION SET — fewer, simpler individual instructions — not a limit on what programs can be built. Complex programs are still achieved by combining many simple instructions; RISC just changes how the underlying building blocks are designed.

Applied / scenario 5
Why does RISC's approach require multiple register sets, in a way CISC does not need as urgently?
Reveal answer

Because RISC keeps data in registers as much as possible rather than accessing memory repeatedly — this only works well if there are enough registers available; this also connects to pipelining (Section 19.02), where each pipeline stage needs its own register access.

Short answer 6
Name the four aspects that define a processor's "architecture" from a programmer's viewpoint.
Reveal answer

The instruction set, the instruction format, the addressing modes, and the registers accessible by instructions.
