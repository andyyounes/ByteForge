19.03 Parallel Processing
SISD, SIMD, MISD, MIMD — and scaling parallelism up to whole networks of computers. Completes Chapter 19.
Theory

The four categories of parallel system

CategoryMeaningExample
SISDSingle Instruction, Single Data streamEarly personal computers — one processor, one memory, no parallelism
SIMDSingle Instruction, Multiple Data streamArray/vector processors — one instruction runs on many processors, each with its own memory and data
MISDMultiple Instruction, Single Data streamNot implemented in commercial products
MIMDMultiple Instruction, Multiple Data streamModern symmetric multiprocessor PCs — identical processors, each executing a different instruction

SIMD in more detail

  • ONE instruction is broadcast to MULTIPLE processors, each of which has its OWN dedicated memory — every processor executes the SAME instruction, but on its OWN local data.
  • Ideal for problems that apply an identical operation across a large dataset (e.g. graphics/vector processing).

MIMD in more detail

  • Multiple IDENTICAL processors, each running a DIFFERENT instruction at any given moment (symmetric multiprocessing).
  • The "multiple data" stream doesn't need multiple physical memories — a SINGLE memory, suitably PARTITIONED, can supply each processor. Each processor might also have its own dedicated CACHE memory.

Scaling up: multicomputer systems

  • MASSIVELY PARALLEL COMPUTERS ("supercomputers") are used by large organisations for highly complex mathematical processing.
  • The key architectural difference from a multiprocessor system: instead of a BUS structure connecting multiple processors, there is a NETWORK infrastructure connecting multiple whole COMPUTER units — these communicate by passing MESSAGES over the network.
  • CLUSTER COMPUTING is an alternative multicomputer approach: a very large number of ordinary PCs networked together.

Chapter 19 summary

  • A control unit can be hard-wired or microprogrammed.
  • RISC processors offer several advantages over CISC — chiefly, simpler hard-wired control and easier pipelining.
  • Pipelining is instruction-level parallelism, splitting fetch-decode-execute into overlapping stages for major speedup, at the cost of trickier interrupt handling.
  • Parallelism can operate at the instruction level (pipelining), the processor level (SIMD/MIMD), or the whole-computer level (massively parallel/cluster computing).
Practice — Test Yourself

These questions cover parallel processing categories and draw together the whole of Chapter 19 (completes Section 19.03 and Chapter 19).

Short answer 1
What is the key difference between SIMD and MIMD?
Reveal answer

SIMD: ONE instruction runs on MULTIPLE processors, each working on its own data. MIMD: MULTIPLE processors each execute a DIFFERENT instruction, potentially on different data.

Short answer 2
What replaces a bus structure in a massively parallel computer system, compared to a single multiprocessor computer?
Reveal answer

A network infrastructure, connecting multiple separate computer units that communicate by passing messages, rather than a bus connecting multiple processors within one machine.

Fill in the blank 3
Parallelism can be based at the ______ level, the ______ level, or the ______ level.
Reveal answer

Instruction (pipelining); processor (SIMD/MIMD); computer (massively parallel/cluster computing).

Spot the error 4
A student says a modern multi-core PC running several different applications simultaneously is an example of SIMD. What's the correct classification?
Reveal answer

MIMD — each processor core is running a DIFFERENT instruction (from a different application), which is exactly the "multiple instruction" part of MIMD, not the single-instruction pattern of SIMD.

Applied / scenario 5
In an MIMD system, how can multiple processors share data without each needing a physically separate memory?
Reveal answer

A single memory can be suitably PARTITIONED so different processors access different sections — combined with individual dedicated cache memory per processor for faster local access.

Short answer 6
What is cluster computing?
Reveal answer

A type of multicomputer system where a very large number of ordinary PCs are networked together to work as a combined parallel system.
