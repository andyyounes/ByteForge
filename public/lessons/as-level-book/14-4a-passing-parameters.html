14.04–14.05 Passing Parameters to Subroutines and Functions
Giving a subroutine data to work with — parameters, arguments, and the subroutine interface.
Theory

Parameters vs. arguments

  • When a subroutine needs values from the main program, it declares a PARAMETER LIST in its header — placeholders for the values it expects.
  • At call time, the actual values supplied are called ARGUMENTS. Their order must match the order of parameters in the header — this is known as the SUBROUTINE INTERFACE.
  • You don't need to know a built-in function's internal identifiers to call it — you just supply arguments in the right order.

Function header with parameters

FUNCTION <functionIdentifier>(<parameterList>) RETURNS <dataType>
  • <parameterList> is a list of identifiers and their data types, separated by commas.
FUNCTION SumRange(FirstValue : INTEGER, LastValue : INTEGER) RETURNS INTEGER DECLARE Sum, ThisValue : INTEGER Sum ← 0 FOR ThisValue ← FirstValue TO LastValue Sum ← Sum + ThisValue ENDFOR RETURN Sum END FUNCTION NewNumber ← SumRange(1, 5) // arguments 1 and 5 map to FirstValue, LastValue in order
# Python def SumRange(FirstValue, LastValue): Sum = 0 for ThisValue in range(FirstValue, LastValue + 1): Sum = Sum + ThisValue return Sum NewNumber = SumRange(1, 5)
Practice — Test Yourself

These questions only cover what THIS subsection taught — parameters, arguments, and the subroutine interface (completes Sections 14.04–14.05).

Short answer 1
What is the difference between a parameter and an argument?
Reveal answer

A parameter is the placeholder identifier declared in the subroutine header; an argument is the actual value supplied when the subroutine is called.

Short answer 2
What is the name for the ordered relationship between a subroutine's parameter list and the arguments supplied when it's called?
Reveal answer

The subroutine interface.

Fill in the blank 3
The order of arguments supplied at call time must match the order of ______ in the subroutine's header.
Reveal answer

Parameters.

Spot the error 4
Given FUNCTION SumRange(FirstValue : INTEGER, LastValue : INTEGER) RETURNS INTEGER, a student calls it as SumRange(5, 1) intending to sum 1 to 5. What actually happens?
Reveal answer

FirstValue becomes 5 and LastValue becomes 1 (matched by POSITION, not intention) — the FOR loop from 5 TO 1 would not execute at all in most pseudocode conventions, so Sum stays 0, not the intended 15.

Applied / scenario 5
Write a pseudocode function header for a function called Factorial that takes one INTEGER parameter, Number, and returns an INTEGER.
Reveal answer

FUNCTION Factorial(Number : INTEGER) RETURNS INTEGER

Short answer 6
Why don't you need to know a built-in function's internal variable names to use it?
Reveal answer

Because you only interact with it through its interface — supplying arguments in the correct position and type is enough; its internal implementation is hidden from the caller.
