3.04 Computer Graphics: Halftoning
A trick borrowed from newspaper printing, decades before computers existed.
Key Terms
Halftoning
Approximating a continuous grey tone using an array of dots — varying dot size or number to change the perceived tone.
Raster image processor
Hardware/software combination that converts graphics-file data into the physical screen display or printed page.
Theory

The shared limitation behind screens AND printed pages

  • Both screen displays and printed pages share the same underlying limitation — a limitation well understood by the NEWSPAPER PRINTING industry long before computers existed.
  • The problem: a photograph has CONTINUOUS tones, but a printer at any given position on a page could only print black or nothing — no in-between grey.

The original solution — halftoning with variable dot SIZE

  • Halftoning approximates a grey tone by printing an array of black dots; VARYING THE SIZE of the dots changes the tone that's perceived.
  • This technique relies on a limitation of the human eye — it doesn't register the individual dots if they're sufficiently small.

The computer-graphics variation — variable dot COUNT, not size

  • Normally, neither screen nor printer technology can produce dots of VARYING size — but the same visual effect can be produced by varying the NUMBER of dots created within a "halftone cell" instead.
  • It's now standard practice for grey-scale or colour images to be presented using this halftoning-based approach.
  • This requires a RASTER IMAGE PROCESSOR (hardware and/or software) to control the conversion of graphics-file data into the physical screen display or printed page.
Practice — Test Yourself

These questions only cover what THIS subsection taught — halftoning (completes Section 3.04).

Short answer 1
What is the shared limitation of both printer and screen technology that halftoning solves?
Reveal answer

At any given position, they can only produce black/on or nothing/off — no continuous range of in-between grey tones directly.

Short answer 2
In the ORIGINAL newspaper-printing version of halftoning, what was varied to change the perceived tone?
Reveal answer

The SIZE of the printed dots.

Fill in the blank 3
In computer graphics, since dot size usually can't vary, the same effect is achieved by varying the ______ of dots created within a halftone cell.
Reveal answer

Number.

Spot the error 4
A student says: "Halftoning works because computer screens can now display true continuous grey tones directly." What's wrong with this?
Reveal answer

Halftoning exists PRECISELY because screens/printers CAN'T produce true continuous tones directly — it approximates the effect using arrays of dots (varying size or number), relying on the human eye not registering the individual dots when small enough.

Applied / scenario 5
What component is responsible for converting the data stored in a graphics file into the actual pattern of dots shown on a screen or printed page?
Reveal answer

The raster image processor — a combination of hardware and software.

Short answer 6
Why doesn't the human eye notice the individual dots used in halftoning?
Reveal answer

The technique relies on a limitation of human vision — sufficiently small dots simply aren't resolved as individual dots by the eye, so they blend into an apparent continuous tone.
