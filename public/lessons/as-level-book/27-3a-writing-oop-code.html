27.03 Writing Object-Oriented Code
Declaring a class, instantiating an object, and calling methods — in Python, VB.NET, and Pascal.
Theory

Declaring a class in Python

  • The constructor is __init__ (two underscores each side). EVERY method's first parameter is self, referring to the object itself.
  • A LEADING UNDERSCORE before an attribute name (e.g. self._Registration) signals it's meant to be PRIVATE — Python doesn't enforce this strictly, but the convention communicates intent.
class Car: def __init__(self, n, e): # constructor self._VehicleID = n self._Registration = "" self._EngineSize = e self._PurchasePrice = 0.00 def SetPurchasePrice(self, p): self._PurchasePrice = p def GetVehicleID(self): return self._VehicleID

Declaring a class in VB.NET

  • Method bodies are included INSIDE the class declaration, like Python.
  • Every attribute is preceded by Private; every public method header starts with Public. The constructor is ALWAYS named New.
Class Car Private VehicleID As String Private EngineSize As Integer Private PurchasePrice As Decimal = 0.0 Public Sub New(ByVal n As String, ByVal e As String) VehicleID = n EngineSize = e End Sub Public Sub SetPurchasePrice(ByVal p As Decimal) PurchasePrice = p End Sub Public Function GetVehicleID() As String Return VehicleID End Function End Class

Declaring a class in Pascal

  • UNLIKE Python/VB.NET, Pascal's class definition contains only method HEADERS — the full method CODE follows separately, with the CLASS NAME prefixing each method identifier (e.g. Car.SetPurchasePrice).
  • By convention, the constructor is named Create.
Car = class private VehicleID : string; EngineSize : integer; PurchasePrice : currency; public constructor Create(n : string; e : integer); procedure SetPurchasePrice(p : currency); function GetVehicleID : string; end; constructor Car.Create(n : string; e : integer); begin VehicleID := n; EngineSize := e; end; function Car.GetVehicleID : string; begin GetVehicleID := VehicleID; end;

Instantiating and using an object — all three languages

Python: ThisCar = Car("ABC1234", 2500) VB.NET: Dim ThisCar As New Car("ABC1234", 2500) Pascal: ThisCar := Car.Create('ABC1234', 2500); // Calling a method — object identifier, dot, method identifier, arguments Python: ThisCar.SetPurchasePrice(12000) VB.NET: ThisCar.SetPurchasePrice(12000) Pascal: ThisCar.SetPurchasePrice(12000);
Practice — Test Yourself

These questions only cover what THIS subsection taught — declaring, instantiating, and using classes across languages (completes Section 27.03).

Short answer 1
What is the special first parameter that every method in a Python class must include?
Reveal answer

self — referring to the object itself.

Short answer 2
In Pascal, where does the actual code for a class's methods appear, relative to the class definition?
Reveal answer

Separately, AFTER the class definition — the class definition itself only contains method headers, not the full method code.

Fill in the blank 3
In VB.NET, the constructor is always named ______; in Pascal, the convention is to name it ______.
Reveal answer

New; Create.

Spot the error 4
A student writes a Python method def SetPurchasePrice(p): without a self parameter. What will go wrong when it's called?
Reveal answer

Python automatically passes the object itself as the first argument to any method called via dot notation — without a self parameter to receive it, the method will raise an error about too many arguments, or misinterpret the intended parameter p as self.

Applied / scenario 5
Write the Pascal method HEADER (as it would appear inside the class definition) for a function GetEngineSize that returns an integer.
Reveal answer

function GetEngineSize : integer;

Short answer 6
What syntax is used to call a method on an object, across all three languages?
Reveal answer

Object identifier, followed by a dot, followed by the method identifier and its argument list — e.g. ThisCar.SetPurchasePrice(12000).
