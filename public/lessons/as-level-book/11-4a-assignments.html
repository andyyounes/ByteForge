11.04 Assignments
Assigning, updating, copying, and the classic three-line swap using a temporary variable.
Key Terms
Identifier table
A table listing the variable identifiers required for a solution, with explanations.
Theory

Four things you can do with assignment

  • Assigning a value: Number ← 15 stores 15 in Number.
  • Updating a value: NumberOfGuesses ← NumberOfGuesses + 1 reads the CURRENT value, adds 1, and stores the result back into the SAME variable.
  • Copying a value: Value2 ← Value1 — Value1 keeps its own value unchanged; Value2 now also holds a copy of it.
  • Swapping two values — needs a THIRD, temporary variable, or the second value would simply overwrite the first before it's saved.

Why swapping needs a temporary variable

  • If you tried Value1 ← Value2 then Value2 ← Value1 directly, Value1's ORIGINAL value would already be lost by the second line — you'd just end up with two copies of the original Value2.
Temp ← Value1 Value1 ← Value2 Value2 ← Temp
  • Step 1 saves Value1's original content into Temp BEFORE it can be overwritten. Step 2 overwrites Value1 with Value2's content. Step 3 recovers the ORIGINAL Value1 (now safely in Temp) into Value2.
Worked Example — miles to km, using an identifier table

Problem: convert a distance in miles to km.

Identifier table: Miles — distance as a whole number of miles. Km — the result of Miles × 1.61.

INPUT "Enter miles:" Miles Km ← Miles * 1.61 OUTPUT "Km:" Km
Practice — Test Yourself

These questions only cover what THIS subsection taught — assigning, updating, copying and swapping values (completes Section 11.04).

Short answer 1
Why does swapping two variables' values require a THIRD, temporary variable?
Reveal answer

Without it, the second value moved would overwrite the first value before it could be saved anywhere — a temporary variable holds one value safely while the swap happens.

Short answer 2
What does NumberOfGuesses ← NumberOfGuesses + 1 do, step by step?
Reveal answer

It reads the CURRENT value of NumberOfGuesses, adds 1 to it, then stores that new result back into NumberOfGuesses, overwriting the old value.

Fill in the blank 3
After Value2 ← Value1, Value1's own value ______ (changes/stays the same) until it is separately reassigned.
Reveal answer

Stays the same.

Spot the error 4
A student tries to swap Value1 and Value2 with just two lines: Value1 ← Value2 then Value2 ← Value1. Trace through it — what actually happens?
Reveal answer

After line 1, Value1's ORIGINAL value is already lost — Value1 now equals Value2. Line 2 then just copies this (already-changed) Value1 back into Value2, so Value2 ends up unchanged and Value1's original value is gone entirely. No real swap occurs.

Applied / scenario 5
In the miles-to-km example, why is an identifier table constructed before writing the pseudocode?
Reveal answer

It's helpful to first list and explain every variable the solution will need (here, Miles and Km), clarifying exactly what each one represents before the algorithm itself is written.

Short answer 6
In the swap algorithm, which line RECOVERS the original Value1 into Value2?
Reveal answer

The third line, Value2 ← Temp — Temp is still holding Value1's original content from the first line.
