13.03 Data Types
Five simple types every language has — plus two that Python doesn't build in at all.

A quirk worth knowing: Python has no separate CHAR type

  • In Python, a single alphanumeric character is simply represented as a STRING OF LENGTH 1 — there's no dedicated character type distinct from string.

Strings are a "structured" type

  • The string data type is called a STRUCTURED type, because it's essentially a SEQUENCE of characters, not one atomic value.
  • A special case: the EMPTY string — a value of type string, but with no characters stored in it at all.

Boolean values, represented as numbers underneath

  • True is represented internally as 1; False as 0.

Date and Currency — not always built in

  • Pseudocode recognises DATE and CURRENCY as data types — but Python does NOT provide either as a built-in data type.
  • In Python, a date is instead handled via the datetime class (Section 13.08); for currency, a plain float is used instead.
  • Other languages (VB.NET, Pascal) DO provide dedicated Date/Currency types internally, each with their own specific storage format.

Beyond the simple types

  • There are many more data types than covered here — programmers can also DESIGN AND DECLARE their own custom data types (covered later, Chapter 16).
Practice — Test Yourself

These questions only cover what THIS subsection taught — the simple data types (completes Section 13.03).

Short answer 1
What pseudocode data type would you use to store a person's exact age in whole years?
Reveal answer

INTEGER.

Short answer 2
Why doesn't Python have a separate CHAR type distinct from STRING?
Reveal answer

Python represents a single character simply as a string of length 1 — there's no dedicated character type at all.

Fill in the blank 3
The string data type is called a ______ type, because it's essentially a sequence of individual characters.
Reveal answer

Structured.

Spot the error 4
A student says: "Every programming language, including Python, has a built-in DATE data type." What's wrong?
Reveal answer

Python has NO built-in DATE (or CURRENCY) data type — dates must be handled via the separate datetime class instead, unlike VB.NET or Pascal which provide dedicated Date types directly.

Applied / scenario 5
A program needs to store a product's price, e.g. $19.99. Since Python has no CURRENCY type, which data type should be used instead?
Reveal answer

float (REAL in pseudocode) — used as the substitute for currency values in Python.

Short answer 6
What is an "empty string", precisely?
Reveal answer

A value of data type string, but with no characters stored in it at all.
