13.04 Boolean Expressions
Logic statements from Chapter 11, now with exact comparison and boolean operator syntax.
Theory

Conditions ARE Boolean expressions

  • Chapter 11's "logic statements" (conditions) are also known as Boolean expressions — they evaluate to either TRUE or FALSE, known as Boolean values.
  • Simple Boolean expressions use COMPARISON operators. Complex ones also use BOOLEAN operators.
OperationPseudocodePython

Not equal<>!=

OperationPseudocodePython
AND (logical conjunction)ANDand

The trap worth flagging explicitly

  • Pseudocode uses a PLAIN = for equality comparison — but Python (like most real languages) needs the DOUBLE equals == for comparison, reserving single = purely for assignment.
  • Confusing these two in real code is one of the most common early programming mistakes.
Practice — Test Yourself

These questions only cover what THIS subsection taught — comparison and Boolean operators (completes Section 13.04).

Short answer 1
What are conditions also known as, and what two values can they evaluate to?
Reveal answer

Boolean expressions — they evaluate to TRUE or FALSE (Boolean values).

Short answer 2
In Python, what symbol is used to test for EQUALITY, as opposed to assignment?
Reveal answer

== (double equals) — a single = is reserved for assignment.

Fill in the blank 3
In pseudocode, "not equal to" is written as ______; in Python, it's written as ______.
Reveal answer

<>; !=

Spot the error 4
A student writes Python code if x = 5: intending to check if x equals 5. What's wrong, and what should it be?
Reveal answer

A single = is the ASSIGNMENT operator in Python (this would actually cause a syntax error inside an if-condition) — it should be if x == 5:, using the double-equals comparison operator.

Applied / scenario 5
Which Boolean operator would you use to check that BOTH of two conditions are true at once?
Reveal answer

AND (Python: and).

Short answer 6
Name the three Boolean operators covered in this lesson.
Reveal answer

AND, OR, NOT.
