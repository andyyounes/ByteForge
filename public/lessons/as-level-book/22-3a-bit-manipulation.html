22.03 Bit Manipulation
Using individual bits as flags, and the AND/OR/XOR tricks to clear, set, toggle, and test them. Completes Chapter 22.
Theory

Why use individual bits as flags?

  • Instead of calling a procedure directly when a sensor condition is detected, Boolean FLAG variables can be set instead (e.g. Sensor1HighFlag, Sensor1LowFlag).
  • At the machine-code level, these flags can each be represented by a SINGLE BIT within one byte — much more memory-efficient than one whole variable per flag.

The four bitwise operations, and what each achieves

OperationEffect on a target bitOperand pattern
AND with 0Forces that bit to 0 (clears it)0 in that position, 1s elsewhere to preserve them
AND with 1Leaves that bit UNCHANGED, but can force OTHER bits to 0 (masking)1 in the position(s) to keep, 0 elsewhere
OR with 1Forces that bit to 1 (sets it)1 in that position, 0s elsewhere to preserve them
XOR with 1TOGGLES that bit (flips 0→1 or 1→0)1 in that position, 0s elsewhere to preserve them

Worked assembly examples (bit positions 0, 1, 2 used as flags)

LDD 0034 ; load the byte into the accumulator AND #B00000000 ; AND with all zeros STO 0034 ; clears EVERY bit to 0 LDD 0034 XOR #B00000001 ; XOR with a 1 in position 0 STO 0034 ; TOGGLES the flag at position 0 only LDD 0034 AND #B00000010 ; AND with a 1 only in position 1 STO 0034 ; keeps position 1 as-is, zeros everything else ; (result can then be compared to denary 2 to test the flag) LDD 0034 OR #B00000100 ; OR with a 1 in position 2 STO 0034 ; SETS the flag at position 2, leaves others unchanged
  • The key pattern: AND is for CLEARING bits (or masking/testing), OR is for SETTING bits, XOR is for TOGGLING bits — in each case, a 0 in the operand at a given position leaves that bit alone (for OR/XOR) or clears it (for AND), while a 1 does the active operation.

Chapter 22 summary

  • A monitoring system needs sensors; a monitoring AND control system also needs actuators.
  • Monitoring/control programs run in an effectively infinite, timed loop, reading sensors at controlled intervals.
  • The program sends signals to actuators when sensor values indicate control action is needed.
  • Bit manipulation (AND/OR/XOR) lets an assembly-language program set, clear, toggle, and test individual flag bits efficiently.
Practice — Test Yourself

These questions cover bit manipulation and draw together the whole of Chapter 22 (completes Section 22.03 and Chapter 22).

Short answer 1
Which bitwise operation would you use to SET a specific bit to 1, without affecting any other bits?
Reveal answer

OR, with a 1 in that bit's position and 0s everywhere else.

Short answer 2
Which bitwise operation TOGGLES a bit (flips it to the opposite value)?
Reveal answer

XOR, with a 1 in that bit's position.

Fill in the blank 3
To test whether a specific bit is set while ignoring all others, you ______ the byte with an operand containing a 1 only in that position, then compare the result to the corresponding denary value.
Reveal answer

AND.

Spot the error 4
A student wants to SET bit 2 to 1 but writes AND #B00000100 instead of OR #B00000100. What actually happens?
Reveal answer

AND with that operand would CLEAR every bit except bit 2 (which stays unchanged, not necessarily set to 1) — it does not guarantee bit 2 becomes 1, and it destroys all other flag values. Only OR reliably sets a bit to 1 while preserving the others.

Applied / scenario 5
Why might a control system's machine code represent four Boolean flags as four bits of ONE byte, rather than four separate byte-sized variables?
Reveal answer

It's far more memory-efficient — packing multiple flags into individual bits of a single byte uses a fraction of the storage that four separate variables would require, which matters especially in constrained embedded/control hardware.

Short answer 6
Which bitwise operation, applied with an all-zero operand, clears every bit in a byte to 0?
Reveal answer

AND (ANDing any bit with 0 always produces 0, regardless of its original value).
