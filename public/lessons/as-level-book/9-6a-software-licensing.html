9.06 Software Licensing
Free doesn't always mean the same thing — three genuinely different kinds of "free". Completes Chapter 9.
Key Terms
Open source software
Free, with unlimited use allowed and access to the source code.
Shareware
Free for use for a limited period, but no source code provided.
Freeware
Free with unlimited use allowed, but no source code provided.
Copyleft
The condition that a modified version's source code must be released under the same usage terms.
Theory

Commercial software — several payment models

  • A fee per individual copy.
  • A site licence — a defined number of copies allowed to run at any one time.
  • Special rates for educational use.
  • Earlier or limited versions offered free or at reduced price.

Open licensing — two global non-profit organisations, subtly different philosophies

  • The Open Source Initiative makes open source software (including source code) available for free, aiming for COLLABORATIVE development. Users are free to use, modify, copy, or distribute it as needed.
  • The Free Software Foundation has similar goals, but adds "COPYLEFT" — if the software is modified, the modified version's source code must ALSO be released under the same usage conditions.
  • The two organisations aren't in competition, but each offers a different range of products, reflecting their subtly different philosophies.

Shareware — commercial software on a trial basis

  • Might be a LIMITED version of a full package, or free to use for a TRIAL PERIOD.
  • A beta test version of new software might also be considered a form of shareware.
Practice — Test Yourself

These questions only cover what THIS subsection taught — software licensing (completes Section 9.06 and Chapter 9).

Short answer 1
What does a "site licence" allow, that paying per individual copy doesn't?
Reveal answer

A defined NUMBER of copies to be running at any one time, under one licence, rather than paying separately for each individual copy.

Short answer 2
What is "copyleft", and which organisation introduced it?
Reveal answer

The condition that if software is modified, the modified version's source code must be made available under the SAME usage conditions — introduced by the Free Software Foundation.

Fill in the blank 3
______ is free with unlimited use but no source code; ______ is free with unlimited use AND source code access; ______ is free but only for a limited trial period, with no source code.
Reveal answer

Freeware; open source software; shareware.

Spot the error 4
A student says: "Freeware and open source software are exactly the same thing, since both let you use the software for free with no limits." What's the key difference being missed?
Reveal answer

Source code access. Open source software gives access to the source code (so it can be studied, modified, and redistributed); freeware does not provide the source code at all.

Applied / scenario 5
A developer takes copyleft-licensed source code, modifies it, and wants to sell the modified version WITHOUT releasing its source code. Is this allowed under copyleft terms?
Reveal answer

No — copyleft specifically requires that if the software is modified, the modified version's source code must ALSO be made available under the same usage conditions as the original.

Short answer 6
What might a beta test version of new commercial software be classified as?
Reveal answer

Shareware.
