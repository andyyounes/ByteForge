1.04 Vector Graphics
Storing a drawing as instructions and geometry, not as pixels.
Key Terms
Vector graphic
A graphic made of components defined by geometric formulae and properties (line colour, style, etc.) — not stored pixel-by-pixel.
Drawing list
The list of commands (one per object) stored in a vector graphic file.
Theory

What's actually stored in a vector graphic file

  • A vector file stores a DRAWING LIST — one command per object in the image (a circle, a line, etc.), each with a list of ATTRIBUTES defining its properties.
  • For a circle: the position of its centre and its radius are the basic geometric data. Additional attributes: line thickness, line style, line colour, and fill colour (if applicable).

The most important property: genuine scalability

  • A vector image's objects are NOT defined by explicit pixel dimensions — they're defined relative to an imaginary drawing canvas.
  • Whenever the image is displayed, the file is read, the calculations are performed FRESH, and objects are drawn at whatever scale is currently needed.
  • Because the image is genuinely RECALCULATED at every scale, resizing (even enlarging significantly) causes NO distortion — this is the fundamental advantage over a bitmap.

A real limitation of vector files

  • A vector graphic file can only be displayed DIRECTLY on a graph plotter — an expensive, specialised piece of hardware.
  • For normal display (a screen, a printer), the vector file must first be CONVERTED into a bitmap before it can actually be shown.
Practice — Test Yourself

These questions only cover what THIS subsection taught — vector graphics.

Short answer 1
What is stored in a vector graphic file, instead of individual pixel colours?
Reveal answer

A drawing list — a command for each object in the image, along with its attributes (position, size, colour, line style, etc.).

Short answer 2
Why can a vector image be enlarged without any loss of quality?
Reveal answer

Because the objects are defined relative to an imaginary canvas, not by fixed pixel dimensions — every time the image is displayed, the drawing calculations are performed FRESH at whatever scale is currently requested.

Fill in the blank 3
The two essential geometric properties defining a circle in a drawing list are its ______ and its ______.
Reveal answer

The position of its centre, and its radius.

Spot the error 4
A student claims a vector image can be displayed directly on any ordinary computer screen without any conversion. Why is this incorrect?
Reveal answer

A vector file can ONLY be displayed directly on a graph plotter (specialised, expensive hardware) — for a normal screen or printer, the vector file must first be converted into a bitmap.

Applied / scenario 5
A company logo needs to be used at both business-card size and billboard size, from the same source file, with no loss of quality at either size. Which storage approach (vector or bitmap) should be used, and why?
Reveal answer

Vector — since it's genuinely scalable with no distortion at any size, one source file can be recalculated and displayed correctly at both a tiny business-card scale and an enormous billboard scale.

Short answer 6
Give two typical properties (beyond basic geometric shape/position) that an object's attributes in a drawing list might define.
Reveal answer

Any two of: line thickness, line style, line colour, fill colour.
