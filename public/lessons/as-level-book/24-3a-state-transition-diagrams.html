24.03 State-Transition Diagrams
Modelling a system as a finite state machine — states, inputs, transitions, and outputs. Completes Chapter 24.
Theory

Finite state machines (FSMs)

  • An FSM has a fixed set of possible STATES, a START STATE, a set of INPUTS that trigger transitions between states, and (optionally) a set of possible OUTPUTS.
  • An input to the FSM produces a TRANSFORMATION from one state to another (or possibly back to the same state).
Finite state machine (FSM): a machine that consists of a fixed set of possible states with a set of inputs that change the state and a set of possible outputs.
State-transition table: a table that gives information about the states of an FSM.
State-transition diagram: a diagram that describes the behaviour of an FSM.

Reading a state-transition table

Current state S1Current state S2
Input aS1S1
Input bS2S2
  • Reading this: in S1, input 'a' causes NO change; input 'b' moves to S2. In S2, input 'b' causes NO change; input 'a' moves back to S1.

Diagram conventions

  • The START state is marked with an incoming arrow from nowhere (often written as "→ S1").
  • A FINAL (halting) state is shown as a DOUBLE-CIRCLED state.
  • If an input PRODUCES AN OUTPUT, this is shown with a VERTICAL BAR notation on the transition — e.g. "input b / output c" means: on input b, output c is produced, and the state changes accordingly.

Worked example — an intruder detection system

  • Description: pressing START activates the system; pressing START again while active does nothing; entering a PIN de-activates it; a triggered SENSOR moves the active system into ALERT MODE; after 2 minutes without de-activation, an ALARM BELL rings.

  • The START state is "System inactive". This table maps DIRECTLY onto a state-transition diagram: 4 states (inactive, active, alert, alarm), with labelled arrows for each event.

Worked example — an FSM WITH outputs (two's complement conversion)

  • An FSM processing bits one at a time (least significant first) can convert a positive binary number to its two's complement negative equivalent: OUTPUT the bits up to and including the first 1 UNCHANGED; after that, output the INVERSE of each remaining input bit.
  • This needs TWO states: "before the first 1" and "after the first 1" — with the OUTPUT rule differing between the two states, shown via the vertical-bar notation on each transition.

Chapter 24 summary

  • A decision table models every possible combination of conditions and its resulting action, and can often be SIMPLIFIED by spotting redundant conditions.
  • JSP designs program structure to mirror data structure, using sequence, selection, and iteration components.
  • A finite state machine has a start state, a fixed set of states, and inputs that transform one state into another (possibly producing outputs) — represented via a state-transition table or diagram.
Practice — Test Yourself

These questions cover state-transition diagrams and draw together the whole of Chapter 24 (completes Section 24.03 and Chapter 24).

Short answer 1
How is a final (halting) state shown on a state-transition diagram?
Reveal answer

As a double-circled state.

Short answer 2
In the intruder detection system, what event moves the system from "System active" to "Alert mode"?
Reveal answer

Activating a sensor.

Fill in the blank 3
When an input to an FSM produces an output, this is shown on the diagram using a ______ notation.
Reveal answer

Vertical bar (e.g. "input / output").

Spot the error 4
A student's state-transition table for the intruder system has "Alert mode" with input "Press start button" transitioning to "System active". Based on the system description, is this correct?
Reveal answer

No — pressing start while already active/alert has NO effect per the description; in Alert mode, pressing the start button should leave the system in Alert mode (no change), not transition it back to System active.

Applied / scenario 5
In the intruder system's Alarm bell ringing state, what event returns the system to System inactive?
Reveal answer

Entering the PIN.

Short answer 6
What three things define a finite state machine?
Reveal answer

A fixed set of possible states, a set of inputs that change the state, and a set of possible outputs.
