22.01 Sensors, Actuators and Feedback
The two hardware devices at the heart of every monitoring and control system, and why feedback makes control possible.
Theory

Monitoring vs. control

  • MONITORING measures some physical property (temperature, pressure, light intensity, flow rate, movement) using a SENSOR — a hardware device that measures a property and transmits a value to a computer.
  • Two reasons to monitor: (1) SAFETY — check a value stays within acceptable limits, taking immediate action if a dangerous level is reached; (2) ROUTINE control — continuously ensure a property stays as required, correcting deviations.
  • CONTROL additionally needs an ACTUATOR — a hardware device that receives a signal from a computer and adjusts a controlling device's setting.
Sensor: a hardware device that measures a property and transmits a value to a controlling computer.
Actuator: a hardware device that receives a signal from a computer and adjusts the setting of a controlling device.

ADC and DAC

  • An Analogue-to-Digital Converter (ADC) converts a sensor's real-world analogue signal into digital data the computer can process.
  • A Digital-to-Analogue Converter (DAC) converts the computer's digital output back into an analogue control signal for the actuator.
  • These are usually INTEGRAL to the sensor/actuator device itself, rather than separate standalone components.

Feedback — measure, act, measure again

  • A monitoring-and-control system is a CONTINUOUS process: measure → (if needed) act → measure AGAIN. This repeated measure-act cycle is what creates FEEDBACK.
  • A CLOSED-LOOP FEEDBACK CONTROL SYSTEM is the special case where feedback DIRECTLY controls the operation: a controller compares the ACTUAL output (from the sensor) with the DESIRED output, and sends a signal to the actuator based on the DIFFERENCE.
Practice — Test Yourself

These questions only cover what THIS subsection taught — sensors, actuators, and closed-loop feedback (completes Section 22.01).

Short answer 1
What is the key difference between a pure monitoring system and a monitoring AND control system?
Reveal answer

A pure monitoring system only needs a sensor to measure and report a property. A monitoring and control system additionally needs an actuator, to actually adjust the controlled environment based on what's measured.

Short answer 2
In a closed-loop feedback control system, what does the controller compare?
Reveal answer

The actual output (as read by the sensor) with the desired output — the difference determines what signal to send to the actuator.

Fill in the blank 3
An ______ converts a sensor's analogue signal into digital data; a ______ converts the computer's digital output into an analogue control signal.
Reveal answer

ADC (analogue-to-digital converter); DAC (digital-to-analogue converter).

Spot the error 4
A student says feedback in a control system just means "the system reports what it did afterwards". What's missing from this description?
Reveal answer

Feedback isn't just a report — it's the mechanism that DIRECTLY drives further control action: after an actuator acts, the sensor measures again, and that new measurement feeds back into deciding the NEXT control action, forming a continuous loop.

Applied / scenario 5
A safety system monitors a nuclear reactor's temperature but takes NO automatic action — it just alerts a human operator if a dangerous level is reached. Is this a monitoring system, or a monitoring-and-control system?
Reveal answer

A monitoring system — it uses a sensor and checks limits, but has no actuator taking automatic control action; the actual response is left to a human.

Short answer 6
What physical device is an actuator often built around, according to the coursebook's simplification note?
Reveal answer

An electric motor that drives a controlling device.
