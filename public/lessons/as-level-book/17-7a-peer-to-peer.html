17.07 Peer-to-Peer (P2P) File Sharing
BitTorrent — how a structureless network of peers still manages to share files fast and fairly.
Theory

What P2P is

  • P2P has NO overall structure and NO controlling mechanism — every peer acts as BOTH a client and a server, and each peer is just one end-system.
  • BitTorrent is the most-used P2P protocol, valued for enabling FAST file sharing.

Problem 1 — finding peers with the wanted content

  • Every content provider creates a "TORRENT" — a small file describing the content: the name of a TRACKER (a server that leads peers to the content) and a list of the CHUNKS making up the content.
  • The torrent file is at least THREE ORDERS OF MAGNITUDE smaller than the actual content, so it transfers almost instantly.
  • The TRACKER maintains a list of all other peers currently downloading/uploading — collectively called the "SWARM".

Problem 2 — fast downloads for everyone

  • Peers SIMULTANEOUSLY download and upload chunks, exchanging lists of which chunks they have.
  • Peers prefer to download RARE chunks first — but each time a rare chunk is downloaded, it automatically becomes LESS rare (since the downloader can now also offer it), which naturally balances availability across the swarm.

Problem 3 — discouraging "leechers"

  • A LEECHER only downloads and never uploads (contributes nothing back).
  • The fix: a peer initially tries other peers RANDOMLY, but continues uploading only to peers that also provide REGULAR downloads in return.
  • A peer that downloads slowly or not at all eventually becomes ISOLATED or "CHOKED" — cut off from further uploads by other peers.
Practice — Test Yourself

These questions only cover what THIS subsection taught — P2P architecture and BitTorrent (completes Section 17.07).

Short answer 1
What is the role of a tracker in BitTorrent?
Reveal answer

A server that maintains a list of all other peers (the "swarm") actively downloading or uploading a particular piece of content, helping peers find each other.

Short answer 2
Why is a torrent file so much smaller than the content it describes?
Reveal answer

Because it only contains a description — the tracker's name and a list of chunk identifiers — not the actual content data itself, making it at least three orders of magnitude smaller.

Fill in the blank 3
A peer that only downloads and never uploads is called a ______, and can eventually be ______ by other peers.
Reveal answer

Leecher; isolated (or choked).

Spot the error 4
A student claims BitTorrent has a central server that stores and distributes the actual file content to every peer. What's the misconception?
Reveal answer

BitTorrent has NO controlling central structure for the content itself — the tracker only helps peers FIND each other; the actual content chunks are exchanged directly between peers, who act as both client and server.

Applied / scenario 5
Why does preferring to download rare chunks first make the overall swarm more resilient?
Reveal answer

It spreads the rarest chunks across more peers as quickly as possible — since a chunk becomes less rare the moment it's downloaded by a new peer (who can then also offer it), this reduces the risk of any single chunk being lost if the original holder disconnects.

Short answer 6
In BitTorrent's approach to discouraging leechers, how does a peer initially decide who to try uploading to?
Reveal answer

Randomly — then it continues uploading only to peers that reciprocate with regular downloads, cutting off (choking) those that don't.
