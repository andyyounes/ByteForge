17.02 Communication and Transmission Concepts
Data flow modes, message types, and the two big approaches: circuit switching vs. packet switching.
Theory

Data flow modes

  • SIMPLEX: data flows in ONE direction only.
  • HALF DUPLEX: data flows both ways, but NOT at the same time.
  • FULL DUPLEX: data flows both ways SIMULTANEOUSLY.

Message types

  • BROADCAST: one-to-all (e.g. traditional radio/TV).
  • MULTICAST: one source to MANY specific destinations.
  • UNICAST: one-to-one.

Circuit switching

  • The method used in the traditional telephone system (PSTN) — now often provided digitally, e.g. via a leased line, for data as well as voice.
  • Steps: (1) sender identifies the intended receiver, (2) the system checks the receiver is ready, (3) if available, a SEQUENCE OF LINKS is established across the network, (4) data is transferred, (5) the links are removed.
  • The dedicated links GUARANTEE unimpeded transmission for the duration of the call/session — but the circuit must be fully established BEFORE any data moves.

Packet switching

  • Allows data transmission WITHOUT establishing a circuit first. Data can't be sent as a continuous stream — instead it's split into PACKETS, each with a HEADER (delivery instructions) plus the data body.
  • The links used are NOT pre-defined at the moment a packet is sent, unlike circuit switching.
Protocol: a set of rules for data transmission which are agreed by sender and receiver.

Connectionless vs. connection-oriented packet-switching services

  • CONNECTIONLESS: a packet is sent with NO knowledge of whether the receiver is ready to accept it.
  • CONNECTION-ORIENTED: the first packet includes a request for ACKNOWLEDGEMENT. If received, the sender continues transmitting further packets; if not, it retries the first packet.

Practice — Test Yourself

These questions only cover what THIS subsection taught — data flow modes, message types, and circuit/packet switching (completes Section 17.02).

Short answer 1
What is the difference between half duplex and full duplex?
Reveal answer

Half duplex allows data to flow both ways, but only one direction at a time. Full duplex allows both directions SIMULTANEOUSLY.

Short answer 2
What must happen before data can be transferred in circuit switching, that is NOT required in packet switching?
Reveal answer

A sequence of dedicated links must be established across the network first, forming a complete circuit — packet switching requires no such pre-established circuit.

Fill in the blank 3
In a ______ service, the first packet requests an acknowledgement before further packets are sent; in a ______ service, packets are sent with no such check.
Reveal answer

Connection-oriented; connectionless.

Spot the error 4
A student says a broadcast message is sent to "a few chosen destinations". What message type are they actually describing?
Reveal answer

That's a MULTICAST, not a broadcast — broadcast is one-to-ALL, while multicast targets a specific, limited SET of destinations.

Applied / scenario 5
Why is packet switching better suited than circuit switching to the unpredictable, bursty traffic patterns of Internet usage?
Reveal answer

Packet switching doesn't require a dedicated circuit to be reserved for the full duration of a session — packets from many different communications can share the same links as needed, making better use of available capacity than a fixed, pre-established circuit would.

Short answer 6
What are the two parts that make up a packet?
Reveal answer

A header (containing delivery instructions) and the data body.
