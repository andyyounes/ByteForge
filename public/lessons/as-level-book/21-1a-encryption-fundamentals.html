21.01 Encryption Fundamentals
Symmetric vs. asymmetric key encryption, and the security concerns encryption addresses.
Theory

The basic model

  • PLAINTEXT is encrypted (using an algorithm plus a KEY) into CIPHERTEXT. The receiver DECRYPTS the ciphertext (using an algorithm plus a key) back into plaintext.
Plaintext: data before encryption.
Ciphertext: the result of applying an encryption algorithm to data.

Five security concerns (this chapter covers three)

  • CONFIDENTIALITY: only the intended recipient can decrypt the ciphertext.
  • AUTHENTICITY: the receiver must be certain WHO sent the message.
  • INTEGRITY: the ciphertext must not be modified in transit.
  • Non-repudiation and availability are the other two, but NOT covered further in this chapter.
  • Confidentiality concerns arise because a message could be INTERCEPTED and read. Integrity concerns cover both DELIBERATE tampering and ACCIDENTAL corruption during transmission.

A fundamental principle: the algorithm is public, the key is secret

  • The encryption ALGORITHM must NOT be secret — it's in the public domain. The KEY must be secret.
  • There are two approaches: SYMMETRIC key encryption and ASYMMETRIC key encryption.

Symmetric key encryption

  • ONE key is used for BOTH encryption and decryption — shared secretly between sender and receiver.
  • The hard problem: how do sender and receiver both get hold of this shared secret key SECURELY in the first place?

Asymmetric key encryption

  • TWO different keys: one for encryption, a DIFFERENT one for decryption. Only ONE of the pair is secret.
  • The process starts with the RECEIVER, who holds a PUBLIC key (not secret) and a PRIVATE key (secret, known only to them).
  • The receiver sends their PUBLIC key to a sender. The sender encrypts with the public key and sends the ciphertext. Only the receiver — holding the matching PRIVATE key — can decrypt it.
  • The same public key can be given to MANY different people, letting the receiver get private messages from ANY of them.
  • For TWO-WAY communication, both parties need their OWN private key and must send their matching public key to the other.
Public key: the non-secret half of an asymmetric key pair, shared openly.
Private key: the secret half of an asymmetric key pair, known only to its owner.

Ensuring real confidentiality against interception

  • Two requirements: the encryption ALGORITHM must be COMPLEX, and the KEY must use a LARGE number of bits.
  • Even with public algorithms and asymmetric keys, one gap remains: some organisation is still needed to PROVIDE keys and ensure their SAFE delivery to the right individuals — this is addressed in the next lesson (digital certificates).
Practice — Test Yourself

These questions only cover what THIS subsection taught — encryption basics, security concerns, and symmetric/asymmetric keys (completes Section 21.01).

Short answer 1
Why must the encryption ALGORITHM be public, while the key stays secret?
Reveal answer

Security should depend only on the secrecy of the key, not on the algorithm remaining unknown — a publicly scrutinised algorithm can be tested and trusted, while the key alone provides the actual protection.

Short answer 2
In asymmetric encryption, which key does a sender use to encrypt a confidential message to a receiver?
Reveal answer

The receiver's PUBLIC key — only the receiver's matching PRIVATE key can then decrypt it.

Fill in the blank 3
In symmetric key encryption, there is ______ key, used for ______ encryption and decryption.
Reveal answer

One (a single); both.

Spot the error 4
A student says asymmetric encryption needs both keys to be kept secret, "since they're both part of the same pair". What's wrong?
Reveal answer

Only ONE key in the pair (the private key) needs to stay secret. The public key is deliberately shared openly — that's the whole point of asymmetric encryption, avoiding the need to securely exchange a shared secret in advance.

Applied / scenario 5
Two people, Alice and Bob, want secure TWO-WAY communication using asymmetric encryption. What must each of them have?
Reveal answer

Each needs their own public-private key pair, and each must send their PUBLIC key to the other — so Alice encrypts to Bob using Bob's public key, and Bob encrypts to Alice using Alice's public key.

Short answer 6
Which security concern addresses whether a message was tampered with (deliberately or accidentally) during transmission?
Reveal answer

Integrity.
