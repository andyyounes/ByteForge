28.03 Assembly Patterns: Repetition and Input/Output
Loops via jump-back instructions, and handling strings with indexed addressing. Completes Section 28.03.
Theory

Repetition — REPEAT...UNTIL

A ← 0 LDM #0 REPEAT STO A OUTPUT "*" LOOP: LDM #42 // ASCII '*' A ← A + 1 OUT UNTIL A = 5 LDD A INC ACC STO A CMP #5 JPN LOOP // loop back if NOT yet equal to 5
  • The pattern: a LABEL (LOOP:) marks the top of the loop; the body executes; a condition is tested; JPN jumps BACK to the label if the loop should CONTINUE.
  • This mirrors REPEAT...UNTIL directly — the loop body always runs at least ONCE, and the test happens at the END.

Input and output — single characters

INPUT A IN STO A OUTPUT B LDD B OUT
  • IN stores the typed character's ASCII code into ACC; a simple STO then saves it to a variable.
  • OUT outputs whatever character corresponds to ACC's current ASCII value.

Handling a whole STRING — indexed addressing and a sentinel value

  • To output a string stored in CONSECUTIVE memory locations, a LOOP plus INDEXED addressing is used — the index register (IX) counts through each character position in turn.
  • Loop structure: initialise IX (often to -1, so the first INC makes it 0), increment IX each pass, use LDX to fetch the character at the calculated position, OUT it, then check for the END-OF-STRING marker — conventionally the CARRIAGE RETURN character (ASCII 13).
  • If the carriage return hasn't been reached yet, JPN loops back for the next character.
// Outputting a string stored starting at label STR, until ASCII 13 (carriage return) LDR #-1 LOOP: INC IX LDX STR OUT CMP #13 JPN LOOP
  • The SAME technique — indexed addressing plus a sentinel value — works for INPUT: read characters one at a time with IN, store each at the calculated indexed position with STX, and stop once the carriage return is entered.

Outputting a NUMBER (not just a character)

  • A number must first be CONVERTED into its equivalent STRING representation (digit by digit), stored in consecutive memory locations — THEN the string-output method above can be reused unchanged.
Practice — Test Yourself

These questions only cover what THIS subsection taught — assembly patterns for repetition and I/O (completes Section 28.03).

Short answer 1
Why does the REPEAT...UNTIL pattern test its condition AFTER the loop body, rather than before?
Reveal answer

This matches REPEAT...UNTIL's own semantics — the body must always run at least once, with the test only happening at the end of each pass, unlike a WHILE loop which tests first.

Short answer 2
What ASCII value is conventionally used as the "end of string" sentinel?
Reveal answer

13 (carriage return).

Fill in the blank 3
To output a string of characters stored in consecutive memory locations, a loop combined with ______ addressing is used.
Reveal answer

Indexed.

Spot the error 4
A student's loop initialises IX with LDR #0 instead of LDR #-1, then immediately does INC IX before the first character access. What position does the first LDX actually read from?
Reveal answer

Position 1, not position 0 — starting IX at 0 and incrementing before the first use skips over the very first character in the string, since IX becomes 1 before any character is read.

Applied / scenario 5
Why must a number be converted to a string before the string-output loop pattern can display it on screen?
Reveal answer

OUT only knows how to display ONE character based on ACC's ASCII value — a multi-digit number needs to become a sequence of individual digit CHARACTERS stored consecutively, so the same character-by-character output loop can process it.

Short answer 6
In the "output a string" loop, what instruction actually fetches each character using the current index?
Reveal answer

LDX (load, indexed addressing) — it forms the address from the base label plus the current contents of IX.
