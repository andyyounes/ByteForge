6.04 Assembly Language Instructions
Data movement, arithmetic, compare/jump, and I/O — then a full worked trace through a real program. Completes Chapter 6.
Theory

A note on these examples

  • These instructions don't correspond exactly to any one real processor's assembly language — but they ARE representative of the most common instruction categories found in real instruction sets.

Category 1 — Data movement

OpcodeOperandExplanation
LDM#nImmediate addressing — load n directly into ACC
LDR#nImmediate addressing — load n directly into IX
LDD<address>Direct addressing — load into ACC
LDI<address>Indirect addressing — load into ACC
LDX<address>Indexed addressing — load into ACC
STO<address>Store the contents of ACC at the address
  • The mnemonic itself defines the instruction TYPE, WHICH register is involved, and (where relevant) the addressing mode — reading it carefully matters.
  • In RTN, the LDD instruction is: ACC ← [[CIR(15:0)]] — the CIR holds the instruction; only the 16-bit address portion is examined, and the CONTENTS of that memory location are transferred into the accumulator.

Category 2 — Arithmetic operations

OpcodeOperandExplanation
ADD<address>Add the address's content to the content in the ACC
INC<register>Add 1 to the value stored in the specified register
DEC<register>Subtract 1 from the value stored in the specified register

Category 3 — Comparisons and jumps

OpcodeOperandExplanation
JMP<address>Jump to the address specified (unconditional)
CMP<address>Compare the ACC content with the address's content
CMP#nCompare the ACC content with n (immediate — note the #)
JPE<address>Jump to the address IF the previous comparison was TRUE
JPN<address>Jump to the address IF the previous comparison was FALSE
  • The TWO forms of CMP share the same opcode — the # symbol is what distinguishes immediate addressing from a plain address. No # means the operand is interpreted as an address.
  • Comparison here is restricted to asking whether two values are EQUAL.
  • A jump instruction doesn't cause an "instant" jump as such — it supplies a NEW value to the program counter, so the NEXT fetch happens from that new address instead. This OVERWRITES the automatic increment that already happened when the jump instruction itself was fetched.

Category 4 — Input and output

  • IN (no operand): stores the ASCII value of a keyboard-typed character into the ACC.
  • OUT (no operand): displays on screen the character whose ASCII code is currently stored in the ACC.

Reading the trace — why the PC jumps straight from 105 to 106 to 107

  • At address 104, ACC (0000 0101 = 5) is compared with the content of address 205 (0000 0101 = 5) — they're EQUAL, so the comparison is TRUE.
  • At address 105, JPE 106 fires because the comparison WAS true — the PC is set to 106, skipping straight there.
  • At 106, DEC ACC would normally decrement — but since this row shows ACC unchanged at 0000 0101, then 107 increments it back to 0000 0110 — the net effect across 106 and 107 here is a genuine trace exercise worth stepping through by hand.
  • Note that memory locations 100–107 and 200–207 themselves do NOT change during execution here — only the PC and ACC registers change; STO 206 would be the one instruction capable of changing memory, at address 107 in this layout.
Practice — Test Yourself

These questions only cover what THIS subsection taught — assembly language instructions and program tracing (completes Section 6.04 and Chapter 6).

Short answer 1
What is the difference between CMP 205 and CMP #205?
Reveal answer

CMP 205 compares the ACC against the CONTENT of memory address 205 (direct addressing). CMP #205 compares the ACC directly against the literal value 205 (immediate addressing) — the # makes the difference.

Short answer 2
What does a jump instruction actually DO to make the "jump" happen?
Reveal answer

It supplies a new value to the program counter, overwriting the automatic increment that happened when the jump instruction was fetched — so the NEXT fetch reads from the new address instead of the next sequential one.

Fill in the blank 3
The IN instruction stores the ______ value of a typed character into the ______.
Reveal answer

ASCII; accumulator (ACC).

Spot the error 4
A student says: "JPE and JPN both jump unconditionally, they're just given different names for style." What's wrong?
Reveal answer

Both are CONDITIONAL jumps, not unconditional. JPE jumps only if the PREVIOUS comparison was TRUE; JPN jumps only if it was FALSE. JMP is the genuinely unconditional jump.

Applied / scenario 5
In the worked trace, why does execution jump from address 104 straight through the comparison logic to reach address 106?
Reveal answer

The CMP at 104 found the ACC equal to the value at address 205, making the comparison TRUE — so the JPE at 105 fires and redirects the program counter to 106, exactly as JPE's definition requires.

Short answer 6
Do memory locations 100–107 and 200–207 change while the traced program executes?
Reveal answer

No — throughout this trace only the PC and ACC registers change; the instructions and data values in memory stay as originally set (until an instruction like STO is actually reached and executed).
