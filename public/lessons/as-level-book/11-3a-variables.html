11.03 Variables
A named box for a value — and the exact naming rule that makes an identifier readable.
Key Terms
Variable
A storage location for a data value that has an identifier.
Theory

Why named memory locations are needed

  • Input data needs to be stored in memory — we need a way to REFER to a specific memory location so algorithm statements can act on the value stored there.
  • These named memory locations are VARIABLES — think of them as labelled boxes; an input value is stored in the box bearing the matching identifier.

Naming rules and the Camel Caps convention

  • An identifier must NOT contain spaces — only letters, digits, and the underscore (_) symbol.
  • To make an algorithm easier to understand, a variable's name should REFLECT its use — often meaning more than one word is combined into one identifier.
  • The convention shown here is "Camel Caps" (e.g. NumberOfGuesses, ThisPlayer) — capitalising the start of each word makes a multi-word identifier easier to read.
Practice — Test Yourself

These questions only cover what THIS subsection taught — variables and identifier naming (completes Section 11.03).

Short answer 1
Give the precise definition of a variable.
Reveal answer

A storage location for a data value that has an identifier.

Short answer 2
What characters are allowed in a variable identifier?
Reveal answer

Letters, digits, and the underscore (_) symbol — no spaces.

Fill in the blank 3
The naming convention that capitalises the start of each word within a multi-word identifier (e.g. NumberOfGuesses) is called ______.
Reveal answer

Camel Caps.

Spot the error 4
A student names a variable Number Of Guesses (with spaces). What's wrong, and how should it be written?
Reveal answer

Identifiers cannot contain spaces. It should be written as one identifier using Camel Caps: NumberOfGuesses.

Applied / scenario 5
Why is a variable name like Age better than a name like X for storing a person's age?
Reveal answer

A variable's name should reflect its USE, to make the algorithm easier to understand — Age immediately tells a reader what the value represents, while X gives no indication at all.

Short answer 6
What is a useful mental picture for a variable, according to this lesson?
Reveal answer

A box with a name label on it — when a value is input, it's stored in the box bearing that identifier.
