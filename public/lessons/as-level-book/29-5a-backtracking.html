29.07 Instantiation and Backtracking
Watching how Prolog actually searches the knowledge base to find (or fail to find) an answer.
Theory

Instantiation, not assignment

  • When Prolog answers a query with something like X = stew, the = is NOT assignment (as in imperative programming) — it shows INSTANTIATION: X has been matched to the value stew for this particular solution.

Watching Prolog work: the trace facility

  • Typing trace. before a query shows EVERY step Prolog takes while trying to satisfy it — invaluable for understanding exactly HOW an answer was reached (or why a query failed).
Trace termMeaning
CallThe initial entry to a predicate
CreepProlog is moving to the next predicate
ExitA successful return
RedoBacking into a predicate again for another possible answer
FailProlog can find no more solutions along this path

Worked example — tracing containsMeat(X)

containsMeat(X) :- ingredient(X, Meat, _), meat(Meat). Trace summary: Call: containsMeat(X) Call: ingredient(X, Meat, _) Exit: ingredient(tagine, aubergine, 250) Call: meat(aubergine) Fail: meat(aubergine) -- aubergine is NOT meat, so BACKTRACK ...retry ingredient with the NEXT possible match... Exit: ingredient(stew, beef, 400) Call: meat(beef) Exit: meat(beef) -- SUCCESS Exit: containsMeat(stew) X = stew
  • This shows BACKTRACKING in action: when meat(aubergine) FAILS, Prolog doesn't give up — it goes BACK to the previous goal (ingredient) and tries the NEXT possible match, continuing until it either succeeds or runs out of options entirely.
Practice — Test Yourself

These questions only cover what THIS subsection taught — instantiation and backtracking (completes Section 29.07).

Short answer 1
What does "X = stew" actually mean in a Prolog response?
Reveal answer

The variable X has been instantiated (matched) to the value stew for this solution — it is not an assignment statement.

Short answer 2
What does "backtracking" mean?
Reveal answer

When a goal fails, Prolog goes back to a previous goal and tries the next possible match/alternative, rather than giving up entirely.

Fill in the blank 3
In a Prolog trace, ______ marks a successful return from a predicate, while ______ marks the point where no more solutions can be found.
Reveal answer

Exit; Fail.

Spot the error 4
A student says "once meat(aubergine) fails, the whole query containsMeat(X) must fail too". Why is this wrong, based on the trace?
Reveal answer

Prolog BACKTRACKS instead of giving up immediately — it retries the ingredient goal to find OTHER possible matches (like stew/beef), and only reports overall failure if EVERY possible path has been exhausted.

Applied / scenario 5
Why is the trace facility useful for a programmer debugging a Prolog rule that isn't returning the expected results?
Reveal answer

It shows the EXACT sequence of calls, successes, failures, and backtracking Prolog performs — letting the programmer see precisely where the logic diverges from what was expected, rather than only seeing the final answer (or lack of one).

Short answer 6
What trace term indicates Prolog is moving forward to evaluate the next predicate?
Reveal answer

Creep.
