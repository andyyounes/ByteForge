11.07 Working with Arrays
One data structure, three real algorithms: populate it, linear-search it, bubble-sort it — with a genuine optimisation. Completes Chapter 11.
Key Terms
Linear search
Checking each element of an array in turn for a required value.
Nested loop
A bubble sort's outer/inner loop structure — a loop containing another loop.
Theory

Why use an array at all

  • Seven separate variables could store seven numbers — but this becomes tedious (and unworkable) for, say, 70 numbers.
  • A one-dimensional (1D) array — also called a "linear list" — solves this: one identifier (e.g. MyList), with each element accessed by its POSITION (index), e.g. MyList[4] for the fourth element.
  • A loop can populate every element in turn: FOR Index ← 1 TO 7 / INPUT MyList[Index] / ENDFOR.

Linear search — the simplest search algorithm

  • Start at the FIRST element; check each one in turn until the value is found, or the end of the array is reached.
MaxIndex ← 7 INPUT SearchValue Found ← FALSE Index ← 0 REPEAT Index ← Index + 1 IF MyList[Index] = SearchValue THEN Found ← TRUE ENDIF UNTIL Found = TRUE OR Index >= MaxIndex IF Found = TRUE THEN OUTPUT "Value found at location:" Index ELSE OUTPUT "Value not found" ENDIF
  • The COMPLEX condition in the loop (Found = TRUE OR Index >= MaxIndex) is what lets the loop exit EARLY the moment a match is found, without needing to scan the rest of the array.
  • Using MaxIndex (rather than a hardcoded number) in the termination condition makes the algorithm easy to ADAPT to a differently-sized array — only ONE line needs to change.

Bubble sort — the basic version

  • Compare adjacent pairs, swapping if out of order, working down the array: (1,2), then (2,3), then (3,4)… each pass moves the LARGEST remaining value into its correct position at the end.
n ← MaxIndex - 1 FOR i ← 1 TO MaxIndex - 1 FOR j ← 1 TO n IF MyList[j] > MyList[j + 1] THEN Temp ← MyList[j] MyList[j] ← MyList[j + 1] MyList[j + 1] ← Temp ENDIF ENDFOR n ← n - 1 // don't re-check values already in their correct position ENDFOR
  • Why n decreases each outer pass: after each complete pass, the LARGEST unsorted value is already correctly placed at the end — there's no need to compare it again on later passes.
The optimisation — stop early if nothing was swapped

If a full pass through the inner loop makes NO swaps at all, the array must already be fully sorted — continuing further passes wastes comparisons.

Solution: a boolean variable NoMoreSwaps, set to TRUE before each pass and flipped to FALSE the moment any swap happens. If it's STILL TRUE after a full pass, the sort can stop — replacing the fixed-count outer loop with a CONDITIONAL loop instead.

Practice — Test Yourself

These questions only cover what THIS subsection taught — 1D arrays, linear search, and bubble sort (completes Section 11.07 and Chapter 11).

Short answer 1
In linear search, what TWO conditions (combined with OR) can cause the loop to stop?
Reveal answer

Found becomes TRUE (the value was located), OR Index reaches/exceeds MaxIndex (the end of the array was reached without finding it).

Short answer 2
Why does bubble sort's inner loop range (n) get smaller after each outer-loop pass?
Reveal answer

Each complete pass correctly places the largest remaining unsorted value at the end of the range still being checked — so that position never needs comparing again on subsequent passes.

Fill in the blank 3
Using ______ (rather than a hardcoded number) in a search's termination condition makes the algorithm easy to adapt to an array of a different size.
Reveal answer

MaxIndex (a variable holding the array's element count).

Spot the error 4
A student's bubble sort always runs the full number of outer-loop passes, even when the array became fully sorted after the second pass. What optimisation from this lesson fixes this waste?
Reveal answer

A NoMoreSwaps flag — set TRUE before each pass, flipped to FALSE the moment any swap occurs. If it's still TRUE after a full pass, the array is already sorted and the algorithm can stop early, replacing the fixed-count loop with a conditional one.

Applied / scenario 5
Why is a temporary variable (Temp) needed inside bubble sort's swap step, just like in the assignment lesson's swap algorithm?
Reveal answer

The same reason as any swap: without Temp holding one value safely, the second assignment would overwrite the first value before it could be moved into its new position.

Short answer 6
What is a "linear list", and what is the more formal name used for this same data structure?
Reveal answer

A "linear list" is the same thing as a one-dimensional (1D) array — a data structure with one identifier, where each element is accessed by its position (index).
