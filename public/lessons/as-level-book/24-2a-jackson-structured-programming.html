24.02 Jackson Structured Programming (JSP)
Designing a program's structure to mirror the structure of the data it processes.
Theory

The core idea

  • JSP designs a program's structure based DIRECTLY on the structure of the DATA it will process.
  • A structure is built from ELEMENTARY components (no further parts) and COMPOSITE components: SEQUENCE, SELECTION, or ITERATION.
  • SEQUENCE: two or more components, one after another. SELECTION: two or more parts, exactly ONE of which is chosen. ITERATION: one part, repeating ZERO or more times.

Worked example — an order form

  • Top level: header, order body, totals, payment method.
  • The HEADER is a SEQUENCE (customer name THEN address).
  • The BODY is an ITERATION (repeated product-ID/quantity/etc. lines).
  • The PAYMENT METHOD is a SELECTION (cheque OR bank card — only one chosen).

Diagram notation

  • REPETITION is shown by an ASTERISK (*) in the corner of a repeated component.
  • SELECTION is shown by a CIRCLE (○) in the corner of components where only one is chosen.

From data structure to program structure

  • Once the DATA structure diagram is drawn, a corresponding PROGRAM structure diagram follows directly: "Process Header data", "Process Order Body data", "Read Payment method", etc. — each data component maps to a matching PROCESSING step.
  • Below "Process Order form" sit "Process Header data" (Read Customer Name, Read Customer Address), "Process Order Body data" (Read Product ID, Read Quantity, Add Postage & Packing, Calculate Total price), and "Read Payment method" (Process Cheque OR Read Bank card details).

Beyond simple cases

  • In more complicated systems, OUTPUT data can be subjected to the SAME kind of structural analysis — which can sometimes reveal CONFLICTS between the natural structure of the input and the natural structure of the output, needing careful resolution.
Practice — Test Yourself

These questions only cover what THIS subsection taught — JSP structure components and diagrams (completes Section 24.02).

Short answer 1
What are the three types of composite component in JSP?
Reveal answer

Sequence, selection, and iteration.

Short answer 2
What symbol marks a repeated component on a JSP diagram?
Reveal answer

An asterisk (*) in the corner of the component.

Fill in the blank 3
JSP designs a program's structure based on the structure of the ______ it processes.
Reveal answer

Data.

Spot the error 4
A student marks a component representing "payment method: cheque OR bank card" with an asterisk. What's wrong?
Reveal answer

The asterisk denotes ITERATION (repetition), not selection. A choice between exactly one of several alternatives should be marked with a CIRCLE (○), the selection symbol.

Applied / scenario 5
A data structure diagram shows "Order Body" made up of repeated product lines. What kind of composite component is this, and what does that imply about the number of repetitions?
Reveal answer

Iteration — meaning the product-line component can repeat ZERO or more times (an order could theoretically contain no product lines, or many).

Short answer 6
Once a data structure diagram is drawn, what does it directly lead to?
Reveal answer

A corresponding program structure diagram — each data component maps onto a matching processing step in the program's design.
