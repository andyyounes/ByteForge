9.02 The ACM/IEEE Software Engineering Code of Ethics
Not a look-up table for right answers — eight principles meant to guide a judgement.
Key Terms
ACM
Association for Computing Machinery — a global professional body based in the USA.
IEEE
Institute of Electrical and Electronics Engineers — a global professional body based in the USA.
Theory

What the code deliberately is NOT

  • The authors are explicit: the code is NOT a look-up table prescribing an action for a given circumstance.
  • Instead, the PUBLIC INTEREST is the central focus, and the code presents fundamental principles a professional should use to make a thoughtful, considered ethical JUDGEMENT.

Structure — 8 principles, 80 clauses

  • Each of the 8 principles has a one-sentence definition in the preamble.
  • In the FULL code, each principle expands into individual CLAUSES — a checklist-style framework covering specific aspects to consider.
  • There are 80 clauses in total, numbered 1.01 through 8.09.

The eight principles

  1. PUBLIC — act consistently with the public interest.
  2. CLIENT AND EMPLOYER — act in the best interests of client and employer, consistent with the public interest.
  3. PRODUCT — ensure products/modifications meet the highest professional standards possible.
  4. JUDGMENT — maintain integrity and independence in professional judgment.
  5. MANAGEMENT — managers/leaders shall promote an ethical approach to managing development/maintenance.
  6. PROFESSION — advance the integrity and reputation of the profession, consistent with the public interest.
  7. COLLEAGUES — be fair to and supportive of colleagues.
  8. SELF — participate in lifelong learning and promote an ethical approach to the profession.

Many clauses aren't software-specific at all

  • Examining individual clauses shows many relate to proper behaviour for ANY group of professionals, not specifically software engineers.
  • Example (2.03): use a client's/employer's property only in ways properly authorized, with their knowledge and consent.
  • Example (6.06): obey all laws governing their work, UNLESS — in exceptional circumstances — compliance would be inconsistent with the public interest. This clause genuinely advocates law-breaking to serve the public interest in extreme cases (e.g. whistle-blowing).
  • Clause 5.05 is unusually detailed: it doesn't just ask for realistic quantitative estimates (cost, scheduling, personnel, quality, outcomes) — it also insists on an UNCERTAINTY assessment of those estimates.
Worked Example — applying ethics to a real scenario

Scenario: your project manager cuts testing time from one month to one week because the project is behind schedule.

Step-by-step approach: (1) rule out any immediate public-interest concern; (2) identify the PRIMARY concern — clause 3.10, ensure adequate testing/debugging/review; (3) identify the SECONDARY concern — poor management, clauses 5.01 and 5.11 (ensure good management, don't ask an engineer to violate the Code); (4) decide what ACTION to take — clauses 6.11-6.13 (recognise violations, express concerns to those involved, and if that's impossible/counter-productive/dangerous, report to appropriate authorities).

Practice — Test Yourself

These questions only cover what THIS subsection taught — the ACM/IEEE Code of Ethics (completes Section 9.02).

Short answer 1
What do the authors explicitly say the code is NOT meant to be?
Reveal answer

A look-up table that prescribes a specific action for a defined circumstance — it's meant to guide a thoughtful ethical judgement instead.

Short answer 2
How many principles does the code define, and how many total clauses?
Reveal answer

8 principles, 80 clauses (numbered 1.01 to 8.09).

Fill in the blank 3
Clause 6.06 requires obeying all laws governing the work, UNLESS compliance would be inconsistent with the ______ ______.
Reveal answer

Public interest.

Spot the error 4
A student says: "This code exists specifically to give software engineers a rule for every possible situation, so they never have to think for themselves." What's wrong?
Reveal answer

The authors explicitly reject this framing — the code is not a look-up table. It provides fundamental principles precisely so a professional can make their OWN thoughtful, considered ethical judgement, not to remove judgement entirely.

Applied / scenario 5
In the worked example (testing time cut from a month to a week), which principle/clause covers the PRIMARY concern, and which covers the SECONDARY concern?
Reveal answer

Primary: clause 3.10 (PRODUCT) — ensure adequate testing, debugging, and review. Secondary: clauses 5.01/5.11 (MANAGEMENT) — poor management is the underlying cause of the primary problem.

Short answer 6
Which principle covers "advance the integrity and reputation of the profession"?
Reveal answer

PROFESSION (principle 6).
