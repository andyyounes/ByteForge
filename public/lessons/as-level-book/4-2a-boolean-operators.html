4.02 Boolean Operators
Six precise operator definitions — including the two, NAND and NOR, that AS level adds beyond the basic three.
Key Terms
Logic expression
Logic propositions combined using Boolean operators, which may be written with a defined outcome.
Theory

Turning a problem statement into a formal logic expression

  • The two problem statements from 4.01 can be rephrased using Boolean operators:
  • Take_umbrella = TRUE IF (raining = TRUE) OR (rain_forecast = TRUE)
  • System_on = TRUE IF (office_hours = TRUE) AND (temperature > 25°C)
  • There's no single formally required FORMAT for writing this out — what matters is that the structure makes the underlying logic clear.
OperatorDefinition
NOT ATRUE if A is FALSE
A AND BTRUE if A is TRUE and B is TRUE
A OR BTRUE if A is TRUE or B is TRUE
A NAND BTRUE if A is FALSE or B is FALSE
A NOR BTRUE if A is FALSE and B is FALSE
A XOR BTRUE if A is TRUE or B is TRUE but NOT both

Six operators to know precisely — not just the basic three

  • Any logic expression can, in principle, be built using ONLY AND, OR and NOT — but it's often more convenient to use the other three (NAND, NOR, XOR) directly.
  • NAND and NOR are worth reading carefully: NAND is TRUE whenever EITHER input is FALSE (the exact opposite condition to AND); NOR is TRUE only when BOTH inputs are FALSE (the exact opposite condition to OR).
  • XOR ("exclusive OR") is TRUE when exactly ONE of the two inputs is TRUE — but FALSE if both are TRUE, which is the one case where plain OR would still say TRUE.
Practice — Test Yourself

These questions only cover what THIS subsection taught — the six Boolean operators (completes Section 4.02).

Short answer 1
Give the precise definition of A NAND B.
Reveal answer

A NAND B is TRUE if A is FALSE or B is FALSE.

Short answer 2
How does XOR's definition differ from plain OR's?
Reveal answer

XOR is TRUE if A is TRUE or B is TRUE but NOT both — whereas plain OR is also TRUE when BOTH A and B are TRUE.

Fill in the blank 3
A NOR B is TRUE only when A is ______ AND B is ______.
Reveal answer

FALSE; FALSE.

Spot the error 4
A student claims: "A NAND B is just the opposite of A OR B — they're the same operator with the output flipped." Check this by comparing their definitions carefully.
Reveal answer

Incorrect — NAND is the OPPOSITE of AND (NAND is TRUE whenever AND would be FALSE), not the opposite of OR. The opposite of OR is NOR.

Applied / scenario 5
A = TRUE and B = FALSE. Evaluate: (a) A AND B, (b) A OR B, (c) A NAND B, (d) A XOR B.
Reveal answer

(a) FALSE — needs both TRUE. (b) TRUE — at least one is TRUE. (c) TRUE — at least one (B) is FALSE. (d) TRUE — exactly one input is TRUE.

Short answer 6
Which THREE operators can, in principle, build any logic expression on their own?
Reveal answer

AND, OR, and NOT.
