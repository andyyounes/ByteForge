29.06 Rules in Prolog
Deriving new facts from existing ones — IF this AND this, THEN that.
Theory

The rule structure

  • Recall: Head :- Body. — a rule's BODY consists of calls to predicates, called the rule's GOALS.
  • If the BODY is true, the HEAD is true too.
  • In Prolog notation: :- means IF; a comma , means AND.

Worked example — grandparent and sibling rules

parent(fred, jack). parent(fred, alia). parent(fred, paul). parent(dave, fred). % "G is a grandparent of S if G is a parent of P, and P is a parent of S" grandparent(G, S) :- parent(G, P), parent(P, S). % "A and B are siblings if they share a parent" sibling(A, B) :- parent(P, A), parent(P, B).
  • Note a subtlety: with the sibling rule as written, querying sibling(jack, X) ALSO returns Jack as his OWN sibling (since Jack IS his own parent's child).

Fixing the sibling rule — excluding a person from being their own sibling

sibling(A, B) :- parent(P, A), parent(P, B), not(A = B).
  • Adding not(A = B) as an EXTRA goal excludes the case where A and B are actually the SAME person.

Worked example — a rule that ignores an argument

ingredient(tagine, aubergine, 250). ingredient(stew, beef, 400). meat(chicken). meat(beef). meat(lamb). containsMeat(X) :- ingredient(X, Meat, _), meat(Meat). ?- containsMeat(X). X = stew.
  • This rule COMBINES two facts: "X uses SOME ingredient" (whose amount we don't care about — hence the anonymous variable) AND "that ingredient IS a meat".
Practice — Test Yourself

These questions only cover what THIS subsection taught — Prolog rules (completes Section 29.06).

Short answer 1
What does the comma mean inside a Prolog rule's body?
Reveal answer

AND — all the goals separated by commas must be true for the rule's head to be true.

Short answer 2
Why does the sibling rule need an extra "not(A = B)" clause?
Reveal answer

Without it, the rule would incorrectly report that a person is their OWN sibling, since they share a parent with themselves — the extra clause excludes A and B being the same person.

Fill in the blank 3
In Prolog, ______ replaces the word IF, and a ______ replaces the word AND.
Reveal answer

:- ; comma.

Spot the error 4
A student writes grandparent(G, S) :- parent(G, S), parent(S, P). intending the original grandparent rule. What's wrong with the variable usage?
Reveal answer

The variables are mismatched — this actually checks that G is a parent of S, AND S is a parent of P (an unrelated third person), which does NOT express "G is a grandparent of S". The correct rule is parent(G, P), parent(P, S), chaining through the SAME intermediate person P.

Applied / scenario 5
Given containsMeat(X) :- ingredient(X, Meat, _), meat(Meat)., why is the anonymous variable used for the amount argument?
Reveal answer

The rule only cares WHETHER a dish contains some meat ingredient — the specific amount is irrelevant to this rule's logic, so the anonymous variable signals that clearly.

Short answer 6
What is a rule's body made up of?
Reveal answer

Calls to predicates, referred to as the rule's goals.
