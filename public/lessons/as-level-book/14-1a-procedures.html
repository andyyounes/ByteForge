14.01–14.02 Procedures
Subroutine terminology across languages, and how to define and call a procedure.
Theory

Subroutine terminology

  • A subroutine is a named block of statements you can call whenever needed, instead of repeating them.
  • Pseudocode splits subroutines into two kinds: a PROCEDURE (performs a task) and a FUNCTION (performs a task AND returns a value).

PseudocodePROCEDUREFUNCTION
Pythonvoid function / subroutinefruitful function

Defining and calling a procedure

PROCEDURE <procedureIdentifier>() // procedure header <statement(s)> // procedure body END PROCEDURE CALL <procedureIdentifier>() // how it's called
  • A procedure must be DEFINED before the main program, then CALLED by name whenever its statements are needed.
  • Python: def identifier(): with an indented body — called simply as identifier(), with no CALL keyword needed.

Worked example

PROCEDURE InputOddNumber() DECLARE Number : INTEGER REPEAT INPUT "Enter an odd number: ", Number UNTIL Number MOD 2 = 1 END PROCEDURE CALL InputOddNumber()
# Python def InputOddNumber(): Number = 0 while Number % 2 == 0: Number = int(input("Enter an odd number: ")) InputOddNumber()
  • Note the built-in input() always returns a string, so it must be converted with int() before the MOD test can run on it.
Practice — Test Yourself

These questions only cover what THIS subsection taught — subroutine terminology and defining/calling procedures (completes Sections 14.01–14.02).

Short answer 1
What is the key difference between a procedure and a function?
Reveal answer

A function returns a value as part of an expression; a procedure simply performs a task and does not return a value.

Short answer 2
In pseudocode, what statement is used to call a procedure named DrawShape?
Reveal answer

CALL DrawShape()

Fill in the blank 3
A procedure must be ______ before the main program, and is ______ by name whenever its statements need to run.
Reveal answer

Defined; called.

Spot the error 4
A student writes Number = input("Enter an odd number: ") then tests Number MOD 2 = 1 directly. Why will this fail?
Reveal answer

input() returns a STRING, and MOD needs a number — the string must first be converted with int(): Number = int(input("Enter an odd number: ")).

Applied / scenario 5
Why is defining a procedure once and calling it many times better than repeating its statements every time they're needed?
Reveal answer

It avoids duplicating code — the logic exists in one place, so it's easier to read, easier to fix (only one place to change), and the program is shorter overall.

Short answer 6
What Python keyword introduces the definition of a subroutine?
Reveal answer

def
