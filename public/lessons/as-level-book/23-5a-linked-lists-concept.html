23.06 Linked Lists: The Concept
Nodes, pointers, and why linking beats shifting data around.
Theory

The problem with a linear (array-based) list

  • A linear list stores items in CONSECUTIVE memory locations. This isn't always appropriate — inserting or deleting an item in the middle requires SHIFTING every item after it.
  • A LINKED LIST instead stores each item wherever memory is available, and LINKS them into order using POINTERS.

Key terminology

  • A NODE is one element of the list — it can hold several data items PLUS a pointer.
  • A POINTER is a variable storing the address of the node it points to.
  • A NULL POINTER points at NOTHING (usually represented as 0) — it marks the END of the list.
  • A START POINTER stores the address of the FIRST element.
Node: an element of a list.
Pointer: a variable that stores the address of the node it points to.
Null pointer: a pointer that does not point at anything.
Start pointer: a variable that stores the address of the first element of a linked list.

Inserting a node

  • AT THE START: copy the current StartPointer into the new node's pointer field, then set StartPointer to point to the NEW node.
  • AT THE END: the previous last node's pointer field is set to point to the new node; the new node's own pointer field becomes NULL.
  • IN THE MIDDLE (between existing nodes B and D, inserting C): copy B's pointer field into C's pointer field, then change B's pointer field to point to C.
  • Crucially, NO existing nodes need to physically MOVE — only pointer values change.

Deleting a node

  • DELETING THE FIRST NODE: copy the deleted node's pointer field into StartPointer.
  • DELETING THE LAST NODE: set the PREVIOUS node's pointer field to the null pointer.
  • DELETING A MIDDLE NODE (D, between B and L): copy D's pointer field into B's pointer field, "skipping over" D.
Practice — Test Yourself

These questions only cover what THIS subsection taught — linked list concepts, insertion, and deletion (part of Section 23.06).

Short answer 1
What is the key advantage of a linked list over a linear (array-based) list when inserting or deleting items?
Reveal answer

Only pointer values need to change — no existing data items need to be physically shifted or moved, unlike an array where all following items must be shuffled along.

Short answer 2
What does a null pointer represent?
Reveal answer

A pointer that doesn't point at anything — it marks the end of the linked list.

Fill in the blank 3
To insert a new node C between existing nodes B and D, copy B's pointer field into ______'s pointer field, then set B's pointer field to point to ______.
Reveal answer

C; C.

Spot the error 4
A student deletes the LAST node in a linked list by simply removing it, but forgets to update the previous node's pointer field. What goes wrong?
Reveal answer

The previous node's pointer field still points to the now-deleted node's old memory location — this "dangling pointer" would cause the list traversal to follow an invalid reference instead of correctly reaching the end (null pointer).

Applied / scenario 5
Why is inserting a new node at the START of a linked list especially simple, requiring no traversal at all?
Reveal answer

You only need to know the CURRENT StartPointer value (to copy into the new node's own pointer field) and then update StartPointer to the new node — no need to search through the list to find an insertion point.

Short answer 6
What two things can a node in a linked list hold?
Reveal answer

Data (potentially several data items) and a pointer to the next node.
