5.03 The System Bus
Three separate buses, one crucial rule: a bus never stores data, it only carries it.
Key Terms
Address bus
Carries an address to the memory controller to identify a location to be read from or written to.
Data bus
Carries data to and from the processor.
Word
A small number of bytes handled as a unit by the computer system.
Bus width
The number of separate wires in a bus — defines how many bits it can carry at once.
Theory

What a bus actually is — and isn't

  • A bus is a parallel transmission component — each separate wire carries a single bit.
  • Crucial point: a bus is NOT a storage device. It does not hold data — it's purely a mechanism for TRANSFERRING data between components.
  • The system bus comprises THREE distinct components: the address bus, the data bus, and the control bus.

The address bus — genuinely one-way

  • The address bus's SOLE function is to carry an address, loaded from the MAR onto the bus when directed by the control unit.
  • It is a "one-way street" — it can send an address TO the memory controller, but CANNOT carry an address back from the memory controller to the CPU.
  • Its bus width defines how many memory locations can be directly addressed. In this simple system: 16-bit width → 65,536 addressable locations. Even 32 bits would only reach a little over 4 billion — inadequate for a modern system, hence special addressing techniques are needed for larger memories.

The data bus — and what a "word" is

  • The data bus carries data — which might be an instruction, an address, or a value — travelling CPU↔memory or CPU↔I/O device.
  • A WORD is a defined number of bytes that the system handles as ONE unit — typical word lengths are 16, 32 or 64 bits (2, 4 or 8 bytes).
  • Ideally, bus width MATCHES word length. If it can't, the bus width can be HALF the word length, transmitting a full word over two consecutive transfers instead.

The control bus — narrower, but essential for timing

  • Bidirectional; typically just 8 wires (no need for greater width).
  • Major use: carrying TIMING signals, driven by the system clock — ensuring one component transmits data at exactly the time another component is ready to read it.
  • Clock speed is the MOST important factor for processing speed — but NOT the only one. Insufficient bus width, or inefficient memory access, both limit real-world performance too.

Ports — the missing detail behind the simplified diagram

  • A simple schematic can misleadingly suggest CPU, memory, and I/O devices all have EQUAL, direct access to the buses — the reality is different.
  • Each I/O device connects via an interface called a PORT, which connects to an I/O/device controller managing the CPU↔device interaction.
  • An "internal" port connects a device that's an integral part of the system; an "external" port lets the user connect a peripheral.

USB — the plug-and-play standard

  • Before USB, connecting a peripheral was time-consuming and needed technical expertise — the "plug-and-play" concept aimed to remove that need entirely.
  • USB fully realised plug-and-play. Key facts: supports a HIERARCHY of connections; the computer sits at the root and can handle up to 127 attached devices; devices can be attached while powered on and are auto-configured; the standard has evolved (USB 3.0 being the latest version discussed here).
  • FireWire is an alternative technology, but far less commonly used.
Practice — Test Yourself

These questions only cover what THIS subsection taught — the system bus and USB (completes Section 5.03).

Short answer 1
Why is it wrong to describe a bus as a storage device?
Reveal answer

A bus does not hold data at all — it's purely a mechanism for transferring data from one component to another.

Short answer 2
Why can't the address bus carry an address back from the memory controller to the CPU?
Reveal answer

It is a one-way bus by design — it can only send an address from the CPU (via the MAR) TO the memory controller.

Fill in the blank 3
With a 16-bit address bus, the number of directly addressable memory locations is ______.
Reveal answer

65,536 (2¹⁶).

Spot the error 4
A student says: "The CPU, memory, and I/O devices all have identical, direct access to the address and data buses." What does this lesson say is missing?
Reveal answer

I/O devices don't connect directly — each connects via a PORT, which connects to an I/O/device controller that manages the interaction between the CPU and that device. The simple schematic diagram slightly misrepresents this reality.

Applied / scenario 5
A system has a 32-bit word length but only a 16-bit data bus. How can a full word still be transferred, according to this lesson?
Reveal answer

Since the bus width is HALF the word length, the full word can be transmitted using two consecutive data transfers instead of one.

Short answer 6
Besides clock speed, name TWO other factors that can limit a system's real-world processing performance.
Reveal answer

Insufficient bus width (can't transfer a full data value in one clock cycle), and inefficient memory access.
