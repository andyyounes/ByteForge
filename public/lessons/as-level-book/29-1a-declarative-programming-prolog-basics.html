29.01–29.02 Declarative Programming & Prolog Basics
Describing WHAT a problem is, instead of HOW to solve it — and the three building blocks of Prolog.
Theory

Imperative vs. declarative

  • IMPERATIVE languages (Pascal, VB, Python): the programmer writes sequences of statements reflecting HOW to solve the problem.
  • DECLARATIVE languages: the programmer writes a logical specification describing WHAT the problem/situation IS. The programmer does NOT say what to do — they pose a QUERY (set a GOAL), and it's up to the logic system to work out HOW to answer it.
  • Declarative languages include database query languages (SQL), regular expressions, logic programming, and functional programming.
  • PROLOG is a logic programming language widely used for AI and expert systems.

The three basic Prolog constructs

  • FACTS and RULES together are called CLAUSES — they express the program's logic.
  • QUERIES (goals) are how problems get SOLVED using that logic.
  • A collection of clauses is called a KNOWLEDGE BASE. Writing a Prolog program means writing a knowledge base; USING it means posing queries.
  • A clause has the form: Head :- Body. — and ALWAYS ends with a full stop.

Prolog's single data type: the "term"

  • An ATOM: a general-purpose name with no inherent meaning, always starting with a LOWER-case letter.
  • A NUMBER: integer or float.
  • A VARIABLE: an identifier starting with an UPPER-case letter or underscore.
  • A COMPOUND TERM (predicate): an atom plus a number of arguments in parentheses.
  • A predicate's ARITY is its number of arguments — capitalCity/1 means the predicate capitalCity takes ONE argument.
Prolog is case-sensitive. A lower-case first letter always means an atom; an upper-case first letter (or underscore) always means a variable.
Practice — Test Yourself

These questions only cover what THIS subsection taught — imperative vs. declarative, and Prolog's basic constructs (completes Sections 29.01–29.02).

Short answer 1
What is the fundamental difference between imperative and declarative programming?
Reveal answer

Imperative programs describe HOW to solve a problem (a sequence of steps). Declarative programs describe WHAT the problem/situation is (a logical specification), leaving the "how" to the logic system.

Short answer 2
What is a knowledge base?
Reveal answer

A collection of clauses (facts and rules) that together express a Prolog program's logic.

Fill in the blank 3
An atom always starts with a ______ case letter; a variable always starts with an ______ case letter or an underscore.
Reveal answer

Lower; upper.

Spot the error 4
A student writes the Prolog term Paris intending it to represent the city, but Prolog treats it as a variable instead. What's the mistake?
Reveal answer

Starting with an upper-case letter makes it a VARIABLE, not an atom — to represent the specific city as a fixed value, it must start with a lower-case letter: paris.

Applied / scenario 5
What is the arity of the predicate cityInCountry(paris, france)?
Reveal answer

2 (it has two arguments — written as cityInCountry/2).

Short answer 6
In an imperative program, what would be the equivalent of a Prolog "query"?
Reveal answer

There isn't a direct equivalent — imperative programs are RUN to execute their steps; a Prolog query instead asks the logic system a QUESTION, which it answers by searching the knowledge base.
