1.04 Bitmaps & File Size
Pixels, colour depth, resolution — and a real file-size calculation, kibi/mebi included.
Key Terms
Pixel
The smallest identifiable component of a bitmap image — defined by just its position and its colour.
Colour depth
The number of bits used to store each pixel's colour.
Resolution
The number of pixels per row × the number of rows.
Kibi / Mebi / Gibi
SI-standard prefixes for exact powers of 2: Ki=2¹⁰, Mi=2²⁰, Gi=2³⁰ — distinct from decimal kilo/mega/giga.
Theory

A bitmap is a matrix of pixels — nothing more

  • Most real images (photos, scans, screenshots) aren't made of clean geometric shapes — a bitmap stores the image as a two-dimensional MATRIX of pixels instead.
  • A pixel is defined by exactly two properties: its POSITION in the matrix, and its COLOUR. Whether it's conceptually a tiny square, circle, or dot makes no difference.

Colour depth — how many bits per pixel

  • 1 bit per pixel: the pixel is either black or white — no in-between.
  • 4 bits per pixel: simple greyscale.
  • At least 8 bits per pixel: needed to code a genuinely coloured image.
  • The number of bits used per pixel is called the colour depth.

Resolution — stored image vs. display screen

  • Resolution = (pixels per row) × (number of rows).
  • The resolution of the STORED image and the resolution of the DISPLAY SCREEN are two genuinely separate things — both matter when designing how something will actually look on screen.
  • A bitmap doesn't define the physical SIZE of the image or a pixel — so it's technically scalable, but unlike vector graphics, the actual NUMBER of pixels never changes when you scale it.
  • Scale a bitmap up too far and the fixed number of pixels becomes visible as blocky distortion — the eye can no longer be fooled into seeing a smooth image.
Worked example — minimum file size of a laptop-screen bitmap

Resolution: 1366 × 768. Colour depth: 24 bits per pixel.

Total bits: 1366 × 768 × 24 = 25,178,112 bits.

Convert to bytes: 25,178,112 ÷ 8 = 3,147,264 bytes.

Convert to kibibytes: 3,147,264 ÷ 1024 = 3073.5 KiB.

Convert to mebibytes: 3073.5 ÷ 1024 ≈ 3 MiB.

Why "kibibyte" exists as a separate word from "kilobyte"

  • By the strict SI (International System of Units) convention, "kilo" means exactly 1000 — a "kilobyte" should be 1000 bytes.
  • Computer scientists have traditionally used "kilobyte" to mean 1024 bytes instead — a genuine, long-standing contradiction with the official SI definition.
  • In 1998 the International Electrotechnical Commission (IEC) proposed NEW, unambiguous terms: 1024 bytes = 1 KIBIbyte (KiB) — "kibi" standing for "kilo-BINARY". This has since been adopted by other international standards bodies.
  • A bitmap file's header ALSO takes up space (storing the resolution and colour-coding scheme) — the calculation above gives only the MINIMUM size, excluding this header.
Practice — Test Yourself

These questions only cover what THIS subsection taught — bitmaps, colour depth, resolution, and file size (completes Section 1.04).

Short answer 1
What two properties define a single pixel?
Reveal answer

Its position in the bitmap matrix, and its colour.

Short answer 2
Why does "1 kibibyte" exist as a separate term from "1 kilobyte"?
Reveal answer

To resolve the contradiction between the strict SI definition of "kilo" (exactly 1000) and computer scientists' traditional use of "kilobyte" to mean 1024 bytes — "kibibyte" (KiB) unambiguously means exactly 1024 bytes.

Fill in the blank pseudocode 3
Complete the resolution formula: Resolution = ______ per row × number of ______.
Reveal answer

Resolution = pixels per row × number of rows.

Spot the error 4
A student says a bitmap can be scaled up to any size with no quality loss, "just like a vector graphic". Why is this wrong?
Reveal answer

Unlike a vector graphic, a bitmap's actual NUMBER of pixels never changes when scaled — magnify it too far and the fixed set of pixels becomes visibly blocky, since there's no genuine recalculation of the image at the new scale, only stretching of the same pixel data.

Applied / scenario 5
Calculate the minimum file size (in bytes) of a bitmap image with resolution 800 × 600 and a colour depth of 8 bits per pixel.
Reveal answer

800 × 600 × 8 = 3,840,000 bits. 3,840,000 ÷ 8 = 480,000 bytes.

Applied / scenario 6
Convert 480,000 bytes (from Question 5) into kibibytes.
Reveal answer

480,000 ÷ 1024 ≈ 468.75 KiB.
