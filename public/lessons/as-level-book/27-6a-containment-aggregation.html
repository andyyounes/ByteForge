27.07 Containment (Aggregation)
"Has-a" relationships between classes — building bigger objects from smaller ones. Completes Chapter 27.
Theory

Inheritance vs. containment

  • Inheritance (Section 27.04) is a GENERALISATION/SPECIALISATION relationship ("a Book IS-A LibraryItem").
  • CONTAINMENT is different: one class HAS a component that is of ANOTHER class type ("a Course HAS-A set of Lessons").
Containment: a relationship in which one class has a component that is of another class type.

Worked example — a college course

  • A Course is made up of up to 50 Lesson objects, and may have ONE Assessment object.
  • Course is NOT a special kind of Lesson or Assessment — it simply CONTAINS them as component attributes.

Implementing containment (Python)

class Course: def __init__(self, t, m): self.CourseTitle = t self.MaxStudents = m self.NumberOfLessons = 0 self.CourseLesson = [] # will hold Lesson objects self.CourseAssessment = None def AddLesson(self, t, d, r): self.NumberOfLessons += 1 self.CourseLesson.append(Lesson(t, d, r)) # CREATE a Lesson object here def AddAssessment(self, t, m): self.CourseAssessment = Assessment(t, m) # CREATE an Assessment object here def OutputCourseDetails(self): print(self.CourseTitle, "Maximum number:", self.MaxStudents) for lesson in self.CourseLesson: lesson.OutputLessonDetails()
  • Note how AddLesson creates a NEW Lesson object and stores it INSIDE the Course's own list — this is containment in action. The Course object's data literally includes fully-formed Lesson/Assessment objects.
  • Calling MyCourse.AddLesson("Programming", 120, True) from the main program builds up the course step by step, WITHOUT the main program needing to know anything about how Lesson objects work internally.

Chapter 27 summary

  • Encapsulation combines data (private attributes) and code (public methods) into a class.
  • A constructor instantiates an object; getters/setters provide controlled access to attributes.
  • Inheritance lets a subclass reuse a base class's code, adding its own attributes/methods; an abstract class is never instantiated directly.
  • Polymorphism lets a subclass redefine a method's behaviour while keeping the same identifier.
  • Garbage collection (automatic in Python/VB.NET, manual in Pascal) reclaims memory from unused objects.
  • Containment (aggregation) is a "has-a" relationship — one class holds components that are objects of other class types.
Practice — Test Yourself

These questions cover containment and draw together the whole of Chapter 27 (completes Section 27.07 and Chapter 27).

Short answer 1
What is the key difference between inheritance and containment?
Reveal answer

Inheritance is an "IS-A" relationship (a subclass IS a specialised version of the base class). Containment is a "HAS-A" relationship (one class HAS a component that is an object of another class type).

Short answer 2
In the Course example, what type of object does CourseLesson hold?
Reveal answer

Lesson objects (up to 50 of them).

Fill in the blank 3
Containment is also known by the alternative term ______.
Reveal answer

Aggregation.

Spot the error 4
A student says "Course must be a subclass of Lesson, since a Course is made up of Lessons". What's the misconception?
Reveal answer

A Course is NOT a specialised kind of Lesson — it CONTAINS Lesson objects as components. This is containment ("has-a"), not inheritance ("is-a") — Course and Lesson are unrelated class hierarchies, one simply holds instances of the other.

Applied / scenario 5
A "Car" class has an "Engine" attribute that is itself an object of an Engine class. What relationship does this represent?
Reveal answer

Containment (aggregation) — the Car class HAS-A component that is of another class type (Engine).

Short answer 6
In the AddLesson method, what actually happens when it's called?
Reveal answer

It creates a NEW Lesson object using the given parameters and appends it to the Course's own list of lessons (CourseLesson), incrementing the lesson count.
