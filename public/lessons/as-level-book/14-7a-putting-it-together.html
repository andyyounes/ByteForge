14.07 Putting It All Together
The pyramid-drawing program, fully modularised — procedures, functions, BYVAL and BYREF working together. Completes Chapter 14.
Theory

The full pyramid program, in pseudocode

CONSTANT SPACE ← " " FUNCTION InputMaxNumberOfSymbols() RETURNS INTEGER DECLARE Number : INTEGER Number ← 0 WHILE Number MOD 2 = 0 OUTPUT "How many symbols make the base?" INPUT "Input an odd number: ", Number ENDWHILE RETURN Number END FUNCTION PROCEDURE OutputChars(BYVAL Number : INTEGER, BYVAL Symbol : CHAR) DECLARE Count : INTEGER FOR Count ← 1 TO Number OUTPUT Symbol // without moving to next line ENDFOR END PROCEDURE PROCEDURE AdjustValuesForNextRow(BYREF Spaces : INTEGER, BYREF Symbols : INTEGER) Spaces ← Spaces - 1 Symbols ← Symbols + 2 END PROCEDURE
  • Notice the DELIBERATE choice of parameter/local identifiers that differ from the main program's variable names — this makes it explicit that a subroutine's own namespace is separate from the calling program's.
  • InputMaxNumberOfSymbols is a FUNCTION (returns a value); OutputChars uses BYVAL (only supplies data in); AdjustValuesForNextRow uses BYREF (updates the caller's variables).

Translating to Python — no BYREF, so functions return tuples instead

# Python SPACE = ' ' def InputMaxNumberOfSymbols(): Number = 0 while Number % 2 == 0: print("How many symbols make the base?") Number = int(input("Input an odd number: ")) return Number def OutputChars(Number, Symbol): for Count in range(Number): print(Symbol, end='') def AdjustValuesForNextRow(Spaces, Symbols): Spaces = Spaces - 1 Symbols = Symbols + 2 return Spaces, Symbols # simulates BYREF via multiple return values def main(): MaxNumberOfSymbols = InputMaxNumberOfSymbols() NumberOfSpaces = (MaxNumberOfSymbols + 1) // 2 NumberOfSymbols = 1 while NumberOfSymbols <= MaxNumberOfSymbols: OutputChars(NumberOfSpaces, SPACE) OutputChars(NumberOfSymbols, "*") print() NumberOfSpaces, NumberOfSymbols = AdjustValuesForNextRow(NumberOfSpaces, NumberOfSymbols) main()
  • Discussion point from the coursebook: separate OutputSpaces and OutputSymbols procedures can be MERGED into a single OutputChars procedure that just repeats whatever character it's given — a small but real example of reducing duplication through good subroutine design.

Chapter 14 summary

  • Subroutines (procedures and functions) are declared BEFORE the main program body.
  • Calling a procedure is a program STATEMENT; calling a function happens WITHIN an expression.
  • Parameters are placeholders in the subroutine header; arguments are the actual values supplied at call time — together they form the subroutine interface.
  • BYVAL passes a copy (changes don't escape); BYREF passes an address (changes DO escape back to the caller).
  • Python has no BYREF — the only way to update a caller's variable is to return the new value(s) from a function.
Practice — Test Yourself

These questions draw on the whole of Chapter 14 — procedures, functions, parameters, BYVAL/BYREF, and modular design (completes Section 14.07 and Chapter 14).

Short answer 1
Why are the parameter names inside AdjustValuesForNextRow deliberately different from the variable names used to call it in the main program?
Reveal answer

To make it explicit that parameters and local variables inside a subroutine occupy a SEPARATE namespace from the calling program's variables — even though, with BYREF, they end up referencing the same memory location.

Short answer 2
In the merged design, how did separate OutputSpaces and OutputSymbols procedures become one OutputChars procedure?
Reveal answer

Both procedures did the same underlying job — repeat a character N times — so they were combined into ONE procedure that takes the character as a parameter, removing duplicated logic.

Fill in the blank 3
Calling a function happens within an ______; calling a procedure is a program ______.
Reveal answer

Expression; statement.

Spot the error 4
In the Python version, a student writes AdjustValuesForNextRow(NumberOfSpaces, NumberOfSymbols) as a plain statement (not reassigning the result). What goes wrong on the next loop iteration?
Reveal answer

Since Python has no BYREF, the function's changes are LOST — NumberOfSpaces and NumberOfSymbols in main() never actually update, so the loop either runs forever or produces the same row repeatedly. It must be written as NumberOfSpaces, NumberOfSymbols = AdjustValuesForNextRow(NumberOfSpaces, NumberOfSymbols).

Applied / scenario 5
Write program code for a procedure OutputTimesTable that takes one integer parameter, n, and outputs the times table for n (e.g. "1 x 5 = 5" through "10 x 5 = 50" for n = 5). Use pseudocode.
Reveal answer

PROCEDURE OutputTimesTable(BYVAL n : INTEGER)
  DECLARE Count : INTEGER
  FOR Count ← 1 TO 10
    OUTPUT Count, " x ", n, " = ", Count * n
  ENDFOR
END PROCEDURE

Short answer 6
Write a pseudocode function header for isDivisible, taking two INTEGER parameters x and y, returning a BOOLEAN.
Reveal answer

FUNCTION isDivisible(x : INTEGER, y : INTEGER) RETURNS BOOLEAN
