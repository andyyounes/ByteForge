29.04–29.05 Prolog Variables & the Anonymous Variable
Asking "which one?" instead of "is this true?" — and ignoring values you don't care about.
Theory

Using a variable in a query

cityInCountry(paris, france). cityInCountry(berlin, germany). cityInCountry(cairo, egypt). cityInCountry(munich, germany). ?- cityInCountry(berlin, Country). Country = germany. ?- cityInCountry(City, germany). City = berlin ; City = munich.
  • A VARIABLE (capital letter) in a query asks Prolog to FIND a matching value, rather than just checking true/false.
  • When there's MORE THAN ONE possible answer, typing a SEMICOLON after the first answer asks Prolog for the NEXT one — the semicolon effectively means OR.
  • Each time a variable takes on a specific value during a query, it is said to be INSTANTIATED to that value.

Worked example — a recipe knowledge base

ingredient(tagine, aubergine, 250). ingredient(tagine, tomato, 100). ingredient(stew, beef, 400). ingredient(stew, potato, 600). ?- ingredient(tagine, Ingredient, Amount). Ingredient = aubergine, Amount = 250 ; Ingredient = tomato, Amount = 100.

The anonymous variable

  • If you don't CARE about a particular argument's value, use the ANONYMOUS variable: a plain underscore _.
  • Example: to find tagine's ingredients WITHOUT caring about the amount: ingredient(tagine, Ingredient, _).
  • This makes queries cleaner and communicates intent — "I genuinely don't need this value" — rather than binding it to a named variable you'll never use.
Anonymous variable: the underscore character (_), used in place of a variable whose value is not of interest.
Practice — Test Yourself

These questions only cover what THIS subsection taught — Prolog variables, instantiation, and the anonymous variable (completes Sections 29.04–29.05).

Short answer 1
What does it mean for a variable to be "instantiated"?
Reveal answer

It has been matched to (assigned) a specific value while Prolog was answering a query.

Short answer 2
What does typing a semicolon after Prolog's first answer do?
Reveal answer

Asks Prolog to search for and return the NEXT possible answer, if there is one — the semicolon effectively means "OR give me another".

Fill in the blank 3
The anonymous variable is written as a single ______ character.
Reveal answer

Underscore (_).

Spot the error 4
A student writes the query cityInCountry(Country, germany). intending Country to receive the CITY's name. What's wrong?
Reveal answer

The variable's NAME doesn't determine what it holds — its POSITION in the predicate does. In cityInCountry(City, Country), the first argument slot holds the city, the second holds the country — naming the first-position variable "Country" doesn't change which value it actually receives.

Applied / scenario 5
Write a query using the anonymous variable to find which dishes use "beef" as an ingredient, ignoring the amount, given ingredient(Dish, IngredientName, Amount).
Reveal answer

ingredient(Dish, beef, _).

Short answer 6
Why is using the anonymous variable preferable to using a named variable you never reference again?
Reveal answer

It makes the query's intent clearer — explicitly signalling "this value doesn't matter to me" — rather than introducing a named variable that serves no real purpose.
