3.07 Printers, Scanners and Plotters
Inkjet, laser, scanners, plotters, and 3D printers — the same underlying dots-per-inch logic keeps reappearing.
Key Terms
CCD
Charge-coupled device — an array of photo-sensitive cells used in scanners to detect reflected light.
Graphics plotter
Uses pens to draw directly from a vector graphic file onto paper constrained by sprockets.
Theory

Inkjet printers

  • Cheapest to BUY — but the purchase price is soon dwarfed by the cost of replacement ink. A genuine advantage is small size.
  • Working principle: paper feeds in; the printhead moves across depositing ink; paper advances slightly; repeat until the sheet is fully printed.
  • The printhead has THOUSANDS of nozzles, each with a diameter far smaller than a human hair — spraying ink droplets via either thermal bubble or piezoelectric technology (neither has a significant advantage).
  • Colour printing uses THREE colour cartridges (cyan, magenta, yellow — the subtractive primaries) plus black. Overlapping droplet combinations can, in principle, create any colour.
  • The number of DOTS PER INCH is fixed by the printhead's physical geometry — but the number of dots PER PIXEL is controlled by software. More dots per pixel = better colour definition but WORSE resolution (bigger effective pixel size) — you can't improve both at once.

Laser printers

  • Historically more expensive, and used to offer clearly higher quality — though the gap has narrowed.
  1. The photoreceptor drum is given an electric charge.
  2. The drum revolves step by step.
  3. At each step, a laser (via mirror/lens assembly) is directed to a sequence of positions across the drum's width.
  4. At each position, the laser is switched OFF (leaves the charge) or ON (discharges that position).
  5. This repeats until a full-page electrostatic image has formed.
  6. The drum is coated with charged TONER, which sticks only where the drum has been discharged.
  7. The drum rolls over a (charged) sheet of paper.
  8. The paper is discharged, then passed through HEATED ROLLERS to fuse and seal the toner.
  9. The drum is discharged before the process repeats for the next page.
  • Colour printing needs SEPARATE toners per colour, repeating the whole process per colour — using cyan, magenta, yellow and black, just like inkjet's logical approach.
  • The same dots-per-inch / dots-per-pixel trade-off from inkjet printing applies here too.

Scanners — reversing the printing process

  • A scanner effectively REVERSES printing: it takes a physical image and creates a digital representation from it (rather than the reverse).
  • The paper stays fixed; a light source moves across it; reflected light is directed via mirrors/lenses onto a charge-coupled device (CCD).
  • Three key facts about the CCD: it's an array of PHOTO-SENSITIVE cells; each cell produces an electrical response PROPORTIONAL to light intensity; an analogue-to-digital converter is needed to create a storable digital value.

Graphics plotters and 3D printers

  • A vector graphic CAN be converted to a bitmap for screen display or normal printing — but specialised technical applications sometimes need a more ACCURATE representation on paper, requiring a graphics PLOTTER.
  • A plotter uses PENS on a large sheet constrained by sprockets (which move the paper); pens can be parked or in use — the controlling software draws directly from the original vector file.
  • A 3D printer starts from a 3D design (from CAD software), splits it into LAYERS, and (rather than using ink) squirts material from a nozzle onto the print bed to build each physical layer in turn — repeating layer by layer, then CURING the finished object so the layers weld together.
A real example — a 3D-printed bionic ear

Built using THREE different "inks": silicone (basic structure), a gel containing chondrocyte cells, and silicone infused with silver nanoparticles. The final curing step involved incubation in a culture medium so the chondrocyte cells could produce cartilage.

Practice — Test Yourself

These questions only cover what THIS subsection taught — printers, scanners and plotters (completes Section 3.07).

Short answer 1
For an inkjet printer, what determines the number of dots per inch, and what determines dots per pixel?
Reveal answer

Dots per inch is fixed by the printhead's physical geometry (nozzle spacing); dots per pixel is controlled by the software.

Short answer 2
In a laser printer, where does the toner stick to the drum, and why?
Reveal answer

Toner sticks only to positions on the drum that have been DISCHARGED by the laser — the charged toner is attracted specifically to those discharged spots.

Fill in the blank 3
A scanner's CCD produces, for each cell, an electrical response ______ to the light intensity, which is then converted to a ______ value by an ADC.
Reveal answer

Proportional; digital.

Spot the error 4
A student says: "For an inkjet printer, you can just increase dots per pixel to improve BOTH colour quality and image resolution at the same time." Why is this wrong?
Reveal answer

Increasing dots per pixel improves colour DEFINITION, but makes the effective pixel size bigger, which WORSENS resolution. You can't improve both simultaneously — it's a genuine trade-off, not a free upgrade.

Applied / scenario 5
An engineering firm needs an extremely accurate technical drawing reproduced directly from a vector graphic file, on a large sheet of paper. Which device from this lesson is specifically suited to this, and why?
Reveal answer

A graphics plotter — it draws directly from the original vector graphic file using pens, avoiding the accuracy loss involved in first converting to a bitmap for normal printing.

Short answer 6
In a 3D printer, what happens to the printed object AFTER all the layers have been formed?
Reveal answer

It has to be cured in some way, so the layers are effectively welded together and the material converts to the form required for the finished product.
