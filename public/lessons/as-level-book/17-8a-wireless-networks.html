17.08 Wireless Networks
Bluetooth, WiFi, WiMAX, and cellular networks, in order of increasing scale. Completes Chapter 17.
Theory

Bluetooth (IEEE 802.15)

  • Short-range radio transmission in a confined area.
  • An AD HOC network — no defined infrastructure; connections are created SPONTANEOUSLY as devices come into range.
  • Used for an almost limitless range of applications, from simple ones (a wireless keyboard/mouse) upward.

WiFi (IEEE 802.11)

  • A wireless LAN protocol using radio frequency transmission — sometimes called "wireless Ethernet".
  • Usually built around a WIRELESS ACCESS POINT in an "INFRASTRUCTURE" network (NOT ad hoc, unlike Bluetooth).
  • The access point communicates wirelessly with connected end-systems, and has its OWN wired connection to the Internet.

WiMAX (IEEE 802.16)

  • Worldwide Interoperability for Microwave Access — designed for a MAN or WAN scale, not just a LAN.
  • Used by PSTNs to provide broadband Internet access WITHOUT laying underground cables — local subscribers connect to a local base station's antenna via microwave signal.

Cellular networks

  • A mobile phone is called a "cell phone" because of this underlying infrastructure: the coverage area is divided into CELLS, each with a BASE STATION at its centre.
  • Adjacent cells use DIFFERENT transmission frequencies, which is what allows the whole system to work without interference between neighbouring cells.

Chapter 17 summary

  • Isolated network topologies: single link, bus, ring, star, mesh.
  • Circuit switching needs a pre-established dedicated circuit; packet switching doesn't.
  • Hardware devices increase in intelligence: NIC → hub → switch → router.
  • TCP/IP is a layered protocol stack; TCP ensures safe delivery, IP ensures routing.
  • Key application-layer protocols: HTTP, SMTP/POP3/IMAP, FTP.
  • Ethernet is the dominant LAN protocol; switched Ethernet eliminates the need for CSMA/CD.
  • BitTorrent enables structureless, fair peer-to-peer file sharing.
  • Four major wireless technologies, by increasing scale: Bluetooth, WiFi, WiMAX, cellular networks.
Practice — Test Yourself

These questions cover the four wireless technologies, and draw together the whole of Chapter 17 (completes Section 17.08 and Chapter 17).

Short answer 1
What is the key structural difference between a Bluetooth network and a WiFi network?
Reveal answer

Bluetooth is an "ad hoc" network with no defined infrastructure — connections form spontaneously. WiFi is usually an "infrastructure" network built around a fixed wireless access point.

Short answer 2
Why must adjacent cells in a cellular network use different transmission frequencies?
Reveal answer

To avoid interference — if neighbouring cells used the same frequency, transmissions from one cell would clash with transmissions in the adjacent cell.

Fill in the blank 3
WiMAX operates at ______ or ______ scale, allowing broadband access without laying underground cables.
Reveal answer

MAN (Metropolitan Area Network); WAN (Wide Area Network).

Spot the error 4
A student says 2G's defining feature was "adding Internet capability to phones". Which generation does this description actually belong to?
Reveal answer

3G — that generation introduced multimedia and serious Internet connection capability. 2G's defining feature was simply going digital (from 1G's analogue voice-only technology).

Applied / scenario 5
Rank Bluetooth, WiFi, WiMAX, and a cellular network by increasing scale of operation.
Reveal answer

Bluetooth (short-range, confined area) → WiFi (a single LAN) → WiMAX (MAN/WAN) → cellular network (nationwide, built from many overlapping cells).

Short answer 6
In circuit switching vs. packet switching, which one is more analogous to how the modern Internet moves data?
Reveal answer

Packet switching — the Internet is built around discrete packets routed independently, not pre-established dedicated circuits.
