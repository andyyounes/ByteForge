3.06 Keyboards and Keypads
Pressing a key feels instant — but there's a surprising amount of hardware working behind that illusion.
Key Terms
Key matrix
A grid of row wires and column wires beneath the keys — a key press connects one row wire to one column wire.
Character code
The code sent to the processor representing which key was pressed.
Theory

QWERTY, numeric keypads, and phone keypads — same underlying technology

  • The standard method for inputting significant text has always been the QWERTY keyboard (named after the top-left row of letters).
  • When only numbers are needed, a numeric keypad is used instead. A traditional mobile phone keypad is a different layout again, but can still input text data.
  • The TECHNOLOGY underpinning all of these is the SAME, provided there are actual physical keys involved.

Pressing a key and seeing it on screen is an illusion

  • It APPEARS as though a key press immediately puts the character on screen — but this is genuinely an illusion.
  • The key press must first be converted to a CHARACTER CODE, which is transmitted to the processor. The processor, under OS control, then ensures the character is displayed.
  • The same underlying process happens for a shortcut key combination too — except the processor responds by taking the requested ACTION, rather than displaying a character.

The key matrix — how a key press actually gets detected

  • The keyboard has its own electrical circuitry, a microprocessor, and a ROM chip.
  • Keys sit above a KEY MATRIX — a set of ROW wires crossing a set of COLUMN wires. Pressing a key causes contact at one specific intersection.
  • The microprocessor continuously TESTS whether any row-column circuit has closed. When it detects one, it identifies WHICH intersection caused it.
  • It then uses data stored in the ROM to generate the correct character code for that intersection, and sends this code to the processor.
  • The same principle applies even when TWO keys are pressed simultaneously (e.g. Shift + a letter).
Practice — Test Yourself

These questions only cover what THIS subsection taught — keyboards and keypads (completes Section 3.06).

Short answer 1
Why is seeing a character appear on screen "immediately" after a key press described as an illusion?
Reveal answer

The key press has to first be converted into a character code, transmitted to the processor, and then displayed under OS control — several real steps happen, even though it feels instantaneous to the user.

Short answer 2
What THREE hardware components does a keyboard itself contain, beyond the physical keys?
Reveal answer

Electrical circuitry, its own microprocessor, and a ROM chip.

Fill in the blank 3
A key matrix consists of a set of ______ wires and a set of ______ wires; pressing a key makes contact at one specific intersection.
Reveal answer

Row; column.

Spot the error 4
A student says: "A QWERTY keyboard, a numeric keypad, and a mobile phone keypad all use fundamentally DIFFERENT underlying technologies since they look so different." Correct this.
Reveal answer

The underlying TECHNOLOGY is the same across all of them, provided there are actual physical keys — only the layout and arrangement of keys differs between them.

Applied / scenario 5
A user presses Ctrl+S as a shortcut to save a file, rather than typing a visible character. How does the processor's response differ from a normal letter key press?
Reveal answer

The same underlying detection process happens (key matrix intersection → character code → sent to processor) — but instead of displaying a character on screen, the processor responds by carrying out the requested ACTION (saving the file).

Short answer 6
What does the keyboard's microprocessor continuously do while waiting for input?
Reveal answer

It continuously tests whether any row-and-column circuit in the key matrix has become closed (i.e. whether any key has been pressed).
