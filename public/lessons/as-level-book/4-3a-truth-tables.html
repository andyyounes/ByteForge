4.03 Truth Tables
1 for TRUE, 0 for FALSE — a simple convention that makes any logic expression fully checkable.
Theory

The convention behind every truth table

  • TRUE is represented as 1; FALSE is represented as 0.
  • Labelling convention: the initially defined values are A and B; the value obtained from the expression is X.
  • So the truth table for the AND operator is literally the truth table for X = A AND B.
ABX = A AND B
000
010
100
111

Why a 2-input truth table always has exactly 4 rows

  • A truth table needs one row for EVERY possible combination of the input truth values.
  • With 2 inputs (A and B), there are 2 × 2 = 4 possible combinations — hence 4 rows.
  • For AND, only ONE of those 4 rows (both inputs TRUE) produces a TRUE (1) output — the other three all produce FALSE (0), exactly as the AND definition requires.

Generalising: how many rows for N inputs?

  • The number of rows needed is 2 raised to the power of the number of inputs.
  • 2 inputs → 4 rows. 3 inputs → 8 rows. 4 inputs → 16 rows.
  • This is exactly why problems with many inputs get unwieldy fast — a 4-input problem already needs a 16-row table.
Practice — Test Yourself

These questions only cover what THIS subsection taught — the truth table convention (completes Section 4.03).

Short answer 1
In a truth table, what do the digits 1 and 0 represent?
Reveal answer

1 = TRUE, 0 = FALSE.

Short answer 2
By the labelling convention used in this lesson, what do A, B and X each represent?
Reveal answer

A and B are the initially defined input values; X is the value obtained from the expression built from A and B.

Fill in the blank 3
A truth table with 3 inputs needs 23 = ______ rows to show every possible input combination.
Reveal answer

8.

Complete it 4
Without looking back, complete the truth table for X = A OR B: rows are 00→?, 01→?, 10→?, 11→?
Reveal answer

00→0, 01→1, 10→1, 11→1 — OR is TRUE whenever at least one input is TRUE.

Applied / scenario 5
A logic expression has 5 independent inputs. How many rows will its complete truth table need?
Reveal answer

25 = 32 rows.

Short answer 6
For the AND operator's truth table, how many of the 4 rows produce a TRUE (1) output, and why exactly that many?
Reveal answer

Only 1 row — the one where BOTH A and B are TRUE — because AND's definition requires both inputs to be TRUE simultaneously.
