28.01–28.02 The Processor Instruction Set & Symbolic Addresses
The assembly-language instruction set used throughout this chapter, and why labels beat raw addresses.
Theory

Notation conventions used in this chapter

  • ACC = the Accumulator; IX = the Index Register.
  • # denotes IMMEDIATE addressing (a literal value follows, not an address).
  • B prefixes a BINARY number (e.g. B01001010); & prefixes a HEXADECIMAL number (e.g. &4A).
  • <address> can be an ABSOLUTE address (a raw number) or a SYMBOLIC address (a label).

Data movement and arithmetic instructions

InstructionAddressing modeEffect
LDM #nImmediateLoad the number n directly into ACC
LDD <address>DirectLoad the contents AT the given address into ACC
LDI <address>IndirectThe address to use is stored AT the given address — load the contents of THAT second address into ACC
LDX <address>IndexedForm the address as <address> + contents of IX; load contents of the calculated address into ACC
LDR #nImmediateLoad the number n into IX
STO / STX / STI <address>Direct / Indexed / IndirectStore the contents of ACC at the (calculated) address
ADD <address>—Add the contents of the given address to ACC
INC / DEC <register>—Add 1 to / subtract 1 from the register (ACC or IX)

Comparison, jump, I/O, and bit-manipulation instructions

InstructionEffect
CMP <address> / CMP #nCompare ACC's contents with the address's contents / with number n
JMP <address>Jump unconditionally to the given address
JPE <address>Following a CMP, jump if the comparison was TRUE (equal)
JPN <address>Following a CMP, jump if the comparison was FALSE (not equal)
IN / OUTKey in a character (store its ASCII code in ACC) / output the character whose ASCII code is in ACC
AND / XOR / OR #n or <address>Bitwise operation between ACC and the operand
LSL #n / LSR #nShift ACC's bits n places left/right, filling with zeros
ENDReturn control to the operating system
<label>: <data>Gives a symbolic address (label) to a memory location holding <data>
  • Data movement, arithmetic, comparison, and jump instructions were introduced in Chapter 6; bitwise instructions in Chapter 22. IN/OUT are new here — needed for genuinely useful, interactive programs.

Symbolic addresses (labels)

  • A LABEL is a symbolic name for a memory location — treat it like a variable name.
  • Using ABSOLUTE addresses directly is very restrictive: adding even ONE extra instruction shifts every address that comes after it.
  • Writing with LABELS lets you think at a higher level — the ASSEMBLER allocates the actual absolute addresses during assembly (Chapter 7).
Label: a symbolic name for the memory location it represents.
Practice — Test Yourself

These questions only cover what THIS subsection taught — the instruction set and symbolic addressing (completes Sections 28.01–28.02).

Short answer 1
What is the difference between LDD and LDI?
Reveal answer

LDD (direct) loads the contents found AT the given address directly into ACC. LDI (indirect) treats the given address as pointing to ANOTHER address — it loads the contents of THAT second address into ACC.

Short answer 2
What does the # symbol indicate in an operand like #34?
Reveal answer

Immediate addressing — the number itself (34) is the value to use directly, not a memory address to look up.

Fill in the blank 3
A ______ is a symbolic name for a memory location, allocated an actual absolute address by the ______ during assembly.
Reveal answer

Label; assembler.

Spot the error 4
A programmer writes a whole program using only absolute addresses, then needs to insert one extra instruction near the start. What problem does this create?
Reveal answer

Every instruction and jump target AFTER the insertion point now needs its address manually recalculated and updated, since absolute addresses don't automatically shift — this is exactly the restrictiveness that symbolic addressing (labels) avoids.

Applied / scenario 5
Following a CMP instruction that evaluates to FALSE, which jump instruction (JPE or JPN) would actually be taken?
Reveal answer

JPN (jump if the comparison was false/not-equal) — JPE only jumps when the comparison was TRUE.

Short answer 6
What must every program end with, and why?
Reveal answer

The END instruction — it returns control to the operating system. Without it, the processor would try to interpret whatever binary pattern comes next as an instruction, likely crashing.
