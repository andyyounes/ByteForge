2.04 Internet-Supporting Hardware
Routers, gateways, servers and proxy servers — the physical devices that make the Internet actually work.
Key Terms
Router
A device that acts as a node on the Internet — found in the backbone fabric and in ISP networks.
Gateway
A device connecting networks of different underlying technologies — can share some router functionality.
Server
Hardware providing services via a network — doesn't help run the network itself, just serves it.
Proxy server
A server that caches web pages and can add a firewall layer of security.
Theory

The Internet is fundamentally a mesh — routers are its nodes

  • The Internet has a structure that's partly hierarchical, but at heart it's a MESH structure.
  • The device acting as a node in this mesh is the router — found throughout the backbone fabric of the Internet and inside ISP networks.

Gateways — for when networks don't speak the same "language"

  • At the periphery of the Internet there are many different TYPES of network, often using different underlying technologies.
  • Whenever networks of a different underlying technology need to communicate, a gateway is the device needed.
  • Part of a gateway's functionality can OVERLAP with what a router provides — the two aren't mutually exclusive roles.

What a server actually is — and what it's NOT

  • A server is specialised computer hardware designed to provide functionality when connected to a network.
  • Crucially: a server does NOT contribute to the functioning of the network itself — it's a means of providing SERVICES via the network, a genuinely different job from a router or gateway.
  • In the context of the Internet, a server may act as: an application server, a web server, a domain name server, a file server, or a proxy server.
Server farms — file serving at scale

File server functionality is very often provided by a "server farm" — a very large number of servers working together in a clustered configuration.

Tier 1 content providers use server farms, and they're also used for cloud storage, which an ISP can offer as part of its service portfolio.

Proxy servers — caching AND security in one device

  • Problem: a web server could become overwhelmed by too many web page requests.
  • Solution: the FIRST time a web page is requested, the proxy server saves a copy in a cache. Every SUBSEQUENT request can then be served directly from the cache — no need to search through the main server's filestore each time.
  • At the same time, a proxy server can act as a FIREWALL, providing some security against malicious attacks on the main server — one device doing two genuinely different jobs (performance AND security).
Practice — Test Yourself

These questions only cover what THIS subsection taught — routers, gateways, servers and proxy servers (completes Section 2.04).

Short answer 1
What kind of overall structure does the Internet have "at heart", and what device acts as its node?
Reveal answer

A mesh structure; the router acts as the node.

Short answer 2
When two networks use different underlying technologies and need to communicate, which device is required?
Reveal answer

A gateway.

Spot the error 3
A student claims a server "helps run the network itself, the same way a router does." Why is this wrong?
Reveal answer

A server does NOT contribute to the functioning of the network itself — it only provides services VIA the network. Running the network is the job of devices like routers and gateways, a genuinely separate role.

Fill in the blank 4
A proxy server saves a requested web page in a ______ the first time it's requested, so subsequent requests don't need to search the main server's ______.
Reveal answer

Cache; filestore.

Applied / scenario 5
A company's web server keeps getting overwhelmed by requests for the same popular page, and separately the company wants extra protection against malicious attacks. Which single device addresses BOTH problems, and how?
Reveal answer

A proxy server — it caches the popular page after the first request so later requests don't hit the main server's filestore, AND it can act as a firewall, providing security against malicious attacks at the same time.

Short answer 6
What is a "server farm", and name two contexts where they're used.
Reveal answer

A very large number of servers working together in a clustered configuration, very often used to provide file server functionality. Used by Tier 1 content providers, and for cloud storage offered by ISPs.
