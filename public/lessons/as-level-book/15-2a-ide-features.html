15.02 Features of a Typical IDE
Prettyprint, context-sensitive prompts, dynamic syntax checks, and collapsible code blocks.
Theory

Prettyprinting

  • Refers to the visual PRESENTATION of code as it's typed: automatic indentation, and colour-coding of keywords, strings, and comments.
  • Python's IDLE colour-codes keywords, built-in function calls, comments, strings, and header identifiers, and auto-indents code blocks.
  • Visual Studio (VB.NET) and Delphi (Pascal) editors do the same, also colour-coding object references and system directives, and auto-indenting to match the previous line.

Context-sensitive prompts

  • Displays hints or a choice of keywords/identifiers appropriate to the CURRENT insertion point in the code.
  • Example: typing the start of a keyword (like "F") pops up a filtered list of matching keywords/identifiers; choosing one may show an explanation and even offer to auto-insert a code snippet.
  • In Python's IDLE, typing a function name shows the required PARAMETERS as a pop-up, helping you supply arguments correctly.

Dynamic syntax checks

  • As you type a line, the editor checks its syntax immediately and highlights errors (often with a coloured underline), without waiting for you to compile or run the program.
  • Hovering the mouse over the highlighted section often shows an explanation of what's wrong.

Expanding and collapsing code blocks

  • Useful for large programs — collapsing a subroutine's body hides its statements but keeps its HEADING visible, so you can still see what arguments to supply when calling it.
  • Reduces excessive scrolling and helps you focus on the part of the program you're currently working on (e.g. global declarations and the main program body).
Practice — Test Yourself

These questions only cover what THIS subsection taught — IDE features (completes Section 15.02).

Short answer 1
What does "prettyprint" refer to in an IDE?
Reveal answer

The presentation of code — automatic indentation and colour-coding of keywords, strings, and comments.

Short answer 2
What does a context-sensitive prompt display?
Reveal answer

Hints or a filtered choice of keywords and available identifiers, appropriate to the current insertion point in the code.

Fill in the blank 3
A ______ syntax check alerts the programmer to an error as soon as a line is typed, without needing to compile or run the program.
Reveal answer

Dynamic.

Spot the error 4
A student collapses all the subroutine bodies in a long program to reduce scrolling, but then complains they can no longer remember what arguments each subroutine expects. What have they missed about collapsed code blocks?
Reveal answer

Collapsing a subroutine hides its BODY but keeps its HEADING visible — the heading still shows the parameter list, so the required arguments remain visible even while collapsed.

Applied / scenario 5
You start typing a function name in IDLE, and a pop-up immediately appears listing the function's expected inputs. Which IDE feature is this?
Reveal answer

Context-sensitive prompts.

Short answer 6
Name two things prettyprint typically colour-codes.
Reveal answer

Any two of: keywords, built-in function calls, comments, strings, identifiers.
