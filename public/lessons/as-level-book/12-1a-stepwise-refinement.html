12.01 Stepwise Refinement
A 6-line outline of a pyramid-drawing program, refined step by numbered step into real pseudocode.
Key Terms
Stepwise refinement
Breaking down the steps of an outline solution into smaller and smaller steps.
Theory

Why bigger problems need this technique

  • For a solution to be PROGRAMMABLE, its steps must ultimately break down into the basic constructs: sequence, assignment, selection, repetition, input, output.
  • Stepwise refinement takes an outline solution and breaks it into smaller steps, repeating the process until each step is detailed enough to implement directly.
Worked Example — drawing a pyramid, first attempt (too vague)

Input: a symbol and an odd number (the width of the final row). Output: a symmetrical pyramid of that symbol.

01 Set up initial values 02 REPEAT 03 Output number of spaces 04 Output number of symbols 05 Adjust number of spaces and number of symbols for next row 06 UNTIL the required number of symbols have been output in one row

Why this first attempt isn't enough

  • Steps are NUMBERED specifically so later refinements can reference them precisely (e.g. "01.2" refines part of step "01").
  • This level of detail is NOT enough to write real program code — exactly what values need setting? What's "the number of spaces" actually computed FROM?

Refining step 01 — setting up initial values

01.1 INPUT Symbol 01.2 INPUT MaxNumberOfSymbols 01.3 NumberOfSpaces ← (MaxNumberOfSymbols - 1) / 2 01.4 NumberOfSymbols ← 1
  • NumberOfSpaces is HALF of the final row's symbol count — this is exactly what makes the pyramid's slope symmetrical.
  • MaxNumberOfSymbols must be ODD for the pyramid to look right — so step 01.2 gets refined FURTHER, into its own REPEAT loop that keeps asking until an odd number is entered: REPEAT / INPUT MaxNumberOfSymbols / UNTIL MaxNumberOfSymbols MOD 2 = 1.

Refining steps 03, 04, and 05

03.1 FOR i ← 1 TO NumberOfSpaces 03.2 OUTPUT Space // without moving to next line 03.3 ENDFOR 04.1 FOR i ← 1 TO NumberOfSymbols 04.2 OUTPUT Symbol // without moving to next line 04.3 ENDFOR 04.4 OUTPUT Newline // move to the next line 05.1 NumberOfSpaces ← NumberOfSpaces - 1 05.2 NumberOfSymbols ← NumberOfSymbols + 2
  • Step 06's termination check becomes: UNTIL NumberOfSymbols > MaxNumberOfSymbols — checking whether the NEXT row's symbol count has already gone too far.
Practice — Test Yourself

These questions only cover what THIS subsection taught — stepwise refinement (completes Section 12.01).

Short answer 1
Give the precise definition of stepwise refinement.
Reveal answer

Breaking down the steps of an outline solution into smaller and smaller steps.

Short answer 2
Why is NumberOfSpaces set to HALF of MaxNumberOfSymbols minus 1, divided by 2?
Reveal answer

To make the pyramid's slope symmetrical — the leading spaces on each row need to shrink at exactly the right rate to match the growing number of symbols, centred correctly.

Fill in the blank 3
Steps in a stepwise refinement are ______ so that later, more detailed refinements can reference exactly which step they're expanding.
Reveal answer

Numbered.

Spot the error 4
A student's algorithm accepts ANY number for MaxNumberOfSymbols, even numbers. What genuine problem would follow, and how does the refined algorithm prevent it?
Reveal answer

An even final-row width would make the pyramid's symmetric slope calculation come out wrong. The refined step 01.2 wraps the input in its own REPEAT…UNTIL loop, checking MaxNumberOfSymbols MOD 2 = 1, so it keeps re-asking until an odd number is given.

Applied / scenario 5
Why is the FIRST attempt at the pyramid algorithm ("Set up initial values… REPEAT… UNTIL…") not directly programmable, even though it's logically correct?
Reveal answer

It isn't expressed in terms of the basic constructs (assignment, specific loops, exact conditions) — phrases like "set up initial values" and "adjust values" aren't yet concrete enough to translate directly into real code.

Short answer 6
By how much does NumberOfSymbols increase, and NumberOfSpaces decrease, moving from one pyramid row to the next?
Reveal answer

NumberOfSymbols increases by 2; NumberOfSpaces decreases by 1.
