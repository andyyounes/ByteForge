18.03 Boolean Algebra Applications: Sum of Products
Going from a truth table (or a circuit) to a Boolean algebra expression.
Theory

From a truth table to an expression: the sum-of-products method

  • For each ROW of the truth table where the output is 1, form a MINTERM — the AND (product) of every input, using the inverse for any input that is 0 in that row.
  • The final expression is the SUM (OR) of all these minterms.
Half adder's C output (only 1 when A=1 AND B=1): Only one row gives 1 → one minterm → C = A.B Half adder's S output (1 when A=1,B=0 OR A=0,B=1): Two rows give 1 → sum of two minterms → S = A.B̄ + Ā.B
Minterm: a product term (AND of all inputs, each possibly inverted) that corresponds to exactly one row of a truth table producing a 1 output.

From a logic circuit to an expression

  • Work through the circuit gate by gate, using each gate's own truth table, then simplify algebraically at the end.
  • Remember: a NAND gate = AND followed by NOT; a NOR gate = OR followed by NOT.

Worked example — deriving S from a half adder built of NAND gates

  • Inputs A, B feed a NAND gate giving output W. The first three rows of the NAND truth table give a 1, so:
W = A.B̄ + Ā.B + Ā.B̄ Next: W and A feed another NAND gate, giving X. NAND = AND then NOT, so first find the AND part: A.W = A.(A.B̄ + Ā.B + Ā.B̄) Distribute, then apply the inverse law (A.Ā = 0): = A.B̄ + 0 + 0 = A.B̄ Now invert (completing the NAND) using De Morgan's AND form: X = (A.B̄)‾ = Ā + B Similarly for the other NAND branch (W and B): Y = A + B̄ Finally, X and Y feed the last NAND gate: AND part first: X.Y = (Ā+B).(A+B̄) Apply De Morgan's law directly to invert (completing the NAND): S = X.Y‾ = A.B̄ + Ā.B ← matches the truth table exactly!
  • This confirms the NAND-only circuit really does implement the half adder's S output correctly.
Practice — Test Yourself

These questions only cover what THIS subsection taught — sum of products, minterms, and deriving expressions from circuits (completes Section 18.03).

Short answer 1
What is a minterm?
Reveal answer

A product (AND) term formed from every input in the truth table, using the inverse for any input that is 0 in that particular row — one minterm corresponds to exactly one row where the output is 1.

Short answer 2
How many minterms are summed to form the final expression?
Reveal answer

One for every row of the truth table where the output is 1 — no more, no fewer.

Fill in the blank 3
A NAND gate is equivalent to an ______ gate followed by a ______ gate.
Reveal answer

AND; NOT.

Spot the error 4
For a truth table where a row has A=1, B=0 giving output 1, a student writes the minterm as A.B (not inverting B). What's the mistake?
Reveal answer

Since B=0 in that row, B must be INVERTED in the minterm — it should be A.B̄, not A.B. Every 0-valued input in a row must appear inverted in that row's minterm.

Applied / scenario 5
A truth table with inputs A, B has output 1 only in the row A=0, B=0. Write the minterm for this row.
Reveal answer

Ā.B̄ (both inputs inverted, since both are 0 in that row).

Short answer 6
When deriving an expression for a NAND gate's output from its two AND-ed inputs, what's the final step needed to complete the NAND operation?
Reveal answer

Invert (NOT) the AND result — typically achieved using De Morgan's law rather than expanding everything out algebraically.
