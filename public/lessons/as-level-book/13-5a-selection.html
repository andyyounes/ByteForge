13.05 Selection
IF, IF/ELSE, nested IF (elif), and CASE — pseudocode next to real Python.
Theory

IF…THEN

Pseudocode: Python: IF x < 0 if x < 0: THEN print("Negative") OUTPUT "Negative" ENDIF
  • Python replaces THEN with a colon : — indentation shows which statements belong to the condition, instead of an explicit ENDIF.

IF…THEN…ELSE

IF x < 0 if x < 0: THEN print("Negative") OUTPUT "Negative" else: ELSE print("Positive") OUTPUT "Positive" ENDIF

Nested IF — Python's elif

  • Python uses elif (short for "else if") — it must line up with its corresponding if, and there can be as many elif parts as needed.
IF x < 0 if x < 0: THEN print("Negative") OUTPUT "Negative" elif x == 0: ELSE print("Zero") IF x = 0 else: THEN print("Positive") OUTPUT "Zero" ELSE OUTPUT "Positive" ENDIF ENDIF
  • Warning: repeated indentation for deeply nested IFs can get awkward to read — a CASE statement is often preferable when there are many branches.

CASE — an alternative when checking ONE value against MANY options

  • Each CASE condition can be a single value, several values separated by commas, or a RANGE.
  • Python has NO built-in CASE statement — you must use nested IF/elif statements instead.
CASE OF Grade "A" : OUTPUT "Top grade" "F", "U" : OUTPUT "Fail" "B" TO "E" : OUTPUT "Pass" OTHERWISE OUTPUT "Invalid grade" ENDCASE
# Python equivalent — nested if/elif, since there's no CASE keyword if Grade == "A": print("Top grade") elif Grade == "F" or Grade == "U": print("Fail") elif Grade in ("B", "C", "D", "E"): print("Pass") else: print("Invalid grade")
  • The OTHERWISE clause is OPTIONAL, and especially useful for error trapping (catching any value that doesn't match any listed case).
Practice — Test Yourself

These questions only cover what THIS subsection taught — IF/ELSE, nested IF, and CASE statements (completes Section 13.05).

Short answer 1
What Python keyword replaces pseudocode's THEN when writing an IF statement?
Reveal answer

None directly — Python replaces THEN with a colon (:), using indentation instead of an explicit ENDIF to show which statements belong to the condition.

Short answer 2
What is Python's keyword for a nested "else if", and how many can appear in one construct?
Reveal answer

elif — there can be as many elif parts as needed in a single construct.

Fill in the blank 3
Python has no built-in ______ statement — nested IF/elif statements must be used instead.
Reveal answer

CASE.

Spot the error 4
A student writes deeply nested IF statements 5 levels deep to check a grade against 8 possible letter values. What does this lesson suggest instead, and why?
Reveal answer

A CASE statement is preferable when checking ONE value against MANY options — deeply nested IFs become awkward to read, and repeated indentation can make the overall logic hard to follow at a glance.

Applied / scenario 5
Write the CASE condition (in pseudocode) that matches grades B, C, D, or E all at once, as a single range.
Reveal answer

"B" TO "E"

Short answer 6
What is the OTHERWISE clause in a CASE statement particularly useful for?
Reveal answer

Error trapping — catching and handling any value that doesn't match any of the explicitly listed cases.
