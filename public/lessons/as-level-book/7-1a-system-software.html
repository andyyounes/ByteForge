7.01 System Software
Imagine controlling every computer action today by physically pressing buttons — that's what an operating system replaced.
Key Terms
Operating system
A software platform that provides facilities for programs to be run which are of benefit to a user.
System software
Software that helps run the computer system itself, as distinct from application software.
Theory
Using a computer in the 1960s — before operating systems

1. Enter machine room with punched cards and paper tape. 2. Switch on. 3-4. Load cards and tape, pressing buttons for each. 5. Press a button to run the program. 6. Press a button to print output. 7. Switch off. 8. Leave with your cards, tape and printout.

What this scenario reveals — and what was missing

  • The user controlled the computer hardware DIRECTLY, by pressing physical buttons — try imagining how many buttons a modern computer would need to be controlled the same way.
  • The MISSING component from the 1960s scenario was an operating system — software specifically to control the hardware.

System software vs application software — the key distinction

  • An operating system is an example of SYSTEM software.
  • System software is distinguished from APPLICATION software: application software performs a SPECIFIC task for a user, rather than simply helping to run the system itself.
Practice — Test Yourself

These questions only cover what THIS subsection taught — system software and the operating system (completes Section 7.01).

Short answer 1
What was the "missing component" in the 1960s computer-usage scenario described in this lesson?
Reveal answer

An operating system — software to control the hardware, rather than requiring the user to press physical buttons directly.

Short answer 2
What is the key distinction between system software and application software?
Reveal answer

Application software performs a specific task for a user; system software instead helps run the computer system itself.

Fill in the blank 3
An operating system is a software platform providing facilities for programs to be run which are of ______ to a user.
Reveal answer

Benefit.

Spot the error 4
A student says: "A word processor is an example of system software, since it's software that helps the computer run." What's wrong?
Reveal answer

A word processor is APPLICATION software — it performs a specific task for the user (writing documents). System software (like the operating system) is about running the computer system itself, not performing a user-facing task.

Applied / scenario 5
Explain why "pressing a button to load a program from punched cards" was replaced by an operating system, in terms of what the operating system actually does.
Reveal answer

An operating system provides an environment/facilities for running programs on behalf of the user, controlling the hardware itself — replacing the need for the user to manually operate hardware buttons for every single step of loading and running a program.

Short answer 6
Is an operating system an example of system software or application software?
Reveal answer

System software.
