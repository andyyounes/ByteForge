29.09 Lists in Prolog
Head and tail, built-in list predicates, and reading/writing for interactive programs. Completes Chapter 29.
Theory

What a list is

  • An ORDERED collection of terms, written in SQUARE BRACKETS: [1, 2, 3] or [red, green, blue]. The EMPTY list is written [].
  • Elements can be ANY Prolog type, and DIFFERENT types can be mixed in one list.
  • Lists in Prolog serve the role arrays play in procedural languages.

Head and tail

  • Any NON-EMPTY list splits into a HEAD (the first item) and a TAIL (everything else — itself always a list).
  • Written with a VERTICAL BAR: [H|T].
?- showHeadAndTail([fred, jack, emma], Head, Tail). Head = fred, Tail = [jack, emma]. ?- myList([H|T]). % given myList([1,2,3]). H = 1, T = [2, 3].
Head: the first item of a non-empty list.
Tail: the remaining list once the head is removed — always itself a list.

Built-in list predicates

% append(A, B, C) — joins list A and list B to produce list C ?- append([a, b], [c, d], MyList). MyList = [a, b, c, d]. % member(A, B) — true if item A is in list B ?- member(c, [a, b, c, d, e]). true. ?- member(X, [a, b, c, d]). X = a ; X = b ; X = c ; X = d.

Interacting with the user — write and read

  • write(A) outputs A to the screen. read(A) reads a value from the keyboard into A. nl moves output to a new line.
  • assert/1 ADDS a clause to the knowledge base at run time; retractall/1 REMOVES matching clauses — together these let a program build up temporary facts based on user input, then clean them up afterward.
go :- write('Is the temperature high or low?'), read(Temp), nl, assert(temp(Temp)), weather(Weather), write('The weather is '), write(Weather), retractall(temp(_)).

A recursive list-processing rule

writeList([]). % base case: empty list, nothing to output writeList([H|T]) :- write(H), nl, writeList(T). % recursive call on the (shorter) tail
  • This combines EVERYTHING from the chapter: head/tail decomposition, recursion (base case = empty list, general case = process head then recurse on tail), and the write predicate.

Chapter 29 summary

  • Imperative programs say HOW; declarative programs say WHAT, answered via queries.
  • A knowledge base is built from facts and rules (clauses); a predicate's arity is its number of arguments.
  • Variables get instantiated during a query; the anonymous variable (_) ignores values you don't need.
  • Backtracking lets Prolog retry earlier goals when a later one fails, searching for alternative solutions.
  • Recursive rules use themselves as a sub-goal, following the same base-case/general-case discipline as imperative recursion.
  • Lists are manipulated via head/tail decomposition ([H|T]), with built-in predicates like append and member.
Practice — Test Yourself

These questions cover lists and draw together the whole of Chapter 29 (completes Section 29.09 and Chapter 29).

Short answer 1
What is the head and tail of the list [dog, cat, bird]?
Reveal answer

Head = dog; Tail = [cat, bird].

Short answer 2
What does the built-in predicate member(A, B) check?
Reveal answer

Whether item A is present somewhere in list B.

Fill in the blank 3
The base case of the writeList rule handles the ______ list.
Reveal answer

Empty ([]).

Spot the error 4
A student writes writeList([H|T]) :- writeList(T), write(H), nl. (reordering the recursive call before the write). Will this still print all elements, and in what order?
Reveal answer

Yes, it will still print every element (recursion still terminates at the empty base case), but the ORDER reverses — since the recursive call happens first, the tail's elements are printed BEFORE the current head, effectively printing the list backward.

Applied / scenario 5
What result does append([1, 2], [3, 4], Result). produce?
Reveal answer

Result = [1, 2, 3, 4].

Short answer 6
What do assert and retractall let a Prolog program do at run time?
Reveal answer

assert adds a new clause to the knowledge base dynamically (e.g. based on user input); retractall removes matching clauses — together they let a program record temporary facts and clean them up afterward.
