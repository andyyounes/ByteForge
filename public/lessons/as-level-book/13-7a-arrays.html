13.07 Arrays
Python doesn't technically have arrays at all — it has something even more flexible: the list.
Theory

Static vs. dynamic arrays

  • Traditionally, an array is STATIC — declared with a fixed number of elements of ONE data type, unchanged after compilation.
  • Many modern languages now also allow DYNAMIC arrays, which can grow in size as needed.

1D array declaration and Python's genuine difference

DECLARE <arrayIdentifier> : ARRAY[<lowerBound>:<upperBound>] OF <dataType> DECLARE List1 : ARRAY[1:3] OF STRING // 3 elements DECLARE List2 : ARRAY[0:5] OF INTEGER // 6 elements
  • Python has no arrays at all — the equivalent structure is a LIST: an ordered sequence of items that DON'T even have to be the same data type, and Python's lists are DYNAMIC by default.
  • VB.NET and Python both number elements from 0 (the lower bound); Pascal lets you choose ANY integer as the lower bound.
# Python — building a list a few different ways List1 = [] List1.append("Fred") List1.append("Jack") List2 = [0, 0, 0, 0, 0, 0] # 6 zeros, written directly List3 = [0 for i in range(100)] # 100 zeros, built with a loop

Accessing 1D array elements

Pseudocode: NList[25] ← 0 // set the 25th element to zero Python: NList[24] = 0 // ignoring element 0, the "25th" item is index 24
  • Careful: if pseudocode numbers from 1 but Python numbers from 0, the SAME logical element sits at a DIFFERENT index in each — a genuine, common off-by-one translation trap.
  • Python can print an ENTIRE list at once with print(List) — other languages typically need a loop to print one element at a time.

2D arrays — rows first, then columns

DECLARE Board : ARRAY[1:6, 1:7] OF INTEGER
  • Python has no 2D arrays either — the equivalent is a LIST OF LISTS.
# Python — a 6-row, 7-column board of zeros Board = [[0 for i in range(7)] for j in range(6)]
  • Accessing an element: pseudocode Board[3,4] vs. Python Board[2][3] — again, the exact indices shift because Python counts from 0.
Practice — Test Yourself

These questions only cover what THIS subsection taught — 1D and 2D arrays, and Python's list equivalent (completes Section 13.07).

Short answer 1
What is the Python equivalent of an array called, and how is it more flexible than a traditional static array?
Reveal answer

A list — it's dynamic (can grow), and its items don't even have to all be the same data type, unlike a traditional array.

Short answer 2
What is the Python equivalent structure for a 2D array?
Reveal answer

A list of lists.

Fill in the blank 3
A ______ array is fixed in size after compilation; a ______ array can grow in size if required.
Reveal answer

Static; dynamic.

Spot the error 4
Pseudocode array elements are numbered 1 to 25. A student translates NList[25] directly as NList[25] in Python. What's the bug?
Reveal answer

Python numbers elements from 0, so if the pseudocode's element 1 maps to Python's index 0 (ignoring index 0 as a placeholder), the "25th" pseudocode element is actually at Python index 24, not 25.

Applied / scenario 5
How would you print the ENTIRE contents of a Python list in one line, without writing a loop?
Reveal answer

print(List) — Python lets you print a whole list at once, unlike languages such as VB.NET/Pascal which need a loop to output one element at a time.

Short answer 6
In a 2D array declaration, which comes first: the number of rows, or the number of columns?
Reveal answer

The number of rows.
