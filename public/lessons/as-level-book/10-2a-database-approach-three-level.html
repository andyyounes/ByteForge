10.02 The Database Approach
A database is not "a collection of data" — it's an implementation of a theoretical three-level model.
Key Terms
DBMS
Database Management System — software that controls access to data in a database.
DBA
Database Administrator — a person who uses the DBMS to customise the database for user/programmer requirements.
Theory

A database is a MODEL, not just stored data

  • A database is an implementation according to the rules of a THEORETICAL MODEL — not simply "a collection of data".
  • The foundational concept: ANSI's (American National Standards Institute) three-level model, proposed roughly 40 years ago.

The three levels, bottom to top

  • Internal level — the LOWEST level. Details of physical storage (the internal schema) are known ONLY here, controlled by the DBMS software. Only the software's own programmers know this exact storage structure — and the software accommodates any changes needed to the storage medium.
  • Conceptual level — a SINGLE universal view of the whole database, controlled by the DBA. Has a conceptual schema (often also called a "logical schema") describing the data's organisation as perceived by a user or programmer.
  • External level — individual user and programmer VIEWS. Each view has its own external schema describing which PARTS of the database are accessible to it. A single view can support multiple user programs.

What the DBA and DBMS actually do

  • The DBA is responsible for setting up external views AND defining the appropriate, specific access rights for each.
  • The DBMS provides facilities for a programmer to develop a user interface for a program.
  • The DBMS provides a QUERY PROCESSOR — the mechanism for extracting and manipulating data. A programmer incorporates access to queries within a user interface.
  • The DBMS also provides REPORT creation — presenting formatted output.
Practice — Test Yourself

These questions only cover what THIS subsection taught — the ANSI three-level database model (completes Section 10.02).

Short answer 1
Name the three levels of the ANSI database architecture, from lowest to highest.
Reveal answer

Internal level, conceptual level, external level.

Short answer 2
Who controls the conceptual level, and what does it provide?
Reveal answer

The database administrator (DBA) — it provides ONE single universal view of the database's data organisation, via the conceptual (or "logical") schema.

Fill in the blank 3
At the ______ level, only the DBMS software's own programmers know the exact structure used for physical storage on disk.
Reveal answer

Internal.

Spot the error 4
A student says: "A database is really just a big collection of files with data in them, arranged neatly." What's the more precise definition this lesson insists on?
Reveal answer

A database is an IMPLEMENTATION according to the rules of a theoretical model (the ANSI three-level model) — it's specifically the multi-level architecture (internal/conceptual/external) that distinguishes a real database from "just a collection of data".

Applied / scenario 5
The theatrical agency's storage medium is upgraded from one disk technology to another. According to the three-level model, which level absorbs this change, and does it affect users at the external level?
Reveal answer

The internal level absorbs the change — the DBMS software accommodates changes needed in the storage medium. Users at the external level, seeing only their own views, are unaffected by this underlying change.

Short answer 6
What TWO things is the DBA specifically responsible for setting up at the external level?
Reveal answer

The individual views themselves, and the appropriate, specific access rights for each view.
