14.03 Functions
A subroutine that returns a value — and the difference between local and global variables.
Theory

What makes a function different from a procedure

  • A function is used as PART OF AN EXPRESSION — when execution reaches the function call, the function runs, and the returned value is used in place of the call.
  • A function must always RETURN a value from its body. There can be more than one RETURN statement if there are different paths through the function.
FUNCTION <functionIdentifier>() RETURNS <dataType> // function header <statement(s)> // function body RETURN <value> END FUNCTION

Worked example — rewriting a procedure as a function

FUNCTION InputOddNumber() RETURNS INTEGER DECLARE Number : INTEGER REPEAT INPUT "Enter an odd number: ", Number UNTIL Number MOD 2 = 1 RETURN Number END FUNCTION NewNumber ← InputOddNumber() // called from within an expression
# Python def InputOddNumber(): Number = 0 while Number % 2 == 0: Number = int(input("Enter an odd number: ")) return Number NewNumber = InputOddNumber()

Local vs. global variables

  • A LOCAL variable exists only inside the subroutine it's declared in — it cannot be accessed from the main program or any other subroutine.
  • A GLOBAL variable is available everywhere in the program. Declaring variables as global just to avoid passing them properly is considered POOR programming practice.
  • In Python, EVERY variable is local by default, unless explicitly declared global. In VB.NET and Pascal, a variable declared inside a subroutine is local; one declared outside all subroutines is global.
Practice — Test Yourself

These questions only cover what THIS subsection taught — functions, RETURN, and local/global variables (completes Section 14.03).

Short answer 1
Where is a function called from, compared to a procedure?
Reveal answer

A function is called from within an EXPRESSION (e.g. an assignment), because it returns a value to be used there. A procedure is called on its own as a program statement.

Short answer 2
What must every function's body always contain?
Reveal answer

A RETURN statement (possibly more than one, for different paths through the function) — a function must always return a value.

Fill in the blank 3
In Python, every variable is ______ by default, unless it is declared ______.
Reveal answer

Local; global.

Spot the error 4
A student declares Number as a global variable at the top of their program purely so it can be shared between two functions, instead of passing it as a parameter. What's the concern?
Reveal answer

It's considered poor programming practice — global variables can be changed unexpectedly by ANY part of the program, making bugs harder to trace. It's better to declare it locally and pass it explicitly as a parameter (covered in 14.04–14.06).

Applied / scenario 5
Convert this function call into a full pseudocode function header: a function called Square that takes no parameters and returns an INTEGER.
Reveal answer

FUNCTION Square() RETURNS INTEGER

Short answer 6
Where is a global variable accessible from?
Reveal answer

Any part of the program — the main program and every subroutine.
