3.03 Secondary Storage Devices
Magnetic, optical, and solid-state — three completely different physical mechanisms for the same job.
Key Terms
Device driver
Software that lets the OS operate a hardware device — not to be confused with "drive".
Direct-access device
Any sector can be chosen for reading/writing directly — but data within a sector is read sequentially.
Sector
The smallest unit of storage on a disk — a defined number of bytes within a track.
Flash memory
Semiconductor storage with no moving parts — blocks are erased "in a flash" before being rewritten.
Theory

Terminology worth untangling first

  • "Device driver" is the SOFTWARE needed to operate any hardware device.
  • "Drive" was originally the HARDWARE that houses a storage medium and physically transfers data to/from it — but in practice, "hard disk", "hard disk drive" and "hard drive" are now all used to mean the same thing.

Magnetic media — the hard disk

  • Magnetic tape (for sound recording) pre-dates computing — it was the FIRST storage technology adapted for computer use. The hard disk was invented specifically FOR computer storage, arriving later.
  • A read head detects a state of magnetisation as an electrical property; a write head does the reverse — the two are usually combined into one read-write head. The two states of magnetisation are interpreted as 1 or 0.
  • Physical construction: MULTIPLE platters, each with a read-write head per SIDE, all spinning in unison, with actuator arms moving the heads in sync. A cushion of air keeps the head from touching the platter.
  • Logical construction: data is stored in concentric TRACKS, each formatted into SECTORS (a defined number of bytes) — the sector is the smallest unit of storage.

Direct access — but sequential WITHIN a sector

  • A hard drive is a DIRECT-access read-write device — any sector can be chosen directly for reading or writing.
  • However, the data WITHIN a chosen sector still has to be read SEQUENTIALLY.
  • As files are created, deleted and edited, sector use becomes increasingly FRAGMENTED, degrading performance — a defragmentation program reorganises sector allocation to restore it.

Optical media — CD, DVD, and Blu-ray

  • Like magnetic tape, optical storage was adapted from existing non-computing technology (audio CDs).
  • CD-ROM (read-only) came first; CD-RW added write capability; the CD was superseded by the DVD, and then by the more powerful Blu-ray disc.
  • The disc spins; a laser reflects off a surface between a substrate and protective coating. For CD-ROM, indentations ("pits") separated by "lands" cause a PHASE DIFFERENCE in the reflected light, detected by a photodiode and interpreted as 1 or 0.
  • For CD-RW/DVD-RW, the reflective surface is a special alloy — writing ("burning") uses laser heat to change the material to liquid, which then cools into either a crystalline or amorphous solid, giving the 1/0 distinction on later reads.
  • The optical head follows a SINGLE SPIRAL path from centre to edge — but formatting the data into sectors still allows direct access, just like a magnetic disk.
  • Storage capacity depends on how close together individual bit-representations can be placed — governed by spin-speed compensation and, crucially, the LASER'S WAVELENGTH (shorter wavelength = better focus = higher density). This is why infrared (CD) → red (DVD) → blue (Blu-ray) laser light corresponds to increasing storage capacity.

Solid-state media — flash memory

  • Flash memory is a form of EEPROM where the programmable aspect is part of NORMAL use, with no moving parts at all.
  • Built from arrays of transistors ("NAND" technology, named after its resemblance to a NAND logic gate) with memory cells connected in series.
  • Special feature: blocks of memory cells can have their contents erased all at once ("in a flash"). Before writing, a block must first be ERASED; reading also happens a whole block at a time.
  • Used for solid-state drives (replacing hard disks), memory cards, and USB flash drives — currently the technology of choice for removable storage, though alternatives (e.g. PRAM) are under development.
Practice — Test Yourself

These questions only cover what THIS subsection taught — magnetic, optical and solid-state secondary storage (completes Section 3.03).

Short answer 1
What is the smallest unit of storage on a magnetic hard disk, and what does it contain?
Reveal answer

A sector — a defined number of bytes within a track.

Short answer 2
Why is a hard drive described as "direct-access" but data within a sector is still read "sequentially"? Are these contradictory?
Reveal answer

Not contradictory — ANY sector can be chosen directly (that's the direct-access part), but once you're reading that chosen sector, its bytes are read in sequence, one after another.

Fill in the blank 3
For a CD-ROM, indentations called ______ (separated by ______) cause a phase difference in the reflected laser light, interpreted as 1 or 0.
Reveal answer

Pits; lands.

Spot the error 4
A student says: "Blue-ray discs hold more data than DVDs mainly because the disc itself is a different physical size." What's the ACTUAL reason given in this lesson?
Reveal answer

The key factor is the laser's WAVELENGTH — a shorter wavelength (blue laser vs red vs infrared) allows better focus, letting bit-representations be placed closer together, increasing storage density and capacity. The physical disc size is the same across CD/DVD/Blu-ray.

Applied / scenario 5
A manufacturer wants a small, rugged storage device with NO moving parts for a portable USB drive. Which of the three technologies in this lesson fits best, and why?
Reveal answer

Solid-state (flash) memory — it's a semiconductor technology with no moving parts at all, unlike the spinning platters/heads of magnetic disks or the spinning disc/laser mechanism of optical media.

Short answer 6
Before data can be WRITTEN to a block of flash memory cells, what must happen first?
Reveal answer

The data already in that block must first be erased.
