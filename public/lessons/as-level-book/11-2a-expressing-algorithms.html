11.02 Expressing Algorithms
Structured English, pseudocode, or a flowchart — three notations, four constructs, one underlying idea.
Key Terms
Structured English
A subset of English consisting of command statements, used to describe an algorithm.
Pseudocode
Keywords and identifiers describing an algorithm, without following any real language's exact syntax.
Flowchart
Specific shapes, linked together, representing the sequential steps of an algorithm.
Theory

What makes a solution "good"

  • Gives the correct results, uses as little memory as possible, executes as fast as possible.
  • Should also be concise, elegant, and easy to understand.

Four basic constructs used in every algorithm

  • Assignment — a value is given to an identifier, or an existing identifier's value is changed.
  • Sequence — steps performed one after another.
  • Selection — under certain conditions, some steps run; otherwise different (or no) steps run.
  • Repetition (iteration/looping) — a sequence of steps performed a number of times.
  • Plus INPUT and OUTPUT statements, since most problems involve input → process → output.

Why knowing the constructs matters

  • Knowing the constructs tells you how DETAILED your design has to be — every algorithm, in any of the three notations, can be built entirely from these same building blocks.
  • This book types algorithms and program code in a monospace (courier) font.
Practice — Test Yourself

These questions only cover what THIS subsection taught — structured English, pseudocode, flowcharts, and the four constructs (completes Section 11.02).

Short answer 1
List the four basic constructs used when writing algorithms.
Reveal answer

Assignment, sequence, selection, repetition.

Short answer 2
What are the three notations described for expressing an algorithm?
Reveal answer

Structured English, pseudocode, and flowcharts.

Fill in the blank 3
A good algorithmic solution gives the correct results, uses as little ______ as possible, and executes as ______ as possible.
Reveal answer

Memory; fast.

Spot the error 4
A student says: "Pseudocode has to follow the exact syntax rules of a real programming language like Python or Java." What's wrong?
Reveal answer

Pseudocode specifically does NOT follow the syntax of any particular programming language — it uses keywords and identifiers in a way that RESEMBLES a programming language, without being tied to one's exact rules.

Applied / scenario 5
Which construct would you use to repeat a set of steps until a counter reaches a target value?
Reveal answer

Repetition (iteration/looping).

Short answer 6
Why are INPUT and OUTPUT statements needed in addition to the four basic constructs?
Reveal answer

Because many problems solved with a computer involve data flowing in (input), being processed, and results flowing out (output) — this input-process-output shape needs its own statements beyond assignment/sequence/selection/repetition.
