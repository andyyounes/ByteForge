4.01 Boolean Logic and Problem Statements
Every yes/no question can be rewritten as a statement that's simply TRUE or FALSE.
Key Terms
Logic proposition
A statement that is either TRUE or FALSE.
Problem statement
An informal definition of an outcome depending on one logic proposition, or a combination of two or more.
Theory

Rephrasing an everyday question as Boolean logic

  • An everyday question like "Is Colombo further north than Singapore?" gets a yes/no answer.
  • Rephrased for Boolean logic: "Colombo is further north than Singapore — TRUE or FALSE?"
  • This rephrased statement is a LOGIC PROPOSITION (or logic assertion) — it can have only ONE of the two values TRUE or FALSE, never both, never neither.
Two example problem statements

"You should take an umbrella if it is raining OR if the weather forecast is for rain later."

"The air-conditioning system is set to come on in an office only during working hours but also only if the temperature rises above 25°C."

What makes something a "problem statement" rather than just a proposition

  • Each of the two example statements contains TWO logic propositions, combined in some way.
  • Each statement ALSO has an outcome, dependent on how those propositions combine — this is what turns a pair of propositions into a genuine problem statement.
  • A problem statement, formally: an informal definition of an outcome that depends on one logic proposition, or a combination of two or more.
Practice — Test Yourself

These questions only cover what THIS subsection taught — logic propositions and problem statements (completes Section 4.01).

Short answer 1
What are the only two possible values a logic proposition can take?
Reveal answer

TRUE or FALSE.

Short answer 2
What TWO things does a "problem statement" need, beyond being just a logic proposition?
Reveal answer

Two (or more) logic propositions combined together, AND an outcome that depends on how they're combined.

Fill in the blank 3
"The library is open" is an example of a logic ______ — it can only be TRUE or FALSE.
Reveal answer

Proposition (or assertion).

Spot the error 4
A student says: "It is warm today" cannot be a logic proposition, because it's subjective and different people might disagree on whether it's true. Is this actually a problem for using it as a logic proposition?
Reveal answer

No — Boolean logic only requires that a statement CAN be assigned exactly one value, TRUE or FALSE, at a given moment (e.g. once a specific temperature threshold defines "warm"). The definition doesn't require the statement to be objectively unambiguous in everyday language, only that it resolves to one Boolean value in the system being modelled.

Applied / scenario 5
Identify the TWO logic propositions inside this problem statement: "A student passes the course if their coursework mark is above 40 AND their exam mark is above 40."
Reveal answer

Proposition 1: "coursework mark is above 40". Proposition 2: "exam mark is above 40". The outcome ("passes the course") depends on how these two propositions combine (both must be TRUE).

Short answer 6
Rephrase this everyday question as a Boolean logic proposition: "Is Paris the capital of France?"
Reveal answer

"Paris is the capital of France — TRUE or FALSE?" (In this case, TRUE.)
