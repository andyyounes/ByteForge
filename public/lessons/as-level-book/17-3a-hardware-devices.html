17.03 Hardware Connection Devices
NIC, hub, switch, router — increasing intelligence at each step.
Theory

The network interface card (NIC)

  • Any end-system on an Ethernet LAN needs a NIC. Each NIC has a UNIQUE physical address (the MAC address).
  • The end-system ITSELF has no identity on the network — only the NIC does. If you remove a NIC and put it in a different computer, the address MOVES with it.

Hub — the simplest device

  • Sits at the centre of a star topology. ANY incoming communication is BROADCAST to every connected end-system — regardless of who it's actually meant for.
  • Hubs can be chained hierarchically (hub connected to other hubs), or built with an integrated broadband modem to give a whole LAN Internet access.

Switch — a more intelligent hub

  • Can function like a hub, but keeps track of the ADDRESSES of connected devices.
  • This lets it send an incoming transmission as a UNICAST — directly to the specific intended end-system only, rather than broadcasting to everyone.
  • Reduces network traffic compared to a hub, since uninvolved devices no longer receive every transmission.

Router — the most intelligent device

  • Effectively a small computer. Can function as a switch, but additionally DECIDES which device to forward a received transmission to, based on routing information.
  • Its main use is in the Internet's backbone. Closer to end-systems, a router may act as a GATEWAY, a network address translation (NAT) box, or be combined with a FIREWALL.

Practice — Test Yourself

These questions only cover what THIS subsection taught — NIC, hub, switch, and router (completes Section 17.03).

Short answer 1
What is the key difference between how a hub and a switch handle an incoming transmission?
Reveal answer

A hub broadcasts it to ALL connected end-systems. A switch tracks device addresses and sends it as a UNICAST only to the specific intended device.

Short answer 2
What happens to a NIC's physical address if the NIC is moved to a different computer?
Reveal answer

The address moves with the NIC — it belongs to the card itself, not the computer it's installed in.

Fill in the blank 3
A router can additionally make a ______ about which device to forward a transmission to, unlike a switch.
Reveal answer

Decision (routing decision).

Spot the error 4
A student claims a hub is more efficient than a switch because it's simpler. Why is this backwards for network TRAFFIC?
Reveal answer

A hub broadcasts every transmission to every connected device, generating unnecessary traffic on links that don't need the data. A switch's ability to unicast REDUCES overall network traffic — simplicity doesn't translate into network efficiency here.

Applied / scenario 5
Why is the end-system itself said to have "no identification on the network", when it clearly has data to send and receive?
Reveal answer

Because the unique physical (MAC) address belongs to the NIC, not the computer — the network identifies and addresses the NIC, and the computer only communicates through it.

Short answer 6
Name two roles a router might take on nearer to the end-systems, besides plain routing.
Reveal answer

Any two of: a gateway, a network address translation (NAT) box, or being combined with a firewall.
