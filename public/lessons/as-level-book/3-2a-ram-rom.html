3.02 Memory Components: RAM & ROM
Both names are slightly misleading — the real distinctions are volatility and whether you can write to them.
Key Terms
RAM
Volatile memory that can be read from or written to any number of times.
ROM
Non-volatile memory that cannot be written to but can be read from any number of times.
DRAM
Dynamic RAM — built from capacitors that leak charge and need regular recharging.
SRAM
Static RAM — built from flip-flops, holds data indefinitely while powered.
Theory

Three storage types the processor can access directly

  • Registers — contained WITHIN the processor itself (covered in Chapter 5).
  • Cache memory — external to the processor, stores data most likely to be needed again soon.
  • Main memory — external to the processor. Cache + main memory together make up PRIMARY storage.

"Random-access memory" is a slightly misleading name

  • The name suggests the memory itself makes random decisions — it doesn't. A programmer never expects a program to randomly choose which memory location to access.
  • The name actually refers to the fact that ANY location can be accessed independently of which location was accessed previously — it might have been better called "direct-access memory".
  • A better description overall is READ-WRITE memory, since RAM can be repeatedly read from or written to.
  • RAM's other defining characteristic: it is VOLATILE — its contents are lost the moment the system is switched off.

Reading the table — SRAM wins on speed, but nothing else

  • SRAM provides a SHORTER access time — but it compares unfavourably with DRAM on every OTHER measure: cost, bits-per-chip, and power use.
  • DRAM is cheaper, stores more bits per chip, and (despite needing recharging) uses less power overall.
  • The result, once again, is a compromise: cache memory is normally built from SRAM (speed matters most there), while main memory uses DRAM (capacity and cost matter more).

ROM — also a slightly misleading name

  • ROM shares the random/direct-access property of RAM — EXCEPT that it cannot be written to.
  • ROM's other key characteristic: it is NON-VOLATILE. Data in ROM is NOT lost when the system is switched off.
  • ROM is used for data or programs that need to be used UNCHANGED, over and over again (e.g. firmware).
  • Variants exist — PROM (programmable), EPROM (erasable PROM), EEPROM (electrically erasable PROM) — these relate to how the ROM is manufactured/installed, and don't change its BASIC use in a computer system.
Practice — Test Yourself

These questions only cover what THIS subsection taught — RAM, ROM, DRAM and SRAM (completes Section 3.02).

Short answer 1
Why is "random-access memory" considered a slightly misleading name for RAM?
Reveal answer

It sounds as though the memory itself makes random decisions about access — but it actually just means any location can be accessed independently of the previously accessed location. "Direct-access memory" would arguably describe it better.

Short answer 2
Name TWO defining characteristics of RAM mentioned in this lesson.
Reveal answer

It can be read from AND written to repeatedly (read-write memory); and it is volatile (contents lost on power-off).

Fill in the blank 3
DRAM is built from ______, which leak charge and must be regularly ______. SRAM is built from ______, which hold data indefinitely while powered.
Reveal answer

Capacitors; recharged; flip-flops.

Spot the error 4
A student says: "SRAM is strictly better than DRAM, since it's faster — that's why every computer should use SRAM everywhere." What's wrong with this reasoning?
Reveal answer

SRAM only wins on access time — it compares UNFAVOURABLY to DRAM on cost, bits-per-chip, and power use. This is exactly why real systems compromise: SRAM for the small, speed-critical cache, and DRAM for the larger, cheaper main memory.

Applied / scenario 5
A manufacturer wants to store firmware in a device that must survive being unplugged and must never be accidentally overwritten by user software. Which memory type should they use, and why?
Reveal answer

ROM — it is non-volatile (survives power-off) and cannot be written to during normal use, matching exactly the "used unchanged, over and over again" use case firmware needs.

Short answer 6
What do PROM, EPROM and EEPROM all have in common, according to this lesson?
Reveal answer

They're all variants of ROM relating to how it's manufactured/installed — none of these variants change ROM's basic use in a computer system (non-volatile, read-only in normal operation).
