10.07 Structured Query Language (SQL)
DDL builds the structure; DML puts in, changes, and queries the data.
Key Terms
DDL
Data Definition Language — creates/alters table structure; puts NO data in.
DML
Data Manipulation Language — populates, maintains, and queries data.
Theory

SQL underlies everything, even a friendly GUI

  • Even when a database package offers high-level, GUI-driven facilities, that software USES SQL underneath.

DDL — Data Definition Language

  • Creates or ALTERS table structure. These commands create structure ONLY — no data goes in.
CREATE DATABASE BandBooking; CREATE TABLE Band ( BandName varchar2(25), NumberOfMembers number(1)); ALTER TABLE Band ADD PRIMARY KEY (BandName); ALTER TABLE Band_Booking ADD FOREIGN KEY (BandName) REFERENCES Band(BandName);
  • A primary/foreign key CAN be defined directly inside CREATE TABLE — but ALTER TABLE (shown above) is an alternative, and can also add extra attributes later.

DML — Data Manipulation Language

  • Used to first POPULATE tables with data, then for ONGOING maintenance.
INSERT INTO Band VALUES ('ComputerKidz', 5); INSERT INTO Band_Booking (BandName, BookingID) VALUES ('ComputerKidz', '2016/023'); UPDATE Band SET NumberOfMembers = 6; DELETE FROM Band WHERE BandName = 'ITWizz';
  • Two INSERT styles: the simple version (values only, order must be known) and the safer version (attributes named explicitly, then values listed) — the second is the SAFER method.
  • UPDATE changes existing data; DELETE removes it.

Querying — always starts with SELECT

  • The MAIN use of DML is obtaining data via a query.
SELECT BandName FROM Band ORDER BY BandName; SELECT BandName FROM Band_Booking WHERE Headlining = 'Y' GROUP BY BandName;
  • First example: an ordered list of all bands. Second: a list of bands that have headlined a gig — GROUP BY ensures band names aren't REPEATED in the result.

Joining two tables — the inner join

  • A query can be based on a JOIN CONDITION between data in two tables — the most frequently used type is the INNER JOIN.
SELECT VenueName, Date FROM Booking WHERE Band_Booking.BookingID = Booking.BookingID AND Band_Booking.BandName = 'ComputerKidz';
  • Note the FULL attribute names, including the table name — needed once a query spans multiple tables.
  • This particular query finds the venue and date of bookings for the band ComputerKidz.

Accessing SQL from another language

  • Programming languages provide mechanisms for EMBEDDING an SQL command into a program — the same way a program can access data in a file, it can access data in a database.
  • A common real case: server-side scripting (e.g. PHP) accessing a database associated with the web server — connecting, selecting the database, then running a query, all embedded directly in server-side code.
Practice — Test Yourself

These questions only cover what THIS subsection taught — SQL, DDL and DML (completes Section 10.07).

Short answer 1
What is the key difference between DDL and DML?
Reveal answer

DDL creates/alters STRUCTURE only (no data). DML populates, maintains, and queries the actual DATA within that structure.

Short answer 2
Why is the "named attributes" style of INSERT considered the SAFER method?
Reveal answer

It doesn't rely on knowing/matching the exact column order of the table — attributes are explicitly named alongside their values, avoiding a mismatch if the table's column order isn't known or changes.

Fill in the blank 3
Every SQL query used to retrieve data starts with the keyword ______.
Reveal answer

SELECT.

Spot the error 4
A student writes a query joining Band_Booking and Booking but refers to just BookingID in the WHERE clause instead of Band_Booking.BookingID. Why might this cause a problem?
Reveal answer

When a query spans multiple tables that might share an attribute name (like BookingID appearing in both tables), the FULL name (TableName.AttributeName) is needed to make clear exactly which table's column is meant — an unqualified name can be ambiguous.

Applied / scenario 5
Write, in words, what this query does: SELECT BandName FROM Band_Booking WHERE Headlining = 'Y' GROUP BY BandName;
Reveal answer

It produces a list of band names that have headlined at least one gig, with each band name appearing only ONCE in the result (GROUP BY prevents repeats).

Short answer 6
Why might a program embed SQL commands rather than requiring the user to type SQL directly?
Reveal answer

Just as a program can access data in a file without the user writing file-access code themselves, a program can access data in a database with the SQL embedded internally — the user interacts with a friendly interface, not raw SQL.
