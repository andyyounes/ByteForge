12.03 Structure Charts
Boxes for modules, arrows for parameters, a diamond for a decision, a semicircle for repetition.
Key Terms
Structure chart
A graphical representation of the modular structure of a solution.
Parameter
A value passed between modules.
Theory

The basic shape — boxes and levels

  • Each BOX represents a module. Each LEVEL down the chart is a refinement of the level above it.
  • A structure chart ALSO shows the interface between modules — the parameters passed.

Parameters and arrow direction

  • A DOWNWARD-pointing arrow: a parameter supplying a value TO a lower-level module.
  • An UPWARD-pointing arrow: a parameter supplying a NEW value back UP to the higher-level module.
  • This passing of parameters between modules is called the "interface".

Reading the example — averaging two numbers

  • The top-level box names the module; it refines into sub-tasks at Level 1.
  • Number1 and Number2 are passed DOWN into "Calculate average"; the resulting Average is then passed on to "OUTPUT average".

Showing selection — a diamond shape

  • A DIAMOND shape represents a condition that is either TRUE or FALSE — exactly ONE of the two branches beneath it will be followed.
  • Example: a number-guessing game (one guess only) branches into "output congratulation" (if correct) or "output consolation message" (if not).

Showing repetition — a semi-circular arrow

  • A SEMI-CIRCULAR arrow represents repetition of the modules underneath it.
  • A LABEL on that arrow states the exact condition governing when repetition occurs (e.g. "UNTIL NumberOfSymbols = MaxNumberOfSymbols" for the pyramid example).
Practice — Test Yourself

These questions only cover what THIS subsection taught — structure charts, parameters, selection and repetition (completes Section 12.03).

Short answer 1
What does a DOWNWARD-pointing arrow between two module boxes represent?
Reveal answer

A parameter supplying a value TO the lower-level module.

Short answer 2
What shape represents a decision point (selection) in a structure chart?
Reveal answer

A diamond — showing a condition that is either TRUE or FALSE, with exactly one of two branches followed.

Fill in the blank 3
A ______ arrow shows repetition of the modules beneath it, labelled with the exact condition governing when it happens.
Reveal answer

Semi-circular.

Spot the error 4
A student draws an UPWARD arrow from "Calculate Average" to the top-level module, labelling it "Number1, Number2". What's wrong with this label?
Reveal answer

Number1 and Number2 are inputs going DOWN into the "Calculate average" module — an upward arrow should instead carry the RESULT (Average) back up to the calling module, not the original inputs.

Applied / scenario 5
In the pyramid program's structure chart, what does the label on the semi-circular repetition arrow tell you?
Reveal answer

The exact condition under which the modules beneath the arrow (Output spaces, Output symbols, Adjust values for next row) keep repeating — here, "UNTIL NumberOfSymbols = MaxNumberOfSymbols".

Short answer 6
What is the passing of parameters between modules in a structure chart called?
Reveal answer

The interface.
