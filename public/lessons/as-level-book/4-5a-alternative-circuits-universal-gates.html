4.05 Alternative Circuits
Fewer gates isn't always cheaper — sometimes one universal gate, repeated, wins instead. Completes Chapter 4.
Key Terms
Universal gate
A gate type (NAND or NOR) that can, on its own, be combined to build any other logic gate's function.
Theory

The same output can come from different circuits

  • For any given logic problem, MULTIPLE different circuits can deliver the exact same output values from the same inputs.
  • Sometimes a circuit can be SIMPLIFIED by reducing the number of gates — e.g. an AND gate immediately followed by a NOT gate can be replaced by a single NAND gate (fewer components, same result).
  • More advanced simplification techniques exist for complex cases (covered later, Chapter 18).

Manufacturing cost isn't just about gate COUNT

  • Reducing complexity isn't ONLY about reducing the number of gates — manufacturers can also cut costs by building circuits from just ONE type of gate, chosen because that gate is itself cheap to manufacture.
  • This can mean a circuit with MORE components (using only one cheap gate type) actually costs LESS than an alternative with fewer components but mixed, more expensive gate types.

Universal gates — NAND and NOR

  • A UNIVERSAL gate is one that, used repeatedly and combined cleverly, can reproduce the function of ANY other logic gate — including AND, OR, and NOT themselves.
  • NAND is a universal gate. NOR is the other universal gate option.
  • Example: a circuit built ENTIRELY from NAND gates can have exactly the same functionality as a plain OR gate — even though it uses more individual components than a single OR gate would.
  • Manufacturers may deliberately choose the "worse" (more components) NAND-only design anyway, because manufacturing many identical cheap NAND gates can be cheaper overall than manufacturing a mix of different gate types.

Short answer 1
Which two gates are described as "universal gates" in this lesson?
Reveal answer

NAND and NOR.

Short answer 2
An AND gate is immediately followed by a NOT gate. Which single gate has exactly the same overall effect?
Reveal answer

A NAND gate.

Fill in the blank 3
A universal gate is one that can, combined repeatedly, reproduce the function of ______ other logic gate.
Reveal answer

Any.

Spot the error 4
A student says: "Manufacturers always want the circuit with the fewest total logic gates, since fewer components always means lower cost." What does this lesson say is missing from that reasoning?
Reveal answer

Cost also depends on WHICH gate types are used, not just how many. A circuit built entirely from one cheap gate type (like NAND) can cost LESS overall than a circuit with fewer total gates but a mix of more expensive gate types.

Applied / scenario 5
A manufacturer can build a certain circuit either as (a) 3 gates of mixed types (AND, OR, NOT) or (b) 5 NAND gates only. Why might they genuinely prefer option (b) despite it having more components?
Reveal answer

If NAND gates are individually much cheaper to manufacture than the mixed gate types, producing 5 cheap identical NAND gates can cost less in total than producing 3 gates of different, more expensive types — plus there may be manufacturing/design simplicity benefits from using only one gate type throughout.

Short answer 6
Besides reducing the number of gates, what is the OTHER reason given for simplifying/changing a circuit's design?
Reveal answer

Reducing manufacturing COST — which can be achieved by using only one type of (cheap-to-manufacture) gate throughout the circuit, even if that increases the total component count.
