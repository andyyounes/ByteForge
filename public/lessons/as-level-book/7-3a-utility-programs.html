7.03 Utility Programs Used by a PC
Disk formatters, defragmenters, backup software, compression, and virus checkers — run when needed, not as part of routine OS operation.
Theory

What makes something a "utility program"

  • A utility program MIGHT be provided by the OS, or installed as a separate program.
  • Key distinguishing feature: it is NOT executed as part of the normal routine of OS operation. It's run when the USER decides to (or sometimes the OS decides to, in certain circumstances).

Hard disk formatter and checker

  • A disk FORMATTER typically: removes existing data from a previously-used disk; sets up the file system (a table of contents linking recognised files to physical disk locations); and partitions the disk into logical drives if needed.
  • A disk CHECKER/repair utility (sometimes bundled with the formatter) analyses disk contents and repairs where possible. It first checks for errors: "bad sectors" (a physical defect, often from manufacture or mishandling — e.g. moving a computer without securing the disk heads).
  • Other errors come from abnormal events (power loss, sudden shutdown) leaving some files in an unidentifiable state. A repair utility marks bad sectors so the file system stops using them, and tries to RECOVER affected files — otherwise it has to delete them.

Hard disk defragmenter

  • Unlike the disk checker, a defragmenter is NOT primarily about errors — a perfectly FUNCTIONING disk still gradually becomes less EFFICIENT as constant file creation/editing/deletion leaves files fragmented across sectors.
  • The root cause: the logical sector-based arrangement of data (Chapter 3) doesn't allow a file to always be stored as one contiguous block.
  • Example: File A occupies sectors 0-3 fully plus part of sector 4. File B (small) occupies the rest of sector 4. File C occupies sectors 5-7 plus part of 8. If File B is deleted, its space is left UNFILLED (rearranging the whole file system on every change would be too costly). If File A is then extended, it fills sectors 0-4 completely and spills into sectors 8-9 — leaving File A split into two non-contiguous pieces.
  • A defragmenter reorganises storage so all files return to being CONTIGUOUS. This takes time on a large disk, and is IMPOSSIBLE if the disk is too full (no working space to rearrange into).

Backup software, file compression, and virus checkers

  • BACKUP software (vs. a manual backup to a flash drive) can: establish a SCHEDULE for backups, and only create a NEW backup file when something has actually CHANGED.
  • FILE COMPRESSION can be a routine OS feature to save disk space, or a user-chosen program — most important when TRANSMITTING data (e.g. compressing/"zipping" a file before emailing it).
  • A VIRUS CHECKER should be installed PERMANENTLY. Ideally it would only need to scan a file once, on entry to the system — but this ideal is never fully achievable: there's always a delay before a NEW virus is recognised, and a FURTHER delay before the checker is updated to detect it. So regular updates AND routine full-system scans are both necessary.
Practice — Test Yourself

These questions only cover what THIS subsection taught — utility programs (completes Section 7.03).

Short answer 1
What is the defining feature that makes a program a "utility program", according to this lesson?
Reveal answer

It is NOT executed as part of the normal routine of OS operation — it's run when the user (or sometimes the OS, in certain circumstances) decides to.

Short answer 2
Why is a hard disk defragmenter NOT primarily concerned with errors, unlike a disk checker?
Reveal answer

Fragmentation happens to a perfectly FUNCTIONING disk simply through normal use (creating, editing, deleting files) — it's an efficiency problem, not a fault/error problem.

Fill in the blank 3
Defragmentation is impossible if the disk is too ______, because there's no working space to rearrange files into.
Reveal answer

Full.

Spot the error 4
A student says: "Once a virus checker is installed and fully updated, it never needs scanning or updating again — the job is permanently done." Why is this wrong?
Reveal answer

New viruses keep appearing — there's always a delay before a new virus is recognised, and a further delay before the checker is updated to detect it. Regular updates and routine scans are genuinely necessary on an ongoing basis, this ideal "done once" state is never actually achievable.

Applied / scenario 5
A user deletes a small file, then later extends a large file that was stored right next to it. According to the fragmentation example in this lesson, what typically happens to the large file's storage?
Reveal answer

The extended file fills the space left by the deleted file plus more, but likely ends up split across NON-CONTIGUOUS sectors elsewhere on the disk too — because rearranging the whole file system on every single change would be too costly for the system to do automatically.

Short answer 6
Name the two things backup software can do that a purely manual backup to a flash drive cannot.
Reveal answer

Establish a schedule for backups automatically, and only create a new backup file when there has actually been a change.
