5.02 CPU Architecture & Registers
The ALU, the control unit, seven named registers, and how the status register catches an impossible sum.
Key Terms
Accumulator
A general-purpose register that stores a value before and after the execution of an instruction by the ALU.
ALU
Arithmetic and Logic Unit — handles arithmetic or logic processing.
Control unit
Controls data flow throughout the processor/system, and ensures instructions are handled correctly.
Clock speed
The CPU's clock frequency — defines the minimum time period between successive activities.
Theory

The two major CPU components

  • The ALU (Arithmetic and Logic Unit) — responsible for any arithmetic or logic processing needed while a program runs.
  • The control unit — controls data flow throughout the processor (and the whole system), and ensures program instructions are handled correctly.
  • A vital part of the control unit is a CLOCK, used to synchronise processes. Strictly there are TWO clocks: an internal clock (controls activity WITHIN the processor) and the system clock (controls activity OUTSIDE the processor).
  • Clock speed = clock frequency — it defines the MINIMUM time period separating successive activities in the system.

Registers — fast storage right next to the ALU

  • Registers are storage components; their PROXIMITY to the ALU is what allows very short access times.
  • Each register has limited capacity, typically 16, 32 or 64 bits.
  • A register is either general-purpose or special-purpose. If there's only ONE general-purpose register, it's called the ACCUMULATOR — the assumption used throughout this course.
  • The Accumulator stores a single value at a time — a value used by the ALU during instruction execution, which the ALU can then overwrite with a new value afterwards.

Naming pitfalls worth knowing

  • MDR's alternative name, "memory BUFFER register", emphasises that this register must act as a buffer — internal CPU transfers happen much faster than transfers outside the processor.
  • This chapter (and Chapter 6) deliberately IGNORES cache memory — all references are simply to "memory" as in the table above.
  • IX (index register) is sometimes abbreviated "IR" elsewhere — but some sources ALSO abbreviate CIR as "IR", causing confusion. This book always uses IX and CIR to avoid that clash. Similarly, "PC" is reserved for register transfer notation only — everywhere else, PC means "personal computer".

The status register — three flags to know

  • The SR is used when an instruction needs arithmetic or logic processing. Each bit acts as a FLAG, set to 1 if a specific condition is detected.
  • Carry flag (C): set to 1 if there is a carry.
  • Negative flag (N): set to 1 if a result is negative.
  • Overflow flag (V): set to 1 if overflow is detected.
Worked Example — catching an impossible sum with flags

Adding two positive 8-bit numbers that overflow: denary 66 (01000010) + denary 68 (01000100) = 10000110, read as denary −122 if treated as signed. Two positives producing a NEGATIVE result is impossible — and it's caught because BOTH the negative flag (N) AND the overflow flag (V) get set to 1.

Adding two negative 8-bit numbers: −66 (10111110) + −68 (10111100) = 01111010 with a carry out, read as +122 if treated as signed. Two negatives producing a POSITIVE result is impossible — caught because the negative flag is NOT set, while BOTH the overflow flag AND the carry flag ARE set to 1.

Why this matters — the processor can detect its own impossible results

  • In BOTH worked cases, the specific COMBINATION of flags set reveals that something has gone wrong mathematically — the processor can then act on this (e.g. raise an error) rather than silently returning a wrong answer.
Practice — Test Yourself

These questions only cover what THIS subsection taught — CPU architecture and registers (completes Section 5.02).

Short answer 1
What is the name given to the ONE general-purpose register assumed throughout this course?
Reveal answer

The Accumulator.

Short answer 2
What is stored in the Program Counter (PC)?
Reveal answer

The address of where the NEXT instruction is to be read from.

Fill in the blank 3
Registers allow very short access times because of their ______ to the ALU.
Reveal answer

Proximity (closeness).

Spot the error 4
A student writes "IR" to mean the index register in their exam answer. Why is this risky, according to this lesson?
Reveal answer

"IR" is ambiguous — some sources use it for the index register, others for the current instruction register (CIR), causing genuine confusion. This book always uses IX for the index register and CIR for the current instruction register specifically to avoid this clash.

Applied / scenario 5
Two POSITIVE 8-bit numbers are added and the result comes out NEGATIVE. Which combination of status flags reveals this impossible result?
Reveal answer

Both the negative flag (N) AND the overflow flag (V) are set to 1 — exactly as shown in the worked example (66 + 68 in 8 bits).

Short answer 6
Why does this chapter deliberately ignore the existence of cache memory when discussing registers and memory?
Reveal answer

To keep the discussion of the simple CPU model manageable — all references are simplified to just "memory", even though a real system's MDR transfer could sometimes actually be to/from fast cache memory rather than main memory.
