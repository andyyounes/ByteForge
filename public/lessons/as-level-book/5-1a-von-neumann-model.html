5.01 The Von Neumann Model
Five simple rules describe almost every computer you've ever used.
Key Terms
Von Neumann model
A computer architecture based on a processor with direct access to a memory holding a stored, replaceable program.
Stored program
A program held in memory, alongside its data, which can be replaced by a different program at any time.
Theory

Where the model comes from

  • The simplest widely-used computer system model is usually attributed to John von Neumann — he was the first to describe its basic principles in a publication.

The five basic features of the Von Neumann model

  • There is a processor — a central processing unit (CPU).
  • The processor has DIRECT access to a memory.
  • The memory contains a "stored program" (which can be REPLACED by another at any time) and the data that program needs.
  • The stored program consists of individual INSTRUCTIONS.
  • The processor executes instructions SEQUENTIALLY.

Why "stored program" and "replaceable" both matter

  • The program being STORED in memory (rather than hard-wired into the hardware) is what allows the same physical computer to run completely different software.
  • Because the stored program can be replaced at any time, a single machine can be a word processor one moment and a game the next, without any physical change to the hardware.
Practice — Test Yourself

These questions only cover what THIS subsection taught — the Von Neumann model (completes Section 5.01).

Short answer 1
Who is the Von Neumann model of a computer system usually attributed to, and why?
Reveal answer

John von Neumann — he was the first to describe its basic principles in a publication.

Short answer 2
List all FIVE basic features of the Von Neumann model.
Reveal answer

A processor exists; the processor has direct access to memory; memory holds a replaceable stored program plus its data; the program consists of individual instructions; instructions are executed sequentially.

Fill in the blank 3
In the Von Neumann model, instructions are executed ______ — one after another.
Reveal answer

Sequentially.

Spot the error 4
A student says: "The stored program in a Von Neumann computer is fixed permanently when the computer is manufactured, just like the hardware." What's wrong?
Reveal answer

A core feature of the model is that the stored program can be REPLACED by another at any time — it's not fixed at manufacture. This is exactly what lets one physical machine run many different pieces of software.

Applied / scenario 5
Explain, using the Von Neumann model's own features, why a single laptop can run a web browser today and a video game tomorrow without any hardware changes.
Reveal answer

Because the program is STORED in memory rather than built into the hardware, and that stored program can be REPLACED at any time — swapping which program is loaded into memory is enough to completely change what the machine does.

Short answer 6
What does memory hold, according to the Von Neumann model, besides the program's instructions?
Reveal answer

The data required by that program.
