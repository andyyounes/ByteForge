17.06 The Ethernet Protocol
MAC addresses, CSMA/CD, and why switched Ethernet made collision detection obsolete.
Theory

What Ethernet is

  • The dominant LAN protocol, standardised by the IEEE as 802.3. Has evolved through generations: standard, fast, gigabit, 10 gigabit, 100 gigabit — the naming reflects transfer speed.
  • Ethernet transmits data in FRAMES, each containing a SOURCE and DESTINATION address — the physical/MAC address that uniquely identifies one NIC (48 bits, guaranteeing uniqueness), usually written in hexadecimal, e.g. 4A:30:12:24:1A:10.

Standard Ethernet and CSMA/CD

  • Originally implemented on a bus or a hub-based star — either way, transmission was BROADCAST as a connectionless service.
  • Because everyone shared the medium, collisions were possible if two devices transmitted simultaneously. The solution: CSMA/CD (Carrier Sense Multiple Access with Collision Detection).
  • CSMA: an end-system checks the cable's voltage level to detect if a frame is ALREADY being transmitted, and if so, waits a defined time before trying again.
  • CD: even with this waiting rule, two end-systems could still occasionally start at the same moment — CD lets a device DETECT a collision as it happens and DISCONTINUE transmission immediately.
CSMA/CD: Carrier Sense Multiple Access with Collision Detection — a method for controlling shared-medium access by sensing existing transmissions and detecting/stopping on collision.

Modern switched Ethernet — collisions eliminated

  • Modern Ethernet uses a SWITCH as the star's central device, rather than a hub.
  • Each end-system connects to the switch via a FULL-DUPLEX link — no collision is possible along that dedicated link.
  • Since collisions can no longer happen at all, CSMA/CD is simply NO LONGER NEEDED in a fully switched network.

Ethernet within the TCP/IP stack

  • Ethernet is the most likely protocol operating at the DATA-LINK layer beneath IP.
  • Ethernet's data-link layer has TWO sub-layers: the LOGICAL LINK CONTROL (LLC) sub-layer (flow control, error control, part of framing), and the MEDIA ACCESS CONTROL (MAC) sub-layer (completes framing, defines the access method, transmits frames containing the physical addresses).
  • This is exactly why physical addresses are called "MAC addresses" — they're handled at the MAC sub-layer.
Practice — Test Yourself

These questions only cover what THIS subsection taught — Ethernet, CSMA/CD, and switched Ethernet (completes Section 17.06).

Short answer 1
What do the "CS", "MA", and "CD" parts of CSMA/CD each refer to?
Reveal answer

Carrier Sense (checking if the medium is already in use), Multiple Access (many devices share the medium), Collision Detection (detecting and stopping when a collision occurs).

Short answer 2
Why is CSMA/CD no longer needed in a modern switched Ethernet network?
Reveal answer

Each end-system connects to the switch via its own full-duplex link, meaning no collision is possible along that link at all — so collision detection has nothing left to do.

Fill in the blank 3
A MAC address is 48 bits long and is usually written in ______ notation.
Reveal answer

Hexadecimal.

Spot the error 4
A student claims collisions are still possible on a modern switched Ethernet network, just less often than on the original bus/hub design. What's wrong?
Reveal answer

On a switched network with full-duplex links to each end-system, collisions are not merely reduced — they become IMPOSSIBLE on those links, because each end-system has its own dedicated, two-way channel rather than sharing a single medium with others.

Applied / scenario 5
Which Ethernet sub-layer is responsible for actually transmitting frames containing the physical sender/receiver addresses?
Reveal answer

The Media Access Control (MAC) sub-layer.

Short answer 6
What organisation standardised Ethernet, and under what standard number?
Reveal answer

The IEEE (Institute of Electrical and Electronics Engineers), under standard 802.3.
