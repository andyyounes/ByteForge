11.06 Loops
REPEAT, FOR, rogue values, WHILE, and nested loops — five ways to avoid writing the same lines ten times.
Key Terms
Rogue value
A value used to terminate a sequence — same data type, but outside the range of normal expected values.
Nested loop
A loop containing another loop.
Theory

REPEAT … UNTIL — a post-condition loop, counting manually

  • Problem: take 10 numbers, output the largest.
INPUT BiggestSoFar Counter ← 1 REPEAT INPUT NextNumber Counter ← Counter + 1 IF NextNumber > BiggestSoFar THEN BiggestSoFar ← NextNumber ENDIF UNTIL Counter = 10 OUTPUT BiggestSoFar

FOR … ENDFOR — the loop that counts for you

INPUT BiggestSoFar FOR Counter ← 2 TO 10 INPUT NextNumber IF NextNumber > BiggestSoFar THEN BiggestSoFar ← NextNumber ENDIF ENDFOR OUTPUT BiggestSoFar
  • Counter starts at 2 (since the first number was already input BEFORE the loop) and automatically increases each pass, up to and including 10.

Rogue values — ending a loop without knowing the count in advance

  • A rogue value must be the SAME data type as normal input, but OUTSIDE the normal expected range (e.g. 0 terminating a sequence of non-zero numbers, or -1 if 0 is itself a valid input).
INPUT BiggestSoFar REPEAT INPUT NextNumber IF NextNumber > BiggestSoFar THEN BiggestSoFar ← NextNumber ENDIF UNTIL NextNumber = 0 OUTPUT BiggestSoFar
  • Limitation: this REPEAT version still runs its body at LEAST once — so it fails if the very FIRST input is already the rogue value 0.

WHILE … ENDWHILE — a pre-condition loop, can run ZERO times

INPUT NextNumber BiggestSoFar ← NextNumber WHILE NextNumber <> 0 INPUT NextNumber IF NextNumber > BiggestSoFar THEN BiggestSoFar ← NextNumber ENDIF ENDWHILE OUTPUT BiggestSoFar
  • The condition is checked BEFORE the loop body runs — if the very first number is already 0, the loop body never executes at all, correctly handling that edge case.

Running totals and averages — a real accumulator pattern

RunningTotal ← 0 FOR Counter ← 1 TO 10 INPUT NextNumber RunningTotal ← RunningTotal + NextNumber ENDFOR OUTPUT RunningTotal Average ← RunningTotal / 10 OUTPUT Average
  • CRUCIAL: RunningTotal must be INITIALISED to zero before the loop begins — starting from an unknown/leftover value would corrupt the whole sum.

Nested loops — a loop within a loop, producing a grid

INPUT NumberOfRows INPUT NumberOfColumns INPUT Symbol FOR RowCounter ← 1 TO NumberOfRows FOR ColumnCounter ← 1 TO NumberOfColumns OUTPUT Symbol // without moving to next line ENDFOR OUTPUT Newline // move to the next line ENDFOR
  • Each pass of the OUTER loop (one row) completes the ENTIRE inner loop (one full row's worth of symbols) before moving to the next row.
Practice — Test Yourself

These questions only cover what THIS subsection taught — REPEAT/FOR/rogue values/WHILE loops and nested loops (completes Section 11.06).

Short answer 1
What is the defining difference between a REPEAT…UNTIL loop and a WHILE…ENDWHILE loop?
Reveal answer

REPEAT…UNTIL checks its condition AFTER the loop body runs (post-condition), so it always runs at least once. WHILE…ENDWHILE checks BEFORE (pre-condition), so it can run zero times if the condition is already false.

Short answer 2
What property must a rogue value have?
Reveal answer

It must be the SAME data type as the normal input, but OUTSIDE the range of normally expected values.

Fill in the blank 3
Before a running total loop begins, RunningTotal must be ______ to zero.
Reveal answer

Initialised.

Spot the error 4
A sequence of non-zero numbers might have ONLY 0 as its first and only input. A student uses REPEAT…UNTIL with a rogue value of 0 to solve this. What genuinely goes wrong?
Reveal answer

REPEAT…UNTIL always runs its body AT LEAST once — so it will try to process the value 0 as if it were real data (treating 0 as a "number input") before even checking the termination condition, which is wrong. WHILE…ENDWHILE avoids this by checking first.

Applied / scenario 5
In the nested-loop grid example, if NumberOfRows = 3 and NumberOfColumns = 7, how many times does the INNER loop's body execute in total across the whole algorithm?
Reveal answer

21 times (3 rows × 7 columns) — the inner loop runs fully (7 times) for EACH of the 3 passes of the outer loop.

Short answer 6
In the FOR-loop biggest-number example, why does Counter start at 2 rather than 1?
Reveal answer

Because the FIRST number was already input (into BiggestSoFar) BEFORE the loop started — the loop only needs to handle numbers 2 through 10, the remaining 9 numbers.
