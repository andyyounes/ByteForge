16.03 Fixed-Point vs. Floating-Point Representation
Two ways to store a real number in binary — and why floating-point wins on range.
Theory

Real numbers and exponential notation

  • A real number has a fractional part. In denary, it can be written simply (25.3) or in EXPONENTIAL (scientific) notation, e.g. 2.53 × 10¹.
  • For everyday-sized numbers, the simple form is best; for VERY large or VERY small numbers, exponential notation becomes the only practical choice.

Fixed-point representation

  • A defined TOTAL number of bits is split: some for the sign, some for the WHOLE number part, some for the FRACTIONAL part — and this split never changes.
  • Example: 8 bits total — 1 sign bit, 5 bits for the whole number, 2 bits for the fraction.
DescriptionBinary codeDenary equivalent
Largest positive value0 11111 1131.75
Smallest positive value0 00000 010.25
Smallest magnitude negative1 00000 01−0.25
Largest magnitude negative1 11111 11−31.75

Floating-point representation

  • A defined number of bits is used for the MANTISSA (significand), M, and the remaining bits for the EXPONENT, E. The RADIX, R, is not stored — it has an implied value of 2.
  • Example: 8 bits total — 4 bits for the mantissa, 4 bits for the exponent, both in two's complement.
  • Where should the implied binary point sit within the mantissa? Placing it IMMEDIATELY AFTER the sign bit gives the SMALLEST spacing between representable values — this is the preferred choice.
Floating-point representation: a representation of real numbers that stores a value for the mantissa and a value for the exponent.
DescriptionBinary codeDenary equivalent
Largest positive value0111 0111.875 × 2⁷ = 112
Smallest positive value0001 1000.125 × 2⁻⁸ = 1/2048
Smallest magnitude negative1111 1000−.125 × 2⁻⁸ = −1/2048
Largest magnitude negative1000 0111−1 × 2⁷ = −128

Why floating-point wins on range

  • Comparing the two 8-bit examples: fixed-point tops out at ±31.75, but floating-point can reach as high as 112 and as low in magnitude as 1/2048 — a FAR wider range of representable values from the same number of bits.
  • The trade-off: floating-point's mantissa has fewer bits dedicated to it than a fixed-point number's whole fractional part would get, so PRECISION for any single value can suffer — covered further in the next lesson on normalisation.
Practice — Test Yourself

These questions only cover what THIS subsection taught — fixed-point vs. floating-point representation (part of Section 16.03).

Short answer 1
In a floating-point representation, what do the mantissa and exponent each represent?
Reveal answer

The mantissa (significand) stores the significant digits of the value; the exponent stores the power that the implied radix (2) is raised to, which scales the mantissa.

Short answer 2
Is the radix (base) stored as part of a floating-point representation?
Reveal answer

No — it has an implied value of 2 and is never explicitly stored.

Fill in the blank 3
In a fixed-point representation, the split between whole-number bits and fractional bits is ______ (never changes); in floating-point, the exponent effectively lets the binary point ______.
Reveal answer

Fixed; float (move).

Spot the error 4
A student claims fixed-point representation is always worse than floating-point, so it should never be used. What's the oversight?
Reveal answer

Fixed-point trades RANGE for a simpler, more predictable representation with consistent precision across its whole range — it can still be appropriate where the expected range of values is known and limited (e.g. currency with a fixed number of decimal places), even though floating-point wins on overall range.

Applied / scenario 5
Why is placing the implied binary point immediately after the sign bit the preferred choice for a floating-point mantissa?
Reveal answer

It produces the SMALLEST spacing between values that can be represented — giving finer-grained precision across the mantissa's range compared to placing the point elsewhere.

Short answer 6
Which representation generally allows a WIDER range of values to be stored using the same total number of bits — fixed-point or floating-point?
Reveal answer

Floating-point.
