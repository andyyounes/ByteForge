11.05 Logic Statements
The selection construct, relational operators, nested IFs, and two different biggest-of-three algorithms.
Theory

The selection construct, formally

  • A condition consists of at least one LOGIC PROPOSITION (Chapter 4). Conditions are always either TRUE or FALSE.
IF A < B THEN <statement(s)> ELSE <statement(s)> ENDIF
OperatorComparison
=Is equal to
<Is less than
>Is greater than
<=Is less than or equal to
>=Is greater than or equal to
<>Is not equal to

A crucial notational distinction

  • Pseudocode distinguishes between the relational operator = (tests for EQUALITY, used inside a condition) and the assignment symbol ← (used to STORE a value) — they are NOT the same thing.

Compound conditions with AND — a real classification example

  • A person is a child if Age < 13; an adult if Age > 19; a teenager if Age >= 13 AND Age <= 19.
  • More complex conditions are built using the logical operators AND, OR and NOT.

Nested IF statements — an IF inside an IF

  • When one IF statement contains another IF statement, these are called NESTED IF statements.

Two genuinely different algorithms for "biggest of three numbers"

  • Method 1 (nested IF): input all three first, then compare Number1 vs Number2, then compare the bigger of those two against Number3.
  • Method 2 (running comparison): keep a BiggestSoFar variable. Input the first number into it; then for each SUBSEQUENT number, compare it against BiggestSoFar and update if bigger.
  • Method 2's advantages: only TWO variables needed; no nested conditions and no ELSE branches (easier to understand); adapts easily to MORE numbers later.
  • Method 2's disadvantage: potentially MORE assignment operations carried out overall, since BiggestSoFar might need updating more than once.
Practice — Test Yourself

These questions only cover what THIS subsection taught — selection, relational operators, and nested IFs (completes Section 11.05).

Short answer 1
What is the difference between the pseudocode symbols = and ←?
Reveal answer

= tests for equality inside a condition (asking "is this true?"). ← is the assignment symbol, used to STORE a value into a variable. They are genuinely different operations.

Short answer 2
What is a nested IF statement?
Reveal answer

A conditional statement contained within another conditional statement.

Fill in the blank 3
A condition consists of at least one logic ______, and evaluates to either ______ or ______.
Reveal answer

Proposition; TRUE; FALSE.

Spot the error 4
A student says: "The BiggestSoFar method (Method 2) is strictly better than the nested-IF method (Method 1) in every way." What genuine disadvantage does this lesson list for Method 2?
Reveal answer

There's more WORK involved — depending on the input values, BiggestSoFar might need to be reassigned more than once, resulting in potentially more assignment operations overall than Method 1's approach.

Applied / scenario 5
Write the condition, in pseudocode style, for classifying someone as a "teenager" (13 to 19 inclusive).
Reveal answer

Age >= 13 AND Age <= 19

Short answer 6
Which of the two "biggest of three" methods adapts more easily if a fourth number needs comparing too, and why?
Reveal answer

Method 2 (BiggestSoFar) — it just needs one more "input next number, compare against BiggestSoFar" step added, rather than restructuring nested IF/ELSE branches.
