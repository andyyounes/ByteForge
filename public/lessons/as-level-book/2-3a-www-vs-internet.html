2.03 The World Wide Web vs the Internet
Two words people use interchangeably that mean genuinely different things.
Key Terms
World Wide Web (WWW)
A distributed application that runs ON the Internet — websites, web pages, and the hyperlinks joining them.
Hyperlink
A clickable link inside a web page giving direct, near-immediate access to another web page.
Theory

"Using the web" and "using the Internet" are NOT the same thing

  • It's common to treat "the web" and "the Internet" as two names for the same thing — this is genuinely incorrect.
  • The Internet is an internetwork: the physical/logical infrastructure of connected networks (covered in Section 2.02) that data can travel across.
  • The World Wide Web is a distributed APPLICATION that happens to be available on top of that infrastructure — one of many things the Internet can carry, alongside email, file transfer, streaming, and more.

What the web actually consists of

  • The web is an enormous collection of websites, each made up of one or more web pages.
  • The special feature that defines a web page is the hyperlink: clicking one gives direct, essentially immediate access to another web page — this is what makes the web feel like one connected space rather than isolated documents.

Why the distinction actually matters

  • The Internet existed and carried traffic (email, file transfer) for years before the web was invented on top of it — the web is a later, separate application layered onto existing infrastructure.
  • You can use "the Internet" without ever touching "the web" (e.g. sending email, streaming media via a dedicated app) — so the two terms genuinely aren't interchangeable, even in casual use.
Practice — Test Yourself

These questions only cover what THIS subsection taught — WWW vs Internet (completes Section 2.03).

Short answer 1
What IS the World Wide Web, precisely?
Reveal answer

A distributed application available on the Internet — an enormous collection of websites and web pages joined by hyperlinks.

Short answer 2
What is the special feature of a web page that makes the web feel like one connected space?
Reveal answer

The hyperlink — clicking one gives direct, essentially immediate access to another web page.

Fill in the blank 3
The Internet is an ______, while the World Wide Web is a ______ available on top of it.
Reveal answer

Internetwork; distributed application.

Spot the error 4
A student writes: "The Internet and the World Wide Web are just two names for the exact same thing." What's wrong with this statement?
Reveal answer

They are genuinely different things — the Internet is the underlying internetwork infrastructure, while the WWW is one distributed application that runs on top of that infrastructure. You can use the Internet (e.g. email) without using the web at all.

Applied / scenario 5
A user sends an email and, separately, browses a news website. Which of these two activities uses the World Wide Web specifically, and which uses the Internet without necessarily using the web?
Reveal answer

Browsing the news website uses the World Wide Web (a website made of web pages joined by hyperlinks). Sending an email uses the Internet's infrastructure but is not part of the World Wide Web itself.

Short answer 6
Which came first as a working technology: the Internet's underlying infrastructure, or the World Wide Web?
Reveal answer

The Internet's infrastructure came first — the web was later layered on top of already-existing internetwork infrastructure as one particular distributed application.
