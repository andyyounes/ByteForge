18.02 SR and JK Flip-Flops
From combinational to sequential circuits — how a bit of memory is actually built. Completes Section 18.02.
Theory

Combinational vs. sequential circuits

  • Every circuit met so far (adders, gates) is COMBINATIONAL — output depends ONLY on the current inputs.
  • A SEQUENTIAL circuit's output depends on the input AND the PREVIOUS output — this is what gives a circuit "memory".
Combinational circuit: a circuit in which the output is dependent only on the input values.
Sequential circuit: a circuit in which the output depends on the input values and the previous output.

The SR flip-flop ("latch")

  • Built from two NAND gates or two NOR gates. A TWO-STATE device: either Q=1/Q'=0, or the reverse.
  • S=0, R=0: NO CHANGE — outputs stay as they were (this is the "no signal" resting state).
  • S=1, R=0: always sets Q=1, Q'=0.
  • S=0, R=1: always sets Q=0, Q'=1 (the reverse).
  • S=1, R=1 SIMULTANEOUSLY must be AVOIDED — it forces an INVALID state where both Q and Q' end up 0, which breaks the flip-flop's whole purpose.

  • Because a value is STORED but can be ALTERED, an SR flip-flop can act as a 1-bit storage element — a component in RAM.

The JK flip-flop — solving the invalid-state problem

  • Adds a CLOCK PULSE input, which better synchronises when inputs are actually read — avoiding uncertain states from inputs arriving at slightly different times.
  • J acts like a SET input, K acts like a CLEAR — similar in spirit to S and R.
  • Crucially, if BOTH J and K are input as 1 (the case that was INVALID for SR), Q simply TOGGLES (switches to the opposite value) — no invalid state occurs.
Practice — Test Yourself

These questions only cover what THIS subsection taught — combinational vs. sequential circuits, and SR/JK flip-flops (completes Section 18.02).

Short answer 1
What is the key difference between a combinational and a sequential circuit?
Reveal answer

A combinational circuit's output depends only on its current inputs. A sequential circuit's output depends on both the current inputs AND the previous output — giving it memory.

Short answer 2
What input combination must be avoided in an SR flip-flop, and why?
Reveal answer

S=1 and R=1 simultaneously — this forces both Q and Q' to become 0, an invalid state that breaks the flip-flop's function as a storage device.

Fill in the blank 3
In a JK flip-flop, if both J and K are input as 1, the output Q simply ______.
Reveal answer

Toggles (switches to the opposite value).

Spot the error 4
A student says an SR flip-flop with S=0, R=0 "resets both outputs to 0". What's actually happening?
Reveal answer

S=0, R=0 produces NO CHANGE — Q and Q' simply retain whatever values they already held before this input. It's the "no signal" resting state, not a reset.

Applied / scenario 5
Why does adding a clock pulse to the JK flip-flop help avoid uncertain states, compared to the plain SR flip-flop?
Reveal answer

Without a clock, inputs that arrive at slightly different times could cause the circuit to briefly settle into an unpredictable state. The clock pulse gives a defined MOMENT at which inputs are read, giving a much better chance of properly synchronised behaviour.

Short answer 6
Why is an SR flip-flop suitable for use as a component in RAM?
Reveal answer

It stores a single bit's value persistently (via Q/Q'), but that value can also be deliberately CHANGED by applying the right S/R inputs — exactly the read/write behaviour RAM needs.
