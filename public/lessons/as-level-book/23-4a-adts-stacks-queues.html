23.03–23.05 Abstract Data Types, Stacks and Queues
LIFO vs. FIFO — and how a circular queue avoids wasteful data-shifting.
Theory

What is an abstract data type (ADT)?

  • An ADT is a COLLECTION of data with a defined set of OPERATIONS: create a new instance, find an element, insert an element, delete an element, and access all elements systematically.
Abstract data type: a collection of data with associated operations.

Stacks — Last In, First Out (LIFO)

  • Modelled on a real pile of items: you can only access the item on TOP. Removing something other than the top item would collapse the pile.
  • A BaseOfStackPointer always points to the FIRST slot. A TopOfStackPointer points to the LAST element PUSHED on — it decreases when an element is POPPED off.

Queues — First In, First Out (FIFO)

  • Modelled on a real-world queue: new items join at the END; items leave from the FRONT. No pushing in, no leaving from the middle.
  • A naive array implementation would require SHIFTING every remaining item forward one slot whenever the front item leaves — wasteful for large queues.

The circular queue — a more efficient design

  • Instead of shifting data, TWO pointers (front and end) simply move forward as items join/leave.
  • When a pointer reaches the end of the array, it "WRAPS AROUND" back to the beginning — reusing slots that have been vacated, without ever needing to physically move existing data.
Practice — Test Yourself

These questions only cover what THIS subsection taught — ADTs, stacks, and queues (completes Sections 23.03–23.05).

Short answer 1
What are the five basic operations expected of an abstract data type?
Reveal answer

Create a new instance, find an element, insert an element, delete an element, and access all elements systematically.

Short answer 2
What does LIFO stand for, and which ADT does it describe?
Reveal answer

Last In, First Out — it describes a stack, where the most recently added item is the first one removed.

Fill in the blank 3
In a circular queue, when a pointer reaches the end of the array, it ______ back to the beginning.
Reveal answer

Wraps around.

Spot the error 4
A student implements a queue by shifting every remaining item one slot forward every time the front item leaves. What's the drawback of this approach?
Reveal answer

It requires moving potentially MANY data items on every single removal — wasteful and slow for large queues. A circular queue avoids this entirely by just moving two pointers instead of physically shifting data.

Applied / scenario 5
A print spooler processes documents in the exact order they were submitted. Which ADT — stack or queue — models this naturally?
Reveal answer

A queue (FIFO) — the first document submitted is the first one printed, matching first-in-first-out behaviour.

Short answer 6
In a stack, what happens to the TopOfStackPointer when an item is removed (popped)?
Reveal answer

It decreases, to point to the element that is now at the top of the stack.
