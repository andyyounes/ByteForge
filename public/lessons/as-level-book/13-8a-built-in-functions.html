Slicing in Python — the general-purpose way to grab a substring

  • A slice of length L starting at position P is written S[P : P + L].
  • Position counts from 0; the position at the UPPER bound of the slice is NOT included in the result.
  • If you omit the upper bound, the slice runs to the END of the string. If you omit the lower bound, it runs from the BEGINNING.
  • A NEGATIVE lower bound counts backward from the end of the string; a negative upper bound TERMINATES the slice that many characters before the end.

Rounding — always away from zero

  • Python: round(x[, ndigits]) — rounds x to ndigits after the decimal point (default 0 if omitted). The result is still a floating-point number.
  • Rounding convention: AWAY from zero — so 0.5 rounds to 1, and -0.5 rounds to -1.

Truncation — just chop off the decimal part

  • Truncation is DIFFERENT from rounding — it simply returns the WHOLE NUMBER part of a real number, with no rounding logic at all.
  • Python: int(x) — if x is a float, this truncates TOWARDS zero (e.g. int(3.9) gives 3, and int(-3.9) gives -3).

Converting a string to a number

  • A whole number held as a STRING (e.g. from user input) must be converted to use it in a calculation.
  • Python: int(S) converts a string like "5" to the integer 5. float(S) converts a string like "75.43" to the real number 75.43.
  • This is exactly why input()'s result (always a string) often needs converting before it can be used in arithmetic — a direct callback to Section 13.02.
Practice — Test Yourself

These questions only cover what THIS subsection taught — string functions, slicing, rounding, truncation, and string-to-number conversion (completes Section 13.08 and Chapter 13).

Short answer 1
What is the key difference between rounding and truncation?
Reveal answer

Rounding finds the NEAREST whole number (away from zero for exact halves); truncation simply DISCARDS the decimal part entirely, with no consideration of how close it is to rounding up or down.

Short answer 2
In Python, what does ThisString[3:6] return, given a string "ABCDEFG"?
Reveal answer

"DEF" — starting at index 3 (the 4th character, D), up to but NOT including index 6 (G).

Fill in the blank 3
Rounding is always done ______ zero — so both 0.5 and -0.5 round to values FURTHER from zero, not closer.
Reveal answer

Away from.

Spot the error 4
A student reads a number with Age = input("Enter age: ") and then tries Age + 10, expecting arithmetic. What goes wrong, and how is it fixed?
Reveal answer

input() always returns a STRING, so Age + 10 would try to add a string and a number, causing an error. It needs converting first: Age = int(input("Enter age: ")).

Applied / scenario 5
Write the Python slice expression that returns the LAST 3 characters of a string called Word.
Reveal answer

Word[-3:]

Short answer 6
What does ord(ch) return, and what is its pseudocode equivalent?
Reveal answer

The ASCII code (integer value) of the character ch — pseudocode's ASCII(ch).
