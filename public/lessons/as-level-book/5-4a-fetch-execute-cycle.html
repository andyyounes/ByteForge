5.04 The Fetch-Execute Cycle
Fetch, decode, execute — and two things that happen in the SAME clock cycle without either one waiting for the other.
Theory

Full name, three stages

  • The full name is the fetch, DECODE and execute cycle — often shortened to "fetch-execute cycle", but decode genuinely sits in the middle.

The fetch stage — step by step

  1. The address currently in the Program Counter (PC) is transferred within the CPU to the MAR.
  2. During the NEXT clock cycle, TWO things happen SIMULTANEOUSLY: the instruction at the address pointed to by the MAR is fetched into the MDR; AND the address in the PC is incremented.
  3. The instruction now in the MDR is transferred within the CPU to the CIR.

Why the PC increment happens BEFORE decoding, and what jump instructions change

  • Normally, the PC is incremented by 1 as part of the fetch stage — assuming the next instruction is simply the next one in sequence.
  • BUT the instruction just fetched might be a JUMP instruction. In that case, the PC has to be updated according to the jump's condition INSTEAD — but this can only happen AFTER the instruction has been decoded, since decoding is what reveals it's a jump in the first place.

The decode stage

  • The instruction now sitting in the CIR is received as input by circuitry WITHIN the control unit.
  • Depending on the instruction TYPE, the control unit sends signals to the appropriate components so the execute stage can begin.
  • At this stage, the ALU is activated IF the instruction requires arithmetic or logic processing.

The execute stage — deliberately postponed

  • The detailed description of the execute stage is postponed until Chapter 6, where a simple instruction set is introduced — execute's exact behaviour depends entirely on WHICH instruction is being run.
Practice — Test Yourself

These questions only cover what THIS subsection taught — the fetch-decode-execute cycle (completes Section 5.04).

Short answer 1
What is the full, correct name of this cycle (not the shortened version)?
Reveal answer

The fetch, decode and execute cycle.

Short answer 2
Which TWO things happen simultaneously, in the SAME clock cycle, during the fetch stage?
Reveal answer

The instruction pointed to by the MAR is fetched into the MDR, AND the PC's address is incremented — both at once, not one after the other.

Fill in the blank 3
In the fetch stage, the instruction now held in the MDR is transferred within the CPU to the ______.
Reveal answer

CIR (Current Instruction Register).

Spot the error 4
A student says: "If the fetched instruction turns out to be a jump instruction, the PC is simply incremented by 1 as normal, exactly like every other instruction." Why is this wrong?
Reveal answer

For a jump instruction, the PC's contents have to be updated according to the jump condition INSTEAD of the normal +1 increment — but this can only happen AFTER the instruction is decoded, since decoding is what reveals it's a jump instruction in the first place.

Applied / scenario 5
At which exact stage of the cycle does the control unit determine WHICH components need to be activated for the current instruction?
Reveal answer

The decode stage — the instruction in the CIR is analysed by control unit circuitry, which then sends signals to the appropriate components (e.g. activating the ALU if arithmetic/logic processing is needed) so execute can begin.

Short answer 6
Why does this lesson postpone describing the execute stage in detail?
Reveal answer

Because what happens during execute depends entirely on WHICH specific instruction is being run — a proper description needs an actual instruction set to be introduced first, which happens in Chapter 6.
