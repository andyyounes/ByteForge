8.03 Security Measures for Protecting Data
Backup procedures, access rights, and why encryption defeats even a successful break-in.
Key Terms
Authorisation
Definition of a user's access rights to system components.
Disk mirroring
Simultaneously storing data on two disk systems during normal operation.
Theory

Three scenarios needing data protection

  • Data LOSS, access TO data, and protection of data CONTENT — three genuinely distinct problems needing different solutions.

Recovering from data loss — the traditional backup principles

  • Accidental causes: corrupted disk/tape, destroyed disk/tape, system crash, mistakenly erased/overwritten file, or simply forgetting a file's location.
  • Traditional principles: a FULL backup at regular intervals (e.g. weekly); at least TWO generations of full backup kept in storage; INCREMENTAL backups made daily.
  • For maximum security, backup media are stored AWAY from the system, in a fire-proof and flood-proof location.

Why the traditional approach breaks down for 24/7 systems

  • The traditional approach worked when incremental backups ran overnight and full backups ran at the weekend — quiet periods with no live data changes.
  • With systems running 24/7, data can change at ANY moment — a naive backup risks capturing data in an INCONSISTENT state (mid-change).
  • Solution 1: a backup program that effectively FREEZES the file store while copying, but records elsewhere any changes happening due to ongoing use — applying them to the system files once the backup is done.
  • Solution 2: DISK MIRRORING — data is simultaneously stored on TWO disk systems during normal operation (the mirrored systems might even be at remote locations, doubling as disaster recovery).

Restricting access to data — being logged in isn't "all access"

  • Being authorised to USE the system doesn't mean authorised to use ALL of it.
  • Classic example: an employee should be able to look up a colleague's internal phone number, but NOT see that colleague's salary — different data, different access needs, same user.
  • Solution: an AUTHORISATION policy giving different access RIGHTS to different files for different individuals — e.g. no access at all, read-only, read+append (but not full write), etc.

Protecting data content — making a break-in pointless

  • Even with strong access controls, unauthorised access or transmission interception can still happen.
  • If the data is ENCRYPTED, an attacker who gets hold of it still can't actually READ it — turning a successful intrusion into a futile one.
Practice — Test Yourself

These questions only cover what THIS subsection taught — protecting data: backup, access restriction, and encryption (completes Section 8.03).

Short answer 1
Name the three traditional backup principles described in this lesson.
Reveal answer

A full backup at regular intervals; at least two generations of full backup kept in storage; incremental backups made daily.

Short answer 2
Why does a naive backup approach risk problems on a system that runs 24/7?
Reveal answer

Data can change at any moment on a 24/7 system, so a backup could capture data mid-change — leaving it in an INCONSISTENT state, unlike the old approach of backing up during quiet overnight/weekend periods.

Fill in the blank 3
______ is the definition of a user's access rights to system components.
Reveal answer

Authorisation.

Spot the error 4
A student says: "Once a user has logged in and been authenticated, they should automatically be able to access every file on the system." Why is this wrong?
Reveal answer

Authentication only confirms WHO the user is — it doesn't grant blanket access. A separate AUTHORISATION policy is needed to define which specific files/rights each individual actually has, exactly like the phone-number-vs-salary example in this lesson.

Applied / scenario 5
An attacker intercepts a company's data transmission and successfully copies it. Why might this still be a "futile activity" for the attacker, according to this lesson?
Reveal answer

If the data was ENCRYPTED before transmission, the attacker has a copy of unreadable ciphertext — having the data doesn't help them if they can't actually read/use its content.

Short answer 6
Describe disk mirroring, and one extra benefit it can provide beyond normal backup.
Reveal answer

Data is simultaneously stored on two disk systems during normal operation. If the two systems are at remote locations, this can also form part of a disaster recovery plan.
