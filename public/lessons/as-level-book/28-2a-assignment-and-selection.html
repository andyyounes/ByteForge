28.03 Assembly Patterns: Assignment and Selection
Translating pseudocode assignment and IF statements into assembly language design patterns.
Theory

The general problem-solving approach

  • Break the problem into the SAME basic constructs used in high-level languages: assignment, selection, iteration, input/output — then translate EACH construct using a reusable "design pattern" in assembly.

Assignment patterns

  • Core rule: a value must FIRST be generated in the ACCUMULATOR before it can be stored anywhere.
A ← 34 B ← B + 1 B ← B + A LDM #34 LDD B LDD B STO A INC ACC ADD A STO B STO B
  • Simple assignment: generate the value with LDM, then STO it.
  • Incrementing: LOAD the current value, INC it, STORE it back.
  • Adding two variables: LOAD the first, ADD the second, STORE the result.
# A ← -A (two's complement negation, assuming 8-bit values) LDD A XOR #&FF // one's complement: flip every bit INC ACC // add 1 to get two's complement STO A

Selection patterns — a plain IF

IF A = 0 LDD A THEN CMP #0 B ← B + 1 JPN ENDIF ENDIF THEN: LDD B INC ACC STO B ENDIF: ...
  • LOAD the value to test, COMPARE it, then JPN (jump if NOT equal) to skip over the THEN block entirely if the condition is FALSE.
  • Using LABELS like THEN and ENDIF makes the logic much easier to follow than raw addresses.

Selection patterns — IF/ELSE

IF A = B LDD A THEN XOR #&FF // negate A... OUTPUT "Y" INC ACC ELSE ADD B // ...then add B: zero result means A=B OUTPUT "N" CMP #0 ENDIF JPN ELSE THEN: LDM #89 // ASCII 'Y' OUT JMP ENDIF // must jump OVER the ELSE block! ELSE: LDM #78 // ASCII 'N' OUT ENDIF: ...
  • Testing equality WITHOUT a direct "equals" comparison: negate one value and ADD the other — the result is ZERO exactly when the two original values were equal.
  • CRITICAL detail: after the THEN block finishes, an explicit JMP is needed to jump OVER the ELSE block — otherwise execution would fall through and run the ELSE code too.
Practice — Test Yourself

These questions only cover what THIS subsection taught — assembly patterns for assignment and selection (part of Section 28.03).

Short answer 1
Before a value can be stored in a memory location, where must it first be generated?
Reveal answer

In the accumulator (ACC).

Short answer 2
Why is an explicit JMP needed at the end of the THEN block in an IF/ELSE translation?
Reveal answer

Without it, execution would simply continue into the ELSE block after finishing the THEN block — the JMP is needed to skip over the ELSE code entirely, since only one branch should ever execute.

Fill in the blank 3
Following a comparison, ______ jumps if the result was NOT equal (false); ______ jumps if the result was equal (true).
Reveal answer

JPN; JPE.

Spot the error 4
A student translates IF A = 0 THEN B ← B + 1 ENDIF but uses JPE instead of JPN after the CMP. What goes wrong?
Reveal answer

JPE jumps when the comparison IS true — this would SKIP the THEN block exactly when the condition holds (A=0), and execute it when the condition is FALSE — the logic is completely inverted from what's intended.

Applied / scenario 5
Write the assembly pattern (using LDM and STO) for the pseudocode assignment C ← 7.
Reveal answer

LDM #7
STO C

Short answer 6
How can equality between two values (A = B) be tested without a direct "equals" comparison operator?
Reveal answer

Negate one value (e.g. take its two's complement) and ADD the other — if the result is zero, the two original values were equal.
