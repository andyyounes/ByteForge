14.06 Passing Parameters to Procedures
BYVAL vs. BYREF — whether changes inside a procedure escape back to the caller.
Theory

By value — a copy goes in

  • A copy of the current value is passed into the subroutine. Changes made to the parameter inside the subroutine do NOT affect the original variable in the calling program.
  • Written in pseudocode as: BYVAL <identifier> : <dataType>.
PROCEDURE OutputSymbols(BYVAL NumberOfSymbols : INTEGER, BYVAL Symbol : CHAR) DECLARE Count : INTEGER FOR Count ← 1 TO NumberOfSymbols OUTPUT Symbol // without moving to next line ENDFOR OUTPUT NewLine END PROCEDURE

By reference — the address goes in

  • The ARGUMENT must be a variable (not a literal value). A pointer to that variable's memory location is passed in — so changes made inside the procedure DO affect the original variable back in the caller.
  • Written in pseudocode as: BYREF <identifier> : <dataType>.
PROCEDURE AdjustValuesForNextRow(BYREF Spaces : INTEGER, BYREF Symbols : INTEGER) Spaces ← Spaces - 1 Symbols ← Symbols + 2 END PROCEDURE CALL AdjustValuesForNextRow(NumberOfSpaces, NumberOfSymbols) // NumberOfSpaces and NumberOfSymbols themselves are changed by this call

Python is different — pass by object reference

  • Python has NEITHER true BYVAL nor true BYREF — its own mechanism ("pass by object reference") is beyond AS-Level scope, but the practical fix is simple: to get a BYREF-like effect, write a FUNCTION that returns the updated value(s) and reassign them in the caller.
# Python — simulating BYREF using multiple return values def AdjustValuesForNextRow(Spaces, Symbols): Spaces = Spaces - 1 Symbols = Symbols + 2 return Spaces, Symbols NumberOfSpaces, NumberOfSymbols = AdjustValuesForNextRow(NumberOfSpaces, NumberOfSymbols)
Practice — Test Yourself

These questions only cover what THIS subsection taught — BYVAL, BYREF, and Python's alternative (completes Section 14.06).

Short answer 1
What is passed into a subroutine when a parameter is BYREF?
Reveal answer

A pointer to the memory location (address) of the variable — not a copy of its value.

Short answer 2
Does the calling program's variable change if it's passed BYVAL and the procedure modifies the parameter?
Reveal answer

No — BYVAL passes a COPY, so any changes inside the procedure only affect that copy, not the original variable.

Fill in the blank 3
In pseudocode, a parameter passed by reference is written with the keyword ______ before its identifier.
Reveal answer

BYREF.

Spot the error 4
A student tries to call CALL AdjustValues(BYREF 10, BYREF Count), passing the literal value 10 as a BYREF argument. Why is this invalid?
Reveal answer

A BYREF argument must be a VARIABLE, since a memory address is passed in — a literal value like 10 has no variable memory location to reference.

Applied / scenario 5
Since Python has no BYREF, how can you get the effect of updating two variables inside a subroutine and having those changes visible in the caller?
Reveal answer

Write it as a function that returns both updated values as a tuple, then reassign both variables from that call: a, b = MyFunction(a, b).

Short answer 6
Which parameter-passing method — BYVAL or BYREF — is generally used just to supply data into a procedure without expecting any changes back?
Reveal answer

BYVAL.
