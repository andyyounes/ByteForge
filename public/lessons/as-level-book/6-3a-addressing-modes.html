6.03 Addressing Modes
Four different ways to say "here's the value" — from handing it over directly to a two-step address-of-an-address chase.
Theory

Why addressing modes exist

  • When an instruction needs a value loaded into a register, there are several DIFFERENT ways of identifying exactly where/what that value is — these are the "addressing modes".
  • Recall from 6.01: 2 bits of the opcode define the addressing mode — allowing exactly FOUR different modes.
Addressing modeWhat the operand actually is
ImmediateThe value to be used in the instruction, directly
DirectAn address which holds the value to be used
IndirectAn address which holds the address which holds the value
IndexedAn address to which the index register (IX) content must be ADDED, to get the address that holds the value

Reading the four modes as increasing "distance" from the value

  • Immediate: the operand IS the value — zero extra steps needed.
  • Direct: the operand is an ADDRESS — one step (go to that address, read the value there).
  • Indirect: the operand is an address OF an address — two steps (go to that address, read another address, THEN go to THAT address to read the value).
  • Indexed: the operand is a BASE address that must be ADJUSTED by adding whatever's currently in the index register (IX) — useful for accessing a whole array/list of values using the same base instruction, just changing IX.
Practice — Test Yourself

These questions only cover what THIS subsection taught — the four addressing modes (completes Section 6.03).

Short answer 1
In IMMEDIATE addressing, what does the operand actually represent?
Reveal answer

The value to be used in the instruction, directly — no address lookup needed at all.

Short answer 2
How many "hops" through memory are needed to reach the final value under INDIRECT addressing?
Reveal answer

Two — the operand gives an address, at which is stored ANOTHER address, at which the actual value is finally found.

Fill in the blank 3
In INDEXED addressing, the final address is found by adding the contents of the ______ register to the address given in the operand.
Reveal answer

Index (IX).

Spot the error 4
A student says: "Direct and indirect addressing are basically the same thing — both use an address stored in the operand." What's the key difference being missed?
Reveal answer

In DIRECT addressing, the address in the operand holds the VALUE itself. In INDIRECT addressing, the address in the operand holds ANOTHER address, which is where the value is actually found — an extra level of indirection.

Applied / scenario 5
A program needs to loop through 10 consecutive values in an array using the SAME instruction each time, just changing which element it accesses. Which addressing mode is specifically suited to this, and why?
Reveal answer

Indexed addressing — the base address stays fixed in the instruction, while changing the value in the index register (IX) lets the SAME instruction access a different array element each time.

Short answer 6
How many different addressing modes does the simple processor in this course support, and why exactly that many?
Reveal answer

Four — because exactly 2 bits of the opcode are allocated to define the addressing mode, and 2 bits can represent 2² = 4 distinct values.
