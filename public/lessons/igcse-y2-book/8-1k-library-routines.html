8.1k Library Routines — MOD, DIV, ROUND, RANDOM
Ready-made, fully-tested routines every IDE provides — completes Section 8.1.
Key Terms
Library routine
A ready-made, pre-tested procedure or function included with a programming language, ready to use without writing it yourself.
MOD
Returns the REMAINDER of a division.
DIV
Returns the QUOTIENT (whole-number part) of a division.
ROUND
Returns a value rounded to a given number of decimal places.
Theory

Why library routines exist

  • Every IDE includes a standard library of ready-made, fully-tested routines for common tasks — including the string handling from Section 8.1f.
  • Some languages need a specific IMPORT statement to access certain library routines — e.g. Python's from random import random before RANDOM can be used.

Working through the pseudocode examples by hand

  • MOD(10, 3) — 10 divided by 3 is 3 remainder 1, so MOD returns 1.
  • DIV(10, 3) — 10 divided by 3 goes 3 whole times (with 1 left over), so DIV returns 3.
  • ROUND(6.97354, 2) — rounding 6.97354 to 2 decimal places gives 6.97 (the third decimal digit, 3, rounds down).
  • MOD and DIV are a genuine pair: for any division A ÷ B, DIV(A,B) * B + MOD(A,B) always equals A exactly — e.g. 3 × 3 + 1 = 10.
Practice — Test Yourself

These questions only cover what THIS subsection taught — MOD, DIV, ROUND, and RANDOM (completing Section 8.1).

Short answer 1
What is the difference between what MOD and DIV each return?
Reveal answer

MOD returns the REMAINDER of a division; DIV returns the QUOTIENT (the whole-number part) of a division.

Short answer 2
What does RANDOM() return?
Reveal answer

A random number between 0 and 1 inclusive.

Fill in the blank pseudocode 3
Complete the Python equivalent of pseudocode's Value ← MOD(10, 3): Value = 10 ______ 3
Reveal answer

Value = 10 % 3.

Spot the error 4
A student wants a random number and simply writes Value4 = random() at the top of their Python program with no other setup. What real problem might this cause?
Reveal answer

Without from random import random first, Python has no idea what random() refers to — RANDOM specifically needs its library imported before use, unlike MOD/DIV/ROUND which work immediately with no setup.

Applied / scenario 5
Work out MOD(17, 5) and DIV(17, 5) by hand.
Reveal answer

17 ÷ 5 = 3 remainder 2. So DIV(17, 5) = 3, and MOD(17, 5) = 2. Check: 3 × 5 + 2 = 17. ✓

Short answer 6
What genuine relationship always holds true between DIV(A,B), MOD(A,B), B, and A?
Reveal answer

DIV(A,B) * B + MOD(A,B) = A — the quotient times the divisor, plus the remainder, always reconstructs the original number exactly.
