7.4a Standard Methods: Totalling, Counting, Maximum/Minimum & Average
Four building-block patterns that show up in almost every algorithm you'll ever write.
Key Terms
Totalling
Keeping a running total that values are added to.
Counting
Keeping a count of how many times something happens (can also count DOWN).
Average (mean)
Total of all values divided by how many values there are.
Theory

Why these matter

  • Being able to REPEAT existing standard methods is crucial in algorithm design — once turned into a real program, the same pattern may run thousands of times.
  • Five standard methods are required for IGCSE: totalling, counting, max/min/average, linear search, bubble sort (the last two covered in the next two lessons).
Totalling — summing marks in an arrayTotal ← 0 FOR Counter ← 1 TO ClassSize Total ← Total + StudentMark[Counter] NEXT Counter
Counting UP — counting how many students passedPassCount ← 0 FOR Counter ← 1 TO ClassSize INPUT StudentMark IF StudentMark > 50 THEN PassCount ← PassCount + 1 NEXT Counter
Counting DOWN — checking stock, re-ordering when lowNumberInStock ← NumberInStock - 1 IF NumberInStock < 20 THEN CALL Reorder()

Maximum and minimum — two approaches

  • Approach 1: initialise Maximum to the LOWEST possible value, and Minimum to the HIGHEST possible value, then update them as the list is scanned.
  • Approach 2 (if the range of possible values isn't known): initialise BOTH Maximum and Minimum to the FIRST item in the list, then compare against the REMAINING items (starting the loop at position 2).
Approach 1 — using known bounds (0-100 for a percentage mark)MaximumMark ← 0 MinimumMark ← 100 FOR Counter ← 1 TO ClassSize IF StudentMark[Counter] > MaximumMark THEN MaximumMark ← StudentMark[Counter] ENDIF IF StudentMark[Counter] < MinimumMark THEN MinimumMark ← StudentMark[Counter] ENDIF NEXT Counter
Approach 2 — using the first item as the starting pointMaximumMark ← StudentMark[1] MinimumMark ← StudentMark[1] FOR Counter ← 2 TO ClassSize IF StudentMark[Counter] > MaximumMark THEN MaximumMark ← StudentMark[Counter] ENDIF IF StudentMark[Counter] < MinimumMark THEN MinimumMark ← StudentMark[Counter] ENDIF NEXT Counter

Average (mean)

  • An extension of totalling: sum all the values, then divide by how many there are, ONCE the loop has finished.
Calculating a class's average markTotal ← 0 FOR Counter ← 1 TO ClassSize Total ← Total + StudentMark[Counter] NEXT Counter Average ← Total / ClassSize
Practice — Test Yourself

These questions only cover what THIS subsection taught — totalling, counting, and maximum/minimum/average.

Short answer 1
Why is a totalling variable always initialised to zero before a loop begins?
Reveal answer

So the running total starts from a clean, known value — if it weren't initialised, it could hold leftover data from elsewhere in the program, giving a wrong final total.

Short answer 2
Why is MaximumMark initialised to 0 (not some other value) when the known range is 0-100?
Reveal answer

0 is the LOWEST possible value in the known range — starting there guarantees the very first real mark checked will be greater than it, so the maximum gets correctly updated from the start.

Fill in the blank pseudocode 3
Complete this line to calculate an average from a total and a class size: Average ← Total ______ ClassSize
Reveal answer

Average ← Total / ClassSize.

Spot the error 4
A student uses Approach 1 (initialise Maximum to 0, Minimum to 100) to find the highest and lowest value in a list of NEGATIVE temperatures (e.g. -30 to -5). What real problem does this cause?
Reveal answer

Since all the real values are negative, NONE of them would ever be greater than the initial Maximum of 0 — the maximum would incorrectly stay at 0 forever. Approach 2 (initialising Maximum/Minimum to the FIRST actual value in the list) avoids this problem entirely, since it doesn't assume a known "safe" starting bound.

Applied / scenario 5
Write pseudocode using the counting method to count how many items in an array called Score (of length 20) have a value greater than 75.
Reveal answer

Count ← 0
FOR Counter ← 1 TO 20
  IF Score[Counter] > 75
  THEN
    Count ← Count + 1
  ENDIF
NEXT Counter
OUTPUT Count, " items scored above 75"

Short answer 6
Give a real example of "counting down" mentioned in this lesson.
Reveal answer

Checking the number of items left in stock in a supermarket, and triggering a re-order once it drops below a threshold (e.g. 20).
