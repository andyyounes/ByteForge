10.2d Writing an Expression from a Truth Table
Only the rows where the output is 1 matter — OR them together and you're done.
Key Terms
Sum of products
Writing an expression as several AND terms (one per output-1 row) joined by OR — the standard method used here.
Theory

The method — only the 1-rows matter

  • To find the expression a truth table represents, only look at the rows where the OUTPUT is 1 — completely ignore every row where it's 0.
  • For EACH such row, write an AND expression describing exactly that combination of inputs (using NOT for any input that's 0 in that row).
  • Join ALL these AND expressions together with OR — this final combined expression represents the whole truth table.

A simple 2-input example — only ONE row has output 1

  • Only the row A=1, B=0 gives an output of 1.
  • The expression: A AND NOT B (Boolean: A.B̅) — A is 1 so it's written directly; B is 0 so it needs NOT.

Two rows give output 1 — OR them together

  • Row A=0, B=1 gives: (NOT A AND B). Row A=1, B=1 gives: (A AND B).
  • Joined with OR: (NOT A AND B) OR (A AND B).

Verifying two DIFFERENT-looking expressions actually match

  • Sometimes two expressions LOOK different but produce the exact SAME output for every input — e.g. (NOT A AND B) OR (A AND B) might be claimed to equal something simpler.
  • To PROVE this, build a truth table for the alternative expression too, and compare its output column, row by row, against the original — if every row matches, the two expressions are genuinely equivalent.
  • This "build a truth table and compare" method is the standard, reliable way to verify any claimed equivalence between two logic expressions.

A 3-input example — three 1-rows, ORed into one expression

  • If rows (0,0,0), (1,0,0), and (1,1,0) each give output 1, the three individual expressions are: (NOT A AND NOT B AND NOT C), (A AND NOT B AND NOT C), (A AND B AND NOT C).
  • Joined together: (NOT A AND NOT B AND NOT C) OR (A AND NOT B AND NOT C) OR (A AND B AND NOT C).
  • The METHOD is identical regardless of how many inputs or how many 1-rows exist — just more terms get ORed together.
Practice — Test Yourself

These questions only cover what THIS subsection taught — deriving a logic expression from a truth table.

Short answer 1
Which rows of a truth table actually matter when deriving its logic expression?
Reveal answer

Only the rows where the OUTPUT is 1 — rows with output 0 are ignored entirely.

Short answer 2
If a truth table has THREE rows where the output is 1, how many AND terms will the final expression have, and how are they joined?
Reveal answer

Three AND terms (one per output-1 row), joined together with OR.

Fill in the blank pseudocode 3
For a row where A=0, B=1, C=1 gives output 1, complete the AND term: (______ A AND B AND C)
Reveal answer

(NOT A AND B AND C) — A is 0, so it needs NOT; B and C are both 1, so they're written directly.

Spot the error 4
A student writes an AND term for a row where the output is 0. What's wrong with including this term?
Reveal answer

Only rows with output 1 should contribute a term — including a 0-output row's term would make the final expression output 1 for an input combination that should genuinely give 0, making the expression wrong.

Applied / scenario 5
A truth table for inputs A, B has output 1 only when A=0, B=0, and also when A=1, B=1. Write the full logic expression.
Reveal answer

(NOT A AND NOT B) OR (A AND B) — this is, incidentally, exactly the XNOR function.

Short answer 6
How would you PROVE that two differently-written expressions actually represent the same logic?
Reveal answer

Build a truth table for each expression and compare their output columns row by row — if every row matches exactly, the two expressions are genuinely equivalent.
