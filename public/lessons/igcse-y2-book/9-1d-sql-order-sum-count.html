9.1d SQL — ORDER BY, SUM, COUNT
Sorting results, and pulling a single summary number out of a whole table.
Key Terms
ORDER BY
Sorts query results by a given field, ascending (default) or descending (DESC).
SUM
Returns the total of all values in a numeric field.
COUNT
Counts how many records match a given condition.
Theory
ORDER BY — Mr Smith's patients, alphabetically by family nameSELECT HospitalNumber, FirstName, FamilyName FROM PATIENT WHERE Consultant = 'Mr Smith' ORDER BY FamilyName;

ORDER BY — ascending by default, DESC for descending

  • ORDER BY FamilyName alone sorts in ASCENDING (A-Z, or smallest-to-largest for numbers) order — this is the default.
  • ORDER BY FamilyName DESC sorts in DESCENDING (Z-A, or largest-to-smallest) order instead.
  • Multiple fields can be given — ORDER BY Consultant, FamilyName sorts by Consultant first, and within each Consultant's group, by FamilyName.
COUNT — how many patients does Mr Smith have?SELECT COUNT(HospitalNumber) FROM PATIENT WHERE Consultant = 'Mr Smith';
SUM — total badges awarded across a whole cub scout groupSELECT SUM(Badges) FROM CUB;

Reading SUM and COUNT — one number back, not a list

  • COUNT(Field) returns HOW MANY records match — a single number, not a list of records.
  • SUM(Field) returns the TOTAL of every value in that field across all matching records — the field must be numeric (integer or real).
  • Both are used inside a SELECT — they replace naming individual fields, since the result is a calculated summary, not raw field values.
  • A WHERE clause can still be combined with COUNT/SUM — e.g. COUNT(HospitalNumber) WHERE WardNumber = 7 counts only ward-7 patients, not the whole table.
Practice — Test Yourself

These questions only cover what THIS subsection taught — ORDER BY, SUM, and COUNT.

Short answer 1
What sort order does ORDER BY use if DESC is not written?
Reveal answer

Ascending order (A-Z, or smallest-to-largest for numbers) — this is the default when DESC isn't specified.

Short answer 2
What is the key difference between what SUM and COUNT each return?
Reveal answer

SUM adds up all the VALUES in a numeric field. COUNT returns how many RECORDS match, regardless of what values are actually in any field.

Fill in the blank pseudocode 3
Complete the query to count patients NOT in ward 7: SELECT COUNT(HospitalNumber) FROM PATIENT WHERE WardNumber ______ 7;
Reveal answer

WHERE WardNumber <> 7;.

Spot the error 4
A student tries to run SELECT SUM(FamilyName) FROM PATIENT;. Why does this not make sense?
Reveal answer

SUM only works on NUMERIC fields (integer or real) — FamilyName is a text field, and text values can't be meaningfully added together.

Applied / scenario 5
Write an SQL query to list every patient's HospitalNumber, FirstName, and FamilyName, sorted by Consultant first, then by FamilyName within each consultant.
Reveal answer

SELECT HospitalNumber, FirstName, FamilyName
FROM PATIENT
ORDER BY Consultant, FamilyName;

Applied / scenario 6
A cub scout leader wants to know how many cubs are in the "red" six. Write an SQL query to count them (assume a text field called Six).
Reveal answer

SELECT COUNT(CubNumber)
FROM CUB
WHERE Six = 'red';
