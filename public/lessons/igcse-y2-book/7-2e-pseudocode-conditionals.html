7.2e Pseudocode: Conditional Statements
IF/ELSE, CASE OF, nested IFs, and every comparison operator you'll need to write them.
Key Terms
Conditional statement
A statement that performs different actions depending on a condition's value.
Nested IF
An IF statement placed inside another IF statement's THEN or ELSE path.
CASE OF
A conditional structure choosing between several specific values of one variable.
Theory

Two types of conditional statement

  • A condition that's TRUE or FALSE: IF … THEN … ELSE … ENDIF.
  • A choice between SEVERAL values: CASE OF … OTHERWISE … ENDCASE.
IF … THEN … ELSE … ENDIFIF Age < 18 THEN OUTPUT "Child" ELSE OUTPUT "Adult" ENDIF

How IF works

  • The THEN path runs if the condition is TRUE; the ELSE path runs if FALSE.
  • ELSE is OPTIONAL — an IF doesn't always need one.
  • The statement always ends with ENDIF.
  • A condition can use a BOOLEAN variable directly (e.g. IF Found THEN …), or a COMPARISON (e.g. A > B means "A is greater than B").
Comparison operators
>Greater than
<Less than
=Equal
>=Greater than or equal
<=Less than or equal
<>Not equal
ANDBoth conditions must be true
OREither condition must be true
NOTReverses a condition's truth value
A more complex conditionIF ((Height > 1) OR (Weight > 20)) AND (Age < 70) AND (Age > 5) THEN OUTPUT "You can ride" ELSE OUTPUT "Too small, too young or too old" ENDIF

Nested IF statements

  • A nested IF is an IF statement placed inside another IF's THEN or ELSE path.
  • Shown clearly with an extra level of indentation.
Worked example — validating and grading a percentage mark (nested IF)OUTPUT "Please enter a mark " INPUT PercentageMark IF PercentageMark < 0 OR PercentageMark > 100 THEN OUTPUT "Invalid Mark" ELSE IF PercentageMark > 49 THEN OUTPUT "Pass" ELSE OUTPUT "Fail" ENDIF ENDIF

The mark is only tested for pass/fail if it's genuinely in the valid 0–100 range — the second IF is nested inside the first ELSE, so it only runs when the mark wasn't rejected as invalid.

CASE OF … OTHERWISE … ENDCASE

  • The VALUE of a variable decides which path is taken.
  • OTHERWISE handles all values not explicitly listed.
  • Ends with ENDCASE.
Worked example — a simple calculator using CASE OFCASE OF Choice 1 : Answer ← Num1 + Num2 2 : Answer ← Num1 - Num2 3 : Answer ← Num1 * Num2 4 : Answer ← Num1 / Num2 OTHERWISE OUTPUT "Please enter a valid choice" ENDCASE
Practice — Test Yourself

These questions only cover what THIS subsection taught — IF and CASE OF conditional statements.

Short answer 1
Is the ELSE path in an IF statement always required?
Reveal answer

No — there may or may not be an ELSE path; it's optional.

Short answer 2
What is a "nested IF"?
Reveal answer

An IF statement placed inside another IF statement's THEN or ELSE path — shown with an extra level of indentation.

Fill in the blank pseudocode 3
Complete this comparison operator table entry: ______ means "not equal", and ______ means "greater than or equal".
Reveal answer

Blank 1: <>. Blank 2: >=.

Spot the error 4
A student writes a CASE OF statement but forgets to include an OTHERWISE path, and their test data includes a value not listed in any of the CASE branches. What real problem does this cause?
Reveal answer

Without OTHERWISE, there's no defined behaviour for values that don't match any listed branch — the algorithm doesn't specify what should happen, which is exactly the gap OTHERWISE exists to close (e.g. showing "Please enter a valid choice" for anything unexpected).

Applied / scenario 5
Re-write the nested-IF percentage mark algorithm from this lesson so it instead checks for a mark between 0 and 20, with a pass mark of 10.
Reveal answer

OUTPUT "Please enter a mark "
INPUT Mark
IF Mark < 0 OR Mark > 20
THEN
  OUTPUT "Invalid Mark"
ELSE
  IF Mark > 9
  THEN
    OUTPUT "Pass"
  ELSE
    OUTPUT "Fail"
  ENDIF
ENDIF

The valid range check changes to 0–20, and the pass condition becomes "greater than 9" (i.e. 10 or above) instead of "greater than 49".

Short answer 6
In the CASE OF calculator example, what happens if the user enters Choice = 7?
Reveal answer

Since 7 doesn't match any of the listed values (1, 2, 3, 4), the OTHERWISE path runs, outputting "Please enter a valid choice".
