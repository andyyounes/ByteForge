9.1e Building a Database with SQL (DDL)
Extension: using SQL to CREATE the database structure itself, not just query it. Completes Unit 9.
Key Terms
DDL
Data Definition Language — creates, modifies, and removes a database's STRUCTURE.
DML
Data Manipulation Language — adds, modifies, deletes, and retrieves the DATA stored in a database.
Theory
DML — working with the dataSELECT, WHERE, ORDER BY, SUM, COUNT — everything covered so far in this unit. Reads and reports on data ALREADY in the database.
DDL — working with the structureCREATE DATABASE, CREATE TABLE, ALTER TABLE, PRIMARY KEY — builds and changes the database's actual STRUCTURE (tables, fields, keys) before any data is even entered.

SQL does both jobs

  • Most Database Management Systems use SQL for BOTH DDL and DML — SQL was developed in the 1970s and has since become the industry standard.
  • AS/A Level extends this further into relational databases (multiple linked tables) — this section is an early preview for anyone considering that path.
DDL CommandDescription
CREATE DATABASECreates a new, empty database.
CREATE TABLECreates a table definition — its name and fields.
ALTER TABLEAlters an existing table's definition.
PRIMARY KEYAdds a primary key to a table.
Data TypeDescription
CHAR(n)Fixed-length text, exactly n characters.
VARCHAR(n)Variable-length text, up to a MAXIMUM of n characters.
BOOLEANTrue or False — SQL stores these as the integers 1 and 0.
INTEGERWhole number.
REALNumber with decimal places.
DATEA date, usually formatted YYYY-MM-DD.
TIMEA time, usually formatted HH:MM:SS.
Creating the CubScout database and CUB tableCREATE DATABASE CubScout CREATE TABLE CUB ( CubName VARCHAR(30), DateOfBirth DATE, Address VARCHAR(40), Gender CHAR(1), School VARCHAR(30), TelephoneNumber CHAR(14), DateJoined DATE ); ALTER TABLE CUB ADD PRIMARY KEY (CubNumber);

Reading this script, line by line

  • CREATE DATABASE CubScout — makes a brand new, empty database called CubScout.
  • CREATE TABLE CUB (...) — defines the CUB table's structure: every field's name AND data type, listed together.
  • CubName VARCHAR(30) — a variable-length text field, up to 30 characters. Gender CHAR(1) — a FIXED single character (e.g. 'M' or 'F').
  • ALTER TABLE CUB ADD PRIMARY KEY (CubNumber) — a SEPARATE statement, adding a primary key AFTER the table already exists — note CubNumber itself wasn't listed in the original CREATE TABLE, so this also implies it needs adding as a genuine field first in a real script.
Practice — Test Yourself

These questions only cover what THIS subsection taught — DDL commands and SQL data types for building a database (completes Unit 9).

Short answer 1
What is the key difference between DDL and DML?
Reveal answer

DDL creates/modifies/removes the database's STRUCTURE (tables, fields, keys). DML adds/modifies/deletes/retrieves the actual DATA stored inside that structure.

Short answer 2
What is the difference between CHAR(n) and VARCHAR(n)?
Reveal answer

CHAR(n) is a FIXED length of exactly n characters. VARCHAR(n) is a VARIABLE length, up to a maximum of n characters.

Fill in the blank pseudocode 3
Complete the DDL command that adds a primary key to an existing table: ______ TABLE CUB ADD PRIMARY KEY (CubNumber);
Reveal answer

ALTER TABLE CUB ADD PRIMARY KEY (CubNumber);.

Spot the error 4
A student defines Gender CHAR(1) but then tries to store "Male" in it. What goes wrong?
Reveal answer

CHAR(1) is a FIXED length of exactly 1 character — "Male" (4 characters) doesn't fit. Gender fields using CHAR(1) are meant for a single-letter code like 'M' or 'F', not a full word.

Applied / scenario 5
Write a DDL CREATE TABLE statement for a table called STUDENT with fields: FamilyName (VARCHAR, up to 30 characters) and DateOfBirth (DATE).
Reveal answer

CREATE TABLE STUDENT (
  FamilyName VARCHAR(30),
  DateOfBirth DATE
);

Short answer 6
How does SQL represent Boolean (True/False) values internally?
Reveal answer

As the integers 1 and 0.
