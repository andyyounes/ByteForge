Practice — Test Yourself

These questions only cover what THIS subsection taught — the six gate truth tables.

Short answer 1
What is the exact opposite gate of AND, and how does its truth table relate to AND's?
Reveal answer

NAND — every single output row is the exact opposite (flipped) of AND's corresponding row.

Short answer 2
What is the ONE row where XOR and OR give different outputs, and what does each give there?
Reveal answer

When A=1 and B=1: OR gives 1 (at least one input is 1), but XOR gives 0 (XOR needs EXACTLY one input to be 1, not both).

Fill in the blank pseudocode 3
If A=1 and B=0, what does a NOR gate output?
Reveal answer

0 — NOR only outputs 1 when BOTH inputs are 0; here A=1, so the output is 0.

Spot the error 4
A student says "XOR is just the same as OR". Give ONE input combination that proves this wrong.
Reveal answer

A=1, B=1: OR outputs 1, but XOR outputs 0 — they genuinely differ on this one combination, so they are not the same gate.

Applied / scenario 5
For A=1, B=0, work out the output of: AND, OR, NAND, NOR, and XOR.
Reveal answer

AND=0, OR=1, NAND=1, NOR=0, XOR=1.

Short answer 6
Write the Boolean algebra for a NOT gate.
Reveal answer

X = A̅ (a bar over the letter A).
