7.6a Test Data
Four kinds of test data — normal, abnormal, extreme, and boundary — for proving an algorithm actually works.
Key Terms
Test data
All the items of data required to work through a solution once.
Normal data
Data the solution would normally be expected to work with — used to prove it produces the right result.
Abnormal / erroneous data
Data that should be REJECTED — used to prove the solution correctly refuses invalid input.
Extreme data
The largest and smallest values that normal data can take — should still be accepted.
Boundary data
A pair of values straddling exactly where an accept/reject boundary lies — one accepted, one rejected.
Theory

Why test data is needed

  • To determine whether a solution works correctly, it must be TESTED — usually testing each sub-system separately before testing the whole system together.
  • Pseudocode/flowchart algorithms are tested by a person working through them by hand; programs are tested by running them on a computer — both need data to work with, and a solution often needs to be worked through SEVERAL times with different sets of test data.
  • A set of test data is all the items of data required to work through the solution once.
Worked example — recording 10 exam percentage marks and finding the average

Normal data: 50, 50, 50, 50, 50, 50, 50, 50, 50, 50 → Expected result: 50. Used to prove the solution gives the CORRECT result for data it should normally handle.

Abnormal / erroneous data: -12, eleven → Expected results: both values should be REJECTED. Used to prove the solution correctly refuses data it is NOT supposed to accept.

Extreme data: 0, 100 → Expected results: both values should be ACCEPTED (they are the largest and smallest legal marks).

Boundary data (for the lower boundary of 0): -1, 0 → Expected results: -1 is REJECTED, 0 is ACCEPTED. Boundary data always comes in a pair straddling the exact cut-off point.

Why these four types together

  • Normal data alone only proves a solution CAN work — it doesn't prove it correctly REJECTS bad data, or correctly handles the EDGES of its accepted range.
  • A thorough test uses all four types together: normal (proves it works), abnormal (proves it rejects what it should), extreme (proves the outer edges of valid data are still accepted), and boundary (proves EXACTLY where the accept/reject line falls, to one unit of precision).
Practice — Test Yourself

These questions only cover what THIS subsection taught — the four types of test data.

Short answer 1
What is a "set of test data"?
Reveal answer

All the items of data required to work through a solution once.

Short answer 2
What is the purpose of abnormal (erroneous) test data?
Reveal answer

To prove the solution correctly REJECTS data it is not supposed to accept — it should be used to show the solution does NOT do what it's not supposed to do.

Fill in the blank pseudocode / concept 3
For a mark accepted in the range 0-100, boundary data for the lower boundary is -1 and 0. -1 should be ______ and 0 should be ______.
Reveal answer

-1 should be REJECTED, and 0 should be ACCEPTED.

Spot the error 4
A student tests their percentage-mark algorithm only with the values 40, 55, 72, 88 and concludes it is fully tested. What test data types are missing?
Reveal answer

All four values given are normal data only. The student is missing abnormal/erroneous data (e.g. -5 or 150, to prove rejection), extreme data (0 and 100), and boundary data (e.g. -1/0 and 100/101) — without these, the algorithm's handling of invalid and edge-case input has not been proven at all.

Applied / scenario 5
For an algorithm accepting whole-number marks out of 20, provide boundary data for the UPPER end of the range, and state the expected result for each value.
Reveal answer

Boundary data: 20 and 21. Expected results: 20 is ACCEPTED (the highest legal mark), 21 is REJECTED (one above the legal maximum).

Applied / scenario 6
For that same out-of-20 algorithm, provide a suitable set of extreme test data and its expected results.
Reveal answer

Extreme data: 0 and 20 (the smallest and largest legal marks). Expected results: both should be ACCEPTED.
