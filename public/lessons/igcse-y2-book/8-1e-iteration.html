8.1e Iteration in Real Code
FOR and WHILE loops in Python — plus one real gap: Python has no built-in post-condition loop at all.
Key Terms
range()
Python's function for generating a sequence of numbers to loop over, e.g. range(1, 11, 2).
+=
Shorthand for "add to and reassign" — x += 1 means the same as x = x + 1.
Theory

Count-controlled loops — FOR, using range()

  • Python's range(start, stop, step) generates the sequence of values a FOR loop counts through.
  • Crucially, stop is EXCLUSIVE — range(1, 11, 2) counts 1, 3, 5, 7, 9 (stopping BEFORE 11), matching pseudocode's FOR Counter ← 1 TO 10 STEP 2 which is inclusive of 10.
FOR loop, step 2 — pseudocode vs. Python// Pseudocode — Counter from 1 to 10, in steps of 2 FOR Counter ← 1 TO 10 STEP 2 OUTPUT Counter NEXT Counter # Python — note range()'s stop value is 11, not 10, to include 10 itself for Counter in range(1, 11, 2): print(Counter)

Pre-condition loops — WHILE, checked before every iteration

  • A pre-condition loop MAY have no iterations at all — if the condition is false the very first time it's checked, the loop body never runs.
  • Python uses while with a colon and indentation, exactly like IF.
WHILE loop — pseudocode vs. Python// Pseudocode WHILE TotalWeight < 100 TotalWeight ← TotalWeight + Weight ENDWHILE # Python while TotalWeight < 100: TotalWeight = TotalWeight + Weight
Post-condition loops (REPEAT...UNTIL)Python has NO built-in post-condition loop at all — unlike pseudocode's REPEAT...UNTIL (which always runs at least once), Python only has pre-condition (while) loops.
Simulating one in PythonA while loop with a condition that's always true the first time (or a while True: with a break) is used to fake the "always run at least once" behaviour when it's genuinely needed.

Totalling and counting — mostly identical to pseudocode

  • Totalling: TotalWeight = TotalWeight + Weight — exactly the same shape as pseudocode's TotalWeight ← TotalWeight + Weight.
  • Counting: NumberOfItems = NumberOfItems + 1 works, but Python also has a shorthand: NumberOfItems += 1 means exactly the same thing.
  • += works for any amount, not just 1 — Total += Weight is a shorter way of writing the totalling line above too.
Practice — Test Yourself

These questions only cover what THIS subsection taught — FOR/WHILE loops in Python, and totalling/counting shorthand.

Short answer 1
Why does range(1, 11, 2) reach 10, and not stop at range(1, 10, 2)?
Reveal answer

Because range()'s "stop" value is EXCLUSIVE — range(1, 11, 2) counts up to but not including 11, so it needs 11 (not 10) as the stop value in order to actually include 10 in the sequence: 1, 3, 5, 7, 9.

Short answer 2
What is genuinely missing from Python, compared to pseudocode's three loop types?
Reveal answer

A built-in post-condition loop (like REPEAT...UNTIL) — Python only provides pre-condition (while) and count-controlled (for) loops natively.

Fill in the blank pseudocode 3
Complete the shorthand: NumberOfItems ______ 1 means the same as NumberOfItems = NumberOfItems + 1
Reveal answer

NumberOfItems += 1.

Spot the error 4
A student converts FOR Counter ← 1 TO 5 into Python as for Counter in range(1, 5):. What's wrong, and what SHOULD it be?
Reveal answer

range(1, 5) only produces 1, 2, 3, 4 — it stops BEFORE 5, missing the final iteration that pseudocode's inclusive TO 5 would include. It should be range(1, 6): to genuinely include 5.

Applied / scenario 5
Write the Python range() call that produces exactly the same values as pseudocode's FOR Counter ← 2 TO 20 STEP 2.
Reveal answer

for Counter in range(2, 21, 2): — start at 2, step 2, and the stop value must be 21 (one more than 20) so that 20 itself is genuinely included.

Short answer 6
Why might a Python program need to fake a "run at least once" loop using while True: with a break inside it?
Reveal answer

Because Python has no native post-condition loop — when a task genuinely needs the loop body to run at least once before any condition is checked (like validating an input the first time it's entered), a while loop alone can't naturally express that, so this pattern is used to simulate it.
