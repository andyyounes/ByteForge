10.2c Building a Circuit from an Expression
Split the expression at its OUTERMOST connector first, then build each half separately.
Theory

The strategy — the reverse of 10.2b

  • Given (A XOR C) OR (NOT C NAND B): identify the OUTERMOST connecting gate first — here, OR.
  • Build EACH half of the expression as its own separate sub-circuit: one half for (A XOR C), one half for (NOT C NAND B).
  • Finally, join the two halves together using the OR gate identified at the start.

Producing the truth table two ways — and why using BOTH is useful

  • Method 1: trace through the circuit you just built, stage by stage (as in 10.2a).
  • Method 2: produce the truth table directly from the ORIGINAL expression instead.
  • Using Method 2 as well as Method 1 gives you a genuine CHECK — if both methods agree, your circuit is very likely correct; if they disagree, you've found a mistake somewhere.

Reading the working — three intermediate stages, then combine

  • P is worked out first (A XOR C) — the LEFT half of the OR.
  • Q (NOT C) is an intermediate step needed for the RIGHT half; R (Q NAND B) is the actual right half's real value.
  • X, the final output, is P OR R — combining both halves exactly as the original expression describes.
Practice — Test Yourself

These questions only cover what THIS subsection taught — building a circuit (and its truth table) from a given logic expression.

Short answer 1
When building a circuit from an expression like (A XOR C) OR (NOT C NAND B), which gate should you identify FIRST?
Reveal answer

The OUTERMOST connecting gate — here, the OR gate joining the two bracketed halves together.

Short answer 2
Why is it useful to produce the truth table BOTH by tracing the circuit AND directly from the original expression?
Reveal answer

If both methods give the same result, it's a genuine check that the circuit you built correctly matches the expression it was supposed to represent — a mismatch would reveal a mistake in either the circuit or the working.

Fill in the blank 3
For the expression (NOT C NAND B), when C=1 and B=0: NOT C = ______, and (NOT C) NAND B = ______.
Reveal answer

NOT C = 0 (since C=1). (NOT C) NAND B = 0 NAND 0 = 1 (NAND is 1 unless BOTH inputs are 1).

Spot the error 4
A student builds a circuit for (A XOR C) OR (NOT C NAND B) but accidentally uses an AND gate instead of OR to join the two halves. How would this be caught?
Reveal answer

Tracing the (wrongly built) circuit's truth table and comparing it against the truth table produced directly from the ORIGINAL expression would reveal a mismatch on at least one row — exactly the check this two-method approach is designed to catch.

Applied / scenario 5
For the expression (A XOR C) OR (NOT C NAND B), using the table above, what is X when A=0, B=1, C=0?
Reveal answer

X = 0 (row 3 in the table).

Short answer 6
How does building a circuit from an expression relate to writing an expression from a circuit (10.2b)?
Reveal answer

They're the reverse of each other — 10.2b starts from a circuit and works OUTWARD to an expression; this lesson starts from an expression and works from the OUTERMOST gate inward to build the circuit.
