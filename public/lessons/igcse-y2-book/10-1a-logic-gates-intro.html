10.1a Logic Gates & Truth Tables
Six gates, binary in and binary out — and why the number of rows in a truth table always doubles per input.
Key Terms
Logic gate
A component that takes binary input(s) and produces a binary output, based on a fixed rule.
Logic circuit
Several logic gates combined together to carry out a specific function.
Truth table
A table listing the output for every possible combination of inputs to a gate or circuit.
Theory

Where logic gates actually live

  • Real electronic circuits in computers, solid-state drives, and controlling devices are built from THOUSANDS of logic gates.
  • Six logic gates are covered here: NOT, AND, OR, NAND, NOR, XOR. NOT has ONE input; all five others have TWO inputs.
  • A logic CIRCUIT can have more than 2 inputs overall, even though each individual GATE only ever has 1 or 2.

Why the number of rows in a truth table doubles per input

  • 2 inputs → 2² = 4 possible combinations. 3 inputs → 2³ = 8 combinations. 4 inputs → 2⁴ = 16 combinations.
  • Every input is either 0 or 1 — the number of possible combinations is always a power of 2, since each extra input DOUBLES the number of ways the existing combinations can occur (once with the new input at 0, once at 1).
  • A truth table lists the OUTPUT for every single one of these combinations, not just a few examples.

  • The table above shows all 8 combinations for 3 inputs (A, B, C) — notice the rightmost column alternates every row, the middle column every 2 rows, and the leftmost every 4 rows. Following this pattern guarantees every combination is listed exactly once, with none missed or repeated.

Boolean algebra — an alternative notation you'll see online

  • Boolean algebra uses symbols instead of words: . means AND, + means OR, and a bar OVER a letter means NOT (e.g. A̅ means "NOT A").
  • This is optional for IGCSE — logic notation (AND, OR, NOT written out) is used throughout this course — but Boolean algebra appears constantly on real logic-gate websites, so recognising it is worth knowing.
Practice — Test Yourself

These questions only cover what THIS subsection taught — logic gates, circuits, and truth table combinatorics.

Short answer 1
Which of the six logic gates has only ONE input, unlike all the others?
Reveal answer

The NOT gate.

Short answer 2
How many rows would a truth table need for 4 inputs?
Reveal answer

2⁴ = 16 rows.

Fill in the blank 3
In Boolean algebra, the symbol . means ______, and + means ______.
Reveal answer

. means AND; + means OR.

Spot the error 4
A student builds a truth table for 3 inputs but only lists 6 rows. What's wrong?
Reveal answer

3 inputs require 2³ = 8 rows to cover every possible combination — 6 rows means at least 2 real combinations were missed entirely.

Applied / scenario 5
How many rows would a truth table need for a logic circuit with 5 inputs?
Reveal answer

2⁵ = 32 rows.

Short answer 6
Can a single logic GATE (not a whole circuit) have more than 2 inputs, per this course?
Reveal answer

No — each individual gate has at most 2 inputs (or 1, for NOT). More than 2 overall inputs only happens when several gates are combined together into a full logic CIRCUIT.
