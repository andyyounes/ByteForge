8.1b Input and Output in Real Code
Prompts, casting, and separators — a complete real Python program, built from ideas you already know.
Key Terms
Prompt
A message telling the user exactly what they're expected to input.
Casting
Converting a value from one data type to another, e.g. text input into a real number.
Separator
A character (like a comma) that separates the different parts of an output statement.
Theory

Every input needs a prompt

  • For a program to be useful, the user needs to know what they're expected to type — every input should be accompanied by a prompt explaining what's required.
  • ALL input defaults to a string, in every language — so if the input should actually be an integer or a real number, it must be explicitly CONVERTED (cast) afterwards.
  • In Python, int() converts a string to an integer, and float() converts a string to a real number.
Input with a prompt — pseudocode vs. Python// Pseudocode OUTPUT "Please enter the radius of the cylinder " INPUT Radius # Python — the prompt and the cast happen together, in one line radius = float(input("Please enter the radius of the cylinder "))

Output needs a message too, and a separator between parts

  • Every output should be accompanied by a message explaining what the result actually IS — a lone number with no label isn't useful to a user.
  • If an output statement has several parts, each part needs a separator character between them.
  • In pseudocode, OUTPUT parts are separated by commas. Python's print() also uses commas between its parts.
Output with a message — pseudocode vs. Python// Pseudocode OUTPUT "Volume of the cylinder is ", Volume # Python print("Volume of the cylinder is ", volume)

A complete worked program — volume of a cylinder

  • This combines everything from 8.1a and 8.1b: a constant, two variables, two prompted+cast inputs, a calculation, and a labelled output.
Pseudocode — volume of a cylinderCONSTANT Pi ← 3.142 DECLARE Radius, Length, Volume : REAL OUTPUT "Please enter the radius of the cylinder " INPUT Radius OUTPUT "Please enter the length of the cylinder " INPUT Length Volume ← Radius * Radius * Length * Pi OUTPUT "Volume of the cylinder is ", Volume
Python — the exact same programCONSTPI = 3.142 Radius = float(input("Please enter the radius of the cylinder ")) Length = float(input("Please enter the length of the cylinder ")) Volume = Radius * Radius * Length * CONSTPI print("Volume of the cylinder is ", Volume)

Reading the correspondence, line by line

  • Pseudocode's separate DECLARE lines simply don't exist in Python — Python decides each variable's type automatically the moment a value is first assigned to it.
  • Pseudocode's OUTPUT "..." then INPUT Radius (two lines) become Python's single line combining the prompt AND the cast: float(input("...")).
  • The actual calculation line is IDENTICAL in both — * means multiply in both pseudocode and Python.
Practice — Test Yourself

These questions only cover what THIS subsection taught — input/output statements and casting.

Short answer 1
Why does every single input, in every language, default to a string?
Reveal answer

Because raw keyboard input is just characters typed by the user — the program has no way to know in advance what "kind" of value was intended, so it treats it as text (a string) by default until explicitly told otherwise via casting.

Short answer 2
What does "casting" mean in this context?
Reveal answer

Converting a value from one data type to another — e.g. converting a string like "3.5" typed by the user into an actual real number 3.5 that can be used in a calculation.

Fill in the blank pseudocode 3
Complete the Python line that prompts for and casts an integer age: age = ______(input("Please enter your age "))
Reveal answer

age = int(input("Please enter your age ")).

Spot the error 4
A student writes radius = input("Please enter the radius ") and then tries to use radius directly in a multiplication. What goes wrong, and why?
Reveal answer

Without casting, radius is still a STRING (input always defaults to string), not a real number — multiplying strings doesn't work the way multiplying numbers does, so the calculation would fail or behave unexpectedly. The fix is wrapping it: radius = float(input(...)).

Applied / scenario 5
Write pseudocode AND Python for prompting the user for their name (a string — no casting needed) and outputting "Hello, " followed by their name.
Reveal answer

Pseudocode: OUTPUT "Please enter your name "
INPUT Name
OUTPUT "Hello, ", Name

Python: name = input("Please enter your name ")
print("Hello, ", name)

Short answer 6
Why doesn't the "Hello, [name]" example in Question 5 need any casting?
Reveal answer

Because a name is already a STRING — and input already defaults to a string — so no conversion is needed. Casting is only needed when the required type is something OTHER than a string, like an integer or real number.
