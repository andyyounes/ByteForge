IGCSE Year 2 · Unit 10 · Logic Gates
10.2b Writing a Logic Expression from a Circuit
Work from the inputs inward, naming each gate's own expression before combining them.
Theory

The strategy — inputs first, then work toward the output

  • Start with the gates directly connected to the ORIGINAL inputs — write down each of THEIR expressions first.
  • Then work toward the output, substituting each earlier expression into the gate that uses it.

Worked example — three gates, one XOR combining two smaller results

  • Gate 1 (AND) is connected to inputs A and B: (A AND B).
  • Gate 2 (OR) is connected to inputs B and C: (B OR C).
  • Gate 3 (XOR) joins gate 1's result and gate 2's result together: (A AND B) XOR (B OR C).
  • Square brackets can be added purely for clarity — [(A AND B)] XOR [(B OR C)] — but they aren't strictly necessary once the expression is unambiguous.

A harder case — a gate feeding directly INTO another internal gate

  • Sometimes a gate's output feeds into ANOTHER internal gate, which ALSO uses one of the original inputs directly.
  • Example: gate 1 = (A NAND C), gate 2 = (B AND C). Gate 3 combines gate 1's result WITH the original input A: (gate 1) NOR A — substituting gives ((A NAND C) NOR A).
  • Finally, gate 4 joins THAT result with gate 2's result: ((A NAND C) NOR A) OR (B AND C).
  • The key skill: work out which gates are "ready" first (only using original inputs), then keep substituting completed expressions into whichever gate needs them next, working steadily toward the final output.
Practice — Test Yourself

These questions only cover what THIS subsection taught — writing a logic expression from a circuit diagram.

Short answer 1
Which gates in a circuit should you write an expression for FIRST?
Reveal answer

The gates connected DIRECTLY to the original inputs — those don't depend on any other gate's result, so they can be written immediately.

Short answer 2
In the worked example, what expression represents gate 1 (an AND gate using inputs A and B)?
Reveal answer

(A AND B).

Fill in the blank pseudocode 3
If gate 1 = (A OR B) and gate 2 (an AND gate) combines gate 1's result with input C, what is gate 2's full expression?
Reveal answer

(A OR B) AND C.

Spot the error 4
A student tries to write the final gate's expression BEFORE working out the expressions for the gates feeding into it. Why does this go wrong?
Reveal answer

The final gate's expression depends entirely on substituting in the ALREADY-SOLVED expressions from the gates before it — without those, there's nothing concrete to write in its place, and the expression can't be completed correctly.

Applied / scenario 5
A circuit has: gate 1 (NOR) using A and B; gate 2 (AND) combining gate 1's result with input C. Write gate 2's full expression.
Reveal answer

(A NOR B) AND C.

Short answer 6
Are the square brackets used for clarity in some expressions, like [(A AND B)] XOR [(B OR C)], strictly necessary?
Reveal answer

No — they're optional, added purely to make the expression easier to read. The plain round brackets alone, e.g. (A AND B) XOR (B OR C), are unambiguous on their own.
