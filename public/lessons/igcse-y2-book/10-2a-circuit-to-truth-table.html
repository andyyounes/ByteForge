10.2a Tracing a Circuit into a Truth Table
Split the circuit into stages, solve each stage's own mini truth table, then combine them.
Key Terms
Intermediate value
The output of an internal gate partway through a circuit — not a final input or the final output.
Theory

The strategy — split the circuit into parts

  • A 3-input circuit needs 8 rows in its truth table. Rather than tracing the WHOLE circuit at once, split it into parts (following each gate's wiring), giving each part its own intermediate output label (e.g. P, Q, R).
  • Solve each part's mini truth table one at a time, then combine them into the final table.

Part 1 — the first two gates, using the original inputs A, B, C

  • P comes from an AND gate with inputs A and B.
  • Q comes from a NOR gate with inputs B and C.

Practice — Test Yourself

These questions only cover what THIS subsection taught — tracing a multi-gate circuit into a truth table.

Short answer 1
Why is it useful to split a complex circuit into parts, using intermediate labels like P, Q, R?
Reveal answer

It breaks one hard problem into several small, manageable ones — each part only needs its OWN simple 2-input truth table solved, rather than trying to work out the whole complex circuit's behaviour all at once.

Short answer 2
In Part 2 (combining P and Q), why does the table still need all 8 rows even though the OR gate only has 2 inputs?
Reveal answer

Because P and Q's VALUES already differ across all 8 of the original A/B/C combinations from Part 1 — the OR gate must be evaluated separately for every one of those 8 rows, even though it only ever looks at 2 values (P and Q) at a time.

Fill in the blank 3
When A=1, B=1, C=0: P = A AND B = ______, Q = B NOR C = ______.
Reveal answer

P = 1 (both A and B are 1). Q = 0 (B is 1, so NOR — which needs BOTH inputs to be 0 — gives 0).

Spot the error 4
A student computes the final X column directly from A, B, C, skipping P, Q, R entirely — and gets one row wrong. Why does keeping the intermediate columns help avoid this?
Reveal answer

Working through P, Q, and R one gate at a time means each step is a simple, checkable 1-2 input gate — skipping straight to X requires holding the ENTIRE circuit's logic in your head at once, which is far more error-prone, especially before you're confident with the method.

Applied / scenario 5
Using the final table above, what is X when A=0, B=1, C=1?
Reveal answer

X = 1 (row 4 in the final table).

Short answer 6
Is it acceptable to remove the intermediate P/Q/R columns from the final answer?
Reveal answer

Yes — once the working is done, it's optional to leave a clean final table showing only A, B, C, and X. Keeping the intermediates is good practice while learning, but not required in the final answer.
