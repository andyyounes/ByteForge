9.1a Database Structure — Tables, Records & Fields
Every record is a row. Every field is a column. That's the whole structure.
Key Terms
Table
Holds data about ONE type of item, person, or event — given a meaningful name.
Record
One row in a table — all the data about a single item, person, or event.
Field
One column in a table — one specific piece of information, present in every record.
Theory

The easy way to remember the structure

  • Data is stored in TABLES, made up of many RECORDS. Each record consists of several FIELDS.
  • Each RECORD is a ROW in the table. Each FIELD is a COLUMN in the table.
  • The NUMBER of records varies — records can be added or deleted at any time. The number of FIELDS is FIXED — every record in a table has exactly the same set of fields.
  • This course only covers databases containing a SINGLE table (multi-table "relational" databases are covered at A Level).

A real example — the PATIENT table

  • A table holding hospital patient data might be called PATIENT. Each RECORD would be data about ONE patient (e.g. "Winnie Sing").
  • Each field has a meaningful name, matching what it actually stores: FirstName, FamilyName, DateOfAdmission, Consultant, WardNumber, BedNumber.

The one strict naming rule

  • Field names must be a SINGLE word, with NO spaces — e.g. BedNumber, not "Bed Number".
  • This is why field names are usually written in "CamelCase" (each new word starting with a capital letter, no spaces) rather than separate words.
Practice — Test Yourself

These questions only cover what THIS subsection taught — tables, records, and fields.

Short answer 1
What is the relationship between a record and a row, and between a field and a column?
Reveal answer

Each record IS a row in the table; each field IS a column in the table.

Short answer 2
Why is the number of records in a table variable, but the number of fields fixed?
Reveal answer

Records can be added or deleted at any time as real data changes (a new patient is admitted, one is discharged) — but every record must have the exact SAME set of fields, so the structure of what information is stored per record doesn't change.

Fill in the blank 3
A field name must be a single ______, with no ______.
Reveal answer

A single WORD, with no SPACES.

Spot the error 4
A student names a field "Date Of Admission" (with spaces). Why is this a problem for a real field name?
Reveal answer

Field names must be a single word with no spaces — the correct form would be DateOfAdmission (CamelCase, no spaces).

Applied / scenario 5
A doctor's appointment table needs to record which patient, which doctor, the date, and the time. Suggest four suitable field names.
Reveal answer

Any reasonable single-word (no-space) names work, e.g. PatientName, DoctorName, AppointmentDate, AppointmentTime.

Short answer 6
What kind of database does this course focus on, and what's the more complex alternative (covered at A Level)?
Reveal answer

A single-TABLE database. The more complex alternative is a RELATIONAL database, containing multiple linked tables — covered at AS/A Level.
