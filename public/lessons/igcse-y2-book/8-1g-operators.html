8.1g Arithmetic, Logical & Boolean Operators
The exact symbols Python expects — and the two that quietly differ from pseudocode.
Key Terms
Arithmetic operator
A symbol used to perform a calculation — add, subtract, multiply, divide, power.
Logical operator
A symbol used to compare two values — greater than, less than, equal to, etc.
Boolean operator
A word used to combine or invert TRUE/FALSE conditions: AND, OR, NOT.

The one arithmetic symbol that actually differs

  • +, -, *, and / are identical in pseudocode and Python.
  • "Raised to the power of" is written ^ in pseudocode, but ** in Python — e.g. 2 cubed is 2 ^ 3 in pseudocode, but 2 ** 3 in Python.
  • Expressions can be grouped with brackets in both, exactly the same way: ((x + y) * 3) / Pi.

The two comparisons that actually change in Python

  • "Equal to" is a SINGLE = in pseudocode, but a DOUBLE == in Python — because Python already uses a single = for assignment, and needs a different symbol to mean comparison.
  • "Not equal" is <> in pseudocode, but != in Python.
  • Greater/less than (with or without "or equal") are IDENTICAL in both.

Boolean operators — same words, just lowercase in Python

  • AND, OR, and NOT work exactly the same way conceptually in both — Python just writes them in lowercase (and, or, not) rather than capitals.
  • Example: IF Age >= 13 AND Age <= 19 (pseudocode) becomes if Age >= 13 and Age <= 19: (Python) — checking someone is a genuine teenager.
Practice — Test Yourself

These questions only cover what THIS subsection taught — arithmetic, logical, and Boolean operators in pseudocode vs. Python.

Short answer 1
Which single arithmetic operation is written differently in Python compared to pseudocode, and how?
Reveal answer

"Raised to the power of" — pseudocode uses ^, Python uses **.

Short answer 2
Why does Python need TWO equals signs (==) to mean "equal to", instead of just one?
Reveal answer

Because a single = in Python already means ASSIGNMENT (storing a value into a variable) — a separate symbol, ==, is needed to mean comparison, so the two operations can never be confused.

Fill in the blank pseudocode 3
Complete the Python "not equal" comparison: if Score ______ 0:
Reveal answer

if Score != 0:.

Spot the error 4
A student converts pseudocode's 2 ^ 3 (2 cubed) directly into Python as 2 ^ 3. Why won't this give the expected result of 8?
Reveal answer

Python's ^ is NOT the power operator — it means something entirely different (a bitwise XOR operation). The correct Python power operator is **, so it should be written as 2 ** 3.

Short answer 6
Which comparison operators are IDENTICAL between pseudocode and Python (no change at all)?
Reveal answer

Greater than (>), less than (<), greater than or equal (>=), and less than or equal (<=) — only "equal to" and "not equal" actually change.
