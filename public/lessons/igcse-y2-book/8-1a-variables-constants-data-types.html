8.1a Variables, Constants & Data Types
From pseudocode to real code — the same ideas Chapter 7 taught, now with genuine Python syntax alongside.
Key Terms
Variable
A named data store whose value MAY change while the program runs.
Constant
A named data store whose value does NOT change while the program runs.
Explicit declaration
Stating the exact data type of a variable/constant up front (pseudocode requires this for variables).
Implicit declaration
The data type is decided automatically from the value assigned (Python works this way).
Theory

Five basic constructs of any program

  • Data use — variables, constants, and arrays.
  • Sequence — the order steps happen in.
  • Selection — choosing a path through the program (IF, CASE).
  • Iteration — repeating a sequence of steps (loops).
  • Operator use — arithmetic for calculations, logical/Boolean for decisions.

Variables vs. constants — same idea, different rule

  • A variable holds a value that MAY change while the program runs. A constant holds a value that must NOT change once set.
  • Both should always be given MEANINGFUL names, so the program stays understandable to someone else (or to you, later).
  • Not every language enforces the difference in code — Python doesn't technically stop you reassigning a "constant" — but a good programmer stays clear about which data stores are meant to change and which aren't, regardless of what the language enforces. A common convention: write constant names in ALL CAPS as a signal, even in a language that doesn't require it.
Pseudocode — explicitVariables are explicitly typed; constants are written directly.DECLARE FirstVar : INTEGER DECLARE SecondVar : INTEGER CONSTANT FirstConst ← 500 CONSTANT SecondConst ← 100
Python — implicitNo separate declaration at all — the type is decided by whatever value is assigned. No built-in distinction between variables and constants.FirstVar = 20 SecondVar = 30 FIRSTCONST = 500 SECONDCONST = 100

The five basic data types

  • Integer — a positive or negative WHOLE number, usable with mathematical operators.
  • Real — a positive or negative number with a fractional (decimal) part, also usable with mathematical operators.
  • Char — a single character.
  • String — several characters in length; can even be empty (an "empty string"). A number STORED as a string cannot be used directly in a calculation.
  • Boolean — only ever TRUE or FALSE.

Why this matters beyond just "labelling" data

  • Correct data types let data be stored appropriately (numbers as numbers, characters as characters).
  • They let data be manipulated correctly — numbers with mathematical operators, strings with concatenation (joining text together).
  • They also enable automatic validation in some cases — e.g. a program can refuse to store text where an integer is expected.
Practice — Test Yourself

These questions only cover what THIS subsection taught — variables, constants, and the five basic data types.

Short answer 1
What is the key difference between a variable and a constant?
Reveal answer

A variable's value MAY change while the program runs; a constant's value must NOT change once it's set.

Short answer 2
What is the difference between explicit and implicit declaration?
Reveal answer

Explicit declaration states the exact data type up front (pseudocode's DECLARE ... : INTEGER). Implicit declaration decides the type automatically from whatever value is assigned (how Python works — no separate declaration at all).

Fill in the blank pseudocode 3
Which of the five data types would each of these use? "F" for female → ______. -3.5 → ______. "Hello World" → ______.
Reveal answer

"F" → CHAR (a single character). -3.5 → REAL (a number with a fractional part). "Hello World" → STRING (several characters).

Spot the error 4
A student stores a phone number like "0712345678" as an INTEGER instead of a STRING. What real problem does this cause?
Reveal answer

A leading zero is meaningless in an integer — 0712345678 stored as an integer would silently become 712345678, dropping the leading zero and corrupting the phone number. Data that is never actually used in a calculation (like a phone number) should usually be stored as a string.

Applied / scenario 5
Write the pseudocode DECLARE statements for two variables needed to calculate the volume of a cylinder: Radius and Length (both REAL), plus a constant Pi.
Reveal answer

DECLARE Radius : REAL
DECLARE Length : REAL
CONSTANT Pi ← 3.142

Short answer 6
Even though Python doesn't enforce a difference between variables and constants, why might a programmer still write a constant's name in ALL CAPS?
Reveal answer

To signal to anyone reading the code (including themselves later) that this value is intended to never change, even though Python itself won't stop it from being reassigned — a readability convention, not an enforced rule.
