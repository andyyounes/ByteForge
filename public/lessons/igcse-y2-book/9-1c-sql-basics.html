9.1c SQL Basics — SELECT, FROM, WHERE
SQL — pronounced "es-queue-el" — the standard language for asking a database exactly what you need.
Key Terms
SQL
Structured Query Language — the standard language for querying a database.
SQL script
A list of SQL commands performing a given task, often saved to a file to be reused.
Theory

Why SQL exists — only ask for what you actually need

  • Someone visiting a patient only needs their ward and bed number. A consultant needs a list of all THEIR patients' names. SQL lets each of these very different needs be answered from the SAME table.
  • An SQL command always STARTS with SELECT and ends with a semicolon ;. Only SELECT and FROM are mandatory — everything else is optional.

SELECT — specific fields, or everything-- specific fields, in the order you want them shown SELECT FirstName, FamilyName, WardNumber FROM PATIENT; -- every field SELECT * FROM PATIENT;

WHERE — filtering to only the records you need

  • Without a WHERE clause, a query returns EVERY record in the table. WHERE narrows it down to only records matching a condition.
  • Values in a WHERE condition must match the field's data type EXACTLY.

Example — all of Mr Smith's patientsSELECT HospitalNumber, FirstName, FamilyName FROM PATIENT WHERE Consultant = 'Mr Smith';

Reading this query, line by line

  • SELECT HospitalNumber, FirstName, FamilyName — only show these THREE fields, not every field in the table.
  • FROM PATIENT — look in the PATIENT table.
  • WHERE Consultant = 'Mr Smith' — only include records where the Consultant field exactly matches 'Mr Smith' (quoted, since it's a text field).
  • The result: a list showing just those three fields, for just the patients under Mr Smith's care — nothing else from the table is shown or considered.
Practice — Test Yourself

These questions only cover what THIS subsection taught — SELECT, FROM, WHERE, and comparison operators.

Short answer 1
Which two SQL clauses are mandatory in every query?
Reveal answer

SELECT and FROM — every other clause (WHERE, ORDER BY, etc.) is optional.

Short answer 2
What does SELECT * mean?
Reveal answer

It selects EVERY field (column) in the table, rather than naming specific ones.

Fill in the blank pseudocode 3
Complete this query to find patients in ward 6: SELECT * FROM PATIENT WHERE WardNumber ______ 6;
Reveal answer

WHERE WardNumber = 6; — no quotes, since WardNumber is an integer field.

Spot the error 4
A student writes WHERE Consultant = Mr Smith; (without quotation marks around Mr Smith). What's wrong?
Reveal answer

Text field values in a condition must be enclosed in single quotation marks — it should be WHERE Consultant = 'Mr Smith';. Without quotes, the query would try to interpret "Mr" and "Smith" as something other than a text value, and would fail.

Applied / scenario 5
Write an SQL query to list the FirstName, FamilyName, and BedNumber of every patient NOT in ward 6.
Reveal answer

SELECT FirstName, FamilyName, BedNumber
FROM PATIENT
WHERE WardNumber <> 6;

Applied / scenario 6
Write an SQL query to list every patient who arrived between 12/10/2022 and 30/10/2022 (use BETWEEN).
Reveal answer

SELECT *
FROM PATIENT
WHERE DateOfAdmission BETWEEN '12/10/2022' AND '30/10/2022';
