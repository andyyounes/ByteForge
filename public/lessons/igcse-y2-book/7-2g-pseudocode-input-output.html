7.2g Pseudocode: Input & Output Statements
INPUT, OUTPUT — and when READ and PRINT quietly take their place — completing the pseudocode toolkit.
Key Terms
INPUT
Reads data entry into a named variable.
OUTPUT
Displays information — a string, a variable, or several values separated by commas.
READ / PRINT
Alternative keywords: READ for reading from a file, PRINT when a hard (paper) copy is needed.
Theory

INPUT and OUTPUT

  • INPUT and OUTPUT handle data entry and displaying information.
  • READ can replace INPUT — usually for reading data FROM A FILE.
  • PRINT can replace OUTPUT — when a HARD COPY (paper) is needed.
INPUT — usually followed by the variable storing the entered dataINPUT Name INPUT StudentMark
OUTPUT — a single value, or several separated by commasOUTPUT Name OUTPUT "Your name is ", Name OUTPUT Name1, "Ali", Name3
Practice — Test Yourself

These questions only cover what THIS subsection taught — pseudocode input/output statements.

Short answer 1
When would READ be used instead of INPUT?
Reveal answer

When reading data FROM A FILE, rather than from the user directly.

Short answer 2
When would PRINT be used instead of OUTPUT?
Reveal answer

When a HARD COPY (a paper printout) of the information is required.

Fill in the blank pseudocode 3
Complete this line to output the string "Total: " followed by the value of a variable called Total: OUTPUT ______
Reveal answer

OUTPUT "Total: ", Total — multiple values (a string and a variable) are separated by commas.

Spot the error 4
A student writes OUTPUT Name1 "Ali" Name3 with no separators between the values. What's wrong with this?
Reveal answer

Multiple values in an OUTPUT statement must be separated by COMMAS — it should read OUTPUT Name1, "Ali", Name3.

Applied / scenario 5
Write a pseudocode INPUT statement that reads a value into a variable called Age, and an OUTPUT statement that displays "Your age is " followed by that value.
Reveal answer

INPUT Age
OUTPUT "Your age is ", Age

Short answer 6
What is INPUT usually followed by?
Reveal answer

A variable, where the data being entered is stored.
