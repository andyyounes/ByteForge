7.9c Stacks and Queues
Extension: an early look at Abstract Data Types, for anyone considering A Level Computer Science.
Key Terms
Abstract Data Type (ADT)
A collection of data PLUS a set of operations that work on that data.
Stack (LIFO)
Last In, First Out — the most recently added item is always the first one removed.
Queue (FIFO)
First In, First Out — the earliest added item is always the first one removed.
Push / Pop
Push adds an item to a stack; pop removes the most recently added item from it.
Enqueue / Dequeue
Enqueue adds an item to a queue; dequeue removes the earliest-added item from it.
Theory

What an ADT actually is

  • An Abstract Data Type is a collection of data AND a defined set of operations that work on it — the operations are just as much part of the ADT as the data itself.
  • Stacks and queues are two of the simplest, most common ADTs — both store a LIST of items, but they remove items in completely different ORDERS.

Stack — Last In, First Out

  • Items are added to a stack with push, and removed with pop.
  • In the example above, 27 was pushed first, then 82, then 34, then 79 — a Top Pointer always tracks whichever item was added most recently.
  • A pop always removes whatever is currently on TOP — so popping removes 79 first, even though it's the most recent addition, not the oldest.
  • A push always adds the new item to the top — after popping 79 off, pushing 31 places it on top of 34 (the new top), NOT at the bottom.
  • The Base Pointer (the bottom of the stack) never changes during stack operations — only the Top Pointer moves.

Queue — First In, First Out

  • Items are added to a queue with enqueue, and removed with dequeue.
  • A Front Pointer tracks the item that will be removed NEXT; an End Pointer tracks where the next new item will be added.
  • Dequeue always removes whichever item is at the FRONT — the item that has been waiting longest, exactly like a real queue of people.
  • Enqueue always adds the new item at the END — behind everyone already waiting.
  • Unlike a stack (where only the Top Pointer moves), BOTH the Front Pointer and the End Pointer change during queue operations — dequeue moves the front pointer forward, enqueue moves the end pointer forward.

A real-world way to remember the difference

  • A stack is like a pile of plates — you can only take the top one off, and any new plate goes on top. The plate at the very bottom could sit there for a very long time if plates keep getting added and removed from the top.
  • A queue is like a real queue of people waiting in line — the person who arrived FIRST is served first, and new arrivals join at the back.
Practice — Test Yourself

These questions only cover what THIS subsection taught — stacks, queues, and their operations.

Short answer 1
What does an Abstract Data Type consist of?
Reveal answer

A collection of data, PLUS a defined set of operations that work on that data.

Short answer 2
What do the abbreviations LIFO and FIFO stand for, and which structure does each describe?
Reveal answer

LIFO = Last In, First Out — describes a stack. FIFO = First In, First Out — describes a queue.

Fill in the blank 3
Adding an item to a stack is called ______; removing an item from a stack is called ______.
Reveal answer

Adding = push; removing = pop.

Spot the error 4
A student says: "In both a stack and a queue, adding a new item always changes both pointers." Explain what's wrong with this statement.
Reveal answer

This is only true for a queue (enqueue changes the End Pointer; dequeue changes the Front Pointer — both pointers move over time). For a STACK, the Base Pointer never changes during push or pop — only the Top Pointer ever moves.

Applied / scenario 5
Items are pushed onto an empty stack in this order: A, B, C, D. What order would they be popped off in?
Reveal answer

D, C, B, A — the reverse of the order they were pushed, since a stack is Last In, First Out.

Applied / scenario 6
The same items — A, B, C, D — are enqueued in that order onto an empty queue instead. What order would they be dequeued in?
Reveal answer

A, B, C, D — the SAME order they were added, since a queue is First In, First Out.
