7.3a Explaining the Purpose of an Algorithm
Reading someone else's flowchart or pseudocode and correctly stating what it actually does.
Theory

What this skill involves

  • An algorithm sets out the steps to complete a task — usually shown as a flowchart or pseudocode.
  • Being able to explain an algorithm's PURPOSE means clearly identifying what the task is, and what PROCESSES are needed to complete it, just by reading it.
  • This skill improves with practice at writing algorithms, and at finding/correcting errors in them.
Worked example — what does this pseudocode do?REPEAT Wait (10) Get (Time) UNTIL Time = Alarm_Time OUTPUT AlarmSound

Explaining the example above

  • Purpose: output the alarm sound at the correct time.
  • Processes: waiting 10 seconds; getting the current time (from the system clock); checking the current time against the alarm time; outputting the alarm sound once they match.
A second algorithm to explainINPUT Num1, Num2 IF Num1 > Num2 THEN PRINT Num1, " is largest" ELSE PRINT Num2, " is largest" ENDIF
The matching flowchart for the "largest of two numbers" algorithm.

Explaining the "largest number" example

  • Purpose: find and display whichever of two entered numbers is larger.
  • Processes: input two numbers; compare them; output whichever one is larger, labelled "is largest".
  • If 7 and 18 were entered: since Num1 (7) is NOT greater than Num2 (18), the ELSE path runs, outputting 18 is largest.
Practice — Test Yourself

These questions only cover what THIS subsection taught — explaining the purpose of an algorithm.

Short answer 1
What is the purpose of the alarm-checking algorithm shown in this lesson?
Reveal answer

To output the alarm sound at the correct time — repeatedly checking the current time against the set alarm time until they match.

Short answer 2
What would the "largest number" algorithm output if Num1 = 25 and Num2 = 12?
Reveal answer

25 is largest — since Num1 (25) IS greater than Num2 (12), the THEN path runs.

Fill in the blank 3
Explaining an algorithm's purpose means identifying WHAT the task is, and the ______ needed to complete it.
Reveal answer

Processes.

Spot the error 4
A student says the alarm algorithm's purpose is "to wait 10 seconds". What's wrong with describing it this way?
Reveal answer

"Wait 10 seconds" is only ONE of several PROCESSES within the algorithm, not its overall PURPOSE. The actual purpose is to output the alarm sound at the correct time — waiting is just a step used to repeatedly check the time until it matches.

Applied / scenario 5
Using the "largest number" algorithm from this lesson, what would be output if the numbers 7 and 18 were entered?
Reveal answer

18 is largest — since Num1 (7) is NOT greater than Num2 (18), the condition is false, so the ELSE path runs and outputs Num2.

Short answer 6
Name two forms an algorithm is usually shown in, so its purpose is clear to others.
Reveal answer

A flowchart, or pseudocode.
