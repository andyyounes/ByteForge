7.2d Pseudocode: Conventions & Assignment Statements
The exact house style this book's — and the exam's — pseudocode follows, plus how a value actually gets assigned to a variable.
Key Terms
Pseudocode
A way of describing an algorithm using English-like keywords, without a real language's strict syntax rules.
Assignment
Giving a variable a value, using the ← operator.
Keyword
A word describing a specific pseudocode action (e.g. INPUT), always written in capitals.
Theory

What pseudocode is

  • A simple way of describing an algorithm using English keywords SIMILAR to a high-level language.
  • Data items are given meaningful names, just like variables/constants in real code.
  • UNLIKE real code, pseudocode isn't bound by strict syntax rules — it "pretends" to be programming code.

This book's pseudocode conventions (matching the IGCSE syllabus)

  • A non-proportional (monospace) font is used throughout.
  • All KEYWORDS (e.g. INPUT) are written in CAPITAL letters.
  • All names given to data items and subroutines start with a CAPITAL letter.
  • Conditional and loop statements have their repeated/selected lines indented by TWO spaces.

Assignment statements

  • A value is assigned to a variable using the ← operator.
  • The variable on the LEFT of ← gets the value of the expression on the RIGHT.
  • The right-hand expression can be a single value, or several values combined with mathematical operators.

+Add
−Subtract

Worked example — assignment statements, step by stepCost ← 10 // Cost has the value 10 Price ← Cost * 2 // Price has the value 20 Tax ← Price * 0.12 // Tax has the value 2.4 SellingPrice ← Price + Tax // SellingPrice has the value 22.4 Gender ← "M" // Gender has the value M Chosen ← False // Chosen has the value False
Practice — Test Yourself

These questions only cover what THIS subsection taught — pseudocode conventions and assignment statements.

Short answer 1
How are pseudocode keywords (like INPUT or OUTPUT) always written, according to this book's conventions?
Reveal answer

In CAPITAL letters.

Short answer 2
In an assignment statement like Price ← Cost * 2, which side gets its value updated?
Reveal answer

The variable on the LEFT of the ← (here, Price) is given the value calculated from the expression on the right.

Fill in the blank pseudocode 3
Given Cost ← 10 and Price ← Cost * 2, what value does Price end up with?
Reveal answer

Price = 20 (10 × 2).

Spot the error 4
A student writes: input Name as a pseudocode line, in lowercase. What convention does this break?
Reveal answer

Keywords must be written in CAPITAL letters — it should be INPUT Name, not input Name. (The variable name, "Name", is correctly capitalised, but the keyword itself is not.)

Applied / scenario 5
Trace through the following assignment statements and state the final value of each variable:
Amount ← 100
TotalPrice ← Amount * 3.5
Discount ← 0.2
FinalPrice ← TotalPrice – TotalPrice * Discount
Reveal answer

Amount = 100. TotalPrice = 100 × 3.5 = 350. Discount = 0.2. FinalPrice = 350 − (350 × 0.2) = 350 − 70 = 280.

Short answer 6
How many spaces should repeated or selected statements (inside a loop or conditional) be indented by, according to this book's conventions?
Reveal answer

Two spaces.
