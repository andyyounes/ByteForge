8.1d Selection in Real Code
IF and CASE, exactly as taught in Chapter 7 — now written the way Python actually expects them.
Key Terms
elif
Python's keyword for "else if" — chaining another condition onto an if statement.
Theory

IF statements — the same logic, different punctuation

  • Pseudocode's THEN and ENDIF don't exist in Python — Python uses a colon : and INDENTATION instead to show what belongs inside the IF.
  • Getting the indentation right in Python isn't just neat formatting — it's how Python knows which lines are actually part of the IF block at all.
IF with ELSE — pseudocode vs. Python// Pseudocode IF Age > 17 THEN OUTPUT "You are an adult" ELSE OUTPUT "You are a child" ENDIF # Python if Age > 17: print("You are an adult") else: print("You are a child")

CASE OF becomes a chain of elif

  • Python has no direct equivalent of pseudocode's CASE OF ... ENDCASE — instead, multiple choices are written as if, then a chain of elif ("else if"), ending in an optional else for anything not matched (the same job as pseudocode's OTHERWISE).
  • Each elif is checked in order, top to bottom, until one matches — exactly like CASE OF checks each option in order.
CASE OF a calculator operator — pseudocode vs. Python// Pseudocode CASE OF OpValue "+" : Answer ← Number1 + Number2 "-" : Answer ← Number1 - Number2 "*" : Answer ← Number1 * Number2 "/" : Answer ← Number1 / Number2 OTHERWISE OUTPUT "Please enter a valid choice" ENDCASE # Python if OpValue == "+": Answer = Number1 + Number2 elif OpValue == "-": Answer = Number1 - Number2 elif OpValue == "*": Answer = Number1 * Number2 elif OpValue == "/": Answer = Number1 / Number2 else: print("Please enter a valid choice")

What stays exactly the same

  • The COMPARISON OpValue == "+" uses two equals signs in Python (one equals sign, =, is only ever assignment, never comparison) — pseudocode uses a single = for comparison, which is a genuine difference to watch for.
  • The order of checks, and the idea of a final "catch-all" branch for anything unmatched, is identical in both.
Practice — Test Yourself

These questions only cover what THIS subsection taught — writing IF and CASE OF as real Python code.

Short answer 1
What replaces pseudocode's THEN and ENDIF in Python?
Reveal answer

A colon : after the condition, and INDENTATION to show which lines belong inside the IF block — there are no THEN or ENDIF keywords at all.

Short answer 2
What Python keyword replaces pseudocode's CASE OF / multiple choices?
Reveal answer

A chain of if / elif / elif ... / else — Python has no direct CASE OF equivalent.

Fill in the blank pseudocode 3
Complete the Python comparison for checking if Score equals 100: if Score ______ 100:
Reveal answer

if Score == 100: — two equals signs, since a single = is only ever assignment in Python.

Spot the error 4
A student writes if Score = 100: in Python, expecting it to check whether Score equals 100. What's actually wrong with this line?
Reveal answer

A single = in Python means ASSIGNMENT, not comparison — this line would actually be trying to assign 100 to Score inside the if condition, which is invalid syntax in Python and would cause an error, not perform a comparison. It must be ==.

Applied / scenario 5
Convert this pseudocode into Python: IF Grade = "A"
THEN
  OUTPUT "Excellent"
ELSE
  OUTPUT "Keep trying"
ENDIF
Reveal answer

if Grade == "A":
    print("Excellent")
else:
    print("Keep trying")

Short answer 6
In the CASE OF / elif chain example, what does pseudocode's OTHERWISE become in Python?
Reveal answer

A final else — the catch-all branch that runs if none of the earlier if/elif conditions matched.
