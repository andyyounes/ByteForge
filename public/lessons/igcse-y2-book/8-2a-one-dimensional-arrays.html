8.2a One-Dimensional Arrays
One name, many values — accessed by index, not by a separate variable for each one.
Key Terms
Array
A data structure holding several elements of the SAME data type, all under one identifier name.
Index
The position number used to access one specific element in an array.
List (Python)
Python's equivalent structure — but unlike an array, a Python list CAN mix different data types.
Theory

Why arrays exist at all

  • An array stores multiple data items UNIFORMLY — all under the same identifier, each accessed separately via its index.
  • This lets a list of items be stored, searched, and ordered — e.g. names sorted alphabetically, or temperatures searched for a particular value — without needing a completely separate variable name for every single item.
  • The first element's index is usually 0 (most languages, including pseudocode and Python, index from 0 by default here).

Declaring a one-dimensional array in pseudocode

  • A declaration needs: the array's NAME, its first index, its last index, and its data TYPE.
Declaring MyList — 10 integers, index 0 to 9DECLARE MyList : ARRAY[0:9] OF INTEGER

Populating one element at a time, by index

  • Setting a single element uses square brackets with its index: MyList[4] ← 27 puts 27 into the 5th position (index 4, since counting starts at 0).
Populating an entire array using a loopOUTPUT "Enter these 10 values in order 27, 19, 36, 42, 16, 89, 21, 16, 55, 72" FOR Counter ← 0 TO 9 OUTPUT "Enter next value " INPUT MyList[Counter] NEXT Counter OUTPUT MyList[1] // this would display 19

Reading the loop — Counter IS the array index

  • The loop variable Counter is used directly as the array index — each pass through the loop reads one value into the NEXT position, without needing 10 separate INPUT statements written by hand.
  • MyList[1] displays 19 — the SECOND item (index 1), not the first, because indexing starts at 0.
Python — populating an array (list) directly, all at oncemyList = [27, 19, 36, 42, 16, 89, 21, 16, 55, 72]

Python's "list" — similar, but not identical to a real array

  • Python doesn't have a strict array type — it uses a LIST instead, which is more flexible.
  • A Python list CAN hold mixed data types (a string, an integer, and a boolean all in the same list) — a true array must hold only ONE data type throughout.
  • For IGCSE purposes, a Python list used to hold a single data type behaves exactly like the arrays this course describes.
Practice — Test Yourself

These questions only cover what THIS subsection taught — one-dimensional arrays.

Short answer 1
What four things does a pseudocode array declaration need to specify?
Reveal answer

The array's name, its first index value, its last index value, and its data type.

Short answer 2
What is the one key difference between a true array and a Python list?
Reveal answer

A Python list can hold MIXED data types in the same list; a true array must hold only ONE data type throughout.

Fill in the blank pseudocode 3
Complete the declaration for an array called Scores holding 5 REAL numbers, indexed 0 to 4: DECLARE Scores : ______[0:4] OF ______
Reveal answer

DECLARE Scores : ARRAY[0:4] OF REAL.

Spot the error 4
A student wants to display the FIRST item in MyList and writes OUTPUT MyList[1]. What's actually wrong with this?
Reveal answer

Index 1 is the SECOND item (19), not the first — since indexing starts at 0, the first item is MyList[0] (27).

Applied / scenario 5
Write pseudocode to populate a 5-element array called Ages (indexed 0 to 4) using a FOR loop and INPUT.
Reveal answer

FOR Counter ← 0 TO 4
  OUTPUT "Enter next age "
  INPUT Ages[Counter]
NEXT Counter

Short answer 6
Why does using an array (with a loop and index) genuinely save code, compared to using 10 separate named variables?
Reveal answer

A loop can populate or process EVERY element using just a few lines, regardless of how many elements there are — 10 separate variables would need 10 separate lines repeated for every operation, and the number of lines would grow every time more data needed storing.
