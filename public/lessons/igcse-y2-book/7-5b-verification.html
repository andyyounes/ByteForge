7.5b Verification
Checking data hasn't changed as it moved — a different job from validation's reasonableness checks.
Key Terms
Verification
Checking that data has been accurately copied from one source to another, e.g. input into a computer or transferred between parts of a system.
Double entry
Entering the same data twice (sometimes by different operators) and comparing the two entries.
Screen / visual check
A manual check where the user confirms entered data is correct before continuing.
Theory

What verification is

  • Verification checks that data has been accurately copied from one source to another — for instance, input into a computer, or transferred from one part of a computer system to another.
  • This is a DIFFERENT job from validation: validation checks data is REASONABLE; verification checks data hasn't CHANGED or been mis-copied during entry or transfer.
  • Two verification methods for input data are covered here: double entry, and screen/visual check.

Double entry

  • The same data is entered TWICE — sometimes by two different operators.
  • The computer system compares both entries; if they DIFFER, an error message is shown asking for the data to be entered again.
  • Common for critical data such as passwords (type it, then "confirm password") or sensitive records entered by data-entry clerks.

Screen / visual check

  • A MANUAL check carried out by the user who is entering the data — not automated by the computer.
  • Once data entry is complete, the data is displayed on the screen and the user is asked to confirm it is correct before continuing.
  • The user either checks the displayed data against a paper document being used as the input source, OR confirms it is correct from their own knowledge.
ValidationAutomated. Checks data is REASONABLE (e.g. in range, right type, not blank). Can be done with a single entry.
VerificationOften manual, or compares two independent entries. Checks data has NOT CHANGED / been mis-copied during entry or transfer.
Practice — Test Yourself

These questions only cover what THIS subsection taught — verification, and how it differs from validation.

Short answer 1
What does verification check, that validation does not?
Reveal answer

Verification checks that data has been accurately COPIED from one source to another (e.g. entered correctly, or transferred correctly between systems) — whereas validation only checks that data is REASONABLE, without knowing whether it matches its original source.

Short answer 2
How does double entry detect an error?
Reveal answer

The same data is entered twice (sometimes by different people), and the computer system compares the two entries — if they don't match, an error message asks for the data to be re-entered.

Fill in the blank pseudocode / concept 3
A screen/visual check is a ______ check completed by the user, while double entry is completed by the ______ system comparing two entries.
Reveal answer

A screen/visual check is a MANUAL check completed by the user; double entry is completed by the COMPUTER system comparing two entries.

Spot the error 4
A student says: "A range check on an age field is a form of verification." Explain why this is incorrect.
Reveal answer

A range check is a VALIDATION technique — it checks the value is reasonable (falls within an expected range), not whether it was copied/entered accurately from its original source. Verification methods are things like double entry or a screen/visual check.

Applied / scenario 5
A website asks a new user to type their password, then type it again into a "Confirm password" box. Which verification method is this, and why is it useful here specifically?
Reveal answer

This is double entry. It's especially useful for passwords because they are usually masked (shown as dots/asterisks) as they're typed, so a visual/screen check wouldn't catch a mis-typed character — comparing two independent entries is the only reliable way to confirm it was typed correctly both times.

Applied / scenario 6
A data-entry clerk types a customer's address from a paper form, then the system displays it back on screen and asks "Is this correct? Y/N" before saving. Name this verification method.
Reveal answer

A screen/visual check — the user manually compares the displayed data against the original paper document before confirming.
