7.2c Flowcharts
Four standard symbols, connected by arrows, are enough to describe any algorithm — from checking an alarm to calculating a ticket discount.
Key Terms
Algorithm
The steps required to complete a task, together with the order they're performed in.
Terminator
The oval symbol marking START and STOP.
Decision symbol
A diamond with exactly two labelled outputs (yes/no), used for selection and repetition.
Theory

What a flowchart is

  • Shows diagrammatically the STEPS required to complete a task, and the ORDER they're performed in.
  • These steps + order together are called an algorithm.
  • Flowcharts effectively communicate how a system/sub-system's algorithm works, and are drawn using standard symbols.
Terminator (START/STOP)
Process (an action)
Input / Output
Decision (two outputs)

The four standard symbols

  • Terminator: an oval, used at the START and STOP of every flowchart.
  • Process: a rectangle, showing an action (e.g. assigning a value to a variable). If a process is defined ELSEWHERE, its name is shown in this box instead of the full detail.
  • Input/output: the SAME symbol is used for both — entering data (e.g. INPUT X) or displaying it (e.g. OUTPUT "Error").
  • Decision: a diamond, used to decide which action happens next — for both SELECTION and REPETITION/ITERATION. A decision box always has exactly TWO outputs, and both flow lines out of it should be clearly labelled (e.g. "yes"/"no").
  • Flow lines: arrows showing the direction of flow — usually (but not always) top-to-bottom and left-to-right.

Worked example — checking the alarm time

  • START → Get Time → decision: "Time = Alarm Time?" → if NO, wait 30 seconds and check again → if YES, Sound Alarm → STOP.
  • This shows a REPEATING check (a loop back to "Get Time" via the "No" path) until the condition becomes true.
The "check alarm time" flowchart — the "no" path loops back to keep checking; the "yes" path sounds the alarm.

Worked example — concert ticket cost calculator

  • Tickets cost $20 each. 10+ tickets → 10% discount. 20+ tickets → 20% discount. Maximum 25 tickets per transaction.
  • Algorithm: START → output prompt → INPUT N (number of tickets) → check N ≥ 1 AND N < 26 (if not, stop/reject) → check N < 10 (discount D=0) → else check N < 20 (D=0.1) → else D=0.2 → calculate Cost ← N * (1 - D) → OUTPUT cost → STOP.
  • Variable names are kept SHORT (N for number of tickets, D for discount) so the text fits neatly inside flowchart boxes.
Practice — Test Yourself

These questions only cover what THIS subsection taught — flowcharts and their standard symbols.

Short answer 1
How many outputs does a decision flowchart symbol always have?
Reveal answer

Always exactly two, and both flow lines out of it should be clearly labelled (e.g. yes/no).

Short answer 2
Which single flowchart symbol is used for BOTH input and output?
Reveal answer

The parallelogram — the same symbol shows both entering data (e.g. INPUT X) and displaying it (e.g. OUTPUT "Error").

Fill in the blank 3
In the concert ticket example, buying 10 tickets gives a ______% discount, and buying 20 tickets gives a ______% discount.
Reveal answer

Blank 1: 10. Blank 2: 20.

Spot the error 4
A student draws a decision box in their flowchart with only ONE flow line leaving it. What's wrong with this?
Reveal answer

A decision symbol must ALWAYS have exactly two outputs (e.g. yes/no) — a decision with only one way out isn't genuinely deciding between two possible paths, and doesn't match the standard symbol's definition.

Applied / scenario 5
A vending machine flowchart needs to: ask for a coin, check if enough money has been inserted, and either dispense the item or ask for more money. Describe which flowchart symbols would be used for each of these three steps.
Reveal answer

"Ask for a coin" and "insert coin" → an input/output symbol (parallelogram). "Check if enough money has been inserted" → a decision symbol (diamond), with two labelled paths (e.g. yes/no). "Dispense the item" or "ask for more money" → each a process symbol (rectangle) or another input/output symbol, depending on whether it's an action or a message shown to the user.

Short answer 6
What is shown inside a process box if that process is defined elsewhere (not fully detailed in this flowchart)?
Reveal answer

Just the NAME of that process (e.g. "Sort list"), rather than the full detail of how it works.
