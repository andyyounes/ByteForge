8.2b Two-Dimensional Arrays
A table with rows and columns — every element needs TWO indices to locate it, not one. Completes Section 8.2.
Key Terms
Two-dimensional array
An array organised as rows and columns — a "table" — where each element needs a row index AND a column index.
Theory

A table, not just a list

  • A two-dimensional array can be thought of as a TABLE — rows and columns. A table with 10 rows and 3 columns holds 30 elements in total.
  • The first element is at position (row 0, column 0).

Declaring a two-dimensional array in pseudocode

  • The declaration needs FIVE things: first/last row index, first/last column index, and the data type.
Declaring MyTable — 10 rows, 3 columnsDECLARE MyTable : ARRAY[0:9, 0:2] OF INTEGER
Populating a 2D array needs NESTED loops — one per dimensionFOR ColumnCounter ← 0 TO 2 FOR RowCounter ← 0 TO 9 OUTPUT "Enter next value " INPUT MyTable[RowCounter, ColumnCounter] NEXT RowCounter NEXT ColumnCounter OUTPUT MyTable[2,1] // this would display 98

Reading the nested loop — why TWO loops are needed

  • A single-dimension array only needs ONE loop (one index to iterate over). A two-dimension array needs TWO nested loops, since there are TWO indices (row and column) to work through.
  • The OUTER loop here runs once per column; the INNER loop runs once per row within that column — so every row is filled in for column 0, THEN every row is filled in for column 1, and so on.
  • MyTable[2,1] means row 2, column 1 — displaying 98 in the example table above.
Python — a 2D array is a "list of lists"MyTable = [[27, 31, 17], [19, 67, 48], [36, 98, 29], [42, 22, 95], [16, 35, 61], [89, 46, 47], [21, 71, 28], [16, 23, 13], [55, 11, 77], [34, 76, 21]]

Python has no true 2D array — it embeds lists inside a list

  • Python achieves the same "rows and columns" structure by putting one list INSIDE another — each inner list is one row.
  • Accessing an element uses two sets of square brackets: MyTable[2][1] in Python means the same position as pseudocode's MyTable[2,1].
Practice — Test Yourself

These questions only cover what THIS subsection taught — two-dimensional arrays.

Short answer 1
How many elements does a 2D array with 10 rows and 3 columns hold in total?
Reveal answer

30 elements (10 × 3).

Short answer 2
Why does populating a 2D array need TWO nested loops instead of one?
Reveal answer

Because a 2D array has TWO indices (row and column) that both need to be worked through — one loop handles the row index, the other (nested inside it) handles the column index, together covering every combination.

Fill in the blank pseudocode 3
Complete the declaration for a 2D array called Grid, 5 rows (0-4) and 4 columns (0-3), of type INTEGER: DECLARE Grid : ARRAY[______] OF ______
Reveal answer

DECLARE Grid : ARRAY[0:4, 0:3] OF INTEGER.

Spot the error 4
A student converts pseudocode's MyTable[2,1] directly into Python as MyTable[2,1]. What's wrong with this in Python specifically?
Reveal answer

Python doesn't use a comma inside one set of brackets for a 2D structure — since Python's 2D array is really a list of lists, it needs TWO separate sets of square brackets: MyTable[2][1].

Applied / scenario 5
Using the example table shown at the top of this lesson, what value is at MyTable[2,0]?
Reveal answer

36 — row 2, column 0.

Short answer 6
What is the key structural difference between how Python represents a 2D array compared to pseudocode's ARRAY[r,c]?
Reveal answer

Python has no true 2D array type at all — it simulates the same rows-and-columns structure by nesting one list inside another (a "list of lists"), rather than using a single structure with two indices built in.
