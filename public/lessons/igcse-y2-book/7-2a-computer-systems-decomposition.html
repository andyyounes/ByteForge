7.2a Computer Systems, Sub-systems & Decomposition
Breaking a whole computer system down to inputs, processes, outputs, and storage — using an alarm app as the running example.
Key Terms
Sub-system
A smaller, self-contained part of a larger computer system, performing one job.
Top-down design
Decomposing a system into sub-systems, then those into smaller sub-systems, until each does just one action.
Stepwise refinement
The process of repeatedly breaking a system down into smaller sub-systems.
Sub-routine
The programmed implementation of one sub-system, expressed via flowchart or pseudocode.
Theory

What a computer system is made of

  • A computer system consists of: software, data, hardware, communications, and people.
  • Every computer system can be divided into SUB-SYSTEMS, and each sub-system can be divided further, until each sub-system performs just ONE action.
  • Systems vary hugely in size — from a small smartphone alarm app to some of the largest systems in the world (e.g. a weather forecast service) — and most people interact with many different systems daily without noticing.

Top-down design and stepwise refinement

  • Top-down design: decompose a system into sub-systems, then break each sub-system into smaller sub-systems, repeating until each does one single action.
  • This repeated breaking-down process is called stepwise refinement.
  • Benefit: each part of a problem becomes smaller and more manageable. For large systems, this ALSO means several programmers can work INDEPENDENTLY on different sub-systems at the same time — reducing overall development and testing time.
  • Each sub-system can be developed as a SUB-ROUTINE, with its own flowchart or pseudocode showing how it works.

Decomposing into inputs, processes, outputs, storage

  • Any problem solved via computer system decomposes into these four component parts:
  • Inputs: the data entered while the system is active.
  • Processes: the tasks performed using the input data (and any previously stored data).
  • Outputs: information displayed or printed for the user.
  • Storage: data saved to files on a suitable medium, for future use.
Worked example — decomposing an alarm app

Inputs: time to set the alarm; remove a previously set alarm time; switch an alarm off; press snooze.

Processes: continuously check if the current time matches a set alarm time; storage/removal of alarm times; managing snooze.

Outputs: continuous sound/tune (at alarm time, or after snooze expires).

Storage: the time(s) for alarms currently set.

Practice — Test Yourself

These questions only cover what THIS subsection taught — computer systems, sub-systems, and decomposition into inputs/processes/outputs/storage.

Short answer 1
What is "stepwise refinement"?
Reveal answer

The process of repeatedly breaking a system down into smaller sub-systems, until each sub-system performs just one action.

Short answer 2
Why does top-down design help when developing a LARGE computer system, beyond just making the problem smaller?
Reveal answer

It allows several programmers to work independently on different sub-systems at the same time, reducing overall development and testing time.

Fill in the blank 3
Any computer-based problem decomposes into four component parts: ______, processes, ______, and storage.
Reveal answer

Blank 1: inputs. Blank 2: outputs.

Spot the error 4
A student claims: "Top-down design means writing the whole program in one go, then splitting it into pieces afterwards to check it works." What's wrong with this?
Reveal answer

This is backwards — top-down design DECOMPOSES the system into sub-systems FIRST (before coding), breaking it down repeatedly until each piece is small and manageable. It's not about writing the whole thing first and splitting it up afterwards.

Applied / scenario 5
A vending machine accepts coins, lets the user select an item, dispenses the item and any change, and keeps a running total of sales. Decompose this system into its inputs, processes, outputs, and storage.
Reveal answer

Inputs: coins inserted, item selection. Processes: checking enough money inserted, calculating change owed, updating the running sales total. Outputs: dispensed item, dispensed change, display messages (e.g. amount owed). Storage: the running total of sales, and current stock levels of each item.

Short answer 6
What are the five things a computer system is made up of, according to this lesson?
Reveal answer

Software, data, hardware, communications, and people.
