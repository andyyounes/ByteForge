8.1i Procedures and Functions
Naming a group of statements once, so it can be called from anywhere — with or without a returned value.
Key Terms
Procedure
A named group of statements that performs a task — does NOT return a value.
Function
A named group of statements that performs a task AND returns a value to the main program.
Parameter
A variable that stores the value of an argument passed INTO a procedure or function.
Header
The first line of a procedure/function definition — its name, parameters (with types), and (for a function) its return type.
Theory

Why define something once, instead of repeating code

  • Programs often need to perform the SAME task in several places — subroutines (procedures/functions) are defined ONCE and can be CALLED many times, instead of retyping the same statements repeatedly.
  • A procedure performs a task — it does not return a value. A function performs a task AND returns a value back to whatever called it.
  • Different languages use different terminology: procedures are called "void functions" in Python; functions are called "fruitful functions" in Python.
A procedure without parameters — pseudocode vs. Python// Pseudocode PROCEDURE Stars OUTPUT "************" ENDPROCEDURE CALL Stars # Python def Stars(): print("************") Stars()
A procedure WITH a parameter — pseudocode vs. Python// Pseudocode — prints Number stars PROCEDURE Stars (Number : INTEGER) DECLARE Counter : INTEGER FOR Counter ← 1 TO Number OUTPUT "*" NEXT Counter ENDPROCEDURE CALL Stars(7) # Python def Stars(Number): for Counter in range(Number): print("*", end="") Stars(7)

A procedure call must match its definition

  • When a procedure is defined WITH parameters, the arguments in the CALL must match the parameters in the DEFINITION — same number, in the same order.
  • For IGCSE Computer Science, the number of parameters used is limited to two.
  • A procedure call is a standalone statement on its own line — CALL Stars(7).
A function — Fahrenheit to Celsius, pseudocode vs. Python// Pseudocode FUNCTION Celsius (Temperature : REAL) RETURNS REAL RETURN (Temperature - 32) / 1.8 ENDFUNCTION MyTemp ← Celsius(MyTemp) # Python — no need to declare the data type at all def Celsius(Temperature): return (Temperature - 32) / 1.8 MyTemp = Celsius(MyTemp)
Procedure callsStandalone statements on their own line — CALL Stars(7) — nothing is returned to be used elsewhere.
Function callsMade as PART of an expression, usually on the right-hand side of an assignment — MyTemp ← Celsius(MyTemp) — because a value comes back that needs somewhere to go.

What a header always contains

  • The NAME of the procedure or function.
  • Any PARAMETERS passed in, and their data type.
  • For a function specifically: the data type of the value it RETURNS.
Practice — Test Yourself

These questions only cover what THIS subsection taught — procedures, functions, and parameters.

Short answer 1
What is the key difference between a procedure and a function?
Reveal answer

A function returns a value back to the main program; a procedure does not return anything.

Short answer 2
Why must a procedure/function call match its definition exactly in terms of arguments?
Reveal answer

Because the arguments passed in the call are assigned to the parameters in the definition, in order — a mismatched number or order of arguments would mean the wrong values end up in the wrong parameters, or the call would be invalid entirely.

Fill in the blank pseudocode 3
Complete the function header for one that takes a REAL parameter Value and returns a REAL: FUNCTION Square (Value : REAL) ______ REAL
Reveal answer

FUNCTION Square (Value : REAL) RETURNS REAL.

Spot the error 4
A student writes CALL Celsius(MyTemp) as a standalone line, expecting the converted temperature to be used afterwards. What's wrong with this?
Reveal answer

Celsius is a FUNCTION, not a procedure — its return value needs somewhere to go. Calling it as a standalone statement (like a procedure) throws the returned value away; it should be assigned instead: MyTemp ← Celsius(MyTemp).

Applied / scenario 5
Write a pseudocode FUNCTION called Double that takes a parameter Value (INTEGER) and returns Value multiplied by 2.
Reveal answer

FUNCTION Double (Value : INTEGER) RETURNS INTEGER
  RETURN Value * 2
ENDFUNCTION

Short answer 6
Why doesn't Python's function definition need to state a data type for its parameter or return value, unlike pseudocode?
Reveal answer

Because Python uses implicit typing throughout — the type of any value is decided automatically by what's actually assigned or passed in, so there's no separate step where a type must be explicitly declared.
