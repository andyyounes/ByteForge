7.2f Pseudocode: Iteration (Loops)
Three loop structures, one job each — knowing exactly which one to reach for.
Key Terms
Iteration
Repeating actions as part of an algorithm — implemented with loop structures.
Post-condition loop
A loop that tests its exit condition at the END — REPEAT…UNTIL always runs at least once.
Pre-condition loop
A loop that tests its condition at the START — WHILE…DO may never run at all.
Theory

Three loop structures

  • FOR … TO … NEXT: a SET number of repetitions, known in advance.
  • REPEAT … UNTIL: an UNKNOWN number of repeats, but always completed AT LEAST ONCE.
  • WHILE … DO … ENDWHILE: an UNKNOWN number of repeats, that may NEVER run at all.
All three loops doing the exact same job — printing ten stars

FOR Counter ← 1 TO 10
  OUTPUT "*"
NEXT Counter

Counter ← 0
REPEAT
  OUTPUT "*"
  Counter ← Counter + 1
UNTIL Counter > 9

Counter ← 0
WHILE Counter < 10 DO
  OUTPUT "*"
  Counter ← Counter + 1
ENDWHILE

FOR … TO … NEXT is the most efficient way to write this, since the loop counter is managed automatically — no manual increment line needed.

FOR … TO … NEXT

  • A variable is given a start value and an end value; it's incremented by ONE each time until the end value is reached.
  • The loop variable CAN be used inside the loop, as long as its value isn't changed there.
  • Very useful for reading values into a LIST (array) of known length.
FOR loop — reading 10 student names into an arrayFOR Counter ← 1 TO 10 OUTPUT "Enter Name of Student " INPUT StudentName[Counter] NEXT

REPEAT … UNTIL

  • Used when the number of repeats is unknown; repeats UNTIL a condition becomes TRUE.
  • Always runs AT LEAST ONCE — a post-condition loop, since the exit test is at the END.
REPEAT loop — totalling marks until -1 is enteredTotal ← 0 Mark ← 0 REPEAT Total ← Total + Mark OUTPUT "Enter value for mark, -1 to finish " INPUT Mark UNTIL Mark = -1

WHILE … DO … ENDWHILE

  • Used when the number of repeats is unknown; repeats WHILE a condition stays TRUE.
  • If the condition is FALSE the very first time, the loop body NEVER runs — a pre-condition loop, since the exit test is at the START.
WHILE loop — the same totalling taskTotal ← 0 OUTPUT "Enter value for mark, -1 to finish " INPUT Mark WHILE Mark <> -1 DO Total ← Total + Mark OUTPUT "Enter value for mark, -1 to finish" INPUT Mark ENDWHILE
FOR…TO…NEXT
Known number of repeats. Counter managed automatically.
REPEAT…UNTIL
Unknown repeats. Runs at least once. Tests at the END (post-condition).
WHILE…DO…ENDWHILE
Unknown repeats. May run zero times. Tests at the START (pre-condition).
Practice — Test Yourself

These questions only cover what THIS subsection taught — the three iteration/loop structures.

Short answer 1
Which loop type is the best choice when you know exactly how many times you need to repeat something?
Reveal answer

FOR … TO … NEXT — it's the most efficient choice since the loop counter is managed automatically.

Short answer 2
What is the key difference between REPEAT…UNTIL and WHILE…DO…ENDWHILE, in terms of how many times the loop body can run?
Reveal answer

REPEAT…UNTIL ALWAYS runs at least once (its test is at the end — post-condition). WHILE…DO…ENDWHILE might run ZERO times if the condition is already false the first time it's checked (its test is at the start — pre-condition).

Fill in the blank pseudocode 3
Complete this FOR loop to output 5 stars: FOR Counter ← 1 TO ______
  OUTPUT "*"
______ Counter
Reveal answer

Blank 1: 5. Blank 2: NEXT.

Spot the error 4
A student needs a loop that must NEVER run if the starting condition is already false (e.g. don't process an empty list at all), and chooses REPEAT…UNTIL. What's wrong with this choice?
Reveal answer

REPEAT…UNTIL always runs the loop body AT LEAST ONCE, regardless of the condition — it can never skip execution entirely. WHILE…DO…ENDWHILE is the correct choice here, since it tests the condition BEFORE running the body, and can skip it entirely if the condition is already false.

Applied / scenario 5
A program must keep asking the user to enter a password until they type it correctly — the very first attempt could be right or wrong, but the prompt must show at least once. Which loop type fits best, and write the pseudocode for it.
Reveal answer

REPEAT … UNTIL — the prompt must show at least once, matching REPEAT's guaranteed-first-run behaviour.

REPEAT
  OUTPUT "Enter password: "
  INPUT Password
UNTIL Password = "correctpassword"

Short answer 6
In a FOR loop, by how much is the loop variable incremented each time, according to this lesson?
Reveal answer

By steps of one, until the end value is reached.
