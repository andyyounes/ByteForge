\begin{frame}{A rule that only fires past a threshold}
    \Large
    There's no special "edge" concept in code — \texttt{x > 400} IS the edge. Any boundary in a real game is built from exactly this.
\end{frame}


\begin{frame}{IF can replace what's shown, not just add to it}
    \Large
    "You Win!" and the running score are in different branches of the same if/else — only one is ever drawn on a given frame.

    \begin{center}
    \begin{tikzpicture}[scale=0.9]

        \draw[thick] (1,1) -- (2,0) -- (1,-1) -- (0,0) -- cycle;
        \node at (1,0) {\small won?};
        \draw[->, thick] (2,0) -- (3.5,0.7) node[midway, above] {\small yes};
        \node[right] at (3.5,0.7) {\small "You Win!"};
        \draw[->, thick] (2,0) -- (3.5,-0.7) node[midway, below] {\small no};
        \node[right] at (3.5,-0.7) {\small show score};
    \end{tikzpicture}
    \end{center}
\end{frame}

\begin{frame}{Real-World Example}
    \Large
    A car's parking sensor beeping only once you're within a set distance of a wall — the "beep" only fires past a threshold, exactly like this chapter's edge check. In Minecraft, fall damage only triggers past a height threshold — no damage for a 1-block drop, real damage past \textasciitilde{}3 blocks — the exact same "past a threshold" rule.
\end{frame}
