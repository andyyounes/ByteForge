\begin{frame}{Real-World Example}
    \Large
    Toggle a phone's font size / "reader mode" setting live, or compare a site with tiny 10px body text against one with proper 16px+ text — ask which one people would actually keep reading. Minecraft's own "resource packs" are exactly this idea at game-scale: the SAME blocks and items (the content), completely re-skinned to look different (the style).
\end{frame}
